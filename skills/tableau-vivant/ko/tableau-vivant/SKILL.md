# tableau-vivant

코드로 그림을 그리는 엔진과 작업 절차

## 원리

- 그림을 형태 층과 매체 층으로 분리
    + (형태 층) 인체, 머리카락, 의상, 사물, 지형을 3D 기하로 구성. 손가락 5개는 메시 위상이 보장
    + (매체 층) 같은 기하 버퍼를 붓질, 번짐, 선, 종이 결로 다시 그림. 화풍 변경은 매체 교체 1줄
- 모델의 역할은 화가의 판단
    + 무엇을 어떤 구도와 빛과 화풍으로 그릴지 결정하여 사양(JSON)으로 기록
    + 렌더 결과를 직접 보고 고침. 한 번에 완성되는 그림은 드묾

## 작업 절차

각 단계의 산출물이 다음 단계의 입력. 순서를 건너뛰면 재작업 비용이 커짐

### 0. 설치 (최우선)

```bash
bash scripts/install.sh        # 최초 1회. PyTorch CPU, 인체 모델 등 설치. 첫 실행 시 모델 캐시 생성에 약 1분
```

- 다른 작업보다 먼저 실행. 설치 실패 시 오류를 사용자에게 보고 후 중단
- 로컬 환경에서는 사용자 지침의 가상환경 규칙을 따른 뒤 실행

### 1. 기획

- 사용자 요청에서 확정된 항목과 미정 항목을 구분
- 미정 항목은 `references/planning.md`의 선택지 표를 근거로 한 번에 묶어 질의
    + 축: 목적, 주제와 장르, 화풍, 인물, 구도, 조명, 색감, 디테일, 배경
    + 각 축에 추천 기본값을 표시. 사용자가 "알아서"라고 하면 기본값으로 진행하고 적용값을 명시
- 사용자가 이미 충분히 지정했다면 질의를 생략하고 진행

### 2. 디자인

- 디자인 방향 문서(`brief.md`)를 먼저 작성. 양식은 `references/planning.md` 말미
    + 핵심 인상 1개, 구도, 색과 톤, 빛, 화풍 선택 근거를 기록
- 방향 문서를 사양 파일(`spec.json`)로 옮김. 필드는 `references/spec.md`
    + 가까운 예제를 `examples/`에서 골라 수정하면 빠름

### 3. 밑그림 확인

```bash
python scripts/render.py spec.json -o check.png --preview     # 수 초. 자세, 구도, 빛만 확인
python scripts/pose_sheet.py -o pose.png --spec spec.json     # 자세를 정면과 측면에서 확인
```

- 결과 이미지를 직접 열어 확인. 채색 전에 자세와 구도를 확정해야 재작업이 없음
- 손이 몸에 묻히거나 허공에 뜨면 `reach`(손 목표 지점)로 수정. 몸에 얹은 손은 `"lay": true`로 손바닥을 펴서 붙임. `references/figures.md`
- 책, 컵, 휴대폰을 든 인물은 사물의 `held_by`로 손에 쥐게 함. 좌표를 추측하지 않음
- 마주 보는 배치는 `facing`에 상대 인물이나 탁자 이름을 지정
- 몸이 닿는 두 사람은 `pairs`, 3명 이상이 옆 사람과 닿는 줄은 `groups`. 풍경 속 인물 구도는 카메라 `fit: "people"`

### 4. 채색

```bash
python scripts/render.py spec.json -o picture.png
python scripts/render.py spec.json -o sheet.png --styles anime,watercolor,oil   # 화풍 비교가 필요할 때
```

### 5. 검수와 수정

완성 이미지를 직접 열어 아래 항목을 확인. 결함이 있으면 사양을 고쳐 다시 렌더

- 얼굴이 머리카락, 손, 그림자에 가려지지 않았는가
- 손과 발이 의도한 위치에 있고 몸을 뚫지 않는가
- 의상 재단선과 머리카락 끝이 깨끗한가
- 주제가 화면에서 충분한 크기이고 잘리지 않았는가
- 명암 대비가 주제를 향해 모이는가
- 화풍 고유의 특징(선, 붓질, 번짐)이 읽히는가
- 사용자가 지정한 조건(인물 특징, 색, 소품)이 모두 반영되었는가

수정 방향은 `references/styles.md`의 "문제와 처방" 표 참조

### 6. 전달

- 완성 이미지, 사양 파일, 디자인 방향 문서를 함께 전달
    + 사양 파일이 있으면 사용자가 시드, 화풍, 구도만 바꿔 다시 뽑을 수 있음
- 달성하지 못한 부분은 숨기지 않고 명시

## 참조 문서

| 문서 | 읽을 시점 |
| --- | --- |
| `references/planning.md` | 기획 질의를 만들 때, 디자인 방향 문서를 쓸 때 |
| `references/spec.md` | 사양 파일을 작성할 때 (전체 필드) |
| `references/figures.md` | 인물이 등장할 때 (여성과 남성 체형, 얼굴 양식화, 표정, 자세, 손, 손에 든 사물, 투샷과 군상, 머리, 수염, 의상) |
| `references/scenes.md` | 배경, 사물(고전 정물부터 컴퓨터와 현대 가구까지), 카메라(로우 앵글, 더치 틸트, 어깨 너머 포함), 조명을 정할 때 |
| `references/styles.md` | 화풍을 고르거나 조정할 때, 미술사조 재현, 두머 계열, 문제 처방 |
| `references/extending.md` | 카탈로그에 없는 형태나 화풍이 필요할 때, 한계 확인 |

전체 선택지는 `python scripts/catalog.py [figures|poses|hair|outfits|props|environments|light|styles|post|shapes]`로 출력

## 의존성과 라이선스

- 실행 환경: Python 3.10 이상, CPU만으로 동작. GPU와 외부 API 호출 없음
- 패키지: numpy, scipy, opencv-python-headless, pillow, numba, torch(CPU), anny 0.6.1, roma, safetensors, trimesh, pyyaml
- 인체 모델 Anny는 Apache-2.0, 그 기반 자산인 MakeHuman 메시는 CC0
    + 생성한 그림의 이용에 추가 제약 없음

## 기본 원칙

- 인물의 나이는 제한하지 않음. 아이와 청소년도 옷을 입은 모습으로 그릴 수 있음
- 18세 미만 인물은 노출, 속옷 차림, 성적 연출로 그리지 않음
    + 엔진이 18세 미만 몸에 가슴이나 골반이 드러나는 의상(노출, 속옷, 비키니, `perizoma`)을 거부. 남자아이의 수영복 바지와 반바지는 허용
    + 나이 기준은 인체 모델의 자체 나이 보정표(`age` 0.77이 18세). 요청에서 미성년자로 설정하거나 소개한 인물도 18세 미만으로 취급
    + 18세 미만 몸에는 성인 프리셋의 가슴 형태 보정을 적용하지 않음
- 18세 이상 인체 습작 지원. 인체 모델에 골반 세부가 없어 해당 부위는 매끈하게 표현됨
    + 애니메풍이나 동안 얼굴, 작은 체구와 키는 제한하지 않음
    + 남성 인체 습작은 고전풍 `perizoma`나 `briefs`와 함께 구성하면 자연스러움
- 같은 사양과 시드는 같은 그림을 재현. 변주는 `canvas.seed` 변경
- 한계를 정직하게 다룸. 복잡한 주름, 사실적 머리카락 가닥, 사진 수준 질감은 현재 범위 밖. 상세는 `references/extending.md`
