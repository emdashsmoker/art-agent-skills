# 단계별 작업 기법

그림 1장을 기획, 형태, 선, 채색, 후보정, 검증 6단계로 제작하는 방법. 각 단계는 산출물 1개와 통과 기준 1개를 가진다.

## 기획

- 디자인 방향 문서를 아래 5개 항목으로 작성
    + (핵심 인상) 그림이 전달할 인상 1문장
    + (구도) 화면비, 주제 위치, 주제 크기, 시선 방향
    + (색) 주조색 1개, 보조색 1-2개, 강조색 1개
    + (빛) 주광 방향 1개, 보조광 유무
    + (화풍) `anime`, `illust`, `painterly` 중 1개
- 명도는 어두움, 중간, 밝음 3단으로 설계
    + 주제와 배경이 서로 다른 단에 놓이게 배분
    + 가장 밝은 값과 가장 강한 대비는 시선이 가야 할 곳에 1곳만 배치
- 색은 3-5개로 제한
    + 청록 배경에 주황 계열 의상처럼 보색 1쌍을 큰 면적과 작은 면적으로 나누면 안정적
    + 그림자색을 `shadow_of`로 통일하면 조명이 일관됨
- 주광은 1개만 설정
    + 기본값은 좌상단, 인물의 얼굴이 향한 쪽에서 오는 빛이 얼굴을 밝게 유지
- 권장 캔버스는 세로 인물 1024x1280, 가로 풍경 1280x896
    + 긴 변 1600 초과 시 렌더링 시간이 크게 증가

## 형태

- 주제를 조각 목록으로 분해한 뒤 뒤에서 앞 순서로 나열
    + 예시 : 배경, 뒷머리, 목, 옷, 얼굴, 이목구비, 앞머리
    + 예시 : 하늘, 구름, 먼 산, 가까운 산, 호수, 앞쪽 나무
- 조각 1개는 제어점 6-12개의 닫힌 곡선으로 작성
    + `geo.smooth(points, closed=True)`가 점 사이를 매끄럽게 연결
    + 턱끝, 옷깃, 머리카락 끝처럼 각진 곳은 `corners`에 제어점 번호 지정
- 큰 조각부터 배치하고 작은 조각은 큰 조각 기준 상대 좌표로 배치
    + 기준점과 단위 길이를 변수로 두면 전체 크기 조정이 쉬움
    + 예시 : `cx, cy, u = 512, 600, 300` 설정 후 `(cx - 0.4 * u, cy + 0.2 * u)`
- 형태의 개성은 실루엣에서 결정
    + 직선, 완만한 곡선, 급한 곡선을 섞어 단조로운 타원 나열 방지
    + 좌우 대칭은 살짝 깨뜨려야 자연스러움 (고개 기울임, 한쪽으로 쏠린 머리카락)
- 통과 기준은 단색 실루엣만으로 주제가 읽히는 상태
    + `flat_version(style)`로 렌더링하면 빛 없이 밑색만 확인 가능

### 겹침

- `painting.part(mask, color)`는 새 조각 아래의 선을 지움
    + 따라서 그리는 순서가 곧 앞뒤 관계
- 조각 안쪽에만 칠하려면 마스크를 곱함
    + 예시 : `painting.fill(pattern * shirt_mask, color)`
- 조각 위의 가는 표시는 `stroke(..., layer="color", clip=mask)` 사용

## 선

- 선 굵기 기준은 캔버스 높이의 0.2-0.35%
    + 1280 높이에서 외곽선 2.5-4.5px, 내부선 1.5-2.5px
- `outline`은 빛 반대쪽 선을 자동으로 굵게 처리
    + `shade_side`는 굵어질 쪽의 화면 방향, 기본값은 오른쪽 아래
- 열린 선은 `stroke`의 `taper`로 시작과 끝을 가늘게 처리
    + `taper=(0.1, 0.7)`은 빠르게 굵어지고 길게 빠지는 선
- 선 색은 `line_color(style, fill_color)`로 지정
    + 조각 색을 어둡게 한 색이 섞여 선이 그림에 녹아듦
- 선을 생략할 곳을 정함
    + 같은 색 조각끼리의 경계, 빛을 강하게 받는 가장자리, 먼 배경
- 눈, 입, 속눈썹처럼 그림의 내용인 표시는 `layer="color"`로 작성
    + 회화풍은 선 레이어를 버리므로 선 레이어에만 있는 정보는 사라짐

## 채색

### 밑색과 형태 음영

- `paint_part`가 밑색, 형태 음영, 외곽선을 1회에 처리
    + 세부 제어가 필요하면 `part`, `shade_form`, `outline`을 따로 호출
- 형태 음영은 마스크를 부풀려 계산
    + 둥근 덩어리는 `bevel` 생략, 납작한 덩어리는 `bevel`을 폭의 20-30%로 지정
- 그림자 면적은 `threshold`로 조절
    + 얼굴처럼 밝게 유지할 조각은 화풍 기본값보다 0.2-0.3 낮게 지정
- 여러 조각이 한 덩어리로 보여야 하면 합친 마스크로 1회 더 음영
    + 예시 : 머리카락 뭉치별 음영 후 전체 머리 덩어리 음영

### 드리운 그림자

- 가리는 조각의 마스크를 빛 반대 방향으로 밀어 받는 조각에 곱함
    + `sh.cast_shadow(hair_mask, face_mask, offset=(dx, dy))`
    + 좌상단 광원이면 offset은 오른쪽 아래 방향
- 이동 거리는 두 조각 사이의 높이 차이를 표현
    + 앞머리가 이마에 드리우는 그림자는 머리 높이의 5-8%
- 맞닿는 부위는 `sh.occlusion`으로 부드러운 어둠 추가

### 하이라이트

- 가장자리 빛은 `sh.rim(mask, direction, width)` 사용
    + 주광 쪽 가장자리는 따뜻한 밝은색, 반대쪽 림라이트는 차가운 밝은색
- 점 하이라이트는 작은 타원을 `fill`
    + 눈, 입술, 코끝, 금속, 유리
- 띠 하이라이트는 `geo.needle` 여러 개를 흐름 방향으로 배열
    + 머리카락 윤기, 수면 반짝임

### 재질별 요령

| 재질 | 요령 |
|---|---|
| 피부 | 그림자색을 붉게, 볼과 코끝에 옅은 홍조, 그림자 경계에 주황빛 띠 |
| 머리카락 | 뭉치 단위 형태, 뭉치별 음영, 흐름 방향 가닥선, 띠 하이라이트 |
| 천 | 큰 면은 평평하게, 접히는 곳에만 그림자, 옷깃과 소매는 두께 표현 |
| 금속 | 밝음과 어두움의 경계를 선명하게, 주변색 반사 띠 추가 |
| 유리와 물 | 뒤의 색을 비치게, 가장자리와 반사만 밝게 |
| 나뭇잎 | 덩어리 실루엣 우선, 가장자리에만 낱잎 표현 |
| 하늘 | 위는 짙게 지평선은 밝게, 구름은 빛 받는 쪽 가장자리 강조 |

## 후보정

- `finish(painting, style)`이 화풍별 기본 후보정 수행
    + 추가 조정은 반환 이미지에 `fx` 함수를 이어서 적용
- 후보정은 그림의 결함을 고치지 못함
    + 형태와 명도 구조가 통과된 뒤에만 적용
- 회화풍은 `importance`에 정밀하게 그릴 영역 마스크 전달
    + 인물은 얼굴 마스크, 풍경은 생략 가능

## 검증

- 렌더링한 이미지를 직접 열어 아래 표로 점검
    + 전체 1회, 핵심부 확대 크롭 1회

```python
from PIL import Image
Image.open("out.png").crop((300, 340, 740, 780)).resize((880, 880)).save("crop.png")
```

| 결함 | 원인 | 수정 |
|---|---|---|
| 주제가 배경에 묻힘 | 명도 단이 겹침 | 배경 또는 주제 명도를 1단 이동 |
| 형태가 덩어리져 어색함 | 제어점 좌표 오류, 비례 오류 | 실루엣만 렌더링 후 제어점 수정 |
| 조각이 몸 밖으로 튀어나옴 | `lock`의 bend 또는 belly 과다 | 절반으로 줄이고 뿌리 폭 축소 |
| 그림자가 조각의 절반 이상 | threshold 과다 | 0.1-0.2 하향 |
| 뾰족한 조각에 능선 자국 | 부풀림 능선 | `inflate(mask, smoothing=0.45)`를 `height`로 전달 |
| 캔버스 가장자리에 어색한 그림자 | 조각이 화면 끝에서 끝남 | 조각을 화면 밖까지 연장 |
| 선이 기계적으로 균일 | 굵기 변화 없음 | `outline` 사용, `taper` 지정, `geo.wobble` 적용 |
| 이어진 조각 사이에 관절선이 보임 | 조각마다 외곽선 처리 | 마스크를 합쳐 `outline_mask` 1회 적용 |
| 합친 형태의 이음매에 홈이 보임 | 조각 윤곽이 어긋남 | `sh.melt(mask, radius)`로 녹인 뒤 채움 |
| 그림자 색이 옷 위에서 뜸 | 피부 그림자색을 다른 재질에 칠함 | 곱하기 모드로 `style.shadow_tint` 적용 |
| 전체가 뿌옇게 뜸 | 블룸 또는 확산광 과다 | `finish` 대신 `fx` 개별 호출로 강도 하향 |
| 회화풍에서 얼굴이 뭉개짐 | 정밀 영역 미지정 | `importance`에 얼굴 마스크 전달, `detail=1.3` |
| 회화풍이 자잘한 점으로 덮임 | 원본 그림에 잔무늬 과다 | 원본을 단순화, `detail=0.8` |
| 몸 옆선에 혹과 패임 | 기울기가 다른 좌표계의 점을 한 곡선으로 이음 | 높이별 폭 함수 하나로 옆선 생성 |
| 돌린 몸의 가슴이 풍선처럼 붙어 보임 | 공 모양 볼륨만 사용 | 위쪽 비탈을 가슴판까지 곧게 잇는 물방울형으로 변경 |
| 돌린 몸의 먼 쪽 어깨가 뭉툭하게 튀어나옴 | 숨은 팔 대신 몸통 어깨 둥근 부분이 남음 | 먼 쪽 팔이 숨으면 몸통 어깨 둥근 부분 제거 |
| 옆얼굴 위로 머리 가닥이 가로지름 | 정면 기준 옆머리가 얼굴을 지나 이동 | 먼 쪽 옆머리를 뒷머리와 함께 얼굴 뒤에 그림 |
| 옆얼굴이 상자형으로 보임 | 턱 아랫선이 수평이고 턱각이 없음 | 턱 아랫선을 턱각까지 비스듬히 올리고 턱각 뒤는 목으로 이음 |
| 옆얼굴 뒤통수가 맨살로 보임 | 머리카락 경계가 귀에서 멀고 목덜미 앞에 머리가 없음 | 경계를 귀 바로 뒤에 붙이고 가까운 옆머리를 목덜미 앞에 늘어뜨림 |
| 옆얼굴 눈이 정면 눈처럼 보임 | 정면 눈 형태를 그대로 돌림 | 쐐기 형태로 바꾸고 홍채를 세로로 좁혀 앞쪽으로 이동 |
| 볼 가운데 경계가 딱딱한 분홍 얼룩 | 얼굴 전체를 공처럼 부풀려 명암 계산 | 부풀림 깊이(`bevel`)를 얼굴 가장자리 폭으로 제한 |
| 이마와 귀 주변에 연어색 띠 | 두피 덮개 전체가 긴 그림자를 드리움 | 앞머리 다발만 길게, 덮개는 짧게 그림자 |
| 머리와 목 사이에 줄이 생김 | 머리 마스크 아래 경계에서 명암이 끊김 | 턱각 뒤 목 이음 영역까지 넓힌 높이로 명암 계산, 그림자는 턱에서만 드리움 |
| 소매가 퍼프 소매처럼 부풂 | 어깨부터 여유를 줌 | 어깨에서 여유 0, 위팔 절반까지 서서히 증가 |
| 남성 소매가 풍선처럼 부풂 | 굵은 팔 배율 위에 여유를 더함 | 옷 입은 인물은 팔 배율 1.2 안팎, 소매 여유 0.03 안팎 |
| 측면 어깨 위에 검은 사각 조각 | 팔에 가려진 어깨끈의 끝만 남음 | 끈을 팔에 처음 가려지는 지점에서 끝냄 |
| 발이 오리발처럼 길고 납작함 | 발이 길고 발끝까지 얇아짐 | 발 길이를 줄이고 발등과 발끝 두께를 키움 |
| 헐렁한 상의가 임신한 배처럼 튀어나옴 | 가슴에서 천을 수직으로 끝까지 떨어뜨림 | 떨어지는 동안 몸 쪽으로 당겨 비탈지게 처리 |
| 돌린 몸에서 가까운 쪽 라펠이 납작해짐 | 다각형 꼭짓점만 몸에 감음 | 변마다 점을 채운 뒤 몸에 감음 |
| 45도 반바지가 치마처럼 보임 | 천이 두 다리를 한 덩어리로 덮음 | 가까운 다리 윤곽을 천 안에 그림 |
| 앉은 자세에서 반바지가 무릎까지 덮음 | 다리 트임을 골반 높이로 지정 | 허벅지를 따라 일정 길이에서 자름 |
| 앉은 자세에서 치마가 의자 뒤로 늘어짐 | 선 자세용 치마 모양 사용 | 엉덩이와 허벅지를 덮고 무릎 앞에서 늘어뜨림 |
| 앉은 엉덩이가 의자 아래로 처짐 | 몸통 바닥이 다리 사이까지 내려옴 | 의자면에서 몸통과 둔부를 평평하게 자름 |
| 누운 몸의 속옷 레이스가 엉뚱한 방향 | 레이스 방향을 화면 기준으로 지정 | 몸 기울기만큼 방향 회전 |
| 투샷에서 뒷사람 손이 앞사람에 가려짐 | 먼 인물부터 그려 손도 함께 덮임 | `Actor.over`로 손만 다시 덮어 그림 |
| 뻗은 손이 아기 손처럼 작음 | 관람자 쪽으로 향한 손을 길이와 폭 모두 줄임 | 손 축 방향 길이만 줄이고 폭은 유지 |
| 머리 뒤로 올린 손가락이 목이나 턱 옆에 비침 | 몸 뒤 팔을 머리와 목보다 앞에 그림 | 머리, 목, 뒷머리와 그 사이 틈으로 손을 가림 |
| 뒷모습에 주머니, 넥타이, 라펠이 보임 | 앞면 요소의 보임 판정이 뒷모습을 모름 | 뒷모습에서 몸 앞면 보임 값을 0으로 처리 |
| 앉은 후드티와 재킷이 무릎까지 덮어 원피스처럼 보임 | 밑단 높이를 선 자세 기준으로 자름 | 허벅지를 따라 일정 길이만 덮음 |
| 투샷에서 팔 없이 손만 떠 있음 | 팔이 앞사람 뒤로 숨은 손을 `over`로 덮어 그림 | 팔이 보이는 쪽 손으로 잡고 `reach`의 `pole`로 팔꿈치를 앞으로 |
| 측면 끈 옷의 어깨 위에 깃발 모양 조각 | 목선이 앞쪽 끈만 자르고 등 쪽 끈이 없음 | 돌린 몸에서 끈을 어깨 너머 등으로 이어 그림 (`wardrobe._back_straps`) |
| 정면 착석이 선 자세처럼 보임 | 허벅지가 관람자 쪽으로 짧아지고 손이 무릎을 덮음 | 손을 무릎 바깥에 얹고 무릎 아래 정강이에 그림자, 15-20도 돌림 권장 |
| 무릎 꿇은 3/4 자세에서 손이 사타구니 위에 놓임 | 앞으로 뻗은 아래팔이 가까운 손을 몸 가운데로 보냄 | 손을 허벅지 바깥 옆으로 내림 |
| 내려다본 구도에서 발이 그림자 위에 떠 보임 | 바닥 그림자를 발끝 아래에 둠 | 발뒤꿈치와 발끝 가운데에 두고 내려다본 각도만큼 그림자를 넓힘 |
| 잔디에 누운 인물이 지평선 위에 떠 보임 | 누운 몸을 캔버스 세로 가운데에 배치 | `frame(..., floor=행)`으로 바닥 앞쪽에 눕힘 |

| 비니가 바가지 머리처럼 보임 | 검은 머리 위에 검은 모자 | `hat_color`를 머리색보다 1단 밝게 |
| 비니 위로 머리 가닥이 삐져나옴 | 모자 아래 머리 부피가 그대로 | 모자를 쓰면 머리 부피를 눌러 계획, 단 위 머리카락 전체를 모자 볼록 껍질로 덮음 |
| 두머 보정 뒤 가로등 빛이 흰색으로 죽음 | 밝은 눈 위에 `screen`으로 주황을 칠해 채도가 빠짐 | 따뜻한 빛은 `mode="normal"`로 칠함 |
| 두머 보정 뒤 피부 그늘만 분홍으로 튐 | 따뜻한 빛 판정이 피부 그늘까지 포함 | 판정 기준을 빨강-파랑 0.30 이상, 밝기 0.55 이상으로 좁힘 |
| 얼굴 위 눈송이가 잡티처럼 보임 | 눈을 화면 전체에 고르게 뿌림 | `snowfall(..., keep_clear=얼굴 마스크)` |
