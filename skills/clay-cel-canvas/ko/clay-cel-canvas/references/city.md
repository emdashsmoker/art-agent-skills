# 도시 풍경

수치와 함수는 `examples/city.py`에서 검증한 값이다.

## 원리

- 거리를 미터 단위의 3차원 좌표로 정하고 투영 함수 하나로 화면 좌표를 구한다
    + 건물, 창문, 차선, 가로등, 반사가 모두 같은 함수를 지나므로 원근이 서로 어긋나지 않는다
    + 눈대중으로 찍은 좌표는 창문 몇 줄만 지나도 소실점에서 벗어난다

```python
VANISH = (470.0, 720.0)    # 소실점 = 눈높이
FOCAL = 430.0              # 1m 거리의 1m가 차지하는 캔버스 단위
EYE = 1.6                  # 눈높이 (m)

def project(x, y, z):
    """x 오른쪽, y 눈높이에서 아래쪽, z 화면 안쪽 (m)."""
    return (VANISH[0] + FOCAL * x / z, VANISH[1] + FOCAL * y / z)
```

- 땅은 `y = EYE`, 높이 h인 지점은 `y = EYE - h`다
- 소실점의 y가 지평선이다. 화면 높이의 55-60% 지점에 두면 건물이 위로 솟아 보인다
- `FOCAL`이 작을수록 광각이 된다

## 면 3종

| 함수 | 면 | 쓰임 |
|---|---|---|
| `wall_quad(side, z0, z1, y0, y1)` | 길을 향한 건물 벽 (x 고정) | 벽, 창문, 상점 유리 |
| `cross_quad(x0, x1, y0, y1, z)` | 보는 사람을 향한 면 (z 고정) | 건물 정면, 간판, 먼 스카이라인 |
| `ground_quad(x0, x1, z0, z1)` | 땅 (y 고정) | 도로, 인도, 횡단보도, 차선 |

## 그리는 순서

1. 하늘과 먼 스카이라인을 그리고 `art.blur()`로 흐린다
2. 도로와 인도, 차선을 그린다
3. 건물을 먼 것부터 가까운 것 순으로 그린다
4. 가로등과 전선을 그린다
5. 인물을 놓는다
6. 비, 안개 같은 대기 효과를 맨 위에 얹는다

## 건물

- 길 한쪽의 건물 줄은 `(z0, z1, 높이)` 목록으로 만든다
    + 깊이 9-17m, 높이 13-44m를 난수로 정한다
    + 다섯 채에 한 번꼴로 골목 간격을 둔다
- 건물 한 채는 정면 1장과 길 쪽 벽 1장이다
- 먼 건물일수록 색을 안개 색에 섞는다: `mix(color, haze, z / FAR * 0.75)`
- 창문은 층과 칸을 이중 반복문으로 돌며 `wall_quad()`로 만든다
    + 켜진 창과 꺼진 창을 난수로 나눈다. 켜진 비율은 40% 안팎이다
    + 같은 색의 창은 목록에 모아 `art.shapes()`로 한 번에 칠한다
    + 켜진 창에는 `art.light(art.feather(glass, 4), color, 0.35)`로 번짐을 더한다
- 1층은 상점 유리를 칸마다 나누어 크게 낸다

## 빛과 젖은 도로

- 광원마다 3가지를 그린다: 광원 자체, 주변 번짐, 도로의 반사
- 반사는 광원을 땅 아래로 뒤집어 투영한 상이다
    + 높이 h의 광원은 `y = EYE + h`로 투영한다
    + 상을 아래로 여러 번 옮겨 겹치면 젖은 아스팔트의 길게 늘어진 반사가 된다
    + 가까운 광원일수록 늘어짐을 길게 준다: `SMEAR_METRES * FOCAL / z`
    + `examples/city.py`의 `reflect()`가 이 과정을 담고 있다
- 도로 먼 쪽에는 하늘색을 `art.light()`로 얹어 물기를 표현한다
- 애니메풍의 블룸이 켜진 창과 간판을 자동으로 번지게 한다

## 축척을 맞춘 소품

```python
unit = FOCAL / z                                   # 이 깊이에서 1m의 캔버스 길이
with art.place(at=project(x, EYE, z), scale=unit):
    draw_walker(art)                               # 미터 단위로 그린 사람
```

- 가로등, 사람, 자동차는 미터 단위로 그리고 `art.place()`로 축척을 맞춘다
- 사람 한 명이 거리의 크기를 알려 준다

## 조립식 아파트 거리

`examples/doomer_city.py`에서 검증했다. 눈 오는 밤, 왼쪽에 긴 아파트 1동, 정면을 막는 2동, 오른쪽 가로등 줄.

- 긴 벽의 창은 칸(`BAY` 3.4m) × 층(`STOREY` 2.8m) 격자에 놓고 1개씩 투영한다
    + 같은 종류의 창은 `art.shapes()` 1번으로 칠한다. 창 수백 개를 따로 칠하면 느려진다
    + 화면에서 2.5단위보다 작은 꺼진 창은 생략한다. 켜진 창만 점으로 남긴다
- 켜진 창은 전등 14-16%, TV의 푸른 빛 5%다. 많이 켜면 밤이 밝아진다
- 정면을 막는 동은 `scenes.panel_block()`에 투영한 상자를 넘긴다
- 가로등은 나트륨의 주황 빛이다
    + 빛 반경은 `1/z`로 줄인다. 땅의 빛 웅덩이는 땅 위의 원을 투영해 만든다
- 트롤리버스 전선 2가닥이 길을 따라 소실점으로 모이고, 가로등 기둥마다 건물까지 처진 가로 전선이 걸린다
- 길은 눈 덮인 땅 위에 어두운 노면, 양옆의 눈 둔덕, 바퀴 자국 4줄이다
    + 땅은 카메라 1m 앞부터 깐다. 3m부터 깔면 화면 아래가 빈다
