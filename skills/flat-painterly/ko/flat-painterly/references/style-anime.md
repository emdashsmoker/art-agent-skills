# 애니메풍

셀 채색 인물과 그린 배경을 합성하고 촬영 효과로 마감하는 화풍. 예제는 `examples/anime_sky_pilot.py`(인물과 하늘), `anime_night_desk.py`(사물과 실내), `anime_city_window.py`(성인 누드 인체화), `anime_figure_base.py`(여성 전신 베이스), `anime_figure_base_male.py`(남성 전신 베이스), `anime_morning_light.py`(남성 정면 반나체 장면), `anime_turnaround.py`(남녀 턴어라운드와 포즈 시트), `anime_outfit_sheet.py`(의상 시트), `anime_cafe_talk.py`(카페에 마주 앉은 두 사람), `anime_doomer_bus_stop.py`(눈 내리는 밤 정류장의 남자), `anime_doomer_courtyard.py`(인물 없는 단지 안마당 설정샷), `anime_face_templates.py`(얼굴 템플릿 시트), `anime_hair_templates.py`(머리 템플릿 시트), `anime_hair_colors.py`(머리색 시트), `anime_long_hair_platform.py`(해 질 녘 승강장의 긴 생머리), `anime_long_hair_window.py`(창가 역광 뒷모습), `anime_long_hair_walk.py`(공원길 투샷).

## 시각 특징

- 면은 밑색과 그림자색 2단으로 나뉘고 경계가 또렷함
- 윤곽선은 면의 색을 어둡게 한 색으로 긋고 굵기에 강약을 줌
- 눈은 화면에서 가장 세밀한 부분이며 홍채에 세로 그라데이션과 하이라이트가 들어감
- 배경은 인물보다 부드럽게 처리
- 마지막에 화면 전체에 빛 번짐과 공기감을 입힘

## 작업 순서

1. 배경 캔버스에 하늘, 구름, 원경을 그림
    + 하늘은 위가 짙고 지평선으로 갈수록 밝아지는 `Linear` 그라데이션
    + 구름은 `motifs.cumulus`
2. 인물은 `Canvas(..., background=None)` 투명 캔버스에 따로 그림
3. `figure.Figure`로 자세를 정하고 얼굴 좌표계를 리그의 머리에 맞춤
    + 자세 값과 옷 만드는 법은 `references/figure.md`
    + 얼굴은 두개골 반지름을 단위 1로 두고 `references/craft.md`의 비례 표에서 출발
4. 뒤에서 앞으로 부품을 쌓음: 뒷머리, 목과 몸통, 얼굴, 눈과 눈썹, 앞머리
5. 부품마다 `anime.cel(canvas, outline, base, shade, amount, line)` 호출
    + 둥근 부품(팔, 리본, 옷깃)은 amount 0.3-0.4의 자동 그림자로 충분
    + 팔처럼 윤곽 여러 개가 겹치는 부품은 `figure.shape_of`로 합쳐 칠하고 `edge_light`로 바깥 윤곽선만 그음
    + 얼굴과 머리카락은 자동 그림자를 끄고 그림자 도형을 직접 설계해 `clip`으로 넣음
6. 설계 그림자 3종을 넣음
    + 앞머리가 이마에 드리우는 그림자: 앞머리 끝선을 아래로 조금 내린 모양
    + 턱이 목에 드리우는 그림자: 목의 윗부분을 덮는 도형
    + 옷깃과 장식이 옷에 드리우는 그림자: 그 부품을 빛 반대쪽으로 옮긴 모양
7. 머리카락에 결 선과 띠 모양 하이라이트를 넣음
    + 결 선은 `stroke(..., taper=(0.2, 1, 0.2), clip=hair)`
    + 하이라이트는 머리 둥근 면을 따라 도는 지그재그 띠. `g.polygon`으로 만든 뒤 clip 적용
8. `anime.rim_light(character, light)` 후 `background.paste(character)`로 합성
9. `anime.finish(background)`로 촬영 효과를 입히고 필요하면 `post.light_gradient`로 광원 쪽 빛을 추가

## 사물과 실내

- 사물은 `solids`와 `props`로 3차원 입체를 만들고 `s3.draw(..., line=잉크색)`으로 칠과 윤곽선을 한 번에 그림
    + 면 명암이 빛 방향을 따르므로 셀 채색의 2단 명암이 자동으로 맞음
- 밤 장면은 광원을 2개로 나눔
    + 따뜻한 조명(전등)은 면 명암의 빛 방향으로, 차가운 빛(화면, 창)은 SCREEN 합성의 부드러운 타원으로
    + `anime.finish`의 bloom이 화면과 전구를 번지게 함
- 자세한 작업법은 `references/subjects.md`의 현대 사물

## 머리카락

- 앞머리는 닫힌 spline 1개로 그림
    + 위쪽은 두개골보다 조금 바깥을 따라가는 매끈한 호
    + 아래쪽은 끝(뾰족)과 골(뾰족)이 번갈아 나오는 톱니이며 끝과 골 사이에 중간점 1개를 넣어 가닥이 휘게 함
    + 끝과 골의 인덱스를 전부 corners에 지정
- 바람에 날리는 긴 머리는 가닥을 `g.ribbon(중심선, 폭 목록)`으로 하나씩 그림
    + 뿌리 폭을 넓게 잡아 가닥끼리 겹치게 하면 한 덩어리로 흐르다 끝에서만 갈라짐
    + 아래 가닥부터 그려 위 가닥이 덮게 함
    + 가닥의 길이, 폭, 끝 방향을 서로 다르게 함
- 뒷머리의 몸통 부분은 그늘색으로 칠해 얼굴 뒤로 물러나게 함

## 눈

예제의 `draw_eye`가 기준 구현. 눈 중심이 원점이고 눈 반폭이 1인 Frame에서 아래 순서로 쌓음.

1. 흰자: 눈머리와 눈꼬리가 뾰족한 닫힌 곡선. 얼굴 형태와 교집합
2. 흰자 윗그늘: 위쪽 1/3을 덮는 연한 청회색 타원
3. 홍채: 세로로 긴 타원에 위가 짙고 아래가 밝은 `Linear`
4. 홍채 윗그늘과 동공, 아래쪽 반사광
5. 하이라이트 2개: 광원 쪽 위에 큰 것, 반대쪽 아래에 작은 것
    + 좌우 눈 모두 화면상 같은 방향에 둠(`eye.flip`으로 부호 보정)
6. 윗속눈썹: 눈꼬리 쪽이 두꺼운 닫힌 도형. 가장 어두운 색
7. 아랫선과 쌍꺼풀 선: 가는 taper 선

## 색

- 피부 그림자는 피부색보다 붉고 짙은 색
- 머리카락은 밑색, 그늘색, 하이라이트색 3색
- 흰 옷의 그림자는 하늘색 계열
- 윤곽선 색은 부품마다 다르게: 피부는 적갈색, 머리카락은 짙은 밑색, 옷은 청회색

## 촬영 인자

| 인자 | 기본값 | 조절 |
|---|---|---|
| `diffusion` | 0.16 | 올리면 몽환적, 내리면 또렷 |
| `bloom` | 0.25 | 흰 구름과 피부가 날아가면 내림 |
| `shadows`, `highlights` | 남색, 크림색 | 시간대에 맞춤. 노을은 보라와 주황 |
| `aberration` | 0.6 | 0이면 색수차 없음 |
| `grain` | 0.018 | 매끈한 면의 인공적인 느낌을 줄임 |

## 흔한 결함

| 증상 | 처방 |
|---|---|
| 날리는 머리가 물갈퀴나 촉수처럼 보임 | 한 도형으로 그리지 말고 가닥별 ribbon으로 나누며 뿌리 폭을 넓혀 겹침 |
| 얼굴이 하얗게 날아감 | 피부 밑색 명도를 내리고 bloom을 낮춤 |
| 구름의 입체가 사라짐 | 구름 palette의 그늘색을 짙게 하고 diffusion을 낮춤 |
| 눈이 작거나 몰려 보임 | 눈 Frame의 unit과 x 좌표를 조정. 예제 기준은 중심 x ±0.47, 반폭 0.27 |
| 선이 가늘어 밋밋함 | `anime.cel`의 width를 올리고 최종 scale을 1.25 이상으로 |
