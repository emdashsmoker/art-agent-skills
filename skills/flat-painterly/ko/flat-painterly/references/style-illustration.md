# 일러스트풍

제한된 팔레트의 평면 도형을 쌓고 점묘 입자로 명암을 주는 화풍. 포스터, 그림책, 표지 그림에 어울림. 예제는 `examples/illustration_moonlit_camp.py`(풍경), `illustration_autumn_walk.py`(전신 인물), `illustration_fantasy_walk.py`(손잡고 걷는 두 여행자), `illustration_doomer_rooftop.py`(옥상에서 밤 단지를 내려다보는 두 사람).

## 시각 특징

- 윤곽선 없이 색면의 명도 차이로 형태를 구분
- 도형은 단순하고 기하학적이며 세부는 생략
- 밝기 변화는 입자가 흩어지는 점묘로 표현
- 종이와 잉크의 거친 질감이 화면 전체에 깔림

## 작업 순서

1. 팔레트를 먼저 확정
    + 한 색상 계열의 명도 단계 4-6개가 화면 대부분을 차지
    + 보색 강조색 1-2개는 초점에만 사용
2. 배경을 평면 띠나 큰 도형으로 깔음
    + 하늘은 명도가 다른 띠를 쌓고 띠 경계를 점묘로 풀어 섞음
3. 뒤에서 앞으로 도형을 쌓음
    + 먼 것은 밝고 채도 낮게, 가까운 것은 어둡게 하여 층을 구분
    + 직선 도형은 `g.polygon`, 곡선 도형은 `g.spline`
4. 점묘 명암을 넣음
    + `cv.fill(cv.shape(경로, soft=20-50), 색, clip=부모, grain=1.0)`
    + 둥근 물체는 `cv.form_shadow(shape, light, amount, soft=0.5)` 결과를 grain=1.0으로 칠함
    + 빛 번짐(모닥불, 창문 불빛)도 soft 타원을 grain=1.0으로 칠함
    + 역광 물체는 `cv.edge_light(shape, light, width, soft)`로 얻은 윤곽 띠를 grain=1.0으로 칠함
5. 반복 요소(나무, 별, 물결)는 생성 함수 1개를 만들어 난수로 크기와 위치를 흔들며 배치
6. `illustration.render(canvas)` 적용

## 점묘 명암

- soft 값이 클수록 입자가 넓게 퍼짐
    + 작은 물체는 soft 10-16, 산이나 하늘은 30-50
- 명암색은 팔레트 안의 이웃 단계 색을 사용
    + 새 색을 만들지 않아야 제한 팔레트의 통일감이 유지됨
- 입자가 부모 도형 밖으로 나가지 않도록 항상 clip 지정

## 패스 인자

| 인자 | 기본값 | 조절 |
|---|---|---|
| `roughness` | 0.8 | 윤곽의 미세한 흔들림. 올리면 손으로 오린 종이 느낌 |
| `ink_mottle` | 0.10 | 잉크가 덜 묻은 얼룩. 짙은 색면에서 잘 보임 |
| `paper_tint` | 크림색 | 흰색으로 바꾸면 차갑고 현대적인 인상 |
| `paper_fiber` | 0.05 | 종이 섬유 질감 |
| `misregister` | 0 | 1-2를 주면 판이 어긋난 인쇄물 느낌 |

## 흔한 결함

| 증상 | 처방 |
|---|---|
| 층이 서로 붙어 보임 | 이웃한 층의 명도 차이를 키움 |
| 점묘가 지저분한 얼룩처럼 보임 | soft를 줄이고 명암색을 밑색과 가까운 단계로 바꿈 |
| 화면이 밋밋함 | 앞쪽 가장자리에 어두운 큰 도형을 세워 화면을 감싸고 초점에 강조색을 둠 |
| 반복 도형이 도장처럼 보임 | 높이, 간격, 기울기를 난수로 흔듦 |
| 도형 사이로 흰 배경이 비침 | 뒤 도형을 앞 도형 밑으로 넉넉히 연장 |

## 3차원 인물

- `character.paint_figure`로 칠한 인물은 굵고 짙은 선(`line_width` 2.4)과 1단 그림자를 그대로 쓰고 인쇄 질감 패스를 거침
    + 배경은 `fill(grain=1.0)`의 평면 색면으로 두어 인물의 셀 그림자와 질감을 맞춤
