# 작화 기준

## 목차

- 구도
- 명암
- 색
- 선
- 화풍별 마감
- 인물 작도 순서
- 두 사람과 장면 작도
- 결함 대응표
- 인물 다양화
- 그룹샷 작도
- 사물 작도
- 참고 기법

## 구도

- 초점은 1곳으로 정하고 화면 3등분 교차점 부근에 배치
    + 초점이 2곳 이상이면 시선이 분산
- 주제는 화면 높이의 70-85%를 차지하도록 크기 결정
- 인물의 시선 방향과 움직임 방향 쪽에 여백 확보
- 풍경의 지평선은 화면 1/3 또는 2/3 높이에 배치
    + 정중앙 지평선은 화면을 둘로 가름
- 전경, 중경, 원경 3개 층을 확보하여 깊이 확보
- 화면 가장자리는 관절(손목, 무릎, 발목)을 피해 자름

## 명암

- 명암 단계는 밝음, 중간, 어두움 3개로 먼저 설계
    + 3단계 배치가 읽히지 않는 그림은 세부를 더해도 읽히지 않음
- 주광 1개를 고정하고 모든 도형에 같은 `light` 적용
- 초점에 가장 밝은 값과 가장 어두운 값을 인접 배치
- 주제와 배경의 명도는 엇갈리게 배치
    + 주제의 밝은 면 뒤에는 어두운 배경, 그림자 면 뒤에는 밝은 배경
- 입체감이 약하면 빛의 z 성분을 줄여 측광으로 전환
    + 정면광 `(-0.3, -0.4, 0.86)`은 평면적, 측광 `(-0.74, -0.42, 0.52)`는 입체적
- 드리운 그림자(`cast`)는 위 도형과 아래 도형의 거리감 표현
    + 턱 아래 목, 앞머리 아래 이마, 팔 아래 몸통에 적용

## 색

- 팔레트는 주색 1개, 보조색 1-2개, 강조색 1개로 제한
- 그림자는 고유색에 환경색을 곱해 생성(`Style.ambient`)
    + 맑은 낮은 푸른 그림자, 노을은 보라 그림자, 실내 백열등은 갈색 그림자
- 빛은 난색, 그림자는 한색으로 온도를 대비
- 피부 기본색은 밝은 살구 계열, 그림자는 붉은 쪽으로 이동
    + 밝은 피부 `#f8e0d2`, 중간 피부 `#eec6ab`, 그을린 피부 `#c99a7a`
- 원경은 채도를 낮추고 안개색 쪽으로 이동
- 최고 채도 색은 초점 주변에 한정

| 분위기 | 하늘과 배경 | 그림자 환경색 | 강조색 |
|---|---|---|---|
| 맑은 낮 | `#3f78c4`, `#a9cdee` | `(0.80, 0.78, 0.92)` | 난색 노랑 |
| 노을 | `#2b3a78`, `#a0629a`, `#f59a5a` | `(0.60, 0.52, 0.70)` | 주황 |
| 밤 | `#060a1c`, `#15224a` | `(0.30, 0.32, 0.50)` | 창문 불빛 노랑 |
| 고전 유화 | `#3a312b`, `#54453a` | `(0.56, 0.46, 0.48)` | 피부 밝은 면 |

## 선

- 선 굵기는 화면 짧은 변의 0.2-0.3%를 기본으로 설정
- 외곽 윤곽선을 가장 굵게, 내부 세부선을 가늘게 구분
- 빛 반대쪽 선을 굵게(`shade_gain`), 선 끝은 가늘게(`taper`) 처리
- 같은 재질이 이어지는 경계는 선을 생략
    + 목과 어깨, 팔과 몸통, 가슴 윗선은 선 없이 명암으로 연결
- 피부 위 주름선은 검정 대신 피부 그림자색 사용

## 화풍별 마감

- (anime) 명암 경계는 1개만 두고 면적의 60% 이상을 밝은 면으로 유지
    + 얼굴은 `light_bias`로 밝은 면을 넓히고 그림자는 턱 아래와 머리카락 아래에 집중
    + 눈 하이라이트, 머리카락 광택 띠, 확산광으로 밀도 확보
- (illust) 부드러운 명암 위에 약한 경계 1개를 겹치고 선색은 고유색 계열 사용
    + 역광 테두리(`rim`)로 윤곽을 배경에서 분리
    + 배경은 `backdrop.wash`의 얼룩 바탕이 어울림
- (painterly) 기준 그림의 명암 대비를 충분히 확보한 뒤 붓질 적용
    + 붓질은 대비를 줄이므로 기준 그림이 밋밋하면 결과도 밋밋
    + 인물과 건축은 `scale` 0.5-0.6, 풍경은 1.0
    + 초점 도형에 `focus` 0.5-1.0 부여, 배경은 0으로 두어 큰 붓질 유지
    + 어두운 배경과 측광 조합이 고전 유화 인상을 형성
- (watercolor) 밝은 면을 넓게 두고 어두운 고유색(검은 머리, 남색 옷)은 1-2곳으로 제한
    + 물감 면의 경계가 흔들리고 가장자리에 안료가 고이므로 큰 면 위주 구도가 어울림
    + 화면 테두리는 흰 종이로 비워짐, 인물과 초점은 테두리에서 화면 폭의 5% 이상 안쪽에 둠
- (pencil) 명도 구조가 그대로 해칭 단계가 되므로 기준 그림의 명도 차를 3단계 이상 확보
    + 흰 옷과 밝은 벽은 해칭 없이 종이로 남고 머리카락과 짙은 옷은 교차 해칭으로 어두워짐
    + 캐릭터 시트, 장면 습작, 실내 투시 연습에 어울림
- (poster) 옷과 피부의 색상(hue)을 서로 멀게 고름
    + 흰 셔츠와 밝은 피부, 노란 블라우스와 피부처럼 색상이 가까우면 한 색면으로 합쳐져 경계가 사라짐
    + 벽돌색, 청록, 남색, 겨자색처럼 채도 있는 옷색이 판화 인상을 강화
- (neon) 밤 장면과 함께 사용하고 간판, 모니터, 스탠드처럼 발광원이 화면 안에 있어야 함
    + 주광은 간판 쪽에서 오도록 빛 방향을 잡고 반대쪽은 청록 테두리광으로 윤곽을 분리
    + 젖은 바닥에는 `stage.reflection`으로 인물의 반사를 깔아 바닥과 인물을 연결

## 인물 작도 순서

1. 머리 크기와 위치 결정, 머리 높이를 단위로 전신 비례선 배치
2. 뒷머리, 몸통, 목, 얼굴, 앞머리 순으로 도형 추가
3. 고개 방향(`yaw`, `roll`)과 몸 방향(`turn`)을 서로 다르게 주어 정면 대칭 회피
4. 눈, 눈썹, 입의 표정 값 조정
5. 광원과 드리운 그림자 확인
6. 배경 명도를 인물 윤곽과 엇갈리게 조정

- 성숙한 인상은 `jaw` 0.85 이상, `eye_size` 1.0 이하, `bangs="swept"` 또는 `"parted"` 조합
- 부드러운 인상은 `jaw` 0.3 이하, `eye_size` 1.1 이상, `blush` 0.3 조합
- 남성은 체형 수치만 바꾸지 않고 형태 기호를 함께 교체
    + 어깨 폭과 골반 폭의 비를 1.4 이상으로 두고 허리에서 골반으로의 곡선을 최소화
    + 대흉근은 아랫선만 긋고 겨드랑이로 오르는 바깥선은 생략(둥근 바깥선은 유방으로 읽힘)
    + 복부는 백선, 건획, 장골 V선을 피부 그림자색 선으로 작도
    + 자세는 다리를 벌린 지지 자세(`heroic`, `akimbo`)가 남성 인상을 강화
- 옷 입은 인물은 맨몸을 먼저 맞춘 뒤 옷을 입힘
    + 옷은 몸 형태를 여유분만큼 키워 재단하므로 몸 비례가 틀리면 옷도 틀림
    + 상의 소매 길이, 하의 밑단 위치, 신발로 인상을 정하고 색은 상의, 하의, 신발 3색 이내
- 뒷모습은 등쪽 해부 표지(척추, 견갑골, 골반 보조개, 오금)로 앞모습과 구별
    + 뒷모습에서 머리카락은 모두 몸 위에 놓임
- 옆모습은 앞뒤 윤곽의 리듬으로 읽힘
    + 가슴과 배는 앞으로, 허리 뒤와 목덜미는 오목하게, 엉덩이와 종아리는 뒤로 나옴
    + 먼 쪽 팔다리는 먼저 조금 어둡게 그려 앞뒤를 분리
    + 걷기는 팔과 다리를 반대로 흔들고 뒷발은 발끝으로, 앞발은 뒤꿈치로 땅을 짚음
- 캐릭터 시트는 정면, 3/4, 옆, 뒤를 같은 머리 높이와 같은 지면선에 나란히 배치

## 두 사람과 장면 작도

- 두 사람은 먼저 앞뒤 순서를 정함
    + 화면에 가까운 사람을 나중에 그리고 겹치는 쪽 어깨와 팔은 앞사람이 가림
    + 두 사람의 몸과 고개를 서로 조금씩 돌려 관계를 보여줌
- 맞닿는 곳은 한 지점으로 정리
    + 손잡기는 앞사람의 손이 뒷사람의 손을 감싸는 1곳
    + 어깨동무는 목 뒤 어깨선 위로 보이는 아래팔과 먼 쪽 어깨에 걸친 손 2곳
- 키 차이는 정수리 높이로 표현하고 두 발은 같은 지면선에 둠
- 장면은 눈높이 1개와 소실점 1개로 시작
    + 서 있는 사람의 눈은 서 있는 시점의 지평선 근처에 놓임
    + 앉은 시점(눈높이 1.2 m)은 인물이 지평선 위로 솟아 대화 장면에 친밀감을 줌
- 인물 크기는 카메라가 깊이에서 계산하며 눈대중으로 정하지 않음
- 인물이 작게 보이면 무대를 줄이거나 렌즈를 길게(`focal` 상향) 하여 인물 쪽으로 다가감
- 가구는 사람보다 뒤에 있는 것과 앞에 있는 것으로 나누어 인물 앞뒤에 배치

## 결함 대응표

| 증상 | 원인 | 조치 |
|---|---|---|
| 도형 경계에 고립된 그림자 얼룩 | 부풀림 격자가 큰 도형에 비해 거침 | `config.POISSON_MAX_SIDE` 상향 또는 `bulge` 하향 |
| 이어지는 두 도형 사이의 계단이나 턱 | 접합부의 폭이 서로 다름 | 두 도형의 접합 폭을 같은 수식으로 계산 |
| 관절이 공처럼 튀어나옴 | 리본 시작 마구리가 윤곽 밖으로 노출 | 관절 위치를 안쪽으로 이동하거나 바탕 도형의 폭을 키워 오목부를 메움 |
| 같은 피부 안에 선이 가로지름 | 닫힌 외곽선 전체를 그림 | `Line.paths`로 필요한 구간만 지정 |
| 도형 끝이 허공에서 투명하게 사라짐 | `fade_t` 구간이 바탕 도형 밖에 위치 | 흐림 구간을 겹친 영역 안으로 축소 |
| 곡선 모서리에 작은 고리 | 제어점 중복으로 곡선이 되감김 | 중복 제거 후 곡선 2개를 이어 붙임 |
| 고개를 돌린 얼굴에서 먼 쪽 눈이 잘림 | `yaw` 과다 | 0.45 이내로 축소 |
| 세부가 바탕 도형 밖으로 삐져나옴 | `clip` 누락 | 바탕 도형 이름으로 `clip` 지정 |
| 회화풍에서 얼굴이 뭉개짐 | 붓이 큼, 초점 미지정 | `scale` 하향, 얼굴 도형 `focus` 상향 |
| 회화풍 표면이 요철 무늬로 덮임 | 물감 두께 음영 과다 | `relief` 0.10 이하로 하향 |
| 회화풍 색이 얼룩덜룩함 | 붓질별 색 변주 과다 | `jitter` 3 전후로 하향 |
| 화면 전체가 뿌옇게 뜸 | 블룸과 확산광 중복 | `bloom` strength 또는 `diffusion` strength 하향 |
| 밝은 영역이 하얗게 날아감 | 발광 누적 | 발광 강도 하향, `review.stats`의 `clipped_white` 확인 |
| 먼 건물의 창 격자가 물결무늬로 보임 | 축소 표본화 부족 | `city.SUPERSAMPLE` 상향 |
| 능선 표면에 세로 줄무늬 | 가로 방향 기울기만으로 음영 계산 | `ridge_layer`의 `slope_light` 하향 |
| 관절에서 윤곽이 혹처럼 튀어나옴 | 팔다리 시작 마구리가 바탕 윤곽 밖으로 노출 | 리본 `round_start=False` 지정 또는 관절을 안쪽으로 이동 |
| 몸통 아래쪽에 속옷 선 같은 음영 띠 | 몸통 도형의 가장자리 음영 | 몸통에 `shape_with`로 허벅지 도형 지정 |
| 피부가 플라스틱처럼 밋밋함 | 광택과 형태 음영 부재 | `gloss` 0.5-0.7, `modeling` 0.5-0.7, 화풍 `rim` 0.4-0.6 |
| 안쪽 허벅지에 어두운 쐐기 | 가까운 허벅지의 그림자 면과 형태 음영 중첩 | `modeling` 하향 |
| 옷이 허리에 얹은 손을 덮음 | 옷이 팔보다 나중에 그려짐 | 옷 도형에 `under=["arm_left"]` 등 앞쪽 팔 키 지정 |
| 드레스 옆으로 허벅지가 비어져 나옴 | 드레스 옆선이 골반에서 끝남 | 옆선을 허벅지 바깥선(`figure.thigh_outer`)에 맞춰 연장 |
| 앉은 다리의 무릎이 원으로 보임 | 정강이가 허벅지 앞에 그려짐 | 꺾인 다리는 허벅지를 앞에 배치 |
| 몸통 뒤 팔의 어깨가 혹처럼 솟음 | 팔 시작 마구리가 어깨선 위로 노출 | 뒤쪽 팔은 어깨 관절보다 조금 아래에서 시작 |
| 옷 색이 팔이나 손에 묻음 | `clip` 대상이 몸 전체 그룹 | `clip`을 몸통과 허벅지 등 해당 도형 이름 목록으로 한정 |
| 선이 도형 안쪽에서 끊김 | 시작과 끝 가늘어짐 구간이 김 | `Line(taper=(False, True))` 지정 |
| 두 다리가 인어 꼬리처럼 한 덩어리로 보임 | 두 허벅지를 한 덩어리로 부풀려 사이 음영이 사라짐, 관절 구간이 가랑이 아래까지 덮어 사이 선이 생략됨 | 허벅지는 몸통과만 `shape_with`로 묶고 `THIGH_JOINT`를 가랑이 위까지로 축소 |
| 고관절 높이에서 허벅지 바깥에 어두운 띠가 시작 | 몸통과 허벅지의 `bulge` 차이로 같은 덩어리의 음영이 다름 | `shape_with`로 묶은 도형의 `bulge`를 같게 지정 |
| 팔 위에 몸통의 겨드랑이 윤곽이 비침 | 몸통 윤곽이 팔의 관절 흐림 구간 안을 지남 | 몸통의 어깨와 겨드랑이 윤곽을 팔 시작점 안쪽으로 이동 |
| 남성 가슴이 유방처럼 보임 | 대흉근 바깥선이 겨드랑이까지 둥글게 이어짐 | 바깥쪽에 `joints` 추가로 잉크 제외, 아랫선을 직선형으로 조정 |
| 반바지 안쪽에 다각형 경계선이 보임 | 여러 다각형의 외곽을 각각 잉크 처리 | 도형에 `merge` 지정 |
| 소매에 색 띠가 세로로 생김 | 원통 명암 소매와 평평한 셔츠 판의 음영 차이 | 소매를 `polys`와 판과 같은 `bulge`로 작도 |
| 사물이 기울어 보임 | 장면 안에서 `Desk`를 여러 개 사용 | 하나의 `Desk`로 모든 사물 작도 |
| 화면 내용이 화면 밖으로 넘침 | 내용 도형의 `clip` 누락 | `screen()`이 만드는 유리 도형 이름으로 `clip` 지정 |
| 남성 얼굴이 앳되어 보임 | 볼이 넓고 얼굴 면 음영 부재 | `WIDTH_KEYS_MALE` 볼 폭 축소, `shading` 0.6 이상 |
| 얼굴 그림자가 멍처럼 보임 | 흐린 둥근 음영 도형 | 경계가 또렷한 면 그림자(`FACE_PLANE`)로 대체 |
| 회화풍 인체가 마네킹처럼 보임 | 형태 둥글기 부족 | `FigureSpec.form` 1.5-1.8, `modeling` 0.9 이상 |
| 짧은 머리가 헬멧처럼 보임 | 머리 두께가 정수리와 옆에서 같음 | 위는 두껍고 옆은 얇게(`SHORT_VOL`), 외곽에 머리 결(`SHORT_TUFT`) 추가 |
| 바지나 소매 끝이 짧게 잘림 | 통의 축을 솎을 때 마지막 점이 빠짐 | 축 표본에 항상 끝점 포함 |
| 소매 어깨가 혹처럼 솟음 | 소매 시작이 어깨 관절 위 | 소매는 어깨 관절에서 시작(`SLEEVE_ROOT` 0) |
| 소매 안쪽에 팔 윤곽선이 비침 | 몸 잉크가 소매보다 나중에 그려짐 | 소매를 팔 바로 뒤에 다른 그룹(`outfit`)으로 추가하여 앞선 잉크를 가림 |
| 뒷모습 하이힐 굽이 X자로 교차 | 뒤에서 본 발을 발끝 벌림 각도만큼 회전 | 뒤에서 본 발은 정강이 방향만 따르고 벌림 각도는 무시 |
| 옆모습 몸통이 판자처럼 얇음 | 몸통 깊이 부족 | `SIDE_DEPTH` 1.1-1.2, 허리 뒤 오목과 엉덩이 돌출 강화 |
| 옆모습 치마 밑단에 V자 홈 | 앞뒤로 벌어진 두 다리 끝을 정면용 순서로 연결 | 다리 사이 천을 다리 끝 점들의 볼록 껍질로 작도 |
| 옆모습에서 바짓가랑이 두 개가 한 덩어리 | 두 다리 통을 한 도형으로 채움 | 먼 쪽 다리 통을 별도 도형으로 먼저 어둡게 작도 |
| 앉은 인물의 엉덩이가 바지 밖으로 비어져 나옴 | 하의가 몸통만 재단하고 좌석 덩어리를 빠뜨림 | 하의 재단 대상에 좌석 덩어리(`geo["seat"]`) 포함 |
| 겹친 두 인물의 옷에 구멍이 나거나 다른 사람 몸에 옷이 칠해짐 | 두 인물의 도형 이름과 키가 같아 `clip`과 `under`가 서로를 참조 | 인물마다 `FigureSpec.ident` 지정 |
| 어깨동무한 팔이 머리 위로 솟음 | 팔꿈치를 위쪽 해로 역산 | 아래팔을 상대 어깨선 위에 수평으로 두고 위팔은 길이를 줄여 뒤로 보냄 |
| 나무 수관 안에 원 윤곽이 여러 개 보임 | 잎 덩어리 다각형마다 선을 그림 | 수관 도형에 `merge`를 지정해 바깥 윤곽만 잉크 |
| 실내 장면에서 인물이 작게 보임 | 무대가 깊고 화각이 넓음 | 무대 깊이 축소, `Camera.focal` 상향 |
| 책상에 앉은 인물의 손이 책상 앞 모서리에 걸림 | 자세의 팔 높이와 원근 책상 높이가 다름 | 책상 높이 또는 아래팔 각도 조정 |
| 옆얼굴 V넥이 목을 쥔 손처럼 보임 | 옆모습 V넥이 깊어 피부 쐐기가 생김 | 옆모습 V넥은 얕게(`SIDE_NECKLINES["v"]`) |
| 판화풍에서 옷이 피부와 한 색으로 합쳐짐 | 옷과 피부의 색상이 가까움 | 옷색을 피부와 색상이 먼 쪽으로 변경 |
| 연필풍 선이 두 겹으로 보임 | 가는 선의 양쪽 경계를 윤곽선으로 다시 그림 | `pencil`의 선 탐지 유지, 필요하면 `contour` 하향 |
| 밤 장면 인물이 오려 붙인 듯 밝음 | 주광이 낮의 흰빛 | `neon`처럼 `key_tint`와 `ambient`를 낮추고 테두리광 추가 |
| 우산 대가 얼굴 뒤를 지나감 | 주먹이 몸 중심선 위에 있음 | 아래팔을 세워 주먹을 얼굴 옆 어깨 위로 이동 |
| 수채풍 물감 면이 디지털 잡음처럼 보임 | 안료 입자가 너무 잘고 강함 | `granulation` 하향, `pigment`로 큰 얼룩을 키움 |
| 물결머리 가장자리에 밝은 쐐기 | 뒷머리 결 다발이 물결진 덩어리 밖으로 비어져 나와 시작부 투명 구간에 배경이 비침 | 결 다발을 덩어리 반폭표에서 촘촘히 표본화해 같은 물결을 따름 |
| 면도 자국이 갈색 얼룩처럼 보임 | 수염색을 피부 위에 그대로 칠함 | 청회색을 섞고 `alpha` 0.2 내외, `blend="multiply"` |
| 옆얼굴 턱수염이 상자처럼 보임 | 수염 윗선이 귀 아래에서 수평으로 끝남 | 윗선을 귀 앞 구레나룻까지 올려 머리카락과 연결 |
| 곱슬머리 외곽이 엉킨 다각형 | 곱슬 원의 바깥 점을 생성 순서대로 연결 | 머리 중심 기준 각도로 정렬한 뒤 연결 |
| 군중 인물이 근경 나무에 가려지거나 화면 밖으로 잘림 | 장면 근경 도형(`Set.front`)과 화면 폭을 고려하지 않고 배치 | `cam.scale(z)`로 화면 x를 계산해 근경 도형과 화면 가장자리를 피해 배치 |
| 가리키는 손끝이 다른 인물 몸에 묻힘 | 더 가까운 인물이 손끝 앞을 가림 | 대상 인물을 손끝 너머로 옮기거나 더 깊은 z에 배치 |
| 머리 뒤로 올린 팔의 아래팔이 귀 옆에서 뭉툭하게 끝남 | `hidden` 손의 아래팔이 손목 관절에서 끝남 | 엔진이 아래팔을 두개골 중심 쪽으로 연장(`HIDDEN_REACH`) |
| 정면으로 앉은 인물의 다리가 무릎 없는 기둥 | 단축된 허벅지가 정강이와 일직선이라 한 도형으로 작도 | 허벅지 단축 비율 0.6 미만은 두 도형으로 분리(`FORESHORTENED_THIGH`), 옷에 무릎 끝선 추가 |
| 낮은 시점의 도로가 화면 아래에서 끊김 | 거리 그림의 근경 바닥이 2 m부터 시작 | 바닥 시작 깊이를 화면 아래 끝에 맞춤(`GROUND_FILL`) |
| 판화풍 얼굴 볼에 밝은 조각이나 초록 조각 | 부드러운 얼굴 하이라이트가 판화 색 단계 경계를 넘음 | 얼굴 하이라이트에 `accent=True`, 하이라이트 없는 화풍은 생략 |
| 인물이 뒤쪽 가구 위에 선 것처럼 보임 | `back`을 인물보다 먼저 통째로 추가 | `scene.add(s.arrange((z, parts), ...), s.front)`로 가구 사이에 깊이 순서로 배치 |
| 모니터나 커피 머신이 받침 가구에 묻힘 | 위에 놓인 물건이 받침 가구보다 먼 깊이로 정렬됨 | 받침 가구와 같은 깊이로 `stage.placed` 지정 |
| 군중의 걸음이 복제한 듯 똑같음 | 걷기 프리셋 1종을 모두에게 적용 | 사람마다 `walk(phase, stride)`의 단계와 보폭을 다르게 지정 |
| 밤 장면 실내가 낮처럼 밝거나 창밖이 하늘색 | 낮 템플릿을 그대로 사용 | 템플릿에 `.night()` 적용, 인물 쪽 빛은 화풍(`neon`)이나 손에 든 화면 빛 번짐으로 보강 |
| 근접샷에서 머리가 화면 위로 잘림 | 앉은 눈높이 카메라로 가까운 인물을 올려다봄 | 템플릿에 `eye=1.55`, `horizon`을 화면 위쪽으로 지정 |

## 인물 다양화

- 견본 시트는 기본 얼굴 1개에서 칸마다 `HeadSpec` 필드 1개만 바꿔 차이를 읽히게 함
- 군중은 인물마다 나이, 머리 모양, 피부색, 표정, 자세 중 3가지 이상을 다르게 지정
- 노년은 `age`와 `gray`를 함께 올리고 자세와 소품(머그, 안경)으로 보강
- 머리 높이 약 60px 이하의 인물은 주름과 주근깨가 거의 읽히지 않으므로 머리 모양, 수염, 안경, 피부색 같은 큰 차이로 구분

## 그룹샷 작도

- 인원이 4명을 넘으면 깊이를 2-3단으로 나누고 `Set.arrange`로 가구와 함께 깊이 순서 정렬
- 같은 깊이의 인물 간격은 0.6 m 이상, 겹칠 때는 얼굴이 가려지지 않게 x를 엇갈림
- 마주 보는 두 사람은 `pair.conversation`에서 듣는 사람이 화면 왼쪽(`TALK_LISTEN`), 말하는 사람이 오른쪽
- 가리키는 팔은 다른 인물의 머리 높이를 지나므로 대상과 1 m 이상 떨어뜨려 배치
- 앉은 인물 앞 탁자는 `inserts`로 몸과 팔 사이에 넣고 탁자 앞 모서리에서 탁자 깊이의 약 0.8배 뒤에 앉혀 손이 탁자 위에 놓이게 함

## 사물 작도

- 책상 장면은 하나의 `Desk`를 공유해야 모든 사물의 사선이 평행
- 사물은 z가 큰 뒤쪽부터 추가하여 앞 사물이 뒤 사물을 가림
- 밤 장면은 책상과 벽을 어둡게 두고 `glow`(화면)와 `light`(조명)로 빛을 더함
- 작은 사물(마우스, 휴대폰, 게임 패드)은 실제 크기 비율을 유지해야 책상 장면의 축척이 읽힘
- 붓질 화풍에서 사라지기 쉬운 경계(창, 액자)는 선 대신 밝은 테두리 도형으로 분리
