## 머리 비례

머리 높이를 H, 정수리 y를 T라고 둔다. 예제는 H = 453, T = 215, 중심축 x = 500이다.

| 부위 | 위치 | 예제 값 |
|---|---|---|
| 얼굴 폭 (광대) | 0.64-0.68 H | 290-304 |
| 눈 중심 | T + 0.52-0.55 H | y 458 |
| 두 눈 중심 간격 | 0.35 H | 축에서 좌우 80 |
| 눈 폭 | 0.20-0.22 H | 약 98 |
| 눈썹 | 눈 중심 위 0.10-0.13 H | y 400-410 |
| 코끝 | T + 0.74-0.76 H | y 556 |
| 입 | T + 0.85-0.86 H | y 603 |
| 턱 끝 | T + H | y 668 |

- 두 눈 사이에는 눈 한 개가 들어갈 공간을 둔다
- 코는 중심축 위에 둔다
- 머리카락의 정수리는 두개골보다 0.08-0.10 H 높다

## 턱선

얼굴 윤곽은 절반만 찍고 `symmetric()`으로 닫는다.

```python
half = [(500, 215), (590, 232), (640, 300), (652, 400), (645, 480),
        (617, 574, True),      # 턱 각
        (567, 622),
        (520, 662, True),      # 턱 끝 모서리
        (500, 668)]
```

| 인상 | 조절 |
|---|---|
| 날카로운 턱 | 턱 각과 턱 끝을 모서리로 표시. 둘 사이를 직선에 가깝게 |
| 갸름한 턱 | 턱 각의 x를 축 쪽으로 10-20 이동 |
| 둥근 턱 | 모서리 표시 제거. 턱 각과 턱 끝 사이의 점을 바깥으로 10 이동 |
| 각진 턱 | 턱 끝 모서리의 x를 축에서 40 이상으로 확대 |

턱선은 목에 드리운 그림자가 있어야 또렷해진다.

```python
art.shadow(art.move(face_mask, 6, 40) * neck, skin_shadow)   # 얼굴을 그리기 전에 적용
```

## 눈

눈은 그림에서 가장 오래 보는 곳이다. 아래 순서로 쌓는다.

1. 흰자: 아몬드 모양. 안쪽과 바깥쪽 눈꼬리는 모서리로 표시
2. 윗눈꺼풀 그림자: `white * (1 - art.move(white, 0, 9))`
3. 홍채: 타원을 흰자 마스크로 잘라냄. 위쪽 1/5이 눈꺼풀에 가려져야 눈매가 차분해짐
4. 홍채 위쪽의 어두운 그라데이션
5. 홍채 테두리 고리: 큰 타원에서 작은 타원을 뺀 마스크
6. 동공
7. 홍채 아래쪽의 밝은 반사광
8. 윗속눈썹: 닫힌 면으로 그림. 바깥쪽으로 갈수록 두껍게, 끝은 위로 뻗음
9. 아랫속눈썹: 바깥쪽 절반에만 가는 획
10. 쌍꺼풀 선: 피부 그림자 색의 가는 획
11. 눈썹: 안쪽이 굵고 바깥쪽이 가는 획 (`taper="end"`)
12. 하이라이트: 광원 쪽 위에 큰 점 1개, 반대편 아래에 작은 점 1개

- 좌우 눈은 같은 함수에 `side = -1, +1`을 주어 그린다
    + 눈 모양은 좌우 반전한다
    + 하이라이트 위치는 반전하지 않는다. 광원이 하나이기 때문이다

## 코와 입

- 코는 적게 그릴수록 좋다
    + 광원 반대편에 작은 삼각형 그림자 1개
    + 코끝 아래에 짧은 획 1개
    + 코끝에 작은 하이라이트 1개
- 입은 3겹이다
    + 윗입술 면, 아랫입술 면, 그 사이의 입술 선
    + 아랫입술 가운데에 작은 하이라이트
    + 아랫입술 밑에 옅은 그림자
- 볼 홍조는 `art.blob()`을 얼굴 마스크로 잘라 0.2-0.3 불투명도로 칠한다

## 머리카락

세 덩어리로 나눈다.

| 덩어리 | 그리는 시점 | 역할 |
|---|---|---|
| 뒷머리 | 목과 옷보다 먼저 | 머리 전체의 실루엣 |
| 앞머리 | 얼굴과 눈보다 나중 | 이마와 얼굴 옆선을 덮음 |
| 가는 가닥 | 앞머리 전후 | 덩어리의 단조로움을 깸 |

- 머리카락 끝은 모서리로 표시해 뾰족하게 만든다
- 앞머리가 얼굴에 드리우는 그림자를 얼굴 위에 적용한다
- 결은 `strands_between()`으로 두 안내 곡선 사이에 긋는다
    + 가닥마다 길이를 다르게 끊어야 자연스럽다
- 윤기는 `sheen()`으로 넣는다
    + 머리 곡면을 가로지르는 호를 따라 결 방향의 짧은 획을 늘어놓는다
- 아래쪽은 `art.ramp()`로 더 짙은 색을 덧칠한다
- 삐져나온 잔머리 2-3가닥은 시작점을 머리카락 안쪽에 둔다

`strands_between()`과 `sheen()`은 `examples/portrait.py`에 있다.

## 머리와 얼굴 템플릿

`examples/head_style.py`의 `HeadLook` 1개로 머리 모양, 머리색, 이목구비를 고른다. 비운 항목은 머리 모듈의 기본값(`DEFAULT_LOOK`, 원래 얼굴)을 쓴다.

```python
from head_style import HeadLook
look = HeadLook(hair="bob", hair_colour="chestnut", eyes="round", brows="arched", lips="full", eye_colour="green",
                earrings="none", hat="beanie", cigarette="lit")
portrait.draw("anime", 1024, look)                       # 흉상
outfits.Look("f", "sundress", "standing", "beach", face=look)              # 전신
outfits.Duo(("f", "bikini"), ("m", "swim_trunks"), "facing", "beach", faces=(look, None))
with portrait.styled(look): ...                          # 머리 모듈을 직접 쓸 때
```

| 항목 | 여성 머리 (`portrait.py`) | 남성 머리 (`portrait_male.py`) |
|---|---|---|
| `hair` | `long_straight`(기본), `long_wavy`, `bob`, `ponytail`, `half_up`, `short_cut` | `short`(기본), `side_part`, `medium`, `two_block` |
| `eyes` | `sharp`(기본), `round`, `soft` | `sharp` |
| `brows` | `natural`(기본), `straight`, `arched` | `straight`(기본), `soft` |
| `lips` | `natural`(기본), `full`, `thin` | `natural` |
| `hair_colour` | 기본 `navy` | 기본 `ink` |
| `eye_colour` | 기본 `amber` | 기본 `blue` |
| `earrings` | `drop`(기본, 금 귀걸이), `earphones`, `none` | `none`(기본), `earphones` |
| `hat` | `none`(기본), `beanie` | 같음 |
| `cigarette` | `none`(기본), `lit` | 같음 |

- 머리색 이름: `navy`, `ink`, `black`, `dark_brown`, `chestnut`, `honey`, `platinum`, `silver`, `burgundy`
    + `"#RRGGBB"`를 주면 짙은 색, 윤기, 그림자 색조, 눈썹 색을 계산한다
    + 눈썹은 머리색을 따른다
- 눈동자 색 이름: `amber`, `blue`, `brown`, `green`, `grey`, `violet`. `"#RRGGBB"`도 된다
- 없는 이름은 고를 수 있는 이름을 알려 주며 멈춘다

### 머리 모양을 그리는 방식

머리 모양 1개는 3가지를 그린다: `back(art)`(몸 뒤), `masks(art)`(칠하기 전 마스크, 얼굴에 그림자를 드리움), `front(art, masks)`(얼굴 위).

| 모양 | 뒷머리 | 앞머리 |
|---|---|---|
| `long_straight` | 어깨 아래까지 | 옆가르마 커튼 앞머리, 오른쪽은 귀 뒤로, 옆으로 쓸린 잔머리 |
| `long_wavy` | 같은 모양을 뺨 아래부터 물결치게 | 같음 |
| `bob` | 턱선에서 고르게 자름 | 양옆이 귀 앞으로 턱까지, 옆으로 쓸린 잔머리 |
| `ponytail` | 정수리 위 묶음과 한쪽으로 늘어진 꼬리 | 넘긴 머리, 관자놀이의 가는 가닥 |
| `half_up` | 어깨 아래까지와 정수리 뒤 작은 매듭 | 넘긴 머리, 잔머리, 가는 가닥 |
| `short_cut` | 귀 위에서 끝남 | 이마를 가로지르는 앞머리, 관자놀이의 짧은 가닥 |
| `short` (남) | 귀와 목덜미에서 끝남 | 가르마에서 쓸린 뾰족한 가닥, 미간의 한 가닥 |
| `side_part` (남) | 같음 | 가르마에서 넘긴 넓은 가닥, 이마가 드러남 |
| `medium` (남) | 턱과 목덜미에 뾰족한 끝 | 눈썹까지 오는 가닥, 귀를 덮는 옆머리 |
| `two_block` (남) | 옆을 짧게 쳐 살이 비침 | 윗머리와 앞머리만 |

- 물결 머리는 안내점을 촘촘히 채운 뒤 높이에 따라 옆으로 민다 (`wave()`)
    + 미는 양이 높이로만 정해지면 가닥의 양쪽 가장자리가 함께 흔들려 굵기가 유지된다
- 이마를 드러낸 머리의 이마선은 가르마에서 반대쪽 관자놀이까지 고르게 둔다
    + 가르마에서 이마선이 꺼지면 머리가 빠지는 것처럼 보인다
- 관자놀이의 가는 가닥은 곡선으로 긋는다. 채운 가닥으로 그리면 머리핀처럼 보인다
- 포니테일 꼬리는 귀에서 떨어뜨려 얼굴 바깥으로 늘어뜨린다
    + 귀 옆에 붙이면 옆머리나 끈처럼 보인다
- 금 귀걸이는 귀를 덮는 모양(`bob`)에서 그리지 않는다 (`shows_ear`). 이어폰은 그 모양에서 줄만 그린다
- 남성의 긴 머리는 턱과 목덜미 끝을 뾰족하게 자른다. 둥글게 두면 바가지 머리가 된다
- 짧은 머리의 옆과 목덜미는 얼굴 윤곽 안쪽으로 접어 넣는다. 밖에 두면 헬멧의 귀덮개처럼 보인다

### 이목구비

- 눈 모양은 흰자, 윗 속눈썹 띠, 눈꼬리 획, 아랫눈꺼풀 선, 쌍꺼풀 선, 홍채 반지름을 한 묶음으로 바꾼다 (`EYE_SHAPES`)
    + `round`: 세로로 크고 눈꼬리가 수평. 눈썹을 5만큼 올린다
    + `soft`: 눈꼬리를 내림. 눈꼬리 획도 아래로 뺀다
- 눈썹은 4점 획과 굵기다 (`BROWS`). 남성 눈썹은 채운 모양이다
- 입술은 윗입술, 아랫입술, 입술 선의 모양과 칠 진하기다 (`LIPS`)
- 턱선과 얼굴 윤곽은 바꾸지 않는다

### 소품

털모자, 담배, 이어폰을 `HeadLook`으로 고른다 (`examples/head_props.py`).

- `hat="beanie"`: 골지 접단이 있는 검은 털모자
    + 머리뼈를 감싼 타원을 챙 높이에서 자른 모양이다
    + 챙은 눈썹 바로 위에 둔다. 이마 위쪽에 두면 머리 위에 얹힌 작은 모자처럼 보인다
    + 챙과 접힌 선은 이마 가운데에서 조금 처진다. 조금 위에서 본 고리이기 때문이다
    + 골지는 각도를 고르게 나눠 옆으로 갈수록 촘촘하다. 골지와 접힌 선은 모자 마스크 안에만 칠한다
- `cigarette="lit"`: 입꼬리에 문 담배, 불씨와 그 빛, 흔들리며 오르는 연기
    + `draw_cigarette(art, tilt, root, droop)`는 사물화에서도 쓴다 (재떨이에 걸친 담배)
- `earrings="earphones"`: 흰 유선 이어폰
    + 보이는 귀에 이어버드를 꽂는다. 줄 2가닥은 턱 아래에서 만나 1가닥으로 옷 속에 들어간다
    + 머리카락에 덮인 귀는 줄만 머리카락 아래에서 나온다
- 소품은 머리를 다 그린 뒤 위에 얹는다. 고르지 않으면 그림이 바뀌지 않는다
- 위치는 머리 모듈마다 `PROPS`(`PropPlaces`)에 적는다
    + 머리뼈 타원, 챙 높이, 입꼬리, 줄이 시작하는 곳, 줄이 만나는 곳, 뒤에서 본 연기 자리
- 뒤에서 본 인물은 `draw_head_back()`이 뒷머리 위에 모자를, 머리 옆에 오르는 연기를 그린다
- 흉상의 테두리 빛 마스크에 모자를 합친다. 빠뜨리면 모자 위에 머리카락 테두리 빛이 남는다

## 목과 어깨

- 목 폭은 얼굴 폭의 0.33-0.38배다
- 어깨 폭은 얼굴 폭의 1.9-2.1배다
- 목은 옷깃보다 좁게 그린다. 넓으면 옷깃 옆으로 살색이 삐져나온다
- 옷은 몸판, 깃, 봉제선 순으로 쌓는다
    + 깃이 몸판에 드리우는 그림자 1개가 옷의 두께를 만든다

## 나이대 조절

| 요소 | 성인 | 어려 보이는 쪽 |
|---|---|---|
| 눈 중심 높이 | T + 0.52 H | T + 0.58 H 이상 |
| 눈 세로 / 가로 | 0.40 이하 | 0.55 이상 |
| 홍채가 가려지는 정도 | 위쪽 1/5 가림 | 전부 보임 |
| 코에서 턱까지 | 0.25 H | 0.20 H 이하 |
| 턱선 | 모서리가 있는 직선 | 둥근 곡선 |
| 목 | 길고 또렷함 | 짧음 |

성인 인물은 왼쪽 열의 값을 쓴다.

## 생동감

- 머리를 3-6도 기울인다
    + 머리 부품의 모든 곡선에 같은 `rotate()`를 적용한다
    + 몸은 기울이지 않는다
- 머리 모양을 좌우 비대칭으로 만든다
    + 한쪽은 귀 뒤로 넘기고 반대쪽은 앞으로 내린다
- 장신구 1개가 시선의 쉼표가 된다

## 전신 비례

전신은 머리 길이 8개 높이다. 머리 1개를 100으로, 땅을 y = 0으로, 위쪽을 음수로 둔다.

| 지점 | y | 반폭 또는 굵기 |
|---|---|---|
| 정수리 | -810 | 머리 폭 72 (애니메 머리는 실제보다 6% 크게) |
| 턱 | -700 | |
| 어깨선 | -650 | 반폭 66-74, 바깥으로 처짐 |
| 가슴선 | -600 | 반폭 72-78 |
| 허리 | -520 | 반폭 50-56 |
| 배꼽 | -497 | |
| 엉덩이 최대 폭 | -410 | 반폭 80-92 |
| 가랑이 | -390 | 허벅지 굵기 82-92 |
| 무릎 | -220 | 굵기 46 |
| 종아리 최대 | -160 | 굵기 50-53 |
| 발목 | -40 | 굵기 25 |

| 팔의 지점 | y | 굵기 |
|---|---|---|
| 어깨 관절 | -625 | 33 |
| 팔꿈치 | -520 (허리 높이) | 25 |
| 손목 | -405 (가랑이 높이) | 19 |
| 손끝 | -330 (허벅지 중간) | |

- 손 길이는 머리의 0.7배다
- 목 길이는 머리의 1/3이다. 길면 머리가 떠 보인다
- 여성은 허리가 좁고 엉덩이 폭이 어깨 폭과 비슷하다
- 어깨 바깥 폭(팔 포함)은 머리 높이의 1.6배(여성), 1.8배(남성) 안팎으로 둔다
    + 이보다 넓거나 어깨가 각지면 옷을 입혀도 근육질로 보인다
    + 작은 머리, 굵은 팔, 아래에서 올려다본 시점도 같은 인상을 더한다
- 몸통 윤곽의 아래 끝은 바지 엉덩이 안에서 끝낸다. 다리 사이로 상의 색이 비치지 않는다

## 자세

서 있는 인물은 콘트라포스토로 세운다. 좌우 대칭으로 세우면 마네킹이 된다.

- 한쪽 다리에 체중을 싣는다
    + 체중 쪽 엉덩이가 올라가고 바깥으로 밀린다
    + 체중 쪽 어깨는 내려간다. 어깨선과 골반선이 서로 반대로 기운다
    + 머리는 체중을 실은 발 위로 돌아온다
- 반대쪽 다리는 무릎을 안쪽으로 살짝 굽히고 발을 옆으로 내놓는다
- 두 팔의 모양을 다르게 한다
    + 착의 예제는 한 팔을 늘어뜨리고 다른 팔의 손을 엉덩이에 얹었다
    + 누드 입상은 한 팔을 머리 뒤로 올리고 다른 팔의 손을 허벅지에 얹었다
- 몸의 중심선이 S자를 그리면 정적인 입상도 살아 보인다
    + 골반 중심을 체중 쪽으로 10-20 밀고 흉곽 중심을 반대쪽으로 10 민다
    + 체중 쪽 허리는 깊게 꺾이고 반대쪽 옆구리는 길게 펴진다
    + 뗀 다리의 무릎을 체중 다리 앞으로 겹치면 곡선이 발끝까지 이어진다
- 올린 팔은 손을 머리 뒤에 감춘다. 팔꿈치 부근에 조절점을 3개 두어야 팔꿈치가 뾰족하게 꺾인다

## 몸 만들기

- 몸통은 목부터 가랑이까지 닫힌 곡선 1개다 (`TORSO`, 조절점 27개)
- 팔다리는 관절을 지나는 튜브다: `art.tube([(x, y, 굵기), ...])`
    + 다리는 조절점 7개: 엉덩이, 허벅지 중간, 무릎, 종아리, 정강이 아래, 발목 2개
    + 중심선을 곧게 두지 않는다. 허벅지는 바깥으로, 종아리는 다시 바깥으로 휘게 찍어야 다리 곡선이 나온다
- 몸통, 다리, 발, 늘어뜨린 팔, 반대쪽 위팔의 마스크를 `np.maximum.reduce()`로 합쳐 부품 1개로 그린다
    + `bulge` 없이 그리면 몸 전체가 이어진 한 덩어리로 음영된다
    + 부품을 따로 그리면 관절마다 공 모양 명암이 생겨 관절 인형이 된다
- 팔다리가 몸에 붙는 곳의 선은 따로 긋는다

```python
inner = art.grow(body, -3)
apart = 1 - art.grow(np.maximum.reduce([torso] + feet), 2)
art.outline(limb, art.line_color(SKIN), clip=inner * apart)
```

## 이음매 처리

몸 앞을 가로지르는 팔은 합칠 수 없으므로 따로 그린다. `examples/figure.py`의 `add_limb()`가 이 처리를 한다.

- 위팔은 몸에 합쳐 두고 팔 전체 튜브를 그 위에 다시 그린다
- 어깨 관절 주변에서는 새로 칠하지 않는다
    + `art.blob(root, 60)`으로 만든 범위에서 팔 마스크를 서서히 지운다
    + 그 범위에서는 이미 그려진 몸의 색과 명암이 그대로 보인다
- 팔이 몸에 드리우는 그림자를 팔보다 먼저 적용한다
- 맨살의 손은 팔 마스크에 합쳐 한 번에 칠한다. 방법은 아래 '손발을 팔다리에 잇기'에 있다
- 소매가 있으면 순서가 반대다. 손을 먼저 그리고 소매를 그 위에 그린다

## 머리 얹기

```python
HEAD_SCALE = 106 / 453            # 흉상 예제의 머리 길이 453을 머리 1개로
with art.place(at=CHIN, scale=HEAD_SCALE, pivot=(500, 668), angle=-3):
    head = portrait.head_masks(art)
    portrait.draw_back_hair(art)   # 몸보다 먼저
# ... 몸을 그린다 ...
with art.place(at=CHIN, scale=HEAD_SCALE, pivot=(500, 668), angle=-3):
    art.shadow(art.move(head["face"], 6, 40) * torso, shadow)   # 턱이 목에 드리우는 그림자
    portrait.draw_ear(art)
    portrait.draw_head_front(art, head)
```

- 뒷머리는 몸보다 먼저, 얼굴과 앞머리는 몸보다 나중에 그린다
- 흉상 예제의 턱 끝 `(500, 668)`을 기준점으로 삼아 목 위에 맞춘다

## 머리 돌리기

정면 그림 머리를 좌우 35도까지 돌린다 (`atelier.turn`). 3차원 몸에 얹을 때는 `nude.draw_figure()`가 머리 방향과 카메라에서 각도를 구해 자동으로 돌린다.

- 원리: 얼굴의 점마다 앞으로 나온 깊이를 준다
    + 깊이는 납작한 타원체에 코 높이를 더한 값이다 (`FaceDepth`)
    + 점은 깊이 x sin(각도)만큼 옆으로 가고 폭은 cos(각도)로 줄어든다
    + 가장 앞에 있는 얼굴 가운데가 가장 많이 움직인다. 중심선이 돈 쪽으로 밀리고 먼 쪽 눈과 입이 좁아진다
- 점을 옮기는 방식은 부위마다 3가지다

| 방식 | 함수 | 부위 |
|---|---|---|
| 표면 | `surface()` (머리 모듈의 `head()`) | 눈, 눈썹, 코, 입, 앞머리, 볼 그림자 |
| 껍데기 | 변환 없음 (머리 모듈의 `shell()`) | 뒷머리, 귀, 귀걸이. 둥근 두개골의 윤곽은 어느 쪽에서 봐도 같음 |
| 윤곽 | `outline()` | 얼굴 윤곽. 가까운 쪽은 턱 모서리까지 제자리, 먼 쪽과 턱 끝은 표면처럼 움직임 |

- 10도를 넘으면 먼 쪽 귀를 그리지 않는다. 뺨 뒤로 숨는다
- 홍채는 그 자리의 좁아지는 비율(`squeeze()`)만큼 가로로 줄인다
- 8도를 넘으면 콧대 선을 그린다
- 3차원 몸에 얹을 때 머리의 고정점은 돌린 턱 위치다
- 머리 모듈은 `turned(각도)` 문맥과 `FACE_DEPTH` 상수를 갖춘다 (`portrait.py`, `portrait_male.py`)
- 35도를 넘는 측면과 옆얼굴은 그리지 못한다
- 머리가 카메라에서 110도 넘게 돌아 있으면 얼굴 없이 머리카락만 그린다 (`nude.BACK_VIEW`)
    + 뒤에서는 뒷머리 그림을 몸과 옷 위에 얹는다. 긴 머리가 등을 덮기 때문이다
    + 이 처리가 없으면 얼굴이 뒤통수에 그려진다
    + 35-110도 사이는 35도로 돌린 얼굴과 머리 뒤쪽의 머리카락 덩어리가 함께 보인다

## 손

`examples/hands.py`의 손은 손목 중심이 원점이고 손가락이 위(-y)를 향하며 길이가 100이다.

| 비례 | 값 |
|---|---|
| 손바닥 폭 | 손 길이의 0.45 |
| 가운뎃손가락 | 손 길이의 0.44 |
| 손가락 길이 비 (검지 : 중지 : 약지 : 새끼) | 0.91 : 1 : 0.93 : 0.73 |
| 마디 길이 비 (첫째 : 둘째 : 셋째) | 0.46 : 0.30 : 0.24 |
| 손가락 굵기 | 손 길이의 0.09-0.11 |

- `draw_hand(art, pose, palm_side)`: 손등 또는 손바닥이 보이는 손
    + `Pose`의 `spread`는 손가락 벌림, `curl`은 마디 굽힘, `stretch`는 앞뒤로 향한 손가락의 단축이다
    + `stretch`를 0.3으로 주면 접은 손가락의 마디만 남는다
    + 준비된 자세: `OPEN`, `RELAXED`, `POINTING`, `VICTORY`
- `draw_hand_side(art)`: 엄지 쪽에서 본 힘 뺀 손. 늘어뜨린 팔 끝에 쓴다
- 손가락은 튜브다. 손바닥과 합쳐 부품 1개로 그리고 손가락끼리 닿는 곳에만 선을 긋는다
- 손등에는 손톱과 마디 주름을, 손바닥에는 손금 3줄과 마디 금을 넣는다
- 왼손은 `flip=True`로 만든다
- 맞닿은 손가락 사이에는 `separate()`가 어두운 틈을 넣는다
    + 선화가 없는 화풍에서도 손가락을 셀 수 있다

## 발

`examples/feet.py`의 발은 앞에서 본 모습이다. 발목 중심이 원점, 발가락이 아래(+y), 엄지발가락이 +x 쪽이다. 단위는 전신과 같다 (머리 1개 = 100).

- `draw_foot(art, instep, join)`: 발등 쐐기 1개와 발가락 타원 5개
    + `instep`은 발목에서 발가락 뿌리까지의 길이다. 바닥을 디딘 발은 24, 뒤꿈치를 든 발은 44
    + 반대쪽 발은 `flip=True`로 만든다
- 발가락은 엄지에서 새끼로 갈수록 작아지고 뒤로 물러난다
    + 반폭 7.0, 4.4, 4.0, 3.7, 3.3. 뒤로 물러나는 정도 0, 0.5, 2, 4, 6.5
    + 발가락 끝 사이에 틈이 남는 폭이어야 어떤 화풍에서도 5개가 세어진다
- 새끼발가락부터 그리고 엄지발가락을 마지막에 그린다. 앞 발가락이 뒤 발가락을 가린다
- 발톱은 발가락 위쪽의 작은 타원, 발등에는 발가락으로 퍼지는 힘줄 빛 3줄, 발목 양옆에 복사뼈 빛
- 앞에서 본 발은 작아 보이므로 전신에서는 1.2배로 그린다

## 손발을 팔다리에 잇기

손과 발을 팔다리와 따로 칠하면 손목과 발목에서 명암이 끊겨 장갑이나 양말처럼 보인다.

```python
with hand_placement(art):
    hand = hands.hand_parts(art, pose)             # 마스크만 만든다
arm = np.maximum(art.tube(ARM), hands.hand_mask(hand))
add_limb(art, arm, SKIN, SHOULDER, trunk, shadow)  # 팔과 손을 한 덩어리로 칠한다
with hand_placement(art):
    hands.finish_hand(art, hand, pose)             # 손가락 틈, 손톱, 주름만 얹는다
```

- 발도 같다: `feet.foot_parts()`로 마스크를 만들어 다리와 합치고 `feet.finish_foot()`으로 세부를 얹는다
- 같은 `art.place()`를 두 번 쓰므로 배치를 함수로 만들어 둔다

## 3차원 마네킹

전신, 특히 앉거나 누운 자세는 `atelier.mannequin`의 3차원 몸으로 만든다. 2차원 좌표로 팔다리를 찍으면 자세가 복잡해질수록 길이와 앞뒤 겹침이 어긋나 몸이 뒤틀린다.

```python
from atelier import Camera, sculpt
from atelier.mannequin import FEMALE, MALE, Pose, Reach, build, add_skull
from atelier.sculpt import Scene, RoundBox, rotation, facing

pose = Pose(pelvis=(x, y, z), pelvis_frame=rotation(turn, lean, tilt),
            chest_frame=..., head_frame=...,
            left_hand=Reach(target, bend, forward, back, curl), right_hand=..., left_foot=..., right_foot=...)
scene = Scene()
scene.add(RoundBox(...), "floor")                  # 소품도 같은 장면에 넣는다
marks = build(scene, pose, physique=FEMALE)         # 몸을 넣고 기준점을 돌려받는다. 남성은 MALE
add_skull(scene, marks)                             # 그려 얹을 머리 자리
result = sculpt.render(art, camera, scene)
sculpt.paint(art, result, "skin", skin, shadow, deep, sheen=0.28)
```

- 좌표는 미터 단위다. x 오른쪽, y 보는 사람에게서 멀어지는 쪽, z 위쪽
- 체형은 `FEMALE`(키 1.68m)과 `MALE`(키 1.80m) 2종이다. 둘 다 8등신이다
- 자세는 데이터다

| 항목 | 뜻 |
|---|---|
| `pelvis` | 두 고관절 사이 점의 위치. 서 있으면 높이 여성 약 0.87, 남성 약 0.935. 앉으면 의자 높이 + 0.08 |
| `pelvis_frame`, `chest_frame`, `head_frame` | 골반, 가슴, 머리의 방향. `rotation(turn, lean, tilt)` 또는 `facing(up, front)` |
| `Reach.target` | 손목 또는 발목이 갈 위치 |
| `Reach.bend` | 팔꿈치 또는 무릎이 향할 방향 |
| `Reach.forward`, `Reach.back` | 손가락이나 발가락이 향할 방향, 손등이나 발등이 향할 방향 |
| `Reach.curl` | 손은 0 편 손에서 1 주먹, 발은 0 평평에서 1 발끝을 뻗음 |

- 팔꿈치와 무릎은 역운동학으로 계산한다. 뼈 길이는 어떤 자세에서도 유지된다
    + 닿지 않는 목표는 가능한 곳까지만 뻗고 `marks["strain"]`에 얼마나 모자랐는지 기록한다
    + 2cm 넘게 모자라면 목표를 몸 쪽으로 옮긴다
- 손을 머리 뒤나 무릎 위에 두려면 먼저 한 번 `build()`해서 기준점을 얻고 그곳을 목표로 준다 (`nude.resolve()`, `Setting.hand_behind_head`, `Setting.hand_at`)
- 바닥을 디딘 발의 발목 높이는 여성 0.081, 남성 0.088 안팎이다. 뒤꿈치를 든 발은 0.115-0.125
    + 낮으면 발이 바닥에 묻히고 높으면 뜬다. 발바닥 가장 낮은 점이 바닥 높이와 맞는지 확인한다
- `rotation(turn, lean, tilt)`의 각도 감각
    + turn: 양수면 몸 앞면이 보는 사람의 오른쪽으로 돈다
    + lean: 양수면 위쪽이 보는 사람 쪽으로 기운다
    + tilt: 양수면 위쪽이 보는 사람의 오른쪽으로 기운다
- 콘트라포스토는 골반 tilt와 가슴 tilt의 부호를 반대로 준다. 예제 입상은 골반 7, 가슴 -5
- 누운 자세는 `facing(up=척추 방향, front=배가 향하는 방향)`으로 몸통을 눕힌다

### 렌더링이 하는 일

`sculpt.render()`는 화소마다 광선을 쏘아 형태를 찾고 그림에 필요한 것을 돌려준다.

| 결과 | 쓰임 |
|---|---|
| `masks[group]` | 무리별 덮임 마스크. 윤곽은 화소 이하 정밀도로 매끈하다 |
| `lit` | 실제 표면 방향에서 계산한 빛. `art.shade_by()`로 화풍에 맞는 명암이 된다 |
| `shadow` | 다른 형태가 드리우는 그림자. 팔이 몸에, 몸이 바닥에 |
| `ao` | 겨드랑이, 가슴 밑, 손가락 사이처럼 빛이 덜 드는 골 |
| `sheen` | 젖은 듯한 광택 위치 |
| `contours` | 앞의 형태가 뒤의 형태를 가리는 경계선 |
| `at(point)`, `visible(point)`, `disc(center, normal, radius)` | 3차원 점을 화면에 찍기, 가려졌는지 확인하기, 표면 위 작은 원 그리기 |

- 같은 무리(group)의 형태는 만나는 곳이 녹아 이어진다. 다른 무리는 닿기만 한다
- `blend`는 녹는 폭, `anchor`와 `reach`는 녹임이 미치는 범위다
    + 팔다리는 뿌리 관절에만 녹아 붙고 몸에 닿는 다른 곳에서는 경계가 남는다
- `step=2`(기본값)는 두 화소마다 광선을 쏜다. 결과 차이가 거의 없고 4배 빠르다

### 마네킹 형태를 고칠 때의 규칙

- 한 관절에 형태를 여러 개 녹이면 부피가 더해져 관절이 공처럼 부푼다
    + 관절은 두 형태의 끝을 비슷한 반지름으로 맞대고 녹임 폭을 1cm 안팎으로 둔다
- 녹임이 끝나는 경계가 관절 근처에 있으면 고리 모양 주름이 생긴다
    + `reach`를 녹임 폭의 10배 이상으로 잡는다
- 근육 덩어리(종아리, 엉덩이 옆)는 길쭉한 타원체를 넓게 녹여 붙인다. 짧은 막대 두 개를 잇는 방식은 꺾임을 남긴다
- 팔의 둥근 시작점이 어깨선 위로 솟으면 어깨가 각진다. 어깨 관절 높이를 어깨선에 맞춘다
- 발가락 줄은 발등보다 넓다. 발볼을 납작한 타원체로 넓혀 받친다 (`FOREFOOT`)
    + 발볼이 좁으면 바깥 발가락이 발 밖으로 삐져나와 끊어진 것처럼 보인다. 정면에서 발끝을 볼 때 특히 두드러진다

## 남성

여성과 같은 절차를 밟는다. 흉상, 3차원 마네킹, 누드, 착의 순서다.

### 얼굴 (`examples/portrait_male.py`)

흉상 예제와 같은 함수 이름(`head_masks`, `draw_back_hair`, `draw_ear`, `draw_head_front`)을 쓰므로 마네킹에 그대로 얹힌다.

| 요소 | 여성 흉상 | 남성 흉상 |
|---|---|---|
| 얼굴 폭 (광대) | 기준 | 여성과 같거나 좁게. 넓히면 얼굴이 비어 보임 |
| 턱 | 좁고 뾰족함 | 턱 각이 더 낮고, 턱 끝이 두 모서리 사이로 평평하고 넓음 |
| 광대에서 턱까지 | 매끈함 | 광원 반대편에 셀 그림자 1개. 회화풍에서는 절반 세기로 |
| 눈 | 크고 둥긂, 속눈썹 많음 | 긴 아몬드형. 굵은 윗선 1개가 눈꼬리 밖까지 뻗어 살짝 올라감. 홍채가 윗선에 닿음 |
| 눈썹 | 가늘고 둥긂, 눈에서 멂 | 굵고 곧음, 눈에 가까움, 코 쪽으로 내려감 |
| 코 | 코끝 그림자만 | 그늘 쪽 콧대 선을 길게 |
| 입 | 입술 색 칠함 | 선 1개와 아랫입술 밑 그림자 |
| 볼 | 옅은 홍조 | 홍조 없음 |
| 머리카락 | 길고 귀를 덮음 | 짧지만 부피가 있음. 정수리가 두개골보다 큼. 옆 가르마에서 쓸린 뾰족한 다발들, 미간으로 떨어지는 다발 1개, 귀 앞 옆머리. 옆과 뒤는 귀 높이에서 끝남 |
| 목 | 가늘고 김 | 굵고 목울대가 있음 |

- 머리카락 다발은 `portrait.lock_points(root, tip, width, bend)`로 만든다
    + 뿌리는 정수리 덩어리 안에 두고 이웃 다발과 겹친다. 사이가 벌어지면 이마 살이 톱니처럼 보인다
    + 다발마다 가운데에 끝이 가늘어지는 선을 긋는다 (`lock_centre_points`)
- 남성 얼굴이 밋밋해지는 주원인은 넓은 얼굴에 작은 눈이다. 얼굴을 좁히고 눈을 키운다

### 몸 (`MALE` 체형)

| 부위 | 여성 | 남성 |
|---|---|---|
| 어깨 폭 (어깨 관절 사이) | 0.30 | 0.36 |
| 엉덩이 | 허리보다 크게 벌어짐 | 허리보다 조금 넓음 |
| 가슴 | 가슴 2개, 아래로 처짐 | 납작한 가슴 근육 2개, 아래 가장자리에 골 |
| 배 | 매끈함 | 복근 2열 3단, 엉덩뼈 위 V자 능선 |
| 등 | 좁음 | 겨드랑이 아래 넓은 등 근육이 허리로 좁아짐 |
| 팔다리 | 매끈한 원통 | 이두근, 삼두근, 허벅지 앞 근육을 길쭉한 타원체로 녹여 붙임 |

    + `dataclasses.replace(MALE, ...)`로 필요한 값만 바꾼다
- 어깨 띠와 승모근은 목 뿌리보다 낮게 둔다. 높으면 목을 타고 올라가 머리가 어깨에 얹힌 것처럼 보인다
- 근육은 `Body.muscle()`로 붙인다. 뼈 축을 따라 놓인 길쭉한 타원체를 한쪽으로 밀어 넓게 녹인다
- 복근처럼 골이 남아야 하는 곳은 녹임 폭을 좁게(1.4cm), 덩어리로 읽혀야 하는 곳은 넓게(3cm) 준다

## 누드 인체

정밀 묘사보다 그럴듯함이 목표다. `examples/nude.py`가 마네킹으로 그린 입상, 좌상, 와상 3종을 담고 있다.

- 3차원 몸이 비례, 가림, 그림자, 골의 어둠을 맞춰 준다. 사람이 손으로 넣을 것은 적다
    + 유륜과 젖꼭지, 배꼽: `result.disc()`로 표면 위에 작은 원을 찍는다. `result.visible()`로 가려진 것은 건너뛴다
    + 무릎과 팔꿈치의 따뜻한 혈색: `art.blob()`을 얇게 얹는다
    + 따뜻한 반사광과 주광
- 마네킹에는 성기 형태가 없다. 예제는 다리가 만나는 곳을 매끈한 형태와 그림자로 둔다
    + 여성 예제는 매끈한 형태만으로 고전 누드처럼 읽힌다
    + 남성 예제는 매끈한 형태가 어색하므로 고전 조각처럼 자세나 천으로 사타구니를 가린다
    + 입상: 한 손으로 엉덩이에 잡은 천이 앞으로 늘어진다 (`sculpt.hanging_cloth()`)
    + 좌상: 한쪽 발을 받침에 올려 들린 허벅지가 몸 가운데를 가로지른다
    + 와상: 위쪽 다리를 앞으로 굽혀 겹친다
- 관능미는 묘사의 양보다 자세와 빛에서 나온다
    + 체중을 한 다리에 싣고 골반과 가슴을 반대로 기울인다
    + 한 팔을 머리 뒤로 올리면 몸통이 길게 늘어난다
    + 누운 자세는 위쪽 다리를 앞으로 겹치고 위쪽 팔을 엉덩이에 얹는다
    + 어두운 배경, 한쪽 주광, 반대쪽 가장자리의 따뜻한 반사광
- 화풍은 회화풍이 가장 잘 맞는다. 애니메풍은 명암 경계가 단순해져 만화 인체로 읽힌다
- 같은 장치가 남녀를 모두 그린다: `nude.draw_figure(style, width, setting, sitter)`
    + `Sitter`는 체형, 얹을 머리, 피부색을 묶는다 (`nude.WOMAN`, `nude_male.MAN`)
    + `Setting`은 카메라, 자세, 소품, 방, 덧붙일 물건(`extras`)을 묶는다

## 3차원 몸에 옷 입히기

`examples/figure_male.py`의 방식이다. 2차원 마스크로 옷을 입히는 아래 방식보다 자세 변화에 강하다. 비키니, 란제리, 정장, 후드티, 치마, 드레스, 스카프 같은 옷과 바람, 포즈 프리셋, 투샷, 장면은 `references/wardrobe.md`에 있다.

```python
from atelier.mannequin import TROUSERS, dress
dress(scene, marks, "shirt", ("chest", "abdomen"), 0.012, smooth=0.012)  # 셔츠 몸판
sleeves(scene, marks)                                                    # 곧은 원통 소매 (figure_male.py)
dress(scene, marks, "trousers", TROUSERS, 0.012, smooth=0.012)           # 골반, 허벅지, 정강이
dress(scene, marks, "shoes", ("foot",), 0.006, smooth=0.012)             # 신발 상자 속의 발을 덮는 얇은 막
```

- `dress()`는 몸 형태를 그대로 키워 옷을 만든다. 몸의 굴곡과 관절을 그대로 따른다
    + `smooth`는 근육 사이의 골을 천이 건너뛰게 한다. 0이면 옷 위로 복근이 비친다
    + `smooth`는 0.012 안팎으로 둔다. 녹임마다 부피가 조금씩 붙어 큰 값은 옷 전체를 부풀린다
- 셔츠는 몸을 키운 것이라 목 뿌리와 어깨 위까지 덮는다. 목선은 `scene.carve()`로 파낸다
    + 목 뿌리 둘레를 둥글게 한 번, 앞을 길쭉한 타원으로 한 번 파면 단추를 연 V 목선이 된다
    + 파낸 가장자리를 따라 짧은 막대를 이어 깃을 눕힌다 (`figure_male.open_collar()`)
- 소매는 몸에서 키우지 않는다. 어깨에서 팔꿈치, 팔꿈치에서 손목 위까지 곧은 막대 2개로 만든다
    + 팔을 키운 소매는 이두근과 삼각근을 그대로 드러내 보디빌더처럼 보인다
- 몸에 없는 것은 단순한 형태로 더한다
    + 일자 바지: 무릎 7cm 위에서 발목까지 굵은 막대 1개. 무릎에서 시작하면 천이 무릎뼈를 감싸 혹처럼 보인다
    + 깃: 목 둘레에 짧은 막대를 고리처럼 세움
    + 허리띠: 골반 둘레에 짧은 막대를 촘촘히 이음
    + 신발: 발 전체를 감싸는 둥근 상자. 타원체는 발끝에서 얇아져 발가락이 뚫고 나온다
    + 상자를 날씬하게 줄이면 발이 비친다. 발을 6mm 키운 막을 신발 무리에 더해 막는다
- 옷 입은 전신의 카메라는 눈높이 근처에 둔다. 엉덩이 높이에서 올려다보면 누구나 크고 강해 보인다
- 주머니에 넣은 손은 손을 바지 속으로 밀어 넣으면 된다. 앞의 천이 손가락을 가린다
- 몸 영역 이름: `neck`, `chest`, `abdomen`, `pelvis`, `upper_arm`, `forearm`, `hand`, `thigh`, `shin`, `foot`

## 옷 입히기 (2차원)

- 옷은 몸의 마스크에서 출발한다
    + 몸에 붙는 옷은 몸통과 팔 마스크에 옷 색을 칠한다
    + 품이 넓은 옷은 같은 관절 좌표에 더 굵은 튜브를 쓴다 (`TROUSER_LEGS`)
- 밑단은 직사각형 마스크를 곱해 평평하게 자른다
- 옷의 형태 그림자는 `bulge=30-40`의 납작한 입체로 준다
- 주름은 관절에서 뻗는 곡선 2-3개면 충분하다
- 가슴의 굴곡은 아래쪽 초승달 그림자 1개로 암시한다
