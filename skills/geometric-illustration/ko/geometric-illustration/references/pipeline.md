## 좌표계

- 머리 단위: 머리 폭 = 1, 원점 = 머리 중심, y 아래, z 관찰자 방향
- `HeadFrame.map(uv, z)`: 머리 단위 좌표를 화면 픽셀로 변환
    + `z='surface'`: 얼굴 표면 위의 점. 회전 시 깊이에 따라 이동
    + `z=None`: 실루엣 점. 회전해도 고정
- `BodyFrame.map(uv)`: 몸 좌표(머리 단위)를 픽셀로 변환. 마네킹 필드도 이 프레임으로 격자를 만든다.
- 인체 좌표(`rig_anatomy`): x는 인물의 왼쪽(정면 기준 화면 오른쪽), 쪽 번호 `s = +1`이 그쪽이다. 흉곽 중심 y 1.70, 골반 중심 y 3.40, 발목 8.10, 발바닥 약 8.43
- 장면 좌표
    + 풍경: 픽셀과 캔버스 비율
    + 도시: 미터 단위 거리 좌표(x 오른쪽, y 위, z 앞으로)와 핀홀 카메라(`Camera`)
    + 정물: 탁자 평면 y = 0, 위가 음수 y, 카메라 내려다보기 `PITCH`. 현대 세트는 단위를 키워 더 가깝게 잡음(`scene_modern.UNIT_FRAC`)

## Drawable 모델

`scene.Drawable` 1개는 화면 위 도형 1개다.

| 필드 | 의미 |
|---|---|
| `name`, `group`, `z` | 고유 이름, 재질 그룹, 앞뒤 순서(클수록 앞) |
| `fill`, `fill_mode` | 폴리곤 목록. `evenodd`는 구멍 허용, `union`은 스트로크 리본, `each`는 겹친 덩어리(구름, 잎) |
| `mask`, `line_mask`, `normal_map` | 마네킹이 미리 계산한 커버리지, 선, 법선 패치 |
| `color`, `gradient` | 단색, 2색 `(ca, cb, pa, pb)`, 다중 정지점 `([(t, rgb)...], pa, pb)` |
| `strokes`, `line_color` | 선화 스트로크와 색. 앞 도형에 가려진 선은 자동 제거 |
| `clip` | 다른 Drawable의 채움 영역으로 잘라냄 |
| `casts`, `receives` | 캐스트 섀도 생성 및 수신 |
| `receives_hair` | False면 머리카락 그림자를 받지 않음(옷 위에 얼룩처럼 떨어지는 그림자 방지) |
| `form_radius`, `form_poly` | 의사 법선 반경, 법선 계산용 대리 실루엣 |
| `kind` | `fill`, `shadow`, `highlight`, `form` |
| `clip_vis`, `subtract` | 그림자와 하이라이트의 적용 대상, 빼낼 폴리곤(구름 테두리 빛) |

z 관례: 배경과 하늘 -100, 장면 원경 -90에서 -50, 뒷머리 -10, 옷깃 안쪽 면(상반신과 전신) -0.05, 인체 몸 0에서 1, 구두 0.4, 해부 표식 선 1.01, 손톱 선은 손이 그려진 층 + 0.001, 의상 2-2.3, 들어올린 팔 2.5, 얼굴 5, 정물 소품 5 + 시점 깊이, 턱 괴기 손 5.5, 눈 6, 앞머리 10, 머리 넘기기 손 9.6, 김(steam) 40, 비 60

## 마네킹 형태 엔진

`mannequin.FormBuilder.build(name, group, z, pieces, ...)`가 Drawable을 만든다.

- `Solid`: 구 또는 양 끝 반지름이 다른 원뿔(구-스윕). 3D 좌표
    + 타원 단면 원뿔(`ellipse_cone`): 방향 `lat` 쪽 반지름과 그 직각 반지름이 다르다. 몸통처럼 폭과 두께가 다른 형태를 사슬 1개로 만든다. 시점에서 본 반폭, 깊이 진폭, 비틀림을 닫힌 식으로 계산(`_section`)
    + 타원 단면 원뿔의 끝 마감은 짧다(`CAP_LENGTH`). 사슬 안의 이음매는 `prev_dir`, `next_dir`가 주어지면 이등분선으로 잘라 맞붙인다(`_miter`, `MITER_REACH`, `MITER_MIN_COS`)
    + 타원체(`ellipsoid(c, axes)`): 세 반축 벡터를 임의 방향으로 둔다. 깊이는 광선의 2차식 해로 정확하고, 실루엣은 깊이 판별식이 0이 되는 타원(쉬어 보정)의 1차 거리다. 어느 시점에서도 정확하다
    + 타원체 스윕(`ellipsoid_sweep(centres, widths, heights, lats)`): 단면을 보간해 단면 두께의 20% 간격(`SWEEP_SPACING`)으로 타원체를 촘촘히 잇는다. 발처럼 납작하고 끝이 관찰자를 향하기 쉬운 형태에 쓴다. 조각 블렌드 `k`는 작게 둔다(촘촘한 입체에 큰 `k`를 주면 형태가 부푼다)
    + 관(`tube(points, radii)`): 관절점 사이를 나누고 중심과 반지름을 평활화한 원뿔 사슬. 손가락, 발가락
- `Piece`: 입체 묶음. 내부는 매끄럽게 합쳐짐(`k`). 트리 구조
    + `parent`와 `attach_n`: 앞쪽 `attach_n`개 입체만 부모와 매끄럽게 붙음(어깨, 손가락 뿌리). 나머지는 단단한 경계라서 엉덩이에 얹은 손이 녹아들지 않음
    + 트리의 뿌리는 1개다. `build`는 첫 조각에서 시작하는 트리만 그리므로 따로 떨어진 조각(헤드셋 이어컵 등)도 `parent`로 묶는다(`attach_n=0`이면 단단한 경계)
    + `contour_eps`: 가림선을 그리기 위한 최소 깊이 차. 가슴, 엉덩이처럼 부드럽게 솟는 형태는 크게 두어 아래쪽 곡선만 그림
- 필드 계산
    + 실루엣: 정확한 2D 거리(불균등 캡슐, Inigo Quilez)
    + 깊이: 원뿔은 축 위 구들 중 그 픽셀 위로 가장 높이 솟는 구의 높이(`_sweep_section`, 닫힌 식 + 축 기울기용 뉴턴 1단계), 구는 원형 단면 높이. 깊이 기울기가 법선
    + 윤곽선: 실루엣선(광원 반대쪽이 굵어짐) + 조각 i가 조각 j 앞을 지나는 곳의 가림선. 가림선은 i가 가장 앞 면일 때만 남음
    + 법선: 깊이장을 머리 폭 비례로 평활화(`NORMAL_SMOOTH`, 덮임 정규화)한 뒤 기울기에서 계산. 입체 이음새의 주름이 음영 줄무늬로 번지지 않음
    + 자기 그림자: 깊이장 광선 추적(`SHADOW_REACH`) 후 머리 폭 비례 블러(`SHADOW_SOFT`)
    + 긴 사슬(팔다리 스윕, 몸통 로프트)은 조각 내부 블렌드 `k`를 거의 0으로 둔다(`rig_anatomy.LIMB_K`). 맞붙은 이음매마다 `smin`이 작은 혹을 만들기 때문
    + 광택: 블린 반사(`gloss=(색, 지수, 불투명도)`)
- `select`: 일부 조각만 남긴 덧그림. 몸 전체는 의상 아래에 두고 팔과 손만 의상이나 얼굴 위에 다시 그릴 때 사용
    + 선택 밖 조각이 선택 조각을 가리는지는 그 조각이 실제로 덮는 픽셀에서만 깊이를 비교한다(`SELECT_EDGE_PX`). 깊이장은 입체 창 전체에 외삽되어 있어, 그대로 쓰면 덮지도 않는 몸통이 소매 안쪽을 가려 소매와 몸판 사이에 피부 띠가 생긴다
- `quiet_zones`: 내부 선을 그리지 않는 원형 구역. 단 `QUIET_KEEP` 접두사(`hand_`) 조각의 윤곽은 남겨 가리는 손의 외곽이 사라지지 않음
- 성능: 입체마다 자기 창 안에서만 계산, 큰 상자는 2배 성긴 격자 후 보간

## 레이어 해석 순서

`Resolver.resolve()`는 앞에서 뒤로 1회 순회한다.

1. 각 도형의 보이는 영역 = 채움 x (1 - 앞쪽 누적 덮임)
2. 선화 = (스트로크 + 선 마스크) x (1 - 앞쪽 누적 덮임)
3. 캐스트 섀도 = 앞쪽 `casts` 도형 덮임을 광원 반대로 이동한 값 x 현재 도형 보이는 영역
4. 법선 = `normal_map` 또는 `form_radius` 반경의 둥근 높이장 기울기
5. `form` 도형으로 법선 국소 융기 합성
6. `shadow`, `highlight` 도형을 `clip_vis` 영역에 합성(`subtract` 반영)

산출 레이어: `flat`, `line_rgb`, `line_a`, `normal`, `cast`, `shadow_shape`, `hl_rgb`, `hl_a`, `groups`, `detail`, `unit`, `kind`

## 돌린 몸과 시점 인지 의상

의상 인물의 몸 회전은 포즈 자체를 돌린다(`rig_figure.turned`). 흉곽과 골반 프레임의 yaw, 관절 위치, 팔다리 목표와 방향을 머리 중심을 지나는 세로축으로 돌린다. 몸과 옷이 같은 3D 좌표를 쓰므로 부풀린 몸 조각으로 만든 옷은 그대로 따라 돈다. 정면(`turn` 0)은 이전과 같은 코드 경로를 지나 픽셀까지 같다.

- 고리 각도는 몸 기준이다(theta 0 = 몸 앞). 보이는 반쪽은 `G.view_arc`가 고리의 화면 좌우 끝점(윤곽점) 사이에서 관찰자 쪽 호로 고른다. 목 고리(`NeckAxis`)도 몸 기준 기저를 쓰고 `arc`로 보이는 호를 받는다. 목선 처짐(`drop`)은 몸 앞에서 생긴다
- 휴식 좌표로 적은 윤곽(컵, 탱크톱, 브리프, 재킷 앞 트임)은 돌린 몸에서 `K.rest_mask`로 바뀐다. 옷 깊이장의 각 픽셀을 3D 점으로 되돌리고 `G.rest_coords`(흉곽과 골반 프레임 혼합의 역변환)로 휴식 좌표를 구해 앞면 또는 뒷면 윤곽에 넣어 본다. 그래서 의상마다 뒷면 윤곽을 둔다(`back_rest`, `back_outline`)
- 옷 위의 선과 점(솔기, 주머니, 라펠, 단추, 넥타이)은 `ctx.paths`, `ctx.points`, `ctx.patch`로 만든다. 휴식 좌표에서 곡선을 매끄럽게 한 뒤 몸통 표면 점과 법선(`G.surface_rest`)을 구해 관찰자를 향한 구간만 남긴다. `back=True`는 등 쪽 선(청바지 뒷주머니, 재킷 뒤 솔기)
- 팔다리 고리(소매, 바짓단)는 원래 관찰자 기준이다. 몸 기준 각도가 필요한 줄무늬와 주름은 `limb_view_thetas`로 바꾼다
- 돌린 몸에서는 다리가 화면에서 겹친다. 바짓단 자르기 다각형은 그 다리 영역(`LIMB_FOOT_REACH`) 안에서만 자르고, 맨다리(`bare_legs`, 밑단보다 조금 아래부터)는 다른 다리의 옷을 가리는 차단 조각이 된다
- 스커트의 수직으로 걸리는 부분(`HangFrame`)도 몸 회전만큼 돈다. 보이는 반쪽은 관찰자 쪽을 중심으로 칠한다
- 머리: 2D 얼굴 리그는 -0.35에서 0.35 yaw만 그린다. `head_view`가 몸 회전에서 얼굴 yaw를 정하고(`TURN_YAW`), 1.9 라디안 이상 돌면 뒤통수(`rig_face.build_back_head`, `rig_hair.back_view_hair`)를 그린다. 등이 보이는 몸에서 긴 머리는 등 위(z 3)에 떨어지고(`long_fall`), 옆으로 돌면 뒤쪽으로 밀린다(`HAIR_BACK_SHIFT`)
- 후드는 등이 보이면 옷 위로 올라온다

## 끈과 가림

`K.strap`은 끈을 3D 경로로 받는다. 화면에서 1.5 px 간격으로 다시 나눈 뒤 각 점이 몸 깊이장보다 뒤에 있거나(가림) 바깥 법선이 관찰자 반대쪽이면(뒤로 돌아감) 숨긴다. 보이는 구간마다 리본 1개를 그린다.

- 몸 표면 위의 구간은 깊이장에서 깊이를 읽어 붙인다(`K.surface_points`)
- 목을 도는 홀터 끈은 그려진 목 윤곽에 닿는 반지름(`outfits.neck_fit_radius`, 목과 승모근이 섞여 원뿔보다 넓음)의 고리다. 끈은 목 윤곽에서 정확히 돌아 들어간다
- 어깨를 넘는 끈(브라)은 앞면 점, 승모근 꼭대기 점(`'free'`), 등 쪽 점을 잇는다(`ctx.strap_rest`)
- 몸판의 일부인 끈(크롭탑)은 가장자리 선을 옷 윤곽까지 그린다(`edges_to_form`). 옷 윤곽이 어깨를 넘는 끈의 윗변이 된다
- 옷은 깊이와 무관하게 몸 위 층이다. 돌린 몸의 몸에 붙는 상의는 맨 목을 차단 조각으로 넣는다(`neck_blocker`). 넣지 않으면 목 뒤로 지나는 먼 쪽 끈이 목 앞에 보인다
- 돌린 몸의 반바지는 골반 앞쪽에서 가까운 다리 밑단 안쪽 끝까지 구분선을 그린다(`turned_inseam`). 헐렁한 두 다리가 한 덩어리 스커트처럼 보이지 않는다
- 팔은 의상 위에 다시 그린다(`arms`). 돌린 몸에서는 상의 레시피가 등록한 몸통 옷 조각(`ctx.cover`)을 차단 조각으로 넣어, 몸통 옷이 앞에 있는 곳에서는 팔을 숨긴다. 그래서 `build_figure`는 의상을 먼저 만들고 팔을 나중에 만든다
- 돌린 몸의 터틀넥 진동(소매 구멍)은 휴식 좌표 마스크를 넓게 흐린 뒤 다시 날카롭게 만들어 계단을 없앤다(`TOP_MASK_SMOOTH`). 진동 선은 그 마스크 경계에 그린다(`cut_edge_line`). 휴식 좌표 경로로 그린 선은 다른 표면에 놓여 겨드랑이 피부 위로 지나간다

## 투샷과 배경 합성

- `character.build_group`이 인물마다 완전한 명세를 만든다(`group_character`: 기본값, 성별 프리셋, 의상 색, 인물 필드)
- `group_layout`이 머리 중심, 단위, z 대역, 기본 회전을 정한다. 가장 큰 인물이 프레이밍에 맞고 바닥은 공통이다(앉은 인물은 의자 높이의 바닥)
- 인물마다 `use_build` 안에서 그린 뒤 `namespaced`가 이름에 `p{i}_`를 붙인다. `clip`은 같은 인물 안의 이름이라 함께 바뀐다. 두 번째 인물부터 z를 25씩 뒤로 보낸다(인물 1명의 z 범위는 약 -10에서 12)
- 음영, 광택, 형태 덧그림의 `clip_vis`가 재질 그룹이면 그 인물이 가진 같은 그룹의 이름 목록으로 바꾼다. `clip_vis`가 없으면 자기 그룹으로 본다. 재질 그룹은 그림 전체에 걸쳐 있어 그대로 두면 뒤 인물의 음영이 앞 인물 피부에 번진다
- 손잡기는 두 인물의 안쪽 손목 목표를 화면 사이의 한 점으로 정해 `pose.custom`에 넣는다. 회전한 인물은 회전 전 좌표로 되돌려 넣는다
- 배경 합성(`background.type: scene`)은 장면 모듈이 캔버스 전체를 그리고 인물을 위에 얹는다. 장면의 광원을 쓰고 인물 팔레트에 시간대 색조를 곱한다(`tinted`)
- 장면 Drawable은 z를 `BACKDROP_DROP`(100)만큼 내린다. 장면의 z는 약 -19까지 올라와 두 번째, 세 번째 인물 대역(-35, -60)과 기둥, 바닥 그림자보다 앞에 놓인다
- 장면 위 바닥 그림자는 어두운 색을 반투명으로 얹는다. 배경 팔레트 색은 밤 장면보다 밝아 빛나는 얼룩이 된다
- 장면 위 바닥 그림자의 그룹은 `scenery`다. `bg` 그룹은 수채에서 종이 여백으로 비워진다

## 확장 절차

### 인물 포즈 추가 (`rig_figure.POSES`)

- `_base()`로 체중 이동 자세를 만든 뒤 팔 `Limb`를 교체하는 함수를 등록
- `Limb(target, pole, hand, hand_u, hand_n)`
    + `target`: 손목 위치, `pole`: 팔꿈치가 향하는 방향
    + `hand_u`: 손목에서 손가락 방향, `hand_n`: 손등 방향
- 손이 얼굴이나 머리카락 앞에 와야 하면 `HAND_OVER`에 제스처별 z를 지정
- 옷 아래로 숨길 손은 제스처 `pocket`. 들어 올린 팔 덧그림에서 빠지고 소매, 옷의 차단 조각에서도 빠진다
- 포즈가 기본 시점을 가지면 `POSE_VIEWS`에 (회전, look, 얼굴 yaw)를 넣는다. 걷기처럼 정면에서 읽히지 않는 포즈에 쓴다
- 소품이 필요하면 `pose.prop`(`'wall'`, `'chair'`)을 두고 `build_figure`에서 그린다. 앉은 포즈는 `flat_ankle`(바닥 높이)과 `SEATED`(프레이밍) 등록
- 보폭처럼 평발 신발에서도 뒤꿈치를 든 발은 `keep_steps`
- 남성 손목 목표 보정은 `MALE_TARGETS`

### 체형 추가 (`rig_anatomy.BUILDS`)

- `_BUILD_KEYS`의 값(몸통 로프트, 어깨와 고관절 위치, 팔다리 프로파일, 목, 손, 가슴 형태, 엉덩이, 머리 크기, 어깨띠)을 새 사전으로 넣는다
- 세로 기준 높이(목 1.07, 허리 2.70, 배꼽 2.96, 골반 앞쪽 4.08, 무릎 5.96, 발목 8.10)는 바꾸지 않는다. 옷 재단선이 이 높이를 쓴다
- 렌더는 `character.build_scene`이 `use_build(spec['character']['sex'])` 안에서 만든다. 체형 값을 함수 기본 인자로 묶지 않는다(정의 시점 값이 굳어 전환이 무시된다)
- `config.SEX_PRESETS`에 얼굴, 머리, 의상 기본값을, `check_proportions.TARGETS`에 측정 목표를 넣고 `python scripts/check_proportions.py --build 이름 --sheet turn.png`로 확인한다
- 의상 포즈의 손목 목표가 몸에 닿지 않으면 `rig_figure.MALE_TARGETS`처럼 체형별 목표를 둔다
- 같은 성별의 체형 변형은 `VARIANTS`에 배율 표 1행으로 추가하고 `BUILD_TYPES`에 이름을 넣는다(`references/anatomy.md` 체형 변형). 검사 목표는 자동으로 만들어진다

### 표정과 얼굴 프리셋 추가 (`config.EXPRESSIONS`, `FACE_PRESETS`)

- 1행 = 얼굴 부위별 변경. `key*`는 곱, `key+`는 더함, 그냥 키는 설정
- 벌린 입은 `mouth.open`, 감은 눈은 `eyes.shape: closed`(`rig_face.open_mouth`, `closed_eye`)
- 얼굴 프리셋 결과는 `FACE_LIMITS`(성인 얼굴 범위) 안으로 보정된다

### 머리 모양 추가 (`rig_hair.HAIR_PRESETS`)

- 세 기본 빌더(`long`, `updo`, `short`) 중 하나와 덮어쓸 필드를 적는다. 새 형태가 필요하면 빌더에 플래그를 더한다(`undercut`, `tail`)
- 뒤통수 그림은 `back_view_hair`가 같은 프리셋을 해석해 그린다
- 옆머리 다발은 고정 모양 점 중 끝부분보다 위에 있는 점만 쓴다(`lock_points`, `LOCK_GAP`). 짧은 `side_length`에서 다발이 위로 꺾여 접히지 않는다

### 인체 습작 포즈 추가 (`rig_figure_study.POSES`)

- `A.standing_pose()`를 복사해 흉곽과 골반 회전, 위치, 팔다리 목표, 시점(`view_yaw`, `root_roll`), 얼굴 방향을 지정
- 흉곽과 골반 위치는 `_at(A.CHEST_ORIGIN, dx, dy, dz)`처럼 기준 원점의 상대값으로 적는다. 비례를 바꿔도 포즈가 깨지지 않음
- 서 있는 발은 `foot_dir`의 y 성분을 0으로 둔다(발바닥이 수평)
- 들어 올린 발(`hand='point'`)은 발가락이 발볼에서 꺾여 바닥에 눕는다. 발목 목표를 서 있는 발목보다 약 0.55 높게 두고 `foot_dir`를 아래로 세운다(예: `(-0.12, 0.85, 0.5)`)
- 누운 자세는 골반과 흉곽 프레임 자체를 90도 굴려서 만든다(`pose_reclining` 참조)
- 새 포즈는 가슴과 골반이 자세, 손, 머리카락, 천 중 하나로 가려지도록 설계한다. 정면 상체가 드러나면 `chest_lock`이나 팔로 가린다.
- 등 방향 시점이면 `hide_chest=True`

### 해부 표식 추가 (`rig_anatomy.anatomy_marks`, `leg_marks`)

- 표식 1개 = (이름, 종류, 기준 프레임, 향하는 면, 3D 점 목록). 종류는 `ink`(옅은 선), `groove`(좁은 그림자 홈), `dot`(작은 그림자 점)
- 점은 몸 표면 위에 둔다. 몸통은 `loft_surface(chest, pelvis, y, x비율, back)`로 표면 점을 구한다
- 렌더 시 기준 프레임의 법선이 관찰자를 향할 때만(`FACING_MIN`), 그리고 점이 보이는 표면에서 `MARK_SURFACE_TOL` 안에 있을 때만 그린다. 연속으로 보이는 점 2개 이상이어야 선이 된다

### 손 제스처 추가 (`rig_hand.GESTURES`)

- 손가락별 `(벌림, MCP, PIP, DIP)` 굽힘 각(라디안), 엄지는 손 좌표의 끝점 목표 `(u, v, n)`
- 엄지는 끝점까지 일정 곡률 호로 자동 배치된다.
- 주먹은 MCP보다 PIP를 크게 굽힌다(손등 쪽에서 마디가 보임)
- 엄지 끝을 손바닥 폭 밖으로 멀리 두면 막대처럼 튀어나온다. 손등 방향 성분 `n`은 -0.3에서 0 사이가 자연스럽다
- 확인은 `python scripts/check_proportions.py --hands hands.png`(손등, 엄지 쪽, 손바닥 3방향)가 `--stages`보다 빠르다.
- 손톱은 리그가 만든 윤곽을 `marks.nails`가 그린다. 화면에서 `NAIL_MIN_PX` 미만이면 생략된다

### 모자 추가 (`rig_hat.HATS`)

- `HATS`에 이름을 추가하고 `build_hat`의 분기에 함수 1개를 둔다. 반환은 머리 프레임 위 Drawable 목록
- z는 `HAT_Z`(머리카락 최상층 위)로 두어 모자 아래 머리카락을 가린다. 단 아래로 나올 머리는 모자 윤곽 밖에 남는다
- 실루엣은 `frame.map(..., z=None)`, 얼굴 쪽 선은 표면 깊이로 매핑해 머리 회전을 따르게 한다. 뒷모습(`away=True`)은 모든 점을 실루엣으로 매핑한다
- 색은 팔레트 키 1개(`hat`)를 쓴다

### 의상 추가

- 바스트업 2D 의상: `rig_body.build_bust_outfit` 분기(`turtleneck_sleeveless`만). 다른 의상은 바스트업에서도 3D 의상 경로를 쓴다
- 3D 의상: `outfits.RECIPES`에 함수 1개를 등록하고 `SHOES`에 신발(`pumps`, `sneakers`, `none`), 남성 신발 예외는 `MALE_SHOES`(`oxfords`), 남성 허용은 `MALE_OUTFITS`, `config.OUTFIT_PALETTES`에 기본 색을 넣는다
- 돌린 몸을 위해 레시피는 2D 점(`ctx.surf`)을 직접 쓰지 않고 `ctx.paths`, `ctx.points`, `ctx.patch`, `ctx.strap_rest`를 쓴다. 몸에 붙는 옷과 브리프에는 뒷면 윤곽을 준다. 앞 트임은 `sleeved_top(front_cuts=...)`
- 인쇄된 색 띠(트레이닝복 줄, 지퍼)는 `K.band_stripe`(밑색 그대로 칠함. `K.lines`는 어둡게 한 선화 색)
- 긴 코트 자락은 `G.build_skirt(..., name, color, top_y)`와 주름 깊이(`skirt_folds`)로, 앉은 자세는 `lap_skirt`로 그린다
- 레시피는 4가지 구성으로 짠다
    + 몸에 붙는 옷(`fitted_top`, `briefs`): 해당 몸 조각을 얇게 부풀린 뒤 휴식 자세 좌표의 윤곽(`keep`) 안만 남긴다. 컵, 브리프, 크롭탑
    + 관 모양 옷(`trousers`, `sleeved_top`): 몸통과 팔다리를 부풀린 뒤 허리, 목, 밑단 고리로 자른다(`waist_cut`, `neck_cut`, `hem_cut`). 팔다리 끝은 `tubes`가 비율 위치(엉덩이 0, 무릎 1, 발목 2 / 어깨 0, 팔꿈치 1, 손목 2)에서 자른다
    + 띠(`band`): 몸통 단면 고리 2개 사이를 채운 띠. 벨트, 허리 밴드
    + 선과 작은 도형(`K.lines`, `K.ribbon`, `K.patch_shape`, `K.dots`): 솔기, 주머니, 라펠, 끈, 넥타이, 단추
- 소매가 있는 상의는 어깨 꼭대기(`SHOULDER_CAP`)까지를 몸판에 넣고, 목 옆에서 어깨 끝까지 천이 걸치는 원뿔(`shoulder_bridges`)을 더한다. 어깨선이 곧게 이어지고 소매가 퍼프처럼 부풀지 않는다
- 소매가 있는 상의는 몸판과 소매를 따로 그린다. 소매 조각은 이름 접두사를 따로 쓴다(몸판의 어깨 조각과 이름이 같으면 서로 덮어쓴다). 밑단과 목선은 몸판만, 소맷단은 소매만 자른다. 소매는 몸판이나 맨손이 앞에 있으면 가려진다(`blockers`)
- 목까지 올라오지 않는 목선은 몸의 목 원뿔을 빼고 부풀린다(`without_neck`). 넣으면 목 둘레에 옷이 기둥처럼 남는다
- 목선 자르기는 모든 겹의 옷이 같은 고리 반지름(`NECK_CUT_EASE`)을 쓴다. 안쪽 옷이 더 좁게 잘리면 겉옷 옆으로 삐져나온다
- 목선 고리는 가슴과 수평으로 눕힌다(`NeckAxis.ring(level=True)`). 목에 직각인 고리는 고개가 기울면 한쪽 끝이 내려가 어깨와 어긋난다
- 목선 고리의 양 끝 너머는 어깨 쪽으로 완만히 올라가는 곡선으로 자른다(`NECK_RAMP_RUN`, 높이는 옷 여유 + `NECK_RAMP_RISE`). 승모근 위로 부푼 천이 고리보다 높아 수직으로 자르면 목 옆에 계단이 남는다
- 앞이 트인 겉옷의 트임 윗변(`OPEN_TOP_Y`)은 목 고리보다 위에 둔다. 아래에 두면 목 앞을 가로지르는 깃 조각이 실선으로 남는다
- 짧은 하의는 두 밑단을 잇는 선 아래를 잘라 낸다. 몸통의 아래 끝이 다리 사이에 매달려 보이지 않는다
- z: 수영복, 속옷, 소매 없는 상의는 다시 그린 팔(2.5) 아래, 소매가 있는 옷은 그 위(2.55-2.6). 후드 모자는 목 뒤(-0.5)
- 상반신, 전신 터틀넥과 스커트는 `garment3d`의 `build_top`, `build_belt`, `build_skirt`를 쓴다. 모두 몸 마네킹과 같은 자세 프레임(`rig_anatomy._torso_point`)을 쓴다
    + 몸에 붙는 옷: 해당 몸 조각을 옷 두께만큼 부풀려(`grown`) `FormBuilder`로 그린 뒤 2D 경계 다각형(진동둘레, 허리)으로 자른다. 윤곽, 음영, 가림선이 몸을 그대로 따른다
    + 몸을 두르는 띠: 몸통 단면을 부풀린 3D 고리(`torso_ring`)의 앞쪽 절반을 투영한다. 띠의 끝은 몸 옆선에서 끝난다
    + 늘어지는 옷: 높이별 몸 단면을 구해 일정 기울기로 떨어지는 포락선(`drape`)을 만들고, 그 단면을 3D 격자로 칠한다(`paint_mesh`). 엉덩이 아래는 골반 기울기 대신 수직으로 걸린다(`HangFrame`)
    + 눈높이(`EYE_Y`) 아래의 고리는 앞쪽이 아래로 휜다(`perspective`). 띠와 밑단이 몸을 감싼다는 단서다
    + 옷은 `receives_hair=False`로 둔다
- 목을 감싸는 옷깃
    + 바스트업은 `rig_body.build_collar`의 2D 옷깃을 쓴다
    + 상반신과 전신은 목 원뿔을 따라 부풀린 관(`garment3d.collar_piece`)을 상의 입체에 넣어 몸판에서 그대로 솟게 한다. 윗단, 접힌 띠의 아랫선, 세로 골은 목을 두르는 고리(`NeckAxis.ring`)로 그린다
    + 옷깃 옆선은 둥근 곡선(`COLLAR_FILLET`)으로 진동둘레 선에 이어진다. 두 선이 한 점에서 꺾이면 이음매에 모서리가 남는다
    + 옷깃 안쪽 면은 목보다 뒤(z -0.05)에 둔다. 안쪽 면이 목보다 앞이면 옷깃이 목 앞에 떠 보인다
- 신발이 펌프스가 아니면 포즈의 발뒤꿈치를 바닥에 내린다(`rig_figure.flat_feet`)
- 새 재질 그룹은 `config.DEFAULT_SPEC`의 `shadow_tint`, `cel_threshold`에 같은 이름으로 추가
- 확인: `type`만 바꾼 명세를 포즈 4종(`relaxed`, `hand_on_hip`, `hair_touch`, `chin_rest`)으로 렌더한다. 팔을 굽힌 포즈에서 소매와 밑단 자르기가 몸을 베지 않는지 본다

### 장면 추가

- 함수 시그니처: `build_x(spec, w, h, rng) -> (drawables, light_direction, unit_px)`
- 시간대를 지원하려면 장면 모듈에 `PALETTES[time]`, `LIGHTS[time]`를 두고 `scene_common.scene_time`, `FX[time]` 스위치로 해, 달, 별, 비, 창문 불빛, 젖은 바닥을 켠다
- `character.SCENES`에 등록
- 하늘은 그룹 `sky`, 자체 발광은 `emissive`, 디자인 색 그대로인 요소는 `scenery`
- 깊이는 `scene_common.haze(color, depth)`로 표현: 멀수록 지평선 색에 가까워짐

### 장소 추가 (`scene.site`)

- 장면 모듈의 `SITES`에 이름을 추가하고 장면 빌더의 장소 분기에 함수 1개를 둔다. 첫 값이 기본 장소다
- 카메라, 하늘, 시간대 효과는 기존 장소와 공유한다. 새 장소에만 쓰는 색 키는 `snow_night` 같은 시간대 행에 직접 두고, 나머지 시간대는 기존 키에서 파생한다(`scene_landscape._outskirts_palette`)
- 인물 배경 합성(`background.type: scene`)에서도 같은 `scene.site`를 읽는다

### 시간대 추가 (`scene_common.SKIES`, `FX`)

- `SKIES`에 하늘색 1행, `FX`에 효과 스위치 1행(`sun`, `rim`, `windows`, `lamps`, `moon`, `stars`, `rain`, `wet`, `snow`)을 추가
- 각 장면 모듈의 `PALETTES`, `LIGHTS`에 같은 이름의 행을 추가
- 인물 배경 합성에 쓰려면 `character.SCENE_TINTS`, `SCENE_RIMS`에도 행을 추가한다
- 젖은 바닥 반사는 핀홀 카메라에서 높이 H의 빛을 바닥 아래 -H 지점으로 뒤집어 세로 빛기둥으로 그린다(`scene_city._reflection`)

### 정물 세트 추가 (`scene_modern`)

- `SETS`, `PALETTES`, `LIGHTS`에 세트를 등록하고 `build_modern`의 분기에 함수 1개를 추가
- 단단한 물체는 `scene_props`(평면 다면체 `solid`, `table_box`, 원기둥 `cylinder`, 접시 `disc`, 기울어진 원뿔대 `frustum_hull`), 부드러운 물체는 마네킹 조각으로 만든다
- 화면 내용은 `inset`으로 디스플레이 면 위 사각형을 구해 그룹 `screen`(음영 없음)으로 그린다
- 그림자는 `cast_shadow`가 각 점을 높이만큼 광원 반대쪽으로 밀어 테이블 위 볼록 껍질로 만든다

### 화풍 추가

- 함수 시그니처: `render_x(layers, spec, pal) -> float32 RGB (h, w, 3), 값 0-1`
- `render.STYLE_RENDERERS`에 등록
- 공용 부품: `styles.soft_shaded`, `styles.apply_lines`, `styles.multiply_shadow`, `styles.screen`, `styles.bloom`, `styles.grade`, `styles.backdrop`

### 색보정 룩 추가 (`looks.LOOKS`)

- 함수 시그니처: `look_x(img, rng) -> float32 RGB`, 입력과 출력 모두 값 0-1
- `LOOKS`에 이름을 추가하고 `apply_look`의 분기에 연결한다. 상수는 `DOOMER`처럼 이름 붙은 사전 1개에 모은다
- 룩은 완성 이미지 위에서만 동작하며 레이어를 읽지 않는다. 화풍과 독립이므로 4개 화풍 모두에 같은 룩이 적용된다
- 완성 이미지는 항상 `render.paint`로 만든다(CLI, 도구 스크립트 공통). 화풍 렌더러를 직접 부르면 룩이 빠진다

## 디버깅

- `--stages`로 공정별 이미지를 보고 결함이 처음 나타나는 단계를 찾는다.
- 인체 형태를 바꿨다면 `python scripts/check_proportions.py --sheet turn.png`를 먼저 실행한다. 비례 오차와 윤곽 변곡점(혹) 수가 기준을 넘으면 실패하고, 회전 시트(정면, 3/4, 측면, 뒷면)로 실루엣과 음영을 확인한다(`references/anatomy.md`의 검수 절차)
    + 구조선 단계: 프레임, 스켈레톤 목표점
    + 선화 단계: 곡선 제어점, z 순서, 가림선
    + 밑색 단계: 폴리곤 방향, `fill_mode`
    + 음영 단계: 법선, `cel_threshold`, 자기 그림자
- 특정 Drawable의 선을 찾을 때는 `character.build_scene(spec)` 결과에서 `line_mask`를 영역별로 확인한다.
- 리본 폴리곤이 꼬여 구멍이 생기면 `fill_mode='union'`, 겹친 덩어리에 구멍이 생기면 `'each'`
- `clip`은 이름 목록의 교집합이다. 도로와 인도 둘 중 하나에 그리려면 Drawable을 나눠 각각 1개 이름으로 자른다
- 렌더 1회의 최대 메모리는 0.4-0.9 GB다(전신 유화가 가장 큼). 병렬 렌더는 사용 가능한 메모리를 1 GB로 나눈 수 이하로 둔다
