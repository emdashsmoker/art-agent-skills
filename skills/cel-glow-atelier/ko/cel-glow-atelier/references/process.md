# 작화 공정

사람 작가의 공정을 코드 작업에 대응시킨 문서. 각 단계의 산출물과 판단 기준을 정의함.

## 목차

- 1단계 기획
- 2단계 디자인
- 3단계 형태
- 4단계 채색
- 5단계 명암
- 6단계 선
- 7단계 후보정
- 8단계 검수
- 수정 반복 요령

## 1단계 기획

- 산출물은 3줄 브리프
    + 누구를 그리는가 (나이대, 인상, 머리, 복장)
    + 어떤 분위기인가 (시간대, 감정, 온도감)
    + 어떤 화풍인가 (anime, illust, painterly)
- 사용자가 지정하지 않은 항목은 분위기에 맞춰 직접 결정
- 인상은 얼굴 파라미터로 번역
    + 차갑고 날카로운 인상 : `jaw_sharpness` 0.85 이상, `eye_tilt` 0.016, `smile` 0.1-0.3
    + 부드럽고 온화한 인상 : `jaw_sharpness` 0.3-0.5, `eye_tilt` 0.004, `smile` 0.6 이상
    + 성숙한 인상 : `eye_height` 0.080-0.090, `eyelid_open` 0.88, `chin_length` 1.05
    + 어려 보이는 인상 : `eye_height` 0.10 이상, `iris_scale` 1.1, `chin_length` 0.95
- 눈매와 눈썹 프리셋으로 인상을 한 번 더 굳힘
    + 차갑고 날카로운 인상 : `eye_shape` `upturned`, `brow_shape` `straight`
    + 부드럽고 온화한 인상 : `eye_shape` `droopy`, `brow_shape` `arched`
    + 담백한 인상 : `eye_shape` `monolid`, `nose_shape` `dot`
- 시점도 기획 단계에서 정함
    + 정면 : 얼굴과 표정이 주인공인 그림
    + 반측면 (`head_turn` 1.5-2.5) : 얼굴의 입체와 턱선이 주인공인 그림
    + 옆모습 (`side_*`) : 걷기, 앉기처럼 동작과 실루엣이 주인공인 그림
    + 뒷모습 (`back_*`) : 풍경을 바라보는 장면, 어깨 너머로 돌아보는 장면
- 등장인물 수도 기획 단계에서 정함
    + 1명 : `figure`
    + 관계가 있는 2명 (커플, 친구) : `duo`의 `pose`로 관계를 정함 (나란히, 손잡기, 팔짱, 어깨 감싸기, 마주 보기)
    + 관계가 없는 주변 인물 : `extras`

## 2단계 디자인

- 산출물은 팔레트와 구도 메모
- 팔레트는 13개 색을 한 번에 결정
    + 주조색 1개 (머리 또는 의상), 보조색 1개 (배경), 강조색 1개 (홍채 또는 소품)
    + 강조색은 화면에서 가장 작은 면적에 가장 높은 채도로 배치
- 구도는 `placement`와 포즈 3개 키로 결정
    + 전신 리그는 `shot`으로 자르는 위치를 먼저 고름 : 몸 전체 `full`, 몸매와 의상 `thigh`, 표준 확대 `knee`, 대화와 표정 `waist`
    + `shot`에서는 `x`로 인물을 한쪽에 두어 배경(창, 침대, 소실점)에 여백을 줌
    + 긴장감이나 역동성이 필요하면 `finish.tilt` 3-8도
    + `head_height` 0.38-0.45 : 흉상 표준
    + `eye_center` x 0.45-0.55 : 고개를 돌린 방향에 여백을 더 주면 안정적
    + `head_turn`, `head_tilt`, `gaze` 조합으로 시선 흐름 설계
- 광원은 1개만 사용하고 좌상단(135도)을 기본으로 함

## 3단계 형태

- 리그가 처리하는 영역 : 얼굴 윤곽, 눈, 코, 입, 머리카락, 목, 어깨, 의상
- 형태 검증은 `--stages` 출력의 1번 패널로 수행
    + 비례 기준선 6개 (정수리, 눈썹, 눈, 코, 입, 턱) 확인
    + 실루엣만 보고 인물로 읽히는지 확인
- 자유 장면에서는 큰 덩어리부터 작은 덩어리 순으로 작성
    + 원경, 중경, 근경 순서로 레이어 생성
    + 각 요소는 제어점 4-8개의 스플라인으로 시작

## 4단계 채색

- 밑색은 부위마다 1색, 공정 시트 2번 패널이 이 단계에 해당
- 밑색만으로 색 조화가 성립하는지 먼저 확인
    + 밑색이 어색하면 명암과 후보정으로 해결되지 않음
- 피부에는 붉은 기를 부분적으로 얹어 생기를 줌
    + 위치는 볼, 눈가, 코끝, 입술 아래 (리그가 자동 처리, `airbrush`로 강도 조절)

## 5단계 명암

- 명암은 4종류이며 모두 광원 벡터 1개에서 산출
    + (형태 음영) 덩어리가 광원을 등지는 면
    + (투영 음영) 앞머리가 이마에, 턱이 목에, 옆머리가 어깨에 던지는 그림자
    + (접촉 음영) 턱 밑, 목 뒤 머리카락처럼 맞닿은 곳의 짙은 어둠
    + (림라이트) 광원 쪽 가장자리의 밝은 띠
- 화풍 차이는 음영 경계의 단단함에서 나옴
    + anime : `shadow_softness` 0.02, 경계가 칼같이 선명
    + illust : 0.16, 경계가 부드럽게 번짐
    + painterly : 0.30, 넓게 풀어지고 붓 터치가 질감을 담당
- 그림자색은 명도와 함께 색상도 이동시킴
    + 피부 그림자는 붉은 쪽으로, 흰 옷 그림자는 푸른 보라 쪽으로 이동

## 6단계 선

- 선은 채운 면의 가장자리에서 자동 생성됨
    + 선 색은 인접한 면의 색을 어둡고 진하게 만든 색 (색선)
    + 선 굵기는 광원 쪽에서 가늘고 그림자 쪽에서 굵음 (`line_variation`)
- 내부 선은 끝이 가늘어지는 테이퍼 스트로크로만 그림
    + 굵기가 일정한 선은 도면처럼 보임
- 회화풍은 색면의 경계로 형태를 표현 (`line_width` 0)

## 7단계 후보정

- 화풍별 기본 체인이 자동 적용됨
    + anime : 확산 글로우, 블룸, 색 보정, 그레인
    + illust : 글로우, 블룸, 색 보정, 비네트, 그레인
    + painterly : 붓 터치 재구성, 색 보정, 캔버스 결
- `finish` 키로 항목별 강도 조절
    + `shadow_tint`와 `highlight_tint`는 배경의 어두운 색과 밝은 색에서 가져오면 인물과 배경이 한 조명 아래 놓임
- `ambient`는 인물 하반부에 배경색을 얹어 인물을 장면에 안착시킴

## 8단계 검수

- 최종 PNG를 직접 열어 확인하고 얼굴은 확대하여 재확인
- 확인 순서는 큰 것에서 작은 것
    + 실루엣과 구도
    + 색 조화와 명암 방향
    + 얼굴 (눈, 턱선, 입)
    + 머리카락 경계와 틈
    + 가장자리 결함
- 결함을 발견하면 원인 단계로 돌아가 수정
    + 형태 문제를 후보정으로 덮지 않음

## 수정 반복 요령

- 1회 수정에 1-3개 키만 변경
    + 여러 키를 동시에 바꾸면 무엇이 효과를 냈는지 알 수 없음
- 수치는 허용 범위 안에서 10-20%씩 이동
- 빠른 확인이 필요하면 `canvas`를 [800, 1000]으로 줄여 렌더 (약 3초)
- 머리카락 모양만 바꾸려면 `hair_seed` 변경
- 3회 수정으로 해결되지 않는 결함은 리그의 한계일 가능성이 높으므로 사용자에게 알리고 대안을 제시
