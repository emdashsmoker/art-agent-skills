# 풍경 조립

수치는 `examples/landscape.py`에서 검증한 값이다.

## 깊이를 만드는 규칙

- 먼 것은 옅고 푸르다
    + 원경, 중경, 근경의 색을 밝은 청회색에서 짙은 남색 순으로 정한다
- 뒤에서 앞으로 겹친다
    + 하늘, 구름, 먼 산, 가까운 산, 물, 근경 순으로 그린다
- 세부는 근경에만 둔다
    + 가장 먼 층을 그린 직후 `art.blur(2)`로 흐린다

## 하늘

```python
art.paint(art.everywhere(), sky_top)
art.paint(art.ramp((0, 40), (0, horizon - 120)), sky_mid)
art.paint(art.ramp((0, horizon - 170), (0, horizon)), sky_low)
```

- 그라데이션은 2-3단으로 쌓는다
- 해와 달은 `art.light(art.blob(center, 260), color, 0.55)`로 번짐을 먼저 깔고 원판을 얹는다

## 뭉게구름과 수관

- 공을 쌓아 만든다. 방법은 `examples/meadow.py`의 `puffs()`와 `draw_cloud()`에 있다
    + 가운데는 높고 양 끝은 낮게, 크기가 다른 공 10-25개를 배치한다
    + 새 공은 이미 놓인 공과 닿을 때만 추가한다. 떨어진 공은 떠다니는 조각이 된다
    + 위쪽 공을 먼저, 아래쪽 공을 나중에 그린다
    + 공마다 `bulge` 없이 `part(..., outline=False)`로 그리면 공 하나하나가 구로 음영된다
    + 전체 아래쪽에 `art.ramp()` 그림자를 덧씌워 밑면을 만든다
- 먼 구름을 먼저 그리고 `art.blur()`로 흐린 뒤 가까운 구름을 그린다
- 나무는 줄기와 가지를 `art.tube()`로 만들고 수관을 같은 공 쌓기로 올린다
    + 광원 쪽 가장자리에 밝은 잎 색을 칠한다
    + `art.threshold(art.noise(9, 2), 0.66, 0.03)`으로 잎의 반짝임을 뿌린다
    + 나무 밑 풀밭에 타원 그림자를 깐다
- 애니메풍 배경은 외곽선을 쓰지 않는다. 나무처럼 강조할 대상에만 `art.outline()`을 따로 건다

## 풀밭

- 가까울수록 짙은 색을 `art.ramp()`로 덧칠한다
- 풀잎은 위로 가늘어지는 짧은 획 수백 개다
    + 가까울수록 길고 굵게 그린다
    + 밝은 색과 어두운 색을 반씩 섞는다
    + 획 마스크를 `np.maximum.reduce()`로 합친 뒤 한 번에 칠한다
- 꽃은 `art.shapes()`로 작은 타원 수십 개를 색마다 한 번에 칠한다
- 길은 멀어질수록 좁아지는 닫힌 곡선 1개다

## 층구름

```python
band = art.ramp((0, 40), (0, 150)) * (1 - art.ramp((0, 200), (0, 300)))
clouds = art.threshold(art.noise(150) * 0.6 + art.noise(40) * 0.4, 0.52, 0.04) * band
art.paint(clouds, cloud_color, 0.9)
art.shadow(clouds * (1 - art.move(clouds, 0, -10)), cloud_shadow, 0.5)
```

- 큰 무늬와 작은 무늬를 섞어야 가장자리가 구름답게 부풀어 오른다
- `level`을 올리면 구름이 줄어든다
- 아래쪽 띠에 그림자를 넣으면 두께가 생긴다

## 산

- 능선은 봉우리와 골짜기를 번갈아 찍은 닫힌 곡선이다
    + 봉우리는 모서리로 표시한다
    + 골짜기는 매끄럽게 둔다
    + 봉우리 간격에 난수를 섞는다
- 층마다 봉우리 수와 높이를 다르게 준다
    + 예제는 원경 5개, 중경 3개, 근경 3개다
- `ridge()` 함수는 `examples/landscape.py`에 있다

## 물

- 수면은 직사각형 부품 1개에서 시작한다 (`shade=False, outline=False`)
- 수평선 근처에는 맞은편 산의 색을 `art.ramp()`로 덧칠한다
- 광원 아래에는 `art.light(art.blob(...) * water)`로 빛기둥을 넣는다
- 윤슬은 짧은 가로 획 수십 개다
    + 광원의 x 주변에 정규분포로 흩뿌린다
    + 아래로 내려올수록 길게 그린다

## 나무와 근경

- 침엽수는 아래로 갈수록 넓어지는 삼각형을 쌓는다
- 역광 장면의 근경은 밋밋한 실루엣으로 둔다 (`shade=False, outline=False`)
- 활엽수는 `art.threshold(art.noise(...))`를 둥근 마스크로 잘라 잎 덩어리를 만든다
- 근경의 땅은 화면 아래 모서리를 덮는 짙은 부품 1개로 충분하다

## 구도

- 수평선은 화면의 1/3 또는 2/3 높이에 둔다
- 주제는 화면의 1/3 교차점 근처에 둔다
    + 예제의 배와 해가 이 위치다
- `art.focus_on()`은 주제와 광원 두 곳에만 지정한다

## 겨울 들판

`examples/doomer_landscape.py`에서 검증했다. 낮은 회색 하늘, 송전탑 줄, 자작나무, 지평선의 아파트 마을.

- 눈 덮인 땅은 하늘보다 밝게 둔다. 분위기 층이 대비를 줄이므로 미리 벌려 둔다
- 송전탑과 나무는 미터로 놓고 투영한다 (`project(x, height, z)`)
    + 눈높이 1.7m에서 30m 송전탑은 가까이 있어도 밑동이 지평선 바로 아래에 선다
    + 송전탑 줄은 x를 z에 비례해 옮겨 화면을 비스듬히 가로지르게 한다
    + 전선은 두 탑의 걸이점 사이를 가운데가 처진 곡선으로 잇는다. 처짐은 화면상 길이의 5%
    + 첫 탑의 전선은 화면 밖에 둔 탑에서 온다
- 송전탑은 기울어진 다리 2개, 칸마다 X자 가새, 팔 2단, 아래로 늘어진 애자다
- 자작나무는 흰 줄기에 짧은 검은 가로 무늬, 줄기 중간부터 가는 가지를 4방향으로 낸다 (`scenes.bare_tree`)
- 지평선의 마을은 작은 `panel_block()` 여러 개를 연무로 흐린다
- 근경의 마른 풀은 짧은 획 2-7개를 묶은 덤불로 흩뿌린다. 덤불마다 크기를 다르게 한다
