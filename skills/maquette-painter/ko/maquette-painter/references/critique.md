# 검수와 결함 처방

## 목차
- 검수 순서

- 결함과 처방
- 버퍼 읽는 법
- 수치 점검
- 알려진 한계

## 검수 순서

- 전체 인상: 화면을 작게 보았을 때 주제가 즉시 읽히는가
- 구조: 형태, 비례, 겹침 순서가 맞는가
- 명암: 빛의 방향이 일관되고 명도 덩어리가 분리되는가
- 색: 배색이 계획과 일치하고 강조색이 시선 지점에 있는가
- 세부: 얼굴, 손, 가장자리를 확대(`qa.zoom`)하여 확인
- 매체: 질감이 그림을 돕는가 (질감이 형태를 덮으면 과함)

## 단계별 점검 항목

### 러프
- 주제의 위치와 크기가 구도 계획과 일치
- 인물이 관절 위치에서 잘리지 않음
- 3단 명도에서 주제와 배경이 분리
- 화면 가장자리에 의도하지 않은 빈 띠 또는 잘린 형태가 없음

### 인물
- 두 눈이 얼굴 영역 안에 있고 앞머리에 과하게 가려지지 않음
- 얼굴이 그림자로 반이 갈리지 않음 (의도한 강한 조명 제외)
- 손발 점검 출력이 (5, 5) 또는 가려진 이유가 설명됨
- 목과 어깨의 연결이 자연스러움
- 옷 밖으로 피부가 뚫고 나온 곳이 없음
- 발이 바닥에 닿아 있고 접지 그림자가 있음

### 풍경
- 원경에서 근경으로 갈수록 대비와 채도가 증가
- 수평선이 화면 정중앙을 지나지 않음 (대칭 구도 제외)
- 수면 반사가 위쪽 풍경과 대응
- 나무와 바위의 크기가 거리와 일치

### 정물
- 사물이 탁자면 위에 놓여 보임 (그림자 방향 일치)
- 사물 사이에 겹침이 있어 깊이가 읽힘
- 가장 밝은 하이라이트가 1-2곳으로 제한

### 본 렌더
- 화풍의 특징이 드러남 (수채의 번짐, 유화의 붓질, 셀의 또렷한 경계)
- 초점 영역(얼굴)의 세부가 유지됨
- 마감 효과가 과하지 않음

## 결함과 처방

| 결함 | 원인 | 처방 |
|---|---|---|
| 얼굴 절반이 어두움 | 측면 조명과 강한 형태 음영 | `--light soft_front`, `draw(face_flatten=0.8)`, 또는 azimuth를 0 쪽으로 |
| 눈이 앞머리에 가림 | fringe 끝이 눈 위로 내려옴 | fringe를 wispy, parted, none으로 변경 |
| 얼굴 이목구비가 뭉개짐 | 붓이 얼굴보다 큼 | `--scale` 증가, oil의 `focus_radii` 축소, 크롭을 가깝게 |
| 인물이 마네킹처럼 보임 | 직립 대칭 포즈, 균일 조명 | contrapposto, head에 twist와 side, 측광 조명 |
| 포즈에서 팔다리가 몸을 관통 | 관절 각도 과다 | 해당 관절 값을 줄이고 `--rough`로 확인 |
| 옷이 풍선처럼 부풂 | ease 과다, 겹쳐 입기 | `ease` 축소, 겉옷 수 줄이기 |
| 옷 음영이 얼룩덜룩 | folds 음영과 셀 경계의 충돌 | 의상의 `folds=0`, cel의 `simplify` 증가 |
| 선이 너무 굵거나 흐림 | 인물 크기 대비 선폭 | `draw(line_width=...)` 지정 |
| 배경과 인물이 섞여 보임 | 명도 유사 | 배경 명도를 인물과 반대로, 인물 뒤에 밝은 또는 어두운 도형 배치 |
| 풍경이 평평함 | depth 차이와 haze 부족 | 층별 depth 간격 확대, `haze_strength` 0.4-0.6 |
| 수채가 탁함 | 그림자 겹칠 과다 | `glazes=1`, `strength` 0.75, `vivid` 증가 |
| 수채 번짐이 형태를 무너뜨림 | wetness, wobble 과다 | `wetness` 0.2, `wobble_px` 1.5 |
| 유화가 흐릿함 | 큰 붓만 사용, threshold 높음 | radii에 작은 값 추가, `threshold` 0.04 |
| 유화 렌더가 느림 | 해상도와 가는 붓 | `--scale 0.75`로 확인 후 최종만 원래 배율 |
| 수묵이 회색 덩어리 | 원본 명도 대비 부족 | 구조 색을 밝은 것과 어두운 것으로 분명히, `mist` 증가 |
| 색이 계획과 다름 | 조명색과 그림자색의 영향 | `Light(color="#ffffff")`로 중립화, 또는 해당 영역 `unlit=True` |
| 화면이 어둡거나 밝게 뭉침 | 명도 범위 편중 | `finish.grade(exposure=..., contrast=...)` |
| 하이라이트가 지저분함 | 광택과 머릿결 음영의 충돌 | `Hair(gloss=0, strand=0)`, 의상 `gloss=0` |
| 손이 뭉쳐 보임 | 손이 작게 그려짐, 손가락 겹침 | 손 프리셋을 open 또는 grace로, 크롭을 가깝게 |
| 사물이 떠 보임 | 접지 그림자 없음 | 정물은 `objects.use_light(light)` 후 다시 그림, 인물은 `scenery.contact_shadow` |
| 그림자가 벽에 붙은 스티커처럼 보임 | 평면 이동 그림자 | 사물은 `floor_shadow`가 탁자 위로 눕힘, 건물은 `city.cast_shadows` |
| 가슴, 엉덩이가 따로 붙인 덩어리로 보임 | 덩어리의 경계 주름 | 덩어리 사전에 `blend` 값 지정, bust 1.2 이하 |
| 옆모습 몸통이 판자처럼 얇음 | 몸통 단면 두께 부족 | 몸통 단면표의 front, back 값 확인 (허리 앞뒤 약 0.7 HU) |
| 얼굴 윤곽선이 점선처럼 끊김 | 확대 렌더에서 단차가 여러 픽셀에 걸침 | 엔진이 단차를 머리 0.004 단위 거리로 측정, 선폭(`line_width`) 증가로 보완 |
| 거리 전체가 그늘 | 낮은 해 또는 옆에서 비추는 해 (실제 현상) | 조명 azimuth -30, elevation 45 전후 |
| 구름이 얼룩진 먹물처럼 보임 (수채) | 구름 입체 과다 | `clouds(volume=0.2)` 또는 0 |
| 눈송이가 보이지 않음 | 흰 눈과 밝은 하늘의 명도가 같음 | 어두운 숲, 건물, 인물 앞에 내리도록 구도 조정, near 값을 키워 큰 눈송이 추가 |
| 빗줄기가 매체에 묻힘 | 가는 선이 붓질이나 명도 단계에 흡수됨 | `weather(..., crisp=True)` (비의 기본값), amount 증가 |
| 젖은 바닥이 거울처럼 과함 | 반사 강도 과다 | `wet_reflection(strength=0.35)`, ripple 증가 |
| 우산을 쥔 손이 비어 보임 | 손잡이가 인물 뒤에 그려짐 | `umbrella(part="back")`을 인물 전에, `part="front"`를 인물 다음에 손 마스크를 뺀 clip으로 |
| 파스텔 화면이 회색 점으로 얼룩짐 | 짙은 유색지가 밝은 면 사이로 드러남 (파스텔의 성질) | `style_params`로 paper를 밝게, grain 0.4-0.5 |
| 인상주의 붓질이 형태를 덮음 | 붓이 크고 색 흔들림이 큼 | `style_params`로 radii (12, 6, 3), hue_jitter 0.02, jitter 0.04 |
| 큰 나무의 잎 덩어리가 거대한 얼룩으로 보임 | 수관 크기에 비례한 덩어리 크기 | `broadleaf(density=2-3)` |
| 촛불 장면의 벽이 평평하게 어두움 | 광원 주변 벽 밝기 없음 | `objects.backdrop(glow=(초 x, 불꽃 y, 반경), glow_color)`로 벽에 빛무리 |
| 치마나 원피스 앞으로 걷는 다리가 비침 | 원뿔 단면의 앞 모서리를 다리가 뚫음 | 보폭 축소, 기모노와 치마(한복)는 모서리까지 자동으로 감쌈 |
| 밤 장면 인물 얼굴이 하얀 가면처럼 뜸 | 밝은 피부와 밝은 주광 색 | skin을 fair 이하로, 주광 색을 어둡게 (수은등 `#a4b4d4`), cel의 `key_color` 0.5-0.7 |
| 전선이 보이지 않음 (두머, 수채) | 화풍이 선화 층을 흐리게 함 | `city.wires(..., painted=True, width=1.4-1.6)` |
| 역광 뒷모습이 검은 덩어리로만 보임 | 셀 매체는 윤곽광을 그리지 않음 | 조명 `rim` 0.8-0.9와 cel의 `rim=1.0` (doomer 프리셋에 포함) |
| 밤 눈밭이 검은 공백이 됨 | 낮은 각도의 빛이 지면에 거의 닿지 않음 | 눈 지면을 `unlit=True` 그라데이션으로 칠해 도시 불빛이 비친 밝기를 직접 지정 (`doomer_duo.py`) |
| 연기가 8자 고리처럼 꼬임 | 가닥의 흔들림 주기가 큼 | `smoke(strands=4-5, drift=0.1-0.25)`, 굴뚝은 drift 3-4로 옆으로 눕힘 |
| 한복 치마가 팔을 덮음 | 손을 몸 앞에 둘 때 팔이 치마 단면 안에 들어감 | 손 목표를 몸 앞으로 0.9 HU 이상 내밀거나 팔을 옆으로 내림 |
| 얇은 띠(훈도시, 사라시)가 두껍게 부풀어 보임 | 몸통 단면 찍기가 띠 끝에서 둥글게 넘침 | 띠 질량의 roundness를 낮춤 (`BAND_ROUNDNESS`) |

## 버퍼 읽는 법

`python scene.py --buffers`의 6개 그림.

| 버퍼 | 정상 상태 | 이상 신호 |
|---|---|---|
| albedo | 조명 없는 고유색이 영역별로 깨끗함 | 색이 새거나 구멍이 있음 (그리는 순서, clip 문제) |
| normal | 둥근 형태는 무지개빛 변화, 평면은 균일 | 형태 내부의 급격한 줄무늬 (덩어리 충돌) |
| light | 빛 방향으로 밝고 반대쪽이 어두움 | 전체가 어둡거나 얼룩 (조명 방향, 그림자 과다) |
| region | 영역마다 다른 색 | 영역이 섞임 (이름 중복, 순서 문제) |
| line | 외곽과 겹침에만 선 | 형태 내부의 불필요한 선 (crease 낮추기) |
| depth | 가까울수록 어두움 | 배경과 인물이 같은 값 (layer depth 누락) |

- 결함이 albedo에서 보이면 구조 코드, light에서 처음 보이면 조명 또는 형태, 최종 렌더에서만 보이면 매체 파라미터가 원인

## 수치 점검

`studio.run` 본 렌더가 출력하는 `image check` 항목.

| 항목 | 의미 | 주의 범위 |
|---|---|---|
| value_range | 2퍼센트, 98퍼센트 명도 | 범위가 0.35 미만이면 밋밋함 |
| contrast | 위 범위의 폭 | 화풍에 따라 0.4-0.85 |
| mean_value | 평균 명도 | 0.25 미만 또는 0.8 초과는 의도 확인 |
| clipped_white, clipped_black | 날아간 흰색, 뭉친 검정 비율 | 0.05 초과 |
| saturation | 평균 채도 | 0.03 미만은 무채색에 가까움 |

- 수치는 보조 수단이며 이미지 확인을 대체하지 않음

## 알려진 한계

- 인체는 매끈한 덩어리에 근육 결(목빗근, 견갑골, 비너스 보조개, 남성 복근 등)을 더한 수준이며 힘줄과 혈관 같은 세밀한 굴곡은 표현되지 않음
- 얼굴은 화풍별 양식화된 작도이며 특정 인물의 닮은꼴 표현은 지원하지 않음
- 카메라를 향해 뻗은 팔은 평행 투영으로 그려져 손이 커지지 않고 팔이 짧은 덩어리로 보임
- 몸 전체 tilt는 60 이하 권장 (그 이상은 인물이 화면 밖으로 벗어남)
- 앉은 자세의 전신 크롭은 선 키 기준으로 배치되어 인물이 작게 잡힘 (`height`를 직접 키워 보정)
- 의상은 몸을 감싸는 껍질과 원뿔형 치마로 구성되어 복잡한 재단과 큰 주름은 표현되지 않음
- 머리카락은 덩어리와 가닥 띠로 구성되어 곱슬머리와 땋은 머리는 근사 표현
- 남성 짧은 머리(crop)의 헤어라인은 모든 인물이 같은 곡선을 공유하며 탈모선, 수염, 턱수염은 수염 자국(beard)까지만 표현
- 앞이 열린 코트와 팔짱처럼 팔이 몸 앞을 가로지르는 조합은 안쪽 옷 무늬가 팔 위에 그려지므로 피함
- 투샷에서 늘어진 손이 상대 골반 앞에 겹치면 의도하지 않은 접촉으로 읽힘
    + 렌더 출력의 `tangent check` 경고로 확인
    + 해당 손을 `touch`로 상대 허리나 위팔에 두거나 두 인물 사이 거리를 넓혀 해결
- 투샷 접촉은 손 1개를 상대 몸의 정해진 위치(어깨, 위팔, 허리, 손)에 두는 동작까지 지원
    + 포옹처럼 두 팔이 서로 감기는 동작은 손 위치를 좌표로 직접 지정해야 하며 결과가 불안정함
    + 늘어진 뒷머리는 평면으로 그려지므로 깊이를 등 높이로 근사함
- 누운 자세는 화면 배치가 직립을 기준으로 계산되어 지원하지 않음
- 손으로 턱을 괴거나 볼을 감싸는 포즈는 손 목표 IK가 팔꿈치를 위로 보내는 해를 골라 불안정함 (팔짱, 탁자 위 팔로 대체)
- 날씨는 화면에 내리는 입자 층까지 표현하며 빗방울이 튀는 물보라, 쌓인 눈의 두께, 바람에 휘는 나무는 표현되지 않음
- 젖은 바닥 반사는 바닥에 수직으로 선 물체에 정확하며 기울어진 물체와 바닥에서 떨어진 물체는 근사 표현
- 우산과 양산은 화면 평면에서 조립한 캐노피라 손잡이 축이 관찰자 쪽으로 크게 기울면 형태가 납작해짐
- 원근은 1점, 2점, 3점 투시 지원 (`Perspective`의 yaw, pitch)
- 원경 행인은 단순 실루엣이며 가까운 인물은 `Character`로 그려야 함
- 차량은 평면 조각으로 이어 만든 차체라 곡면 광택과 세부 부품(와이퍼, 안테나)은 생략됨
- 현대 사물은 판재 조립이라 케이블, 포트, 로고 같은 작은 부품은 직접 추가해야 함
- 한계에 해당하는 요청은 가능한 범위의 대안(크롭 변경, 포즈 단순화, 양식화된 화풍)을 제안
