# 유화풍

매끈하게 칠한 밑그림을 붓질의 집합으로 다시 그린 뒤 물감 두께의 요철을 입히는 화풍. 예제는 `examples/oil_harbor_sunset.py`(바다), `oil_summer_fields.py`(들판), `oil_figure_study.py`와 `oil_reclining_figure.py`(인체), `oil_evening_dance.py`(춤추는 두 사람), `oil_doomer_overpass.py`(무릎 위 구도의 여자와 굴뚝), `oil_doomer_pylons.py`(설원과 송전탑 파노라마).

## 시각 특징

- 화면 전체가 방향성 있는 붓 자국으로 덮임
- 붓질마다 색이 조금씩 달라 가까이서 보면 혼색이 보임
- 물감 두께가 빛을 받아 붓결이 도드라짐
- 세부는 작은 붓질이 모여서 표현되고 윤곽선은 없음

## 작업 순서

1. 큰 색면을 그라데이션으로 칠함: 하늘, 물, 땅
2. 구름, 지형, 물체를 밑그림 위에 올림
    + 밑그림은 매끈해도 됨. 붓 자국은 패스가 만듦
    + 작은 터치(물비늘, 반영, 잎)는 타원 도형 수십 개를 난수로 흩뿌림
3. 영역마다 `canvas.direct`로 붓질 방향을 지정
    + 물은 가로(angle 0), 풀과 돛은 세로에 가깝게, 하늘은 완만한 사선
    + 해와 달 주변은 `around=중심`으로 회전 방향
    + 지정하지 않은 곳은 색 경계를 따라가는 방향을 패스가 스스로 계산
    + 넓은 배경의 방향은 수평에 가깝게 잡음. 가파른 사선은 주제보다 먼저 눈에 띔
4. `oil.render(canvas, brush_radii, detail)` 적용
5. `post.grade`로 그늘과 빛의 색조를 맞추고 `post.vignette`로 마감

## 패스 인자

| 인자 | 기본값 | 조절 |
|---|---|---|
| `brush_radii` | (22, 10, 4.5) | 큰 붓에서 작은 붓 순서. 세부가 뭉개지면 2.4 같은 더 작은 값을 끝에 추가 |
| `detail` | None | 형태를 주면 가장 작은 붓이 그 안에서만 쓰임. 초점에만 세부를 주는 용도 |
| `relief` | 0.55 | 물감 두께의 요철. 0이면 평평한 과슈 느낌 |
| `weave` | 0.05 | 캔버스 직조 무늬의 세기 |
| `color_jitter` | 0.05 | 붓질 간 색 차이. 올리면 인상파풍의 끊긴 색 |

- 붓 크기는 논리 단위라 scale을 올리면 같은 그림이 더 촘촘한 붓질로 그려짐
- 패스는 작은 붓을 밑그림과 차이가 큰 곳에만 추가함
    + 세부가 필요한 곳은 밑그림에서 색 대비를 분명히 줌

## 밑그림 요령

- 색면 사이의 명도 차이를 분명히 둠
    + 비슷한 색끼리 맞닿으면 붓질이 경계를 넘어가 형태가 흐려짐
- 초점 물체는 붓 반지름보다 충분히 크게 그림
    + 물체가 가장 작은 붓 지름의 몇 배 크기밖에 안 되면 붓질 몇 개로 뭉개져 형태를 알아보기 어려움
- 역광 구름은 위를 어둡게 아래를 밝게 칠함
- 물의 빛길은 가로로 긴 타원을 광원 아래에 뿌리고 가까울수록 크고 넓게 퍼뜨림
- 물체의 반영은 물체 색의 가로 타원을 아래로 쌓고 내려갈수록 옅게 함

## 흔한 결함

| 증상 | 처방 |
|---|---|
| 평탄한 곳에 같은 크기의 점이 늘어섬 | 그 영역에 `direct`로 방향을 지정해 긴 붓질이 나오게 함 |
| 어두운 면에 원색 얼룩 | `color_jitter`를 낮춤 |
| 초점 물체가 뭉개짐 | `brush_radii` 끝에 작은 값을 추가하고 `detail`로 범위를 제한하며 scale을 올림 |
| 요철이 거칠어 그림이 지저분함 | `relief`를 0.3 안팎으로 낮춤 |
| 입체의 명암이 패스 뒤에 약해짐 | 밑그림의 밝은 면과 그늘 면의 명도 차이를 더 벌림 |
| 살이나 도자기의 매끈함이 사라짐 | `relief`를 0.4, `color_jitter`를 0.035로 낮추고 `detail`로 작은 붓을 그 부위에 모음 |

## 출처

> Hertzmann(1998), Painterly Rendering with Curved Brush Strokes of Multiple Sizes(https://mrl.cs.nyu.edu/publications/painterly98/hertzmann-siggraph98.pdf)

## 3차원 인물

- `character.paint_figure`로 칠한 인물도 유화 패스를 거칠 수 있음
    + 선은 거의 지우고(`line_opacity` 0.28) 그림자 경계를 번지게(`shadow_soft` 0.45) 한 Ink를 씀
    + 패스의 `detail`을 얼굴과 맞잡은 손 둘레에 주어 작은 붓이 초점에 모이게 함
