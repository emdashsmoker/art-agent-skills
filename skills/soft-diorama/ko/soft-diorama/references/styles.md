## 1. 공통 원칙

- 화풍은 3개 층의 조합으로 결정된다
    + 밑그림 단계의 look (선 굵기, 그림자 경계)
    + 배경의 밀도와 초점
    + 마감 함수
- 세 층이 같은 화풍을 가리켜야 한다. 셀 음영 인물에 유화 마감을 씌우면 화풍이 흐려진다
- 밝은 영역이 넓으면 블룸이 화면을 하얗게 덮는다. 주인공의 피부와 옷 중 하나는 중간 명도로 둔다
- 배경은 주인공을 그리기 직전에 `cv.color = blur(cv.color, 1.5-3.0)`로 흐려 초점을 분리한다

## 2. 애니메

| 요소 | 설정 |
|---|---|
| look | `ANIME` |
| 배경 | `sky` + `cloud_bank`, 또는 단순한 실내 색면. 구름 가장자리 `edge=1.0` |
| 색 | 채도 높은 기본색. 그림자는 `shadow_of`가 만드는 차가운 색 |
| 마감 | `finish_anime(cv, glow=0.15-0.25, diffusion=0.06-0.12)` |
| 눈 | `eye_half_height` 0.11-0.125 |

- 역광 테두리 `add_rim_light`를 넣으면 배경에서 인물이 떠오른다
- 하늘이 밝으면 `glow`를 0.15 이하로 낮춘다

## 3. 일러스트

| 요소 | 설정 |
|---|---|
| look | `ILLUSTRATION` (`shade_depth` 1.0-1.2) |
| 배경 | 어두운 그라데이션 + `bokeh` + `sun_glow`, 흐림 3.0 |
| 색 | 피부 `#f7d6c2` 안팎, 옷은 중간-어두운 명도 |
| 마감 | `finish_illustration(cv, glow=0.2-0.3, texture=0.03-0.05)` |

- 광원을 옆이나 뒤에 두고 `add_rim_light(width=8-10)`를 강하게 쓰면 분위기가 산다
- 얼굴의 부드러운 입체 음영(옆면, 눈두덩, 콧대, 입술 아래)은 look이 자동으로 넣는다

## 4. 수채

| 요소 | 설정 |
|---|---|
| look | `SKETCH` |
| 배경 | 밝은 종이색 캔버스 + `wash_backdrop` + 모서리에 `leaves`/`petals` |
| 색 | 밝고 맑은 색. 어두운 색은 마감에서 탁해진다 |
| 마감 | `finish_watercolor(cv, wash=0.10-0.20, bleed=3-5, edge_darkening=1.0-1.6)` |
| 머리 | `HairSpec(shine=0.4-0.6)` |

- `wash`를 올리면 연해지고 `edge_darkening`을 올리면 물감 고인 자국이 진해진다
- 종이 여백이 필요 없으면 `border=0`
- 인물 위로 지나가면 안 되는 소품(꽃잎 등)은 인물보다 먼저 그린다

## 5. 유화

| 요소 | 설정 |
|---|---|
| look | `PAINTERLY` |
| 배경 | 어둡고 단순한 색 덩어리 (`wash_backdrop`), 또는 풍경 |
| 색 | 명도 대비를 크게. 옷은 짙은 색이 잘 받는다 |
| 마감 | `finish_oil(cv, radii=(28,14,7,3), impasto=0.3-0.5, detail=mask)` |
| 머리 | `HairSpec(shine=0.4-0.6)` |

- 인물은 `detail = np.maximum(grow(masks['eyes'], 14), masks['face'] * 0.6)`를 넘겨 얼굴을 작은 붓으로 다시 칠한다
- 풍경은 `radii=(24,12,6,3)`처럼 큰 붓을 유지하면 붓맛이 강해진다
- 붓이 덜 닿은 경계에 밑칠색(`ground`)이 비친다. 장면의 보색 계열 갈색이나 회색이 어울린다
- 작은 글자나 가는 무늬는 붓자국에 묻힌다. 형태를 크게 설계한다

## 6. 두머 무드

무드 프리셋. 세부는 `references/doomer.md`

- 색: `doomer.PALETTE`만 쓴다. 차가운 청회색이 화면의 대부분, 따뜻한 점은 1-2개
- 인물: `ILLUSTRATION`에 `light_height` 0.45-0.55, 가로등 쪽에서 `add_rim_light(color=PALETTE['sodium'])`
- 배경: `panel_block`의 반복 창, `wires`의 사선, `snowfall`의 눈. 밤 장면의 벽은 `wall='#5a6069'`로 어둡게 한다
- 마감: `doomer.finish(cv, warmth=0.3-0.75)`. 저녁놀이 있으면 `warmth`를 올리고 흐린 낮이면 내린다

## 7. 조명 연출

모두 마감 전에 `cv.tint`로, 또는 마감 후 `finish.light_wash`로 넣는다.

```python
# 햇빛이 새어 들어오는 느낌: 광원 쪽 모서리에서 퍼지는 따뜻한 빛
cv.tint(cv.radial((120, 90), 900) ** 1.5, '#fff0c8', 'screen', 0.30)

# 아래쪽을 가라앉혀 시선을 얼굴로 모으기
cv.tint(masks['all'] * cv.linear((0, 760), (0, 1280)), '#2a2f55', 'multiply', 0.25)

# 그림자 쪽에 배경색의 반사광
bounce = shading.rim(masks['all'], (-look.light[0], 0.3), 10, soft=4)
cv.tint(bounce, '#9fc4ff', 'screen', 0.35)

# 마감 뒤 전체 색조 통일
image = finish.light_wash(image, cv.full(), '#ffd9b0', 'soft_light', 0.25)
```

## 8. 팔레트

- 주조색 1개가 화면의 절반 이상을 차지하게 한다 (보통 배경)
- 주인공에는 주조색과 명도 차이가 큰 색을 쓴다
- 강조색은 작은 면적에만 쓴다 (눈, 입술, 소품)
- 그림자색은 직접 고르지 말고 `shadow_of`로 만든다. 피부는 `skin_shadow`
- 시간대별 출발점

| 분위기 | 하늘/배경 | 빛 | 그림자 쪽 |
|---|---|---|---|
| 한낮 | `#2f74d0` → `#cfe9fb` | `#fff6d8` | 푸른 회색 |
| 노을 | `#6f7fc0` → `#f6b79a` | `#ffe0b0` | 보라 |
| 밤거리 | `#2b2440` → `#a8645a` | `#ffc78a` | 남색 |
| 실내 창가 | `#f4e6d2` → `#d9c6bd` | `#fff6da` | 갈색 회색 |

## 9. 문제 해결 표

| 증상 | 원인 | 처방 |
|---|---|---|
| 얼굴이나 옷이 하얗게 날아감 | 블룸 과다, 밝은 면이 넓음 | `glow`와 `diffusion`을 낮춤. 피부나 옷을 한 단계 어둡게 |
| 앞머리가 눈을 덮음 | 앞머리 끝이 낮음 | `bangs_length`를 -0.15 쪽으로. 또는 `side`/`curtain` |
| 먼 쪽 눈이 옆머리에 가림 | 고개 회전이 큼 | `yaw` 절대값을 25 이하로 |
| 머리가 헬멧처럼 보임 | 가닥이 너무 균일 | `wave` 0.2 이상, `bangs='wispy'`, `seed` 변경 |
| 인물이 배경에 묻힘 | 명도 대비 부족 | `add_rim_light`, 배경 흐림, 배경 명도 조정 |
| 그림자 방향이 제각각 | 광원 벡터 불일치 | `look.light`와 배경 함수의 `light` 인자를 같은 값으로 |
| 선이 너무 굵거나 가늚 | 화풍과 선 굵기 불일치 | `replace(look, line_scale=...)` |
| 셀 그림자 경계가 뿌옇다 | `shade_soft`가 큼 | 1.0-1.5로 |
| 수채가 흐릿하고 탁함 | 번짐 과다, 색이 어두움 | `bleed` 3 이하, `wash` 0.10, 밝은 색으로 교체 |
| 유화에서 얼굴이 뭉개짐 | 세밀 영역 미지정 | `detail` 마스크 전달, `radii` 마지막 값을 2-3으로 |
| 유화 붓자국이 지렁이처럼 보임 | 임파스토 과다 | `impasto` 0.3 이하 |
| 구름이 납작함 | 그늘색과 밝은색이 비슷함 | `shade`를 더 짙고 푸르게 |
| 물체가 스티커처럼 떠 보임 | 접지 그림자 없음 | 바닥에 `blur(ellipse)`를 `multiply`로 깔고 그 위에 물체를 그림 |
| 곡선이 찌그러짐 | 제어점 간격이 불균일 | 점을 고르게 배치하거나 점 수를 줄임 |
| 렌더가 느림 | 캔버스가 크거나 유화 | 점검 단계는 절반 크기로. 유화는 마지막에만 |
| 살결이 벌겋게 달아오름 | 그림자가 너무 진함 | `shade_depth`를 1.0-1.25로 |
| 몸이 밋밋한 인형 같음 | 빛이 정면에서 비침 | `light_height` 0.5-0.6, 광원을 옆으로, 배경을 어둡게 |
| 팔다리가 따로 붙인 것처럼 보임 | 셀 음영 look에서 관절 경계가 드러남 | `ILLUSTRATION` 계열 look 사용 |
| 원근으로 붙인 면이 흐릿함 | 평면 그림의 해상도 부족 | 평면 Canvas를 더 크게, `facade(resolution=28)` |
| 둥근 물체가 납작함 | `paint_form`의 초승달 그림자만 있음 | `paint_volume`으로 교체, `bulge`를 폭의 1/3-1/2로 |
| 밤 장면에서 화면이 하얗게 날아감 | 전등 빛을 `screen`으로 크게 올림 | 빛 웅덩이 밖만 어둡게 누르고 웅덩이 안은 제 색을 유지 (`references/objects.md` 6절) |
| 현대 사물이 작고 바닥이 텅 빔 | 카메라가 멀거나 지평선이 낮음 | `focal`을 키우고 `vanishing`의 y를 줄임. 물체를 가까운 z로 |
| 납작한 물체가 두 겹으로 갈라짐 | 위아래 외곽선만 그림 | `solids.slab`으로 두께를 채움 |
| 유화에서 작은 부품이 사라짐 | 큰 붓이 부품을 덮음 | 물체 영역을 `detail` 마스크로 전달 |
| 몸을 돌렸는데 얼굴이 정면을 봄 | 고개는 따로 돈다 | 3/4는 `head_yaw = turn * 0.6-0.8`, 옆모습과 뒷모습은 `head_yaw = turn` |
| 앉은 인물의 엉덩이 아랫선이 울퉁불퉁 | 허벅지가 충분히 앞으로 나오지 않음 | `aim()`의 허벅지 방향 z를 1.0 이상으로, 몸을 20-40도 돌림 |
| 남성 몸이 마네킹처럼 밋밋함 | 정면광이라 근육 고랑이 묻힘 | `light_height` 0.5-0.55, 광원을 옆으로, 몸을 25-35도 돌림 |
| 2점 투시에서 땅이나 길이 뒤집혀 그려짐 | 카메라 뒤의 점을 그대로 투영 | `city.project_polygon`, `city.ground_rects`로 카메라 앞만 그림 |
| 돌린 상자에 붙인 그림이 거꾸로 | 면 모서리 순서가 다름 | `box()`가 돌려준 면 사각형을 그대로 `paste`에 넘김 |
| 뒷모습에서 두 손이 엉덩이 위로 모임 | 팔 각도가 화면 기준이라 몸을 돌려도 그대로 | 팔을 `aim(turn, ...)`으로 몸 기준 방향으로 줌 |
| 뒷모습에서 팔이 팔꿈치쯤에서 잘려 보임 | 앞(z+)으로 뻗은 아래팔이 몸 뒤로 숨음 | 아래팔 방향의 z를 0.3 이하로, x를 몸 바깥쪽으로 |
| 누운 인물이 침대 위에 떠 보임 | `fit()`이 서 있는 발 기준 여유를 둠 | `fit` 상자 바닥을 바닥면보다 0.4-0.5 머리 단위 아래로 |
| 주머니에 넣은 손이 옷 위로 보임 | 손 모양이 일반 손 | `HandSpec('pocket')`을 바지, 양복과 함께. 후드티는 `HandSpec('pouch')` |
| 후드티 소매가 밑단 옆에서 끊겨 손이 사라짐 | 바지 주머니를 긴 상의가 덮음 | `poses.hands_in_pockets(turn, pouch=True)`로 캥거루 주머니에 넣음 |
| 두머 그림이 그냥 어두운 그림으로 보임 | 반복 요소와 따뜻한 점이 없음 | 패널 아파트 창 격자, 전선, 가로등 하나를 넣고 따뜻한 점을 1-2개로 제한 |
| 밤 아파트 벽이 낮처럼 밝음 | 기본 콘크리트 색 | `panel_block(wall='#5a6069')`, 먼 동은 `haze_amount` 0.4-0.7 |
| 담배 연기가 안 보임 | 밝은 벽 앞의 회색 연기 | 어두운 하늘이나 창 앞에서 피어오르게 배치하고 `opacity` 0.6-0.7 |
| 헐렁한 상의의 소매와 몸 사이에 배경이 비침 | 몸에 붙는 옷 기본값 | `top(close=True)` (후드티와 양복 재킷은 기본) |
| 옆얼굴이 머리카락에 가려짐 | 얼굴 옆 가닥이 뺨 앞으로 늘어짐 | `side_length`를 0.8 이하로, 또는 `bangs='side'` |
| 뒷모습 머리가 너무 평평함 | 머리카락 한 덩어리에 빛이 고르게 닿음 | 광원을 옆으로(`light=(-0.75, -0.55)`), `add_rim_light`, `wave` 0.3 이상 |
| 여러 인물의 머리 모양이 똑같아 보임 | 같은 기본 `HairSpec` | 인물마다 `hairstyle()`의 다른 이름을 고른다. 묶음머리와 짧은 머리를 섞으면 실루엣이 갈린다 |
| 포니테일이 정면에서 안 보임 | 꼬리가 머리와 목 뒤에 있음 | 몸이나 고개를 30도 이상 돌린다. 옆모습과 뒷모습에서는 꼬리가 몸 위에 그려진다 |
| 높은 번이 화면 위에서 잘림 | `fit()`이 번 높이를 넣지 않음 | `framing(headroom=0.9)`나 `fit` 상자 위쪽 여백을 늘린다 |
| 표정이 잘 안 보임 | 일자 앞머리가 눈썹을 가림, 얼굴이 작음 | `center_long`, `side_part`처럼 이마가 보이는 헤어, `framing(..., 'face')` |
| 겨울 코트 아랫자락이 종처럼 퍼짐 | `skirt()`로 코트 자락을 만듦 | `long_coat()`를 쓴다. 엉덩이에서 거의 곧게 떨어진다 |
| 달리는 인물의 포니테일이 아래로 처짐 | 꼬리는 기본으로 중력을 따름 | `hairstyle('ponytail', flow=0.6-0.8)` |
| 단체 초상에서 인물이 작고 아래쪽이 빔 | `group()`이 전신을 바닥선에 세움 | `group(..., shot='waist', gap=-0.1)`, 가운데 인물을 마지막에 그림 |
| 앞으로 뻗은 먼 팔(무릎 안기, 팔짱)의 손이 사라짐 | 팔 각도를 화면 각도로 줌 | 팔을 `aim(turn, ...)`으로 준다. 몸 기준 깊이가 있어야 몸 앞에 그린다 |
