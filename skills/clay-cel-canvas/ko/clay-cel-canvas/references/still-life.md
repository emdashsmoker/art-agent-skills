# 정물

수치와 함수는 `examples/still_life.py`에서 검증한 값이다.

## 구성

- 탁자의 뒤 경계선은 화면 높이의 55-60% 지점에 둔다
- 사물은 높이가 서로 다른 3-6개를 고른다
    + 키 큰 것 1개, 중간 것 1-2개, 낮은 것 2-3개
    + 가장 키 큰 것을 화면 중앙에서 벗어난 1/3 지점에 둔다
- 사물끼리 일부가 겹치도록 놓는다. 겹침이 앞뒤 거리를 만든다
- 배경은 어둡게, 광원 쪽만 밝게 칠한다: `art.paint(art.blob(...), wall_light, 0.75)`

## 사물 함수

- 사물마다 함수 1개를 만들고 밑면 중심을 원점으로 그린다
- `art.place(at=탁자 위 위치, scale=크기)`로 놓는다
    + 배치와 크기를 좌표 수정 없이 바꿀 수 있다
- 좌우 대칭인 그릇과 병은 절반 윤곽을 찍고 `symmetric(half, 0)`으로 닫는다
- 손잡이와 줄기는 `art.tube()`로 만든다

## 입체와 재질

| 재질 | 그리는 법 |
|---|---|
| 과일 | `bulge` 생략으로 구 명암. 붉은 기나 노란 기를 `art.blob()`으로 한쪽에 덧칠. 작고 또렷한 하이라이트 1개 |
| 유리병 | 짙은 밑색. 세로로 긴 하이라이트 1줄, 반대편에 탁자 색의 약한 반사 1줄 |
| 도자기 | 밝은 밑색에 구 명암. 넓고 부드러운 하이라이트. 띠 무늬는 몸통 마스크로 잘라 칠함 |
| 금속 | 밝은 띠와 어두운 띠를 번갈아 배치. 하이라이트는 흰색에 가깝게 |
| 포도 | 타원 수십 개를 뒤쪽 줄부터 그림. 알마다 점 하이라이트 1개와 반대편 반사광 1줄 |

- 그림자 쪽 가장자리에 탁자 색의 반사광을 약하게 넣으면 사물이 탁자 위에 놓여 보인다

## 탁자 위의 그림자

```python
def cast_shadow(art, table, width, depth=16):
    shadow = art.shape(ellipse(SHADOW_SHIFT[0], SHADOW_SHIFT[1] - 4, width * 0.62, depth))
    art.shadow(art.feather(shadow, 5) * table, deep_shadow, 0.85)
```

- 사물을 그리기 전에 그림자를 먼저 깐다
- 그림자는 광원 반대쪽으로 밀린 납작한 타원이다
- 탁자와 천을 합친 마스크로 잘라 탁자 밖으로 새지 않게 한다

## 천

- 윤곽은 탁자 위에 놓인 부분과 앞 모서리 아래로 늘어진 부분을 한 곡선으로 그린다
    + 늘어진 아랫단은 물결 모양으로 찍는다
- 주름은 사물 밑에서 탁자 모서리로 뻗는 곡선 3-4개다
    + 곡선마다 굵은 그림자 띠 1개와 옆으로 밀린 가는 빛 띠 1개를 깐다
    + 띠는 `art.feather()`로 가장자리를 푼다
- 탁자 모서리 아래로 늘어진 부분 전체에 그림자를 한 겹 더 준다

## 현대 사물

노트북, 스마트폰, 머그, 스탠드처럼 공장에서 만든 사물은 상자, 판, 원기둥의 조합이다. `examples/desk.py`의 방식으로 3차원에서 조립한다.

- 탁자 윗면을 z = 0으로 두고 미터 단위로 치수를 정한다
    + 노트북 폭 0.32, 깊이 0.22, 두께 0.014. 머그 반지름 0.04, 높이 0.09. 스마트폰 0.072 × 0.15
- `Camera` 하나로 모든 점을 투영한다. 카메라는 탁자 앞 위쪽에 둔다
    + 예제: `eye=(0.06, -0.80, 0.66)`, `target=(0.0, 0.36, 0.12)`, `focal=900`
- 사물마다 자체 좌표로 모양을 정하고 `frame(origin, yaw)`로 탁자 위에 놓는다
    + 조금씩 돌려 놓아야 사람이 쓰던 책상처럼 보인다

| 형태 | 만드는 법 |
|---|---|
| 판 (노트북 바닥, 폰, 공책) | 윗면 `slab()`을 칠하고 `hull(윗면, 아랫면)`으로 두께를 먼저 깐다 |
| 원기둥 (머그, 화분, 스탠드 받침) | `hull(disc(아래), disc(위))`를 `bulge` 없이 칠하면 원기둥 명암이 생긴다. 윗면 `disc()`를 그 위에 얹는다 |
| 기운 면 (노트북 화면) | 경첩 위치와 면의 두 방향 벡터를 정하고 `on_plane()`으로 면 위의 2차원 좌표를 3차원으로 옮긴다 |
| 반복되는 작은 면 (자판, 창) | 이중 반복문으로 `slab()`을 만들고 `art.shapes()`로 한 번에 칠한다 |
| 가는 막대 (스탠드 팔, 펜, 손잡이) | 양 끝을 투영하고 `art.tube()`로 잇는다. 굵기는 `camera.scale_at()`을 곱한다 |

- 화면 속 내용은 글자 없이 색 막대로 표현한다
    + 코드 편집기: 들여쓰기가 다른 짧은 막대 여러 줄, 옆에 파일 목록 막대, 위에 창 단추 3개
    + 스마트폰: 알림 카드 1장과 막대 2줄
- 빛은 3겹이다
    + 화면: `art.light(art.feather(display, 10), glow, 0.3)`으로 번짐을 주고 자판에도 같은 색을 얹는다
    + 스탠드: 갓 아래 원판을 밝은 색으로 칠하고 탁자 위에 큰 타원 빛을 깐다
    + 그림자: 사물의 바닥 윤곽을 전등 반대 방향으로 민 것과 합쳐 `hull()`로 만든다 (`desk_shadow`)
- 벽이 어둡고 광원이 2개(따뜻한 스탠드, 차가운 화면)면 밤 책상의 분위기가 난다

## 초점

- 회화풍에서는 모든 사물에 `art.focus_on(art.feather(mask, 6) * 0.7)`을 준다
    + 사물은 또렷하게, 벽과 탁자는 큰 붓 자국으로 남는다

## 창가 정물

`examples/doomer_still_life.py`에서 검증했다. 밤의 부엌 창턱: 찻잔 받침에 든 홍차, 담배가 타는 재떨이, 카세트테이프.

- 창 밖부터 그린다: 하늘, 맞은편 아파트(`scenes.panel_block`), 가로등 빛, 내리는 눈
    + 그다음 창 구멍을 뚫은 벽을 덮는다. 창 밖 그림을 창 모양으로 자를 필요가 없다
- 창틀은 막대 5개를 `art.shapes()`로 합쳐 부품 1개로 칠한다. 작은 환기창(`VENT`)은 안쪽 틀만 더한다
- 유리 모서리의 성에와 유리에 비친 조명은 창 마스크 안에 옅게 얹는다
- 창턱은 윗면과 앞면 2장이다. 창턱 아래에 라디에이터 날개를 세운다
- 찻잔 받침은 반만 찍은 윤곽을 `symmetric()`으로 닫는다. 뚫린 무늬는 받침 마스크 안의 작은 타원이다
- 재떨이에 걸친 담배는 `head_props.draw_cigarette(art, np.asarray, root, droop=-14)`이다
    + 끝이 들린 각도로 놓고 불씨 끝에서 `draw_smoke()`로 연기를 올린다
    + 담배 끝이 옆 사물에 닿지 않게 간격을 둔다
- 카세트는 각진 몸체, 띠가 있는 라벨, 연필 제목, 릴 창과 릴 2개, 아래 사다리꼴이다
