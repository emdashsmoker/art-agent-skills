## 화풍 3종의 정의

| 구분 | anime | illust | painterly |
|---|---|---|---|
| 형태 표현 | 선과 면 | 면과 가는 선 | 색면과 붓 터치 |
| 음영 단계 | 2단 (밑색, 그림자) | 연속 그라데이션 | 연속, 붓 단위로 끊김 |
| 음영 경계 | 선명 | 부드러움 | 풀어짐 |
| 눈 | 크고 장식적 | 중간 | 작고 사실적 |
| 입술 | 선과 옅은 색조 | 형태를 채색 | 형태를 채색 |
| 배경 | 그라데이션, 빛줄기 | 빛망울, 역광 | 색면 워시 |
| 마감 | 글로우, 그레인 | 블룸, 비네트 | 붓 터치, 캔버스 결 |

- 화풍 선택 기준은 사용자의 단어
    + "애니", "셀", "만화" : anime
    + "일러스트", "웹툰 표지", "게임 일러스트", "반실사" : illust
    + "회화", "유화", "그림 같은", "명화" : painterly

## 팔레트 설계 규칙

- 색은 역할로 배정
    + 주조색 : 화면 면적이 가장 큰 색 (머리 또는 의상)
    + 보조색 : 주조색을 받쳐 주는 배경색
    + 강조색 : 가장 작은 면적, 가장 높은 채도 (홍채, 입술, 소품)
- 그림자색은 밑색에서 3개 값을 함께 이동
    + 명도 하향 10-40%
    + 채도 상향 10-40%
    + 색상을 인접한 따뜻한 쪽 또는 차가운 쪽으로 이동
- 광원이 따뜻하면 그림자는 차갑게, 광원이 차가우면 그림자는 따뜻하게 설정
- 머리 3색은 명도 간격을 확보
    + `hair_shadow`는 `hair` 명도의 55-65%
    + `hair_light`는 `hair`보다 명도가 2배 이상 높고 채도는 낮게
- 배경은 인물보다 명도 대비와 채도를 낮게 유지
    + 어두운 머리에는 밝은 배경, 밝은 머리에는 중간 이하 명도의 배경이 실루엣을 살림
- 코드에서 파생색이 필요하면 `pk.adjust(color, value, sat, hue_shift)` 사용

## 인물 구분과 피부톤

- 한 그림에 인물이 여럿이면 실루엣, 얼굴, 색 3개 층에서 서로 다르게 함
    + (실루엣) 머리 길이와 덩어리가 다른 `hair_style` 조합 (예 : `long_curly`와 `two_block`)
    + (얼굴) `eye_shape`와 `brow_shape`를 다르게 (예 : `droopy`와 `upturned`)
    + (색) `skin_tone`을 2단계 이상 떨어뜨리고 머리색 명도도 다르게
- `skin_tone`을 쓰면 `skin`, `skin_shadow`, `blush`, `lip`은 비워 둠 (프리셋 4색이 서로 맞춰져 있음)
- 짙은 피부톤(`brown`, `deep`)은 `hair_light`와 림라이트를 따뜻한 색으로 두면 얼굴 윤곽이 배경에서 분리됨
- 곱슬머리(`long_curly`, `perm`)는 `hair_light`를 머리색보다 확실히 밝게 두어야 컬 질감이 보임

## 남성 인물

- 형태 대비로 성별을 읽게 함
    + 턱 : `jaw_sharpness` 0.8-0.9가 각진 턱각을 만듦
    + 눈 : `eye_height` 0.060-0.070, 성숙한 인상일수록 작게
    + 머리 : `layered`가 가장 세련되게 읽힘(기본값). `short`, `slicked`는 단정한 인상, `medium`은 중성적
- 잘생긴 인상을 만드는 요소
    + 눈 : 가늘고 긴 눈과 두꺼운 윗꺼풀선 (기본값에 반영됨). 눈을 키우면 소년처럼 보임
    + 각도 : `head_turn` 0.4-0.5와 반대쪽 `gaze`로 비스듬한 시선, 정면 증명사진 구도는 피함. 턱선을 강조하려면 반측면(`head_turn` 2.0-2.5)
    + 빛 : 측광(`azimuth` 120-140)이 광대 아래 음영과 턱선을 살림, `rim_light` 0.5-0.7
    + 앞머리 : `layered` 앞머리가 한쪽 눈썹을 스치면 분위기가 생김
    + 체형 : `muscle` 1.1-1.3, `shoulders` 1.03-1.05. 더 올리면 팔이 굵어져 둔해 보임
- 색은 여성보다 홍조와 입술 채도를 낮게 유지 (기본값에 반영됨)
- 피부 그림자를 조금 더 붉은 갈색 쪽으로 옮기면 햇볕에 그을린 인상
- 정장은 `cloth2` 짙은 남색 또는 회색, `accent` 넥타이는 와인색 또는 짙은 녹색

## 투샷 배색

- 두 인물 중 1명에게만 높은 채도를 줌
    + 예 : 붉은 원피스 #b8344a와 짙은 남색 정장 #262c3c, 넥타이 #7a2a3a로 두 사람을 색으로 연결
- 머리색 명도를 다르게 두면 두 머리가 겹쳐도 경계가 읽힘
- 피부색은 `palette.skin`, `skin_shadow`로 사람마다 조금씩 다르게 주면 자연스러움 (예 : 여성 #f8dccb, 남성 #eec5a6)
- 배경 명도는 두 인물 모두보다 낮거나 높게 맞춤. 한 사람만 배경에 묻히는 배색은 피함

## 배경 설계

- 배경은 2-3개 연산을 겹쳐 구성
    + 1층 : `gradient` 또는 `wash`로 전체 색 결정
    + 2층 : `glow`로 머리 뒤쪽에 빛을 두어 얼굴로 시선 유도
    + 3층 : `bokeh`, `light_shafts`, `petals` 중 1개로 공간감 추가
- `glow`의 `center`는 광원 방향과 같은 쪽에 배치
- 회화풍 배경은 `wash` 1개로 충분하며 붓 터치가 변화를 만듦
- 실내(`room`) 벽은 의상보다 명도가 높고 채도가 낮은 색 (#d9cbbd, #cfd4da), 커튼은 벽과 같은 계열의 짙은 색

## 장면별 광원 레시피

인물과 배경이 같은 빛을 받아야 한 장면으로 읽힘. 아래는 검증된 조합.

| 장면 | `light` (azimuth / elevation) | 인물 쪽 설정 | `finish` |
|---|---|---|---|
| 비 갠 밤거리 | 50 / 32 (가로등 쪽) | `rim_light` 0.85, `ambient` 남색 0.25 | `bloom` 0.45, `diffusion` 0.2, 그림자 남보라, 하이라이트 주황 |
| 노을 역광 해변 | 해가 오른쪽이면 30, 왼쪽이면 150 / 22 | `rim_light` 0.9, `face_shadow_level` -0.3 (얼굴 절반이 어두워지는 것 방지) | `bloom` 0.45, 그림자 보라, `tilt` 3-5 |
| 아침 창가 실내 | 창이 왼쪽이면 140, 오른쪽이면 40 / 30 | `rim_light` 0.5, 밝은 의상 | `diffusion` 0.25, 그림자 하늘색, `tint_strength` 0.1 |
| 조명 켠 밤 실내 | 조명이 왼쪽이면 140, 오른쪽이면 40 / 30 | `room`의 `lamp`와 `window` "night", `ambient` 보라 0.12-0.2 | `bloom` 0.3, 그림자 보라, 하이라이트 호박색 |
| 낮 도심 | 120-130 / 45 | `rim_light` 0.4 | `bloom` 0.2, `vignette` 0.12 |
| 노을 호숫가 풍경 속 인물 | 해가 왼쪽이면 150, 오른쪽이면 30 / 20 | `head_height` 0.075-0.085로 인물을 작게, `rim_light` 0.85 | `bloom` 0.35, 그림자 보라 |

- 해, 가로등, 조명 위치와 `light.azimuth`를 같은 쪽으로 맞춤 (0은 오른쪽, 90은 위, 180은 왼쪽에서 빛이 옴. 90보다 작으면 화면 오른쪽, 크면 왼쪽)
- 회화풍 인물은 `eye_height` 0.078, `lip_fullness` 1.3을 함께 지정. 애니메 비율의 큰 눈은 붓 터치 안에서 어색하게 뜸

## 두머 감성

차갑고 넓은 도시 속에 작게 남은 온기를 그리는 레시피. 판형 아파트, 전선, 가로등, 눈이 무대이고 인물은 어두운 단색 덩어리로 섬.

- 색 위계 : 따뜻한 광원 > 인물 실루엣 > 창 격자 > 하늘
    + 따뜻한 색은 창 불빛(#f2c66b), 나트륨 가로등(#ffb35a), 담뱃불에만 씀
    + 나머지는 회청색(#7a7c88, #9aa0aa)과 먹색(#121826, #24242a)
- 의상 : `cloth` #24242a-#3a3a44, `outer` #26262c, `hat` #1e1e24, 머리 #16161c-#1c1c24
    + 피부는 채도를 낮춘 #efd9cc-#f2ddd2, 그림자 #c4a09a
    + `hair_light`는 가로등 쪽이면 주황 회색(#c8a078), 하늘 쪽이면 청회색(#8a93b8)
- `ambient` : 남색(#26284a) 0.2-0.3, `from` 0.45-0.6으로 하반신을 밤에 섞음
- `rim_light` 0.7-1.0 : 어두운 옷이 어두운 배경에서 분리됨
- `finish.preset` `"doomer"`의 값 : `saturation` 0.70, `contrast` 1.08, 그림자 #1a2436, 하이라이트 #ffb878, `tint_strength` 0.22, `vignette` 0.32, `grain` 0.028, `bloom` 0.30, `diffusion` 0.12
    + 프리셋 위에 spec의 `finish` 키가 덮어씀 (예 : 회화풍은 `radii`만 추가)

| 장면 | 화풍 | `light` | 구성 요점 |
|---|---|---|---|
| 남성 무릎 위 구도 (`doomer_male`) | anime | 70 / 55 (머리 위 가로등) | 비니, 후드티, 입에 문 담배, 뒤로 밤 블록과 전신주, 앞뒤 눈 |
| 여성 옆모습 걷기 (`doomer_female`) | illust | 155 / 18 (해 질 녘 왼쪽) | 롱코트, 자작나무 길, 해 질 녘 블록 |
| 투샷 뒷모습 (`doomer_duo`) | anime | 90 / 12 (정면 창 불빛 역광) | 나란히 선 두 사람과 불 켜진 큰 블록, `rim_light` 1.0 |
| 설정샷 (`doomer_establishing`) | illust | 150 / 20 | 측면 투시 블록 여러 동, 소실점으로 모이는 전선, 작은 행인 2명(`extras`) |
| 도시화 (`doomer_city`) | painterly | 60 / 40 | 안뜰을 둘러싼 블록, 가로등 2개, 잎 진 나무 |
| 풍경화 (`doomer_landscape`) | painterly | 120 / 25 | 송전탑 행렬, 먼 블록, 어두운 구름과 따뜻한 지평선 |
| 사물화 (`doomer_still_life_example.py`) | illust | 창 뒤쪽 위 | 재떨이와 연기, 유리잔 홍차, 카세트 라디오, 창밖 점등 블록 |

- 구도 : 지평선을 낮게 두어 하늘과 건물 면적을 크게, 인물은 3분할선
- 설정샷은 인물 `head_height` 0.02-0.03으로 작게 두어 장소가 주인공이 되게 함
- 하늘 위쪽이 밝으면 그림이 씻겨 보임, 위쪽을 가장 어둡게 두고 지평선 근처에 약한 온기를 둠

## 화풍별 미세 조정

- anime
    + 선이 굵어 보이면 `line_width` 0.0035
    + 얼굴 그림자를 넓히려면 `face_shadow_level` 0.0-0.1
    + 머리 띠 하이라이트를 빼려면 `hair_highlight` "none"
- illust
