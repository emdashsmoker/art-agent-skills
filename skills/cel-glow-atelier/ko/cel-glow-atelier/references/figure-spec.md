# 전신 spec 참조

spec에 `figure` 키가 있으면 전신 리그가 동작함. 얼굴과 머리카락은 흉상과 같은 `character`, `palette` 키를 그대로 사용. 성별은 `character.gender`로 지정.

## 목차

- 구조
- figure 키
- 체형
- 구도
- 포즈 프리셋
- 포즈 직접 지정
- 가구
- 옆모습
- 뒷모습
- 손
- 소품 (담배)
- 의상
- 인체 습작
- 배경 인물 (extras)
- 투샷 (duo)
- 혼합 모드용 좌표

## 구조

- 전신은 2D 골격으로 구성
    + 각도 몇 개가 관절 위치를 정함
    + 팔다리는 관절 2개 사이에 걸린 형태이며 굵기 곡선이 어깨, 팔꿈치, 무릎, 종아리 윤곽을 만듦
    + 몸통은 가슴 틀과 골반 틀을 잇는 곡선 1개
    + 의상은 신체 부위를 바깥으로 넓힌 형태
- 성별마다 체형 계획(body plan)이 따로 있음
    + 여성 : 모래시계 실루엣, 맨발 키 약 7.2 머리, 하이힐 약 7.5 머리
    + 남성 : 넓은 어깨와 좁은 골반의 역삼각형, 굵은 목과 팔다리, 큰 손발, 맨발 키 약 7.4 머리
- 길이 단위는 머리 단위(정수리에서 턱까지 = 1.0)
- 좌우는 항상 화면 기준 (`left` = 화면 왼쪽)
- 얼굴, 머리, 피부톤은 흉상과 같은 `character` 키로 정함 (`portrait-spec.md`의 character 표)
    + 머리 12종, `skin_tone`, `eye_shape`, `brow_shape`, `nose_shape`, `mouth_shape`는 정면, 옆모습, 뒷모습 리그에 모두 적용
    + 뒷모습에서 `two_block`은 짧게 친 뒷머리 띠, `pixie`와 `layered`는 목덜미의 뾰족한 머리끝으로 그려짐
    + 옆모습에서 코와 입 프리셋은 얼굴 윤곽선 자체를 바꿈 (`dot` 코는 낮게, `bridge` 코는 높게, `heart` 입술은 도톰하게)

## 체형

`build`의 값은 성별 기본 체형에 대한 배율이며 1.0이 기본.

| 키 | 권장 범위 | 효과 |
|---|---|---|
| `bust` | 0.8-1.25 | 여성은 가슴 볼륨, 남성은 가슴 근육 크기. 0이면 가슴 음영 없음 |
| `waist` | 0.9-1.1 | 허리 폭. 낮추면 굴곡이 강해짐 |
| `hips` | 0.9-1.15 | 골반과 허벅지 시작 폭 |
| `shoulders` | 0.9-1.1 | 어깨 폭 |
| `legs` | 0.95-1.1 | 다리 길이 |
| `muscle` | 0.8-1.4 | 팔다리 굵기와 근육 음영 강도. 남성 복근과 가슴 근육이 함께 진해짐 |

- 굴곡이 강한 여성 체형 예 : `{"bust": 1.08, "waist": 0.96, "hips": 1.04}`
- 근육질 남성 체형 예 : `{"muscle": 1.3, "shoulders": 1.05}`
- 배율을 한 번에 0.1 넘게 바꾸면 의상 형태가 어긋나기 쉬우므로 렌더 후 확인

## 구도

구도는 2가지 방식 중 1개로 지정.

- (구도 프리셋) `placement.shot` : 화면 아래 가장자리가 인물을 자르는 위치를 이름으로 지정. 크기와 위치가 자동 계산됨
- (직접 지정) `placement.head_height`와 `pelvis` : 머리 크기와 골반 위치를 캔버스 비율로 지정

### 구도 프리셋 (shot)

| shot | 화면 아래 경계 | 용도 |
|---|---|---|
| `full` | 발밑 바닥 (위아래 여백 5%) | 전신, 앉은 전신, 투샷 전신 |
| `thigh` | 허벅지 중간 | 몸매와 의상이 주인공인 그림 |
| `knee` | 무릎 바로 아래 | 서 있는 인물의 표준 상반신 확대 |
| `waist` | 골반 아래 | 상반신과 얼굴, 투샷 대화 장면 |
| `bust` | 가슴 아래 | 전신 리그로 그리는 흉상 (손 제스처 포함) |

- 정수리 위 여백은 캔버스 높이의 5%로 고정, 머리 위로 든 손(`stretch`, `wave`)이 있으면 손끝 기준
- `placement.x` : 인물 중심(투샷은 두 인물의 중심)의 가로 위치, 캔버스 비율, 기본 0.5
- `shot`을 쓰면 `head_height`와 `pelvis`를 함께 쓸 수 없음 (오류로 중단)
- 예 : `"placement": {"shot": "thigh", "x": 0.45}`
- 화면을 기울이는 더치 앵글은 `finish.tilt`(도, 양수는 반시계 방향, 3-8 권장)로 지정하며 빈 모서리가 생기지 않게 자동 확대됨

| `back_walk` | 멀어지며 걷기, 들린 발은 발바닥이 보임 (뒷모습 리그) | |
| `back_sit` | 뒤에서 본 앉은 자세, 정강이가 앉는 면 아래로 보이고 손은 무릎 위에 가려짐 (뒷모습 리그) | `stool` |
| `arms_crossed` | 팔짱. 화면 왼쪽 손은 반대편 팔 아래로 숨고 화면 오른쪽 손은 반대편 위팔을 쥠 | |
| `pockets` | 두 손을 주머니에 넣고 섬. 손목이 의상에 가려짐 | |

- 프리셋은 두 성별 모두에 맞음. 손 위치는 성별 체형에 맞춰 자동 조정됨
- `three_quarter`는 몸만 돌리므로 `character.head_turn`으로 얼굴 방향을 따로 지정
- `pockets`는 주머니가 있는 의상(`dress`, `blouse_skirt`, `sweater_pants`, `suit`, `shirt_pants`, `tshirt_jeans`, `crop_hotpants`, `hoodie_jeans`, 바지나 반바지가 있는 v9 의상 6종)에서 손이 주머니에 들어감
    + 주머니가 없는 의상(`bodycon`, `knit_dress`, `swimsuit`, `trunks`, `lingerie`, `none`)은 힘을 뺀 손을 몸 바깥으로 비스듬히 내림
- `arms_crossed`는 팔이 몸통 앞을 지나므로 상반신 구도(`thigh`, `knee`, `waist`)에서 가장 잘 읽힘
- `stretch`는 손이 머리 위로 올라가므로 `shot`을 쓰면 손끝까지 화면에 들어오도록 자동 조정됨

## 포즈 직접 지정

`pose_overrides`에 아래 항목을 넣어 프리셋을 수정 (정면 리그). 옆모습 포즈 항목은 옆모습 절 참조.

| 항목 | 설명 |
|---|---|
| `spine`, `chest`, `neck` | 허리, 상체, 목의 기울기(도). 0은 수직, 양수는 화면 오른쪽 |
| `hip_tilt`, `shoulder_tilt` | 골반선과 어깨선의 기울기. 양수는 화면 오른쪽이 내려감 |
| `turn` | 몸통 회전(도). 양수는 화면 오른쪽을 향함, 최대 40 |
| `arm_left`, `arm_right` | [위팔, 아래팔] 각도. 0은 수직 아래, 양수는 화면 오른쪽 |
| `leg_left`, `leg_right` | [허벅지, 정강이] 각도 |
| `reach_left`, `reach_right` | 손목 목표점. 지정하면 팔 각도를 자동 계산 (아래 3가지 형식) |
| `elbow_left`, `elbow_right` | 1은 자연스러운 팔꿈치(낮고 몸 바깥), -1은 반대 해 |
| `arm_left_scale`, `arm_right_scale` | [위팔, 아래팔] 길이 배율. 1 미만은 팔이 관객 쪽으로 나온 표현 |
| `leg_left_scale`, `leg_right_scale` | [허벅지, 정강이] 길이 배율. 앉은 자세의 허벅지는 0.42 |
| `hand_left`, `hand_right` | 손 제스처 이름 |
| `hand_left_view`, `hand_right_view` | `back` 손등, `palm` 손바닥 |
| `hand_left_angle`, `hand_right_angle` | 손가락이 향하는 방향(도). 생략하면 아래팔 방향 |
| `hand_left_roll`, `hand_right_roll` | 손의 긴 축 기준 회전(도, -90-90). 양수는 엄지 쪽 옆면이, 음수는 새끼손가락 쪽 옆면이 관객을 향함 |
| `hand_left_pitch`, `hand_right_pitch` | 손가락 끝이 관객 쪽으로 기우는 정도(도, 0-75). 손가락이 짧아 보이는 단축 표현 |
| `foot_left`, `foot_right` | 발끝 방향(도) |
| `behind` | 몸통 뒤에 그릴 팔 목록, 예 : ["left"] |
| `front` | 얼굴과 머리카락 앞에 그릴 팔 목록 |
| `first_leg` | 먼저 그려져 뒤에 놓일 다리 |
| `legs_front` | true면 다리를 몸통 앞에 그림 (허벅지가 관객 쪽으로 나오는 앉은 자세) |
| `seat` | 앉는 면의 높이 (골반 중심 아래 머리 단위). 앉은 자세에 필요 |
| `support` | 포즈의 기본 가구 (`stool`, `pillar`) |

- 뒷모습 포즈도 같은 항목을 씀. 좌우는 화면 기준 그대로임

### 손목 목표점

- 형식 3가지
    + 이름 : `"hip"`. 팔 쪽으로 자동 좌우 반전, 성별 체형에 맞춘 위치
    + 좌표 : `[x, y]`. 골반 중심 기준 머리 단위, x는 화면 오른쪽이 양수, y는 위쪽이 음수
    + 관절 기준 : `["knee_right", dx, dy]`. 다리 관절(`hip_*`, `knee_*`, `ankle_*`) 위치에서 떨어진 거리

| 이름 | 여성 [x, y] | 남성 [x, y] |
|---|---|---|
| `hip` 허리 | [0.61, -0.25] | [0.54, -0.25] |
| `front` 몸 앞 | [0.075, 0.05] | [0.08, 0.06] |
| `lap` 무릎 위 (앉은 자세) | [0.10, 0.16] | [0.10, 0.16] |
| `chest` 가슴 | [0.12, -1.38] | [0.14, -1.45] |
| `by_face` 얼굴 옆 | [0.70, -2.20] | [0.76, -2.30] |
| `wave` 머리 옆 위 | [1.38, -2.62] | [1.50, -2.75] |
| `behind_head` 머리 뒤 | [0.40, -3.05] | [0.42, -3.18] |
| `crown` 정수리 옆 | [0.23, -2.93] | [0.25, -3.05] |
| `pocket` 바지 앞주머니 | [0.42, -0.08] | [0.40, -0.06] |

- 표의 x는 화면 오른쪽 팔 기준, 왼쪽 팔은 이름을 쓰면 자동 반전
- 참고 좌표 (여성) : 어깨 관절 [±0.49, -1.80], 골반 관절 [±0.30, 0.05], 무릎 [±0.38, 1.89], 발목 [±0.41, 3.59]
- 참고 좌표 (남성) : 어깨 관절 [±0.66, -1.83], 골반 관절 [±0.24, 0.05], 무릎 [±0.33, 2.00], 발목 [±0.36, 3.82]
- 손이 얼굴이나 가슴 가까이 오는 자세는 `arm_*_scale`을 [0.45, 0.65] 정도로 줄임
- 손이 머리카락이나 얼굴을 가려야 하면 해당 팔을 `front`에 넣음
- 목표점이 팔 길이보다 멀면 팔이 일자로 펴지므로 목표점을 몸 쪽으로 당김

## 가구

| furniture | 모양 | 조건 |
|---|---|---|
| `stool` | 둥근 스툴 | 앉은 포즈 |
| `chair` | 등받이 나무 의자 | 앉은 포즈 |
| `sofa` | 2인용 소파, 등쿠션과 팔걸이 | 앉은 포즈 |
| `pillar` | 화면 왼쪽 사각 기둥, 기대는 어깨에 닿음 | 서 있는 포즈 (`lean`) |
| `bed` | 더블 침대, 나무 받침, 매트리스, 이불, 베개 2개, 화면 왼쪽 헤드보드 | 앉은 포즈 (`sitting`, `sitting_crossed`) |
| `none` | 가구 없음 | |

- 시점별 지원 가구
    + 정면 : 6종 모두
    + 옆모습 : 5종 모두. `sofa`는 끝에서 본 모습이며 가까운 팔걸이가 엉덩이를 가림, `pillar`는 등 뒤에 붙음
    + 뒷모습 : `stool`, `chair`, `none`. `chair`는 등받이가 몸 앞(관객 쪽)에 그려짐

- 가구는 인물과 같은 머리 단위로 만들어지므로 크기가 자동으로 맞음
- 앉는 면의 높이는 포즈의 `seat`에 맞춰짐
- 소파는 폭이 약 6 머리이므로 캔버스 가로를 넓게 잡음 (예 : [1600, 1500])
- 침대는 긴 쪽 가장자리에 앉은 모습이며 헤드보드가 보이도록 약 18도 돌려 그려짐
    + 길이가 약 6 머리이므로 가로가 긴 캔버스(예 : [1500, 1300])와 `"shot": "full"`, `"x": 0.42` 조합이 안정적
    + `furniture_color`는 이불 색
    + 실내 배경 `room`과 함께 쓰면 침실 장면이 됨 (`figure_lingerie_room.json`)

## 옆모습

`pose`가 `side_stand`, `side_walk`, `side_sit`, `side_wave`, `side_lounge`, `side_lean`이면 옆모습 리그가 동작함.

- 얼굴은 옆얼굴 윤곽(이마, 코, 입술, 턱)으로 그림. 남성은 눈썹뼈, 코, 턱이 더 큼
- 머리 스타일, 앞머리, 의상, 성별, 체형 키는 정면과 같은 값을 씀
- `facing` `left`면 왼쪽을 바라봄 (광원도 함께 맞춰 반전)
- 먼 쪽 팔다리는 몸 뒤에 어둡게, 가까운 쪽 팔은 몸 앞에 그려짐

`pose_overrides` 항목 (각도는 도, 양수는 얼굴 쪽으로 감)

| 항목 | 설명 |
|---|---|
| `lean`, `chest`, `neck` | 허리, 상체, 목의 앞 기울기 |
| `head_pitch` | 양수는 고개를 숙임 |
| `near_arm`, `far_arm` | 가까운 팔과 먼 팔의 [위팔, 아래팔] 각도 |
| `near_leg`, `far_leg` | 가까운 다리와 먼 다리의 [허벅지, 정강이] 각도 |
| `near_foot`, `far_foot` | 발 기울기. 양수는 뒤꿈치가 들림 |
| `near_hand`, `far_hand` | 손 제스처 이름 (손 절의 표) |
| `near_hand_roll`, `far_hand_roll` | 손 회전(도). 기본 55는 손등과 엄지 쪽 옆면이 함께 보이는 각도, 음수는 손바닥 쪽 |
| `near_hand_angle`, `far_hand_angle` | 손가락 방향(도, 0은 아래). 생략하면 아래팔 방향 |
| `seat` | 앉는 면 높이 (골반 중심 아래 머리 단위) |
| `support` | 포즈의 기본 가구 |

- 걷기 반대 발 예 : `{"near_leg": [-14, -30], "far_leg": [20, 5], "near_foot": 40, "far_foot": -12, "near_arm": [16, 32], "far_arm": [-18, -6]}`
- 옆모습 가구는 `stool`, `chair`, `sofa`, `pillar`, `none` 5종. `side_sit`은 `stool`, `side_lounge`는 `sofa`, `side_lean`은 `pillar`가 기본
- 앉는 면은 엉덩이 아래에, 소파 등쿠션과 기둥 앞면은 등이 가장 뒤로 나온 지점에 자동으로 맞춰짐
- 치마는 들어 올린 무릎(허벅지 30도 이상) 위로 천막처럼 덮임

## 뒷모습

`pose`가 `back_stand`, `back_lookback`, `back_walk`, `back_sit`이면 뒷모습 리그가 동작함.

- 골격은 정면 리그와 같고 위에 얹는 형태가 바뀜
    + 머리 : 뒤통수와 귀 뒷면. 짧은 머리는 목덜미가 보이고 `layered`는 뒷머리 끝이 뾰족하게 갈라짐
    + 몸 : 척추 홈, 견갑골, 허리 보조개, 엉덩이 곡선. 남성은 넓은 등 근육 음영이 추가됨
    + 다리 : 무릎 뒤 주름, 종아리, 아킬레스건, 뒤꿈치
    + 의상 : 등판, 재킷 뒤트임, 바지 뒷주머니, 비키니 뒤 끈. 넥타이와 라펠은 그리지 않음
- `look`으로 머리 방향 결정
    + `away` : 뒤통수 (`back_stand`, `back_walk` 기본)
    + `right`, `left` : 그 방향 어깨 너머로 돌아본 옆얼굴 (`back_lookback` 기본은 `right`)
    + `right_3q`, `left_3q` : 정면 얼굴 리그를 35도로 돌린 반측면 얼굴. 눈동자가 관객을 향하고 긴 머리는 등 위로 늘어짐
- 반측면 돌아보기는 `character.gaze`를 지정하면 그 값을 따름
- `back_sit`은 다리와 무릎 위 손을 앉는 면과 몸 뒤에 그림. 의자의 등받이는 몸 앞에 그려짐
- 늘어진 손은 새끼손가락 쪽 옆면이 보이는 각도(-60도)가 기본이며 `hand_*_roll`로 바꿈
- 몸에 붙는 의상(`bodycon`, `swimsuit`)은 엉덩이 곡선이 드러나고 바지와 치마는 약하게 드러남
- 뒷모습 렌더 예 : `figure_back_beach.json`(여성, 돌아보기), `male_back_city.json`(남성, 정장), `figure_back_chair.json`(여성, 의자에 앉아 반측면으로 돌아보기)

## 손

| 제스처 | 모양 |
|---|---|
| `relaxed` | 힘을 뺀 손, 손가락 살짝 굽힘 |
| `open` | 손가락을 벌린 손 |
| `together` | 손가락을 모은 편 손 |
| `point` | 검지만 편 손 |
| `peace` | 브이 |
| `fist` | 주먹 |
| `grip` | 무언가를 쥔 손 |
| `pocket` | 주머니에 넣은 손. 손과 손목이 의상에 가려져 그려지지 않음 |
| `tucked` | 반대편 팔 아래로 숨긴 손 (`arms_crossed`). 그려지지 않음 |

- 남성 손은 손가락과 손바닥이 굵게 그려짐
- 손은 손가락 마디마다 깊이를 가진 3D 점으로 만들어져 `roll`, `pitch`로 각도를 돌릴 수 있음
    + `roll` 60-75 : 늘어뜨린 손을 엄지 쪽에서 본 모습. 정면에서 손등이 납작하게 보일 때 가장 효과가 큼
    + `roll` -45 : 새끼손가락 쪽 옆면
    + `pitch` 30-40 : 인사하는 손이 관객 쪽으로 기울어 손가락이 짧아 보임
    + 돌린 손은 손바닥 두께와 손가락 앞뒤 순서가 자동으로 계산되고 가려진 엄지는 숨겨짐
- 손 각도 렌더 예 : `figure_hand_angles.json` (인사하는 손 `pitch` 35, 늘어뜨린 손 `roll` 70)
- `peace`는 `palm` 시점에서 가장 자연스러움
- 엄지는 자동으로 몸 안쪽을 향함
- 손은 상반신 구도에서도 버티는 수준이며 손만 확대한 그림은 권장하지 않음

## 소품 (담배)

- `figure.cigarette`로 담배 1개와 연기를 그림. 정면, 반측면, 옆모습, 뒷모습 리그와 `extras`, `duo.partner` 모두 사용 가능
- `left`, `right` : 그 손의 검지와 중지 사이에 필터가 끼고 불붙은 끝이 검지 쪽 바깥을 향함
    + 손 좌표로 붙으므로 손의 `roll`, `pitch`, 손목 각도를 따라 함께 돎
    + 그 손이 `pocket`이나 `tucked`면 오류로 중단됨 (보이지 않는 손에 담배를 쥘 수 없음)
    + 늘어뜨린 손이 가장 자연스러움. 얼굴 가까이 든 손은 `arm_*_scale`을 [0.45, 0.65]로 줄여 팔꿈치가 옆으로 튀지 않게 함
- `mouth` : 입꼬리에 물고 아래 바깥쪽으로 기울어짐
    + 정면 리그는 고개를 돌린 쪽의 반대편(관객 쪽) 입꼬리, 옆모습은 입술선 앞
    + 뒷모습 `look` `away`는 입이 보이지 않으므로 그리지 않음
- 연기는 불붙은 끝에서 4가닥으로 올라가며 위로 갈수록 넓고 옅어짐. 광원 쪽으로 조금 흐름
- 담배와 연기는 림라이트 위에 그려짐 (담뱃불이 스스로 빛나므로)
- 정물처럼 인물 없이 담배만 그릴 때는 `paintkit.props.paint_cigarette`, `paintkit.props.smoke` 사용 (`paintkit-api.md`)

- `bikini`는 `swimsuit`와 같은 의상
- `suit`는 양복 요청에 사용, 넥타이 색은 `accent`

- 성별 열은 그 의상이 재단된 대상이며 기본값, 오류 메시지, 문서의 분류에 쓰임
    + 엔진은 spec의 의상을 성별과 무관하게 그대로 그림
    + 의상을 고를 때는 인물의 성별 열이 맞는 의상을 먼저 고르고, 다른 성별 의상은 사용자가 그 조합을 명시한 경우에만 씀
    + 상황별 짝 : 비키니 `swimsuit`와 `trunks`, 크롭티와 핫팬츠 `crop_hotpants`와 `open_shirt_shorts`, 원피스 `dress`와 `suit`, 블라우스와 치마 `blouse_skirt`와 `shirt_pants`, 니트 원피스 `knit_dress`와 `coat_turtleneck` 또는 `sweater_pants`
- 재킷과 코트 색은 `palette.outer`, 비우면 소재 색 (데님 `#5f7fa8`, 가죽 `#34303a`, 코트 `#b08860`)
- 신발 색은 `palette.shoe`
- `swimsuit`, `trunks`, `lingerie`, `none`은 맨발이 기본이며 `heels`를 켜면 구두를 신음
- 모든 의상은 옆모습과 뒷모습에서도 그려짐
    + v9 의상 뒷모습 : 셔츠 칼라 띠, 데님 재킷 요크와 허리 밴드, 코트 중심선과 뒤트임, 민소매 뒤 목선
    + v9 의상 옆모습 : 열린 재킷과 코트의 앞자락 사이로 안의 옷이 보이고 코트 자락은 엉덩이에서 곧게 떨어짐
- v8 의상 3종의 시점별 형태
    + 뒷모습 : 브라 뒤 밴드와 끈, 핫팬츠 뒷주머니, 후드티 등판에 늘어진 후드
    + 옆모습 : 브라 컵 옆면, 크롭 밑단, 후드가 목 뒤에 걸린 모습
- 몸에 붙는 의상(`bodycon`, `swimsuit`)은 몸의 명암을 그대로 따르므로 `build` 변화가 가장 잘 드러남
- 앉은 자세에서 치마류(`knit_dress` 포함)는 허벅지 위를 덮는 천이 자동으로 추가됨
- 앉은 자세에서 롱코트는 앉은 면에서 끊기고 두 앞자락이 허벅지 위에 벌어져 놓임
- 반바지는 다리 조각과 엉덩이 조각으로 나뉘어 앉은 자세에서도 허벅지 위에 보임
- 흉상용 `character.outfit` 값은 전신에서 사용하지 않음

## 인체 습작

- `outfit` `none`은 의상 없는 인체 (인체 습작, 의상 디자인 밑그림 등)
- 엔진이 그리는 범위
    + 성기 형태는 엔진에 없음
    + 여성 : 쇄골, 가슴 음영, 배꼽, 서혜부 선으로 몸통을 표현. 유두 형태는 엔진에 없음
    + 남성 : 가슴 근육, 복근, 장골 V선, 배꼽으로 몸통을 표현. 유두는 옅은 색점
- `trunks`를 여성에게 쓰면 상의가 없는 상태이며 몸통 표현은 위와 같음
- `lingerie`도 몸통 표현은 위와 같으며 속옷이 비치거나 벗겨진 표현은 엔진에 없음
- 미성년자 기준은 SKILL.md의 미성년자 보호 절을 따름
- 회화풍(`painterly`)과 무릎 위 구도가 가장 그림답게 나옴
    + 눈을 작게 (`eye_height` 0.062-0.074), 입술을 도톰하게 (여성 `lip_fullness` 1.3)
    + 배경은 어두운 `wash`, `rim_light` 0.4

## 배경 인물 (extras)

최상위 `extras` 목록의 인물은 전신 리그로 배경에 그려짐. 주인공보다 먼저 그려져 항상 뒤에 놓임.

| 키 | 설명 |
|---|---|
| `character` | 성별, 얼굴, 머리 (흉상과 같은 키) |
| `palette` | 색 |
| `figure` | 포즈, 의상, 체형 등 (이 문서의 figure 키) |
| `at` | [x, z] 미터. 거리(`street`) 위의 위치. x는 도로 중앙에서 가로 거리, z는 카메라에서 앞쪽 거리 |
| `placement` | `head_height`, `pelvis`. 거리가 없는 장면에서 캔버스 비율로 직접 배치 |

- `at`을 쓰면 키(여성 1.63 m, 남성 1.76 m)와 원근에서 크기가 자동 계산됨
- 보도는 도로 중앙에서 x 3.6-6.2 m
- 캔버스 안에 들어오는 조건 : |x| < z x 캔버스 가로 / (1.8 x 캔버스 세로). [1500, 1000] 캔버스면 |x| < 0.83 z
- 가까운 배경 인물 예 : `{"character": {"gender": "male"}, "figure": {"pose": "side_walk", "outfit": "tshirt_jeans", "facing": "left"}, "at": [-4.3, 7.0]}`
- 먼 군중은 `street`의 `people`, 가까운 사람은 `extras`로 나누면 렌더가 빠름
- 주인공과 손을 잡거나 팔짱을 끼는 사람은 `extras` 대신 `duo` 사용 (다음 절)

## 투샷 (duo)

최상위 `duo` 키가 있으면 주인공(`figure`) 옆에 상대 인물(`partner`)을 함께 그림.

```json
"duo": {
  "pose": "arm_in_arm",
  "side": "right",
  "partner": {
    "character": {"gender": "male", "hair_style": "layered"},
    "palette": {"cloth": "#f2f2f4", "cloth2": "#1c2233", "accent": "#7a1a2a"},
    "figure": {"pose": "standing", "outfit": "suit"}
  }
}
```

| 키 | 기본값 | 설명 |
|---|---|---|
| `pose` | "side_by_side" | 두 인물의 관계 (아래 표) |
| `side` | "right" | 상대가 서는 쪽 (화면 기준) |
| `gap` | 포즈 기본값 | 두 골반 중심 사이 거리 (주인공 머리 단위) |
| `front` | "main" | 앞에 그릴 인물, `main` 또는 `partner` |
| `eyes` | 포즈 기본값 | `each_other`(서로 바라봄), `viewer`(관객을 바라봄) |
| `partner` | {} | 상대의 `character`, `palette`, `figure` (주인공과 같은 키) |

| pose | 연출 | 기본 gap | 기본 eyes |
|---|---|---|---|
| `side_by_side` | 나란히 섬, 접촉 없음 | 1.9 | `viewer` |
| `hold_hands` | 안쪽 손을 골반 아래 높이에서 맞잡음 | 2.0 | `each_other` |
| `arm_in_arm` | 주인공이 상대의 굽힌 팔 아래팔에 손을 얹음, 상대의 그 손은 주머니 | 1.4 | `each_other` |
| `arm_around` | 상대가 안쪽 팔을 주인공의 등 뒤 어깨높이로 둘러 먼 쪽 어깨 위에 손을 얹음. 팔은 목 양옆 어깨선 위로 보이고 손은 어깨 앞으로 걸쳐짐 | 1.5 | `each_other` |
| `face_to_face` | 두 인물 모두 옆모습으로 마주 보고 살짝 몸을 기울임 | 1.4 | 서로 마주 봄 |

- 상대의 크기는 실제 키(여성 1.63 m, 남성 1.76 m)로 계산되고 두 인물의 발이 같은 바닥선에 놓임
- `each_other`는 `head_turn`과 `gaze` 중 spec에 지정하지 않은 값만 상대 쪽으로 돌림
- 접촉 포즈(`hold_hands`, `arm_in_arm`, `arm_around`)는 두 인물 모두 정면 포즈여야 함
    + 접촉 손의 목표점과 제스처는 자동으로 들어가며 `pose_overrides`에 같은 항목을 쓰면 그 값이 우선함
    + 나머지 손은 각자의 포즈 프리셋을 따름 (예 : 상대 `pose` `pockets`)
- `face_to_face`는 두 인물을 옆모습 리그로 바꾸고 `facing`을 자동 지정. 옆모습 포즈를 주면 그 포즈를 씀
- `arm_in_arm`의 상대가 주머니 없는 의상이면 손은 몸 옆에 비스듬히 내려옴
- `arm_around`의 팔은 실제로는 등 뒤로 굽어 들어가므로 화면에서는 어깨 사이 거리만큼 짧게 그려짐
    + 손목은 주인공의 먼 쪽 어깨 윤곽(재킷 칼라와 어깨 포함) 위에 놓임
    + 키 작은 상대가 키 큰 주인공을 감싸면 팔꿈치를 더 굽혀 팔이 목 뒤 어깨선 위로 보이게 함
- 구도는 `placement.shot`이 두 인물을 함께 맞춤. 키 큰 인물의 정수리, 공통 바닥, 두 인물의 폭을 모두 고려
    + `shot` 없이 `pelvis`를 쓰면 주인공의 골반 위치, 둘 다 없으면 두 인물을 화면 가운데에 놓음
- `ground_shadow`는 상대 `figure`에 따로 주지 않으면 주인공 값을 따름
- 투샷 렌더 예 : `duo_city.json`(팔짱, 전신), `duo_beach.json`(마주 보기, 상반신), `duo_rain_night.json`(손잡기, 밤거리), `duo_living_room.json`(어깨 감싸기, 실내)

## 혼합 모드용 좌표

`scene.build`가 돌려주는 전신 객체(`portrait`)의 도구.

- `portrait.joints` : 관절 좌표 사전 (머리 단위, 골반 기준). 키는 `pelvis`, `waist`, `chest`, `neck`, `eyes`, `shoulder_left`, `elbow_left`, `wrist_left`, `hip_left`, `knee_left`, `ankle_left`와 `_right` 짝. 옆모습에서 `left`는 먼 쪽, `right`는 가까운 쪽
- `portrait.at(points)` : 골격 좌표를 픽셀로 변환
- `portrait.chest_pt(x, y)`, `portrait.pelvis_pt(x, y)` : 기울어진 가슴과 골반 기준의 점
- `portrait.masks` : 흉상 마스크에 더해 `torso`, `arm_left`, `arm_right`, `leg_left`, `leg_right`, `legs`
- `portrait.hands["right"].mask` : 손 마스크
- `portrait.plan` : 성별 체형 계획 (비례값 전체)
- `portrait.partner` : 투샷의 상대 인물 객체 (같은 도구를 가짐), 투샷이 아니면 없음
- 레이어 순서 (정면) : background, ground_shadow, hair_back, seat, figure, face, features, hair_front, see_through, figure_front, rim
- 레이어 순서 (옆모습) : background, ground_shadow, seat, figure_far, far_shade, figure, face, features, hair_front, figure_front, rim
- 레이어 순서 (뒷모습) : 정면과 같음. `hair_back`은 비어 있고 머리 전체가 `hair_front`에 그려짐, `see_through` 없음
    + 반측면 돌아보기 : `hair_back`이 `figure` 위에 그려짐 (등 위로 늘어진 머리)
    + 앉은 뒷모습 : figure_far(다리, 무릎 위 팔), seat, figure, (의자) seat_front 순
- 레이어 순서 (옆모습 소파) : 가까운 팔걸이가 `figure_front` 위의 `seat_front`에 그려짐
- 레이어 순서 (투샷) : ground_shadow, 뒤 인물의 레이어 전체, 앞 인물의 레이어 전체, `arm_around`면 상대의 손을 맨 위 `duo_hand`에 다시 그림
