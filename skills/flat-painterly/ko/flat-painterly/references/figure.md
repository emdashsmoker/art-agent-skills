## 리그의 원리

- 사람은 인체 비례에 민감해서 관절 좌표를 눈대중으로 적으면 어색함이 바로 드러남
- `figure.Figure`는 뼈 길이를 8등신 비례로 고정하고 자세만 각도로 받음
    + 어떤 자세에서도 팔다리 길이와 몸통 비례가 유지됨
- 단위는 머리 높이, 원점은 골반 중심
    + 선 자세에서 정수리는 골반 중심 위 3.85, 발목은 아래 3.85
- 좌우는 화면 기준
    + `_l`은 화면 왼쪽, `_r`은 화면 오른쪽
- 평면 리그는 정면과 뒷면을 다룸
    + 3/4 측면, 옆모습, 앞뒤로 흔든 팔다리는 `figure3d.Figure3D`를 사용(아래 3차원 리그)

```python
from codepaint import figure
from codepaint import geometry as g

BODY = figure.Figure(
    g.Frame(origin=(560, 1010), unit=236),      # 골반 중심의 화면 좌표, 머리 높이의 화면 길이
    build=figure.FEMALE,                        # 또는 figure.MALE, figure.Build(...)
    hip_tilt=-12, chest_tilt=9, spine=-5, neck=-4, head=-13,
    arm_l=(140, 290), arm_r=(10, -16), leg_l=(4, -6), leg_r=(-4, 2),
    stretch={"thigh_l": 0.96})
```

## 자세 지정

| 인자 | 뜻 | 기준 |
|---|---|---|
| `hip_tilt`, `chest_tilt` | 골반선과 어깨선의 기울기 | 양수면 화면 오른쪽이 내려감 |
| `spine`, `neck`, `head` | 척추, 목, 머리의 기울기 | 수직이 0, 양수면 화면 오른쪽으로 기욺 |
| `arm_l`, `arm_r` | (위팔, 아래팔) 각도 | 아래가 0, 양수면 몸 바깥쪽. 90은 수평, 180은 머리 위 |
| `leg_l`, `leg_r` | (허벅지, 정강이) 각도 | 아래가 0, 양수면 몸 바깥쪽 |
| `stretch` | 뼈 길이 배율 | `{"upper_arm_r": 0.62}`처럼 지정. 화면 쪽으로 뻗은 팔다리를 짧게 |
| `shoulder_drop` | 어깨 관절을 내리는 거리(머리 높이) | 기본 0. 0.12를 주면 위팔 끝이 어깨선 위로 솟지 않음. 새 그림에 권장 |

- 팔다리 각도는 모두 절대 각도
    + 아래팔 각도는 위팔과 무관하게 화면에서 아래팔이 향하는 방향
    + 음수는 몸 안쪽을 향함. 가슴 앞으로 접은 아래팔은 -120 안팎
    + 180을 넘기면 머리 위를 지나 안쪽으로 넘어감. 머리 뒤로 넘긴 아래팔은 290 안팎
- 골반선과 어깨선을 반대로 기울이면 한쪽 다리에 체중을 실은 자세가 됨
    + 체중을 실은 쪽 골반이 올라가고 그쪽 어깨가 내려감
- 자세를 정한 뒤 관절에 점을 찍은 마네킹을 먼저 렌더해서 확인
    + `BODY.joint("elbow_l")`이 관절의 화면 좌표를 돌려줌

## 검증된 자세

예제에서 렌더로 확인한 값. 새 자세는 가까운 값에서 출발해 조정.

| 자세 | 인자 | 예제 |
|---|---|---|
| 한쪽 다리에 체중(화면 오른쪽 다리) | `hip_tilt=-12, chest_tilt=9, spine=-5, leg_r=(-4, 2), leg_l=(4, -6)` | `oil_figure_study.py` |
| 정면으로 걸어오기 | `hip_tilt=7, chest_tilt=-5, leg_l=(-3, 1), leg_r=(6, -4), stretch={"shin_r": 0.82}` | `illustration_autumn_walk.py` |
| 팔을 들어 손을 머리 뒤로 | `arm_l=(140, 290)` | `oil_figure_study.py` |
| 손을 이마 옆에 올리기 | `arm_r=(52, 203), stretch={"upper_arm_r": 0.62, "forearm_r": 0.92}` | `anime_sky_pilot.py` |
| 가슴 앞에 물건 들기 | `arm_r=(14, -128), stretch={"forearm_r": 0.82}` | `illustration_autumn_walk.py` |
| 내려뜨린 팔 | `arm_l=(13, 6)` | `illustration_autumn_walk.py` |
| 전신 기준 선 자세(앞면) | `hip_tilt=-6, chest_tilt=4, spine=-1, head=-3, arm_l=(11, 5), arm_r=(13, 3), leg_l=(6, 1), leg_r=(3, -1), stretch={"neck": 0.72}, shoulder_drop=0.12` | `anime_figure_base.py` |
| 등을 보이고 옆으로 눕기 | `g.Frame(..., rotate=-90)`, `hip_tilt=9, chest_tilt=-9, spine=7, leg_r=(-15, -2), leg_l=(7, 22)` | `oil_reclining_figure.py` |

- 누운 자세는 선 자세용 리그의 Frame을 90도 돌려서 만듦
    + `rotate=-90`이면 머리가 화면 왼쪽을 향하고 리그의 `_r` 쪽이 화면 위쪽이 됨
    + 어깨, 허리, 골반의 폭 차이가 그대로 화면 위쪽 윤곽의 굴곡이 됨
    + 침상의 먼 가장자리를 몸의 중심선 조금 아래에 두고 몸 아래에 접지 그림자를 깔아야 몸이 떠 보이지 않음

## 부위 윤곽과 그리는 순서

| 호출 | 반환 |
|---|---|
| `BODY.torso()`, `BODY.neck()`, `BODY.head()` | 몸통, 목, 정면 머리 윤곽 |
| `BODY.limb(bone, side, scale=1.0)` | bone은 `upper_arm`, `forearm`, `thigh`, `shin`. side는 `"l"`, `"r"` |
| `BODY.foot(side, view="front")` | 발. view는 `"front"`(신발 자리), `"side"`, `"bare_front"`(발가락이 있는 맨발), `"bare_back"`(뒤꿈치) |
| `BODY.parts()` | 위 부위를 이름별로 모은 사전 |
| `figure.shape_of(canvas, paths)` | 겹치는 윤곽 여러 개를 구멍 없이 한 형태로 합침 |

- 모든 윤곽 메서드는 경로 목록을 반환
    + 여러 부위를 `+`로 이어 `figure.shape_of`에 넘기면 한 덩어리가 됨
    + `canvas.shape(*paths)`에 그대로 넘기면 겹친 곳에 구멍이 생기므로 `shape_of`를 사용
- 순서는 뒤에서 앞으로
    + 정면 기본: 뒷머리, 뒤로 간 팔다리, 목, 다리, 몸통, 앞으로 온 팔, 머리, 앞머리
    + 몸 앞을 가로지르는 팔은 몸통 뒤에 그림
- 이어지는 부위는 한 덩어리로 합쳐서 칠해야 관절에 이음매가 생기지 않음
    + 목과 몸통과 위팔, 허벅지와 정강이처럼 묶음
    + 따로 칠한 부위가 만나는 팔꿈치와 골반 앞쪽은 살빛의 부드러운 타원으로 덮어 이음매를 풀어 줌

## 몸의 표지 좌표

`BODY.on_thorax(x, y)`는 어깨선 중앙이 원점인 흉곽 좌표, `BODY.on_pelvis(x, y)`는 골반 중심이 원점인 골반 좌표. 몸이 기울어도 표지가 따라감. 값은 여성 체형 예제 기준.

| 표지 | 좌표 |
|---|---|
| 목 밑 오목한 곳 | 흉곽 (0, 0) |
| 쇄골 | 흉곽 (±0.09, -0.03)에서 (±0.62, -0.05) |
| 가슴 중심 | 흉곽 (±0.35, 0.68), 반지름 0.3 |
| 갈비뼈 아치 | 흉곽 (±0.06, 1.04)에서 (±0.5, 1.5) |
| 배꼽 | 골반 (0, -0.72) |
| 골반뼈 모서리 | 골반 (±0.52, -0.42) |
| 골반 앞쪽 주름 | 골반 (±0.6, -0.3)에서 (±0.1, 0.34) |
| 척추 골(뒷면) | 흉곽 (0, -0.3)에서 골반 (0, -0.2) |
| 어깨뼈(뒷면) | 흉곽 (±0.36, 0.42) |
| 엉치 보조개(뒷면) | 골반 (±0.17, -0.27) |
| 엉덩이 중심(뒷면) | 골반 (±0.4, 0.16), 반지름 0.42 |

- 얼굴은 `BODY.head_frame()` 위에 그림. 단위는 머리 높이, 원점은 머리 중심
    + 눈 중심 (±0.165, -0.02), 눈썹 y -0.12에서 -0.165, 코 밑 y 0.2, 입 y 0.26에서 0.335
- 애니메풍 얼굴은 두개골 반지름을 1로 하는 좌표계로 바꿔서 그림
    + `g.Frame(BODY.head_frame().point(0, -0.08), unit=머리높이 / 2.37, rotate=head각도)`
    + 얼굴 부품 좌표는 `references/craft.md`의 비례 표를 사용

## 옷

- 각도가 있는 인물의 옷은 `garment` 모듈을 사용(아래 의상). 이 절은 평면 리그 정면 그림의 옷
- 소매와 바지통은 `BODY.limb(bone, side, scale=1.25-1.5)`로 팔다리 윤곽을 굵게 만들어 사용
- 상의, 코트, 치마는 `on_thorax`와 `on_pelvis` 점을 이어 spline으로 그림
    + 어깨는 `build.shoulder`보다 0.12-0.14 넓게, 옆구리는 `build.ribcage`보다 0.2 넓게 잡음
    + 몸의 기울기를 좌표계가 따라가므로 옷도 자세에 맞게 기욺
- 체형 값은 `BODY.build.shoulder`, `ribcage`, `waist`, `hip`으로 읽음
- 목도리, 긴 머리, 망토처럼 흐르는 것은 `g.ribbon(중심선, 폭 목록)`

## 손과 발

```python
hand = figure.hand_open(BODY.hand_frame("r", turn=-38), spread=0.45, curl=(0.22, 0.26, 0.3, 0.36), thumb=0.7)
hand = figure.hand_side(BODY.hand_frame("l", flip=True), curl=0.3)
shape = figure.shape_of(cv, hand.paths())          # 손 전체 실루엣
finger = figure.shape_of(cv, hand.parts["index"])  # 부위 하나
```

| 호출 | 용도 |
|---|---|
| `hand_open(frame, spread=1.0, curl=0.0, thumb=1.0, view="back")` | 손등 또는 손바닥에서 본 손. 흔드는 손, 가리키는 손, 주먹 |
| `hand_side(frame, curl=0.25)` | 엄지 쪽 옆에서 본 손. 늘어뜨린 손, 쥔 손 |
| `BODY.hand_frame(side, turn=0.0, flip=False)` | 손목에 붙은 손 좌표계. turn으로 손목을 꺾고 flip으로 좌우 손을 바꿈 |

- curl은 0이 편 손, 1이 쥔 손
    + `hand_open`의 curl은 값 1개 또는 검지, 중지, 약지, 소지 순서의 값 4개
    + 가리키는 손은 `curl=(0.0, 0.85, 0.9, 0.92)`
    + 늘어뜨린 손은 `hand_side(curl=0.3)`, 물건을 쥔 손은 `hand_side(curl=0.6-0.8)`
- 부위는 `palm`, `pinky`, `ring`, `middle`, `index`, `thumb`
    + 손등 쪽은 이 순서로 그리고 손바닥 쪽은 thumb를 palm 다음에 그림
    + 부위마다 따로 칠하고 `edge_light`로 윤곽을 주어야 손가락이 구분됨
- `hand.joints[이름]`은 뿌리에서 끝까지의 마디 좌표
    + 마디 주름과 손톱을 그릴 때 사용. `examples/watercolor_hand_studies.py` 참고
- 쥔 물건은 손바닥과 손가락 사이에 그림
    + 물건을 먼저 그리고 손가락을 위에 얹음
- 장갑, 소매 끝, 주머니로 손을 덮으면 세부 부담이 줄어듦
- 손은 화면에서 머리 높이의 4분의 3 길이
    + 이보다 크게 확대하는 구도에서는 마디의 굴곡이 단순해 보임

## 화풍별 살 칠하기

| 화풍 | 방법 |
|---|---|
| 애니메풍 | 합친 덩어리에 밑색, `form_shadow`(soft 0) 1단 그림자, `canvas.contour`로 바깥 윤곽선. 쇄골, 갈비, 골반뼈는 양 끝이 가는 안쪽 선 |
| 유화풍 | 덩어리마다 밑색, 부드러운 그늘(`form_shadow(soft=0.4)`), 짙은 그늘, 밝은 면(`form_light(soft=0.5)`), 그늘 쪽 반사광(`edge_light`) |
| 수채화풍 | 흰색 밑칠 뒤 살색을 MULTIPLY로 얹고 그늘을 한 번 더 겹칠 |
| 일러스트풍 | 평면 살색에 `form_shadow(soft=0.4)`를 `grain=1.0`으로 |

- 살의 그늘은 붉은 갈색, 가장 짙은 그늘은 어두운 적갈색
    + 그늘 쪽 윤곽에 붉은 반사광을 얇게 얹으면 살이 둥글게 돌아감
- 뼈와 근육의 표지는 윤곽선 없이 가장자리가 풀린 타원 얼룩으로 표현
    + `cv.fill(cv.shape(g.ellipse(...), soft=...), 색, opacity=0.3-0.6, clip=덩어리)`

## 인체 습작

- 대상은 성인으로 한정하고 아래 성인 표지를 모두 갖춤
    + 몸: 8등신 리그와 성인 체형(`figure.FEMALE`, `figure.MALE` 또는 그에 준하는 Build)
    + 얼굴: 작은 눈과 긴 턱. 애니메풍은 `references/craft.md`의 성인 여성 얼굴 표 또는 성인 남성 얼굴 표를 사용
    + 표지: 뚜렷한 코와 색이 있는 입술, 쇄골과 갈비와 골반뼈의 안쪽 선
    + 맥락: 교복, 책가방, 아동용 소품처럼 미성년을 떠올리게 하는 요소를 넣지 않음
    + 하나라도 빠져 미성년으로 보일 여지가 있으면 노출과 매력 연출을 적용하지 않음
- 화풍은 네 가지 모두 가능
    + 애니메풍은 위 얼굴 표지가 특히 중요함. 큰 눈과 짧은 턱은 바로 어려 보임
- 범위는 회화, 일러스트, 해부도의 인체화
    + 전신 기준 그림(베이스)은 머리부터 발끝까지 가리지 않고 그림. 옷과 다른 자세의 기준이 되기 때문
    + 가슴, 등, 엉덩이, 골반, 허벅지의 형태와 명암은 그림
    + 전신 베이스 예제의 골반 앞쪽은 고전 조각과 해부도 수준으로 표현. 여성은 골반 앞쪽 주름이 모이는 둥근 면(치구), 남성은 세부 없는 작은 둥근 덩어리의 빛과 그늘만 둠
    + 장면 그림에서는 천, 자세, 뒷모습으로 가리는 연출도 가능
- 인물의 매력은 자세의 곡선에서 나옴
    + 골반선과 어깨선을 반대로 크게 기울여 몸통에 S자 흐름을 만듦
    + 허리와 골반의 폭 차이를 키운 Build를 사용. 예제는 `Build(shoulder=0.70, ribcage=0.61, waist=0.50, hip=0.83, ...)`
    + 든 팔, 넘긴 머리카락, 흘러내리는 천이 곡선을 이어 줌
- 살은 화면에서 가장 밝고 따뜻한 덩어리로 둠
    + 배경은 어둡게, 천은 살의 보색 쪽 한색으로
    + 빛 받는 쪽 살은 어두운 배경 앞에, 그늘진 쪽 살은 밝은 배경 앞에 두면 양쪽 윤곽이 모두 읽힘
- 유화 패스는 `relief=0.4`, `color_jitter=0.035`로 낮춰 살의 매끈함을 지킴
- 애니메풍 순서: 뒷머리 → 머리 뒤로 넘긴 팔 → 몸 전체를 합친 덩어리 → 설계 그림자(턱 밑, 겨드랑이, 가슴 밑, 허리의 접힌 쪽) → 가슴 → 안쪽 선 → 얼굴 → 앞머리 → 천 → 손
    + 몸통과 다리를 한 덩어리로 합쳐야 골반 아래에 덩어리 경계선이 생기지 않음
    + 턱 밑 그림자는 얼굴 좌표계로 잡아야 머리 크기와 목 길이를 바꿔도 턱에 붙음
    + 창이나 조명을 등진 구도에서는 `anime.rim_light`로 윤곽에 빛 테두리를 둘러 몸을 배경에서 떼어 냄
- 예제: `examples/oil_figure_study.py`(유화 정면 입상), `examples/oil_reclining_figure.py`(유화 뒷면 와상), `examples/anime_city_window.py`(애니메풍 정면 입상), `examples/anime_figure_base.py`(애니메풍 전신 베이스 앞면과 뒷면), `examples/anime_figure_base_male.py`(애니메풍 남성 전신 베이스), `examples/anime_turnaround.py`(남녀 다섯 각도 턴어라운드와 포즈 시트)

## 3차원 리그

`examples/anime_turnaround.py`에서 확인한 사용법. 남녀가 같은 공정을 쓰고 체형, 머리, 색만 바꿈.

- 평면 리그로는 몸을 돌릴 수 없음
    + 관절을 3차원에 놓고 원하는 각도로 투영해야 3/4 측면과 옆모습의 비례가 유지됨
- `Figure3D`는 `figure.Figure`의 인자를 그대로 받고 각도 인자를 더함
    + turn 0에서는 관절과 몸통 윤곽이 평면 리그와 같음
- 몸통은 높이별 단면 11개로 만듦
    + 단면마다 투영된 좌우 끝점을 이어 어느 각도에서도 실루엣이 나옴
    + 가슴과 엉덩이의 앞뒤 두께는 `Depth`가 정함. `FEMALE_DEPTH`, `MALE_DEPTH`
- 발은 점 구름의 볼록 껍질
    + 발끝이 관찰자를 향할 때만 `toes()`가 발가락 5개를 돌려줌

```python
from codepaint.figure3d import Figure3D, MALE_DEPTH
BODY = Figure3D(g.Frame((x, y), unit), build=figure.MALE, depth=MALE_DEPTH, turn=45, elevation=5,
                stretch={"neck": 0.72}, shoulder_drop=0.14, arm_l=(12, 6), arm_r=(12, 6), leg_l=(4, 0), leg_r=(4, 0))
```

| 인자 | 뜻 | 기준 |
|---|---|---|
| `turn` | 몸 전체의 회전 | 0 정면, 45 3/4 앞, 90 오른쪽을 보는 옆모습, 135 3/4 뒤, 180 뒷면. 음수는 왼쪽으로 돎 |
| `elevation` | 내려다보는 시선 | 5 안팎이면 발등과 어깨 윗면이 보여 전신이 안정됨 |
| `lean` | 상체를 앞으로 숙인 각도 | 앉아서 숙인 자세 12-20 |
| `swing` | 팔다리를 앞뒤로 흔든 각도 | `{"leg_l": (허벅지, 정강이)}`. 양수가 몸 앞. 정강이 값도 절대 각도 |
| `head_turn` | 몸과 따로 머리만 돌린 각도 | 어깨 너머로 돌아보기 -70 안팎 |
| `foot_pitch` | 발끝을 내리고 뒤꿈치를 든 각도 | `{"l": 24}`. 걷기의 뒷발 |

| 자세 | 인자 | 예제 |
|---|---|---|
| 턴어라운드 선 자세 | `arm_l=(12, 6), arm_r=(12, 6), leg_l=(4, 0), leg_r=(4, 0), elevation=5`, turn 0, 45, 90, 135, 180 | `anime_turnaround.py` |
| 3/4 앞에서 본 앉기 | `turn=35, lean=6, swing={"leg_l": (86, 2), "leg_r": (90, 12), "arm_l": (14, 62), "arm_r": (18, 66)}, arm_l=(10, -14), arm_r=(8, -16)` | `anime_turnaround.py` |
| 옆에서 본 걷기 | `turn=-90, lean=4, swing={"leg_r": (24, 4), "leg_l": (-14, -38), "arm_r": (-20, -6), "arm_l": (22, 44)}, foot_pitch={"l": 24}` | `anime_turnaround.py` |
| 어깨 너머로 돌아보기 | `turn=155, head_turn=-72, hip_tilt=5, chest_tilt=-3` | `anime_turnaround.py` |
| 옆에서 본 앉기(손을 무릎에) | `turn=75, lean=12, swing={"leg_l": (84, 4), "leg_r": (80, 10), "arm_l": (25, 60), "arm_r": (22, 62)}` | `anime_turnaround.py` |

- 가까운 쪽은 turn의 부호로 정해짐
    + turn 양수면 `_l`이 가깝고 음수면 `_r`이 가까움
    + 걷기와 앉기에서 앞으로 내민 다리를 가까운 쪽에 두면 다리가 덜 겹침
- 칠하는 순서는 `groups()`가 정함
    + 먼 팔다리, 몸(몸통과 깊이가 비슷한 팔다리를 합친 덩어리), 가까운 팔다리 순서
    + 정면과 뒷면에서는 모든 팔다리가 몸에 합쳐져 평면 리그와 같은 한 덩어리가 됨
    + 가까운 다리는 엉덩이와 이어지도록 몸에 합침. 허벅지를 40도 넘게 든 다리는 따로 칠해 배와 허벅지 사이에 선이 생김
- 따로 칠한 덩어리의 이음매
    + 몸 위에 칠하는 가까운 팔다리는 어깨나 고관절 둘레 반지름 0.34 안쪽의 윤곽선을 지움
    + 먼 다리 위를 지나는 골반 윤곽선은 고관절 둘레 0.75 안에서 지우되 가까운 허벅지 자리의 선은 남김
- 겉면 표지는 법선이 관찰자를 향할 때만 그림
    + `surface(part, x, y, side)`로 점과 법선을 얻고 `facing`이 0.12보다 클 때 그림. 0.42까지는 흐리게 시작함
    + 선은 보이는 점이 이어진 구간만 긋고 빛은 3차원 법선과 광원의 각도로 세기를 정함
    + 평면 리그용 표지 좌표(위 표들)를 그대로 쓰고 앞면은 `side="front"`, 뒷면은 `side="back"`
- 둥근 덩어리는 `bulge`의 타원체로 그림
    + 가슴은 흉곽 (±0.31, 0.72)에서 앞면보다 0.17 들인 반지름 0.26×0.27×0.2. 가슴 밑 주름은 타원체 아래 가장자리
    + 엉덩이는 골반 (±0.39, 0.18) 뒷면에 붙인 반지름 0.42×0.4×0.24. 엉덩이 밑 주름도 타원체 아래 가장자리
    + 몸통 단면의 아래 끝(골반 y 0.5)은 가랑이라 폭이 0.12뿐. 그 아래의 표지를 겉면에 붙이면 옆구리로 밀려남
- 손은 손등이나 손바닥이 보이는 정도로 고름
    + 바깥 방향의 향하는 정도가 0.75를 넘으면 `hand_open`(엄지가 몸 앞쪽), 아니면 `hand_side`(손바닥이 몸 가운데 쪽)
- 바닥은 가장 낮은 발 실루엣으로 맞춤
    + 시험용 리그로 발 실루엣의 최저점을 구한 뒤 골반 높이를 정함. 앉은 자세와 뒤꿈치를 든 걷기에도 그대로 맞음

## 각도별 머리와 머리카락

- `head3d.Head3D`가 머리를 3차원으로 다룸
    + `FEMALE_HEAD`, `MALE_HEAD`의 정면 윤곽은 craft.md의 성인 여성, 성인 남성 얼굴 표와 같음
    + `Head3D.on_body(body, spec)`가 몸의 머리 자리, 몸 회전과 `head_turn`을 합친 각도를 맞춤
- 얼굴 부품은 정면 좌표 그대로 그림
    + `head.face()`가 돌려주는 좌표계에 craft.md의 좌표를 넣으면 얼굴 겉면에 붙어 각도만큼 찌그러짐
    + 부품마다 `face.facing(x, y)`가 0.12보다 클 때만 그림. 옆모습에서는 먼 눈이 저절로 빠짐
    + 콧대 선은 먼 쪽(정면이면 그늘 쪽)에 긋고 세 번째 값(lift)으로 얼굴면에서 띄움
- 머리 윤곽은 두개골과 얼굴 두 볼록 껍질
    + 한 덩어리로 감싸면 뒤통수와 턱 끝 사이의 목 자리까지 머리가 됨
- 머리카락은 덮개와 다발
    + 덮개 `cap(style)`은 머리카락 선(hairline) 위의 두피를 부채꼴 조각으로 감싸 귀 위의 홈을 살림
    + 얼굴이 보이는 각도에서는 `face_window(style)`을 덮개에서 뺌
    + 다발 `Lock`은 두피를 따라 내려오다 `hang_from` 아래로 곧게 늘어짐. 단발은 끝이 뭉툭한 taper를 줌

| 순서 | 내용 |
|---|---|
| 1 | `locks(style)["back"]`: 관찰자를 등진 다발. 몸보다 먼저 |
| 2 | 얼굴이 등진 각도의 턱 덩어리. 몸보다 먼저 칠해 목 옆으로 나온 부분만 보이게 함. 거의 뒷면이면 생략 |
| 3 | 몸(`groups()` 순서) |
| 4 | 목에 드리운 그림자: 머리 윤곽을 두개골 반지름의 0.32만큼 내려 몸과 겹친 자리 |
| 5 | 향하는 정도 0.5 이하의 귀 |
| 6 | 머리 살: 밑색, 몸의 절반 양(0.18)의 흐린 그림자, 윤곽선 |
| 7 | 얼굴 부품: 앞머리 그늘, 빛을 덜 받는 쪽 볼의 그늘 띠, 코, 입, 눈, 눈썹 |
| 8 | 향하는 정도 0.5 초과의 귀와 귓바퀴 선 |
| 9 | 덮개(얼굴 자리를 뺀 것), `locks(style)["front"]`, 정수리 빛 띠와 결 선 |

- 볼 그늘 띠는 빛을 덜 받는 쪽에 둠
    + 얼굴면 법선과 광원으로 좌우 볼의 밝기를 비교. 얼굴이 빛 쪽으로 돌면 띠가 반대쪽으로 옮겨 감
- 범위
    + 어깨 위에서 끝나는 다발은 머리 좌표만으로 그림. 어깨 아래로 내려오는 다발은 `drape`를 줘야 몸통을 피함(얼굴과 머리 템플릿)

## 얼굴과 머리 템플릿

`examples/anime_face_templates.py`(얼굴 3종 × 3각도), `examples/anime_hair_templates.py`(머리 8종 × 5각도), `examples/anime_hair_colors.py`(머리색 12종)에서 확인한 템플릿. 긴 머리 장면은 `anime_long_hair_platform.py`(전신 3/4 앞), `anime_long_hair_window.py`(역광 3/4 뒷모습), `anime_long_hair_walk.py`(손잡고 걷는 투샷).

- 템플릿은 `character.restyle`로 고름
    + 얼굴 템플릿은 얼굴형(턱 단면, 코 높이)과 이목구비를 함께 바꿈
    + 머리 모양은 덮개, 머리카락 선, 다발 목록을 바꿈
    + 머리색은 팔레트의 머리 4색(밑색, 그림자, 빛 띠, 선)을 바꾸며 눈썹도 선 색을 따름
    + 피부, 눈, 입술 색과 체형은 그대로 두므로 바꿀 때는 `dataclasses.replace`로 팔레트를 고침

```python
from codepaint import faces, hairstyles
look = ch.restyle(ch.FEMALE, face=faces.FEMALE_SOFT, hair=hairstyles.LONG_STRAIGHT,
                  hair_color=hairstyles.HAIR_COLORS["silver"])
model = ch.place(look, origin, unit, turn, outfit=garment.long_coat())
```

| 얼굴 | 인상 | 얼굴형 | 눈과 눈썹 | 입과 볼 |
|---|---|---|---|---|
| `FEMALE_MATURE`(기본) | 성숙한 | 턱 끝 1.45 | 날개 뺀 아몬드 눈, 가는 호 눈썹 | 아랫입술 색, 볼 터치 |
| `FEMALE_SOFT` | 부드러운 | 넓고 둥근 아래턱, 턱 끝 1.43 | 눈꼬리가 처진 둥근 눈, 쌍꺼풀, 굵은 호 눈썹 | 도톰한 입술, 짙은 볼 터치 |
| `FEMALE_SHARP` | 날카로운 | 좁은 V자 턱, 턱 끝 1.47 | 위로 뺀 날개의 가는 고양이 눈, 곧은 눈썹 | 넓고 얇은 입술, 옅은 볼 터치 |
| `MALE_CLEAN`(기본) | 단정한 | 꺾인 턱 모서리 | 가는 눈, 쌍꺼풀, 굵은 면 눈썹 | 입술선, 턱 끝 그늘 |
| `MALE_GENTLE` | 온화한 | 둥근 턱 | 조금 큰 처진 눈, 가는 호 눈썹 | 입꼬리를 올린 선 |
| `MALE_RUGGED` | 거친 | 넓은 각진 턱, 턱 끝 1.54 | 깊은 눈두덩의 가는 눈, 낮고 두꺼운 일자 눈썹 | 넓은 입, 수염 자국 점묘 |

- 성인 표지를 지키려고 눈 반폭은 0.25 이하, 턱 끝은 1.42 아래로 둠. 눈을 키우고 턱을 줄일수록 어려 보임

| 머리 | 길이 | 다발 구성 |
|---|---|---|
| `BOB`(여성 기본) | 턱선 | 옆 가르마 앞머리, 앞이 긴 옆머리 |
| `LONG_STRAIGHT` | 등 가운데 | 앞머리, 어깨 앞으로 흐르는 옆머리 6가닥(`drape="front"`, `spread`), 등 뒤 9가닥(`drape="back"`) |
| `SHOULDER` | 어깨선 | 앞머리, 어깨 앞 옆머리 4가닥, 어깨 뒤 9가닥 |
| `PONYTAIL` | 꼬리가 등 위쪽 | 이마를 드러낸 덮개, 얼굴 옆 가는 다발 2개, 묶은 매듭, 뒤로 늘어진 꼬리(`drape="back"`) |
| `SHORT`(남성 기본) | 귀가 드러남 | 이마로 흘러내린 앞머리, 목덜미 끝 |
| `SIDE_PART` | 귀가 드러남 | 왼쪽 가르마에서 오른쪽으로 쓸어 넘긴 앞머리 |
| `CROPPED` | 아주 짧음 | 다발 없는 얇은 덮개 |
| `MALE_LONG` | 목덜미를 덮음 | 가운데 가르마 앞머리, 볼 옆 다발, 목을 덮는 뒷머리(`drape="back"`) |

| 머리색 | 이름(`HAIR_COLORS`) |
|---|---|
| 자연색 | `black`(푸른 기 검정), `dark_brown`, `chestnut`, `blonde`, `silver` |
| 애니 원색 | `pink`, `sky_blue`, `navy`, `red`, `purple`, `mint`, `orange` |

- 애니풍 머리색은 그림자를 밑색보다 어둡고 조금 차갑게, 빛 띠는 밝고 채도를 낮춰 잡음. `examples/anime_hair_colors.py`
- 장면의 머리색은 배경 지배색의 보색 쪽을 고르면 인물이 뜸(초록 공원에 분홍, 파란 바다에 은발)

- 긴 다발의 드레이프
    + 머리 좌표의 다발 중심선을 몸 좌표로 옮김. 옮긴 점은 머리로 투영한 자리와 같은 화면 자리에 투영됨
    + 위에서부터 따라가며 몸통 단면을 여유 0.08만큼 부풀린 안에 든 점을 drape 쪽(앞 또는 뒤) 겉면 밖으로 밈
    + 한 번 밀린 다발은 그 자리에서 곧게 늘어지고, 밀기는 12점 앞서 코사인으로 미리 받아 어깨 위에서 휘어 넘어감
    + 중심선의 3분의 2 지점이 몸통 가운데보다 관찰자 쪽이면 몸 다음에, 아니면 몸보다 먼저 칠함
    + 몸 앞으로 흐르지만 얼굴 높이에서는 머리 가운데보다 먼 다발(3/4 각도의 먼 쪽 옆머리)은 얼굴 자리를 빼고 칠함(tucked). 볼 뒤에서 나와 몸 앞으로 흐르는 모양
    + 앞 다발은 관자놀이에서 귀 쪽으로 비켜 내려오게 둠. 같은 phi로 곧게 늘어뜨리면 볼 위에 얹혀 3/4 각도의 가까운 눈을 덮음
    + 긴 다발 뿌리는 좁게 시작함(taper 첫 값 0.35). 넓게 시작하면 정수리 양옆에 뿔처럼 솟음
- 새 얼굴은 `faces.FaceSpec`, 새 머리는 `head3d.HairStyle`과 `Lock`으로 만들고 템플릿 시트 예제에 넣어 5각도로 확인
- 범위
    + 다발은 몸통만 피함. 앞으로 든 팔, 목도리 끝, 소품과의 겹침은 렌더를 보고 확인
    + 바람에 날리는 머리, 크게 숙이거나 누운 자세의 머리는 검증하지 않음
    + 여성 머리 정수리 양옆의 뾰족한 다발 끝은 단발에서 물려받은 모양

## 3차원 인물 그리기

- `character` 모듈이 `figure3d` 몸과 `head3d` 머리를 칠하는 공정 전체를 맡음
    + `character.place(look, 골반 화면 좌표, 머리 높이, turn, elevation, outfit=..., **자세)`가 인물(Model)을 만듦
    + `character.paint_figure(canvas, model)`이 등 뒤 망토, 뒷머리, 덩어리와 옷, 앞 망토, 머리 순서로 칠함
    + 모습(Look)은 체형, 몸통 두께, 머리 모양, 머리카락, 색. `character.FEMALE`, `character.MALE`을 `dataclasses.replace`로 바꿔 씀
- 화풍은 `Ink`로 바꿈
    + 선 굵기와 짙기, 덩어리 그림자의 양과 번짐, 밝은 면의 짙기, 빛 방향을 정함
    + 기본값 `character.ANIME`는 셀 채색. 유화와 수채화는 선을 옅게(0.3-0.55), 그림자를 번지게(0.35-0.45) 한 뒤 화풍 패스를 거침

| 화풍 | Ink 값 | 예제 |
|---|---|---|
| 애니메풍 | 기본값 | `anime_cafe_talk.py` |
| 수채화풍 | `line_width=1.7, line_scale=0.75, line_opacity=0.55, shadow_soft=0.35, light_opacity=0.35` | `watercolor_street_walk.py` |
| 일러스트풍 | `line_width=2.4, line_opacity=0.9, body_shadow=0.32, light_opacity=0.35` | `illustration_fantasy_walk.py` |
| 유화풍 | `line_width=1.5, line_scale=0.7, line_opacity=0.28, body_shadow=0.42, shadow_soft=0.45` | `oil_evening_dance.py` |

- 쥔 손은 `grips=("l",)`로 지정
    + 엄지 쪽에서 본 주먹으로 그림. 막대(우산대, 지팡이)는 주먹 가운데를 지나게 하고 손 실루엣을 빼고 칠해야 손가락 뒤로 지나감
- 엄지 선은 손바닥 안쪽 구간만 옅게 그음(`THUMB_LINE_ON_PALM` 0.35). 둘레 선을 모두 짙게 그으면 엄지가 손바닥 위에 따로 얹힌 덩어리로 보임
- 몸 앞을 가로지르는 먼 쪽 팔은 `in_front=("arm_l",)`로 몸 다음에 칠함
- 무릎 위 구도처럼 인물 일부가 화면 밖으로 나가도 그대로 칠함(`oil_doomer_overpass.py`)

## 의상

- 옷은 몸을 어느 각도로 돌려도 몸을 따라감
    + 몸통 옷은 몸통 단면을 여유(ease)만큼 부풀린 단면으로 만들고 단면마다 투영된 좌우 끝점을 이음
    + 치마, 코트, 로브, 망토의 아랫단은 골반 아래로 단면을 더 쌓아 퍼지게 함. 걷거나 앉아 다리가 단면 밖으로 나가면 단면을 넓혀 덮음
    + 소매와 바짓가랑이는 팔다리를 굵게 감싼 띠, 신발은 발 점 구름을 부풀린 볼록 껍질
- 옷 한 벌 함수가 색을 받아 몸을 받는 함수를 돌려줌
    + `character.place(..., outfit=garment.casual_knit(knit="#a9bf9a"))`
    + 옷 윤곽은 자세와 각도에 따라 달라지므로 몸을 만든 뒤에 계산됨

| 옷 한 벌 | 구성 | 예제 |
|---|---|---|
| `casual_knit` | 둥근 목 니트, 긴 바지, 단화 | `anime_cafe_talk.py`, `anime_outfit_sheet.py` |
| `casual_shirt` | 깃 달린 반소매 셔츠, 바지, 운동화 | `anime_cafe_talk.py` |
| `formal_dress` | 긴 원피스(아랫단 물결과 회전), 짧은 소매, 굽 있는 구두 | `oil_evening_dance.py` |
| `formal_suit` | 재킷, 셔츠 앞섶과 넥타이, 슬랙스, 구두 | `oil_evening_dance.py` |
| `long_coat` | 무릎 길이 코트, 허리띠, 목도리, 장화. length 1.5면 허벅지 길이 | `watercolor_street_walk.py` |
| `mage_robe` | 발목 로브, 종 모양 소매, 허리띠, 망토 | `illustration_fantasy_walk.py` |
| `light_armor` | 튜닉, 가슴 갑옷, 어깨 갑옷, 팔 보호대, 망토 | `illustration_fantasy_walk.py` |

- 조각(Garment)마다 칠할 덩어리(group)가 정해짐
    + 소매는 `arm_l`, 바짓가랑이와 신발은 `leg_l` 덩어리에 얹음. 팔다리가 몸에 합쳐진 각도에서는 몸 덩어리에 얹음
    + 같은 merge 값의 조각이 같은 덩어리에 모이면 한 형태로 합침. 바지 허리와 가랑이 사이에 선이 생기지 않음
    + 망토(group cape)는 등 쪽이 관찰자를 향할 때만 몸 위에, 아니면 몸보다 먼저 칠함
- 새 옷은 `garment.loft`, `limb_span`, `shoe`, `neck_band`, `bulge`로 조각을 만들고 `Garment`로 감쌈
    + `loft(body, top, bottom, ease, hem=Hem(...), half="back", loose=0.6)`. loose는 허리처럼 오목한 곳을 메우는 헐렁한 정도
    + 안쪽 선은 `surface_curve`(몸통 겉면 곡선), `limb_marks`(소매와 바지 주름), `Loft.line_at`(치마 주름), `surface_dots`(단추)
- 범위
    + 앉은 자세의 치마와 원피스는 다루지 않음. 허벅지 위로 늘어지는 천 계산이 없음
    + 옷 주름은 정해 둔 자리의 선이며 천의 물리 계산은 없음

## 투샷과 무대

- `stage.Stage`가 두 사람과 소품이 같은 시선을 공유하는 무대를 만듦
    + 세계 좌표는 x 화면 오른쪽, y 아래(바닥 0), z 멀어지는 쪽. 단위는 머리 높이
    + `stage.place(look, x, z, turn, ...)`가 발을 바닥에 붙인 인물을 세계 위치에 놓음
    + `stage.box`, `stage.cylinder`, `stage.ellipse`가 의자, 탁자, 컵, 바닥 그림자를 같은 시선으로 투영함
- 손이 닿는 자리는 `reach`나 `fists`로 맞춤
    + `reach={"arm_r": 세계 좌표}`이면 그 손목이 목표에 닿도록 팔 각도를 계산함(두 뼈 역운동학)
    + `fists={"arm_r": 세계 좌표}`이면 쥔 주먹의 가운데가 목표에 닿음. 막대를 쥔 손에 씀
    + 맞잡는 손은 두 사람의 목표를 한 점의 양옆 0.12에 두고, 다른 사람의 관절에 닿는 손은 `stage.joint_world`로 목표를 구함
    + 쥔 주먹의 가운데는 `stage.fist_world(model, side)`. 막대는 이 점을 지나게 그림
- 팔꿈치 방향은 `poles`로 정함
    + 기본값 `ELBOW_POLE` (바깥 0.45, 아래 1.0, 뒤 0.35)은 혼자 선 인물에 맞춘 값
    + 어깨를 맞댄 두 사람의 안쪽 팔은 바깥이 상대 쪽이라 기본값이면 팔꿈치가 상대 몸으로 파고듦. 바깥 성분을 0 이하로 줄임
- 칠하기 전에 `stage.collisions([a, b])`로 관통을 확인
    + 팔 뼈 중심선이 상대 몸통 안에 들거나 두 팔 뼈의 거리가 굵기 합보다 작으면 관통으로 봄
    + 보이는 자리의 관통은 칠하는 순서와 무관하게 팔이 잘려 보이므로 poles, 손 목표, 두 사람 간격을 먼저 고침
    + 상대 몸에 가려지거나 그림으로 어색하지 않은 관통은 렌더를 보고 남길지 정함
- 칠하는 순서
    + 먼 사람부터(`stage.far_first`). 두 사람이 겹치면 가까운 사람이 먼 사람의 몸을 덮음
    + 소품과 엇갈리는 팔다리는 `paint_figure(..., defer=("arm_l",))`로 미루고 소품을 칠한 뒤 `paint_deferred`로 칠함
- 맞잡은 손은 두 사람 모두 `grips`로 주먹을 쥐고 한쪽에 `palm_out`을 줌
    + 두 주먹 가운데를 맞잡을 점의 양옆 0.1에 `fists`로 두면 손가락이 가운데에서 맞물림
    + 몸과 깊이가 비슷해 몸 덩어리에 합쳐지는 팔은 `in_front`로 따로 떼어야 코트 자락 위에 손이 보임

| 상황 | 배치 | 예제 |
|---|---|---|

## 흔한 결함

| 증상 | 처방 |
|---|---|
| 관절이 구체관절 인형처럼 보임 | 이어지는 부위를 `shape_of`로 합쳐 한 번에 칠하고 이음매를 살빛 얼룩으로 덮음 |
| 든 팔이 화면 밖으로 나가거나 너무 길어 보임 | 화면 쪽으로 나온 뼈에 `stretch` 0.6-0.8을 주고 각도를 줄임 |
| 누운 몸이 침상 위에 떠 보임 | 침상 가장자리를 몸 중심선 근처로 올리고 접지 그림자를 닿는 선을 따라 깔음 |
| 소매나 바지가 몸에 달라붙어 보임 | `limb`의 scale을 1.3 이상으로 올림 |
| 손이 손가락 묶음처럼 보임 | 부위마다 따로 칠하고 윤곽을 주며 손가락 사이가 붙도록 spread를 0.5 이하로 |
| 남성 근육이 얼룩처럼 보임 | 빛의 soft를 크기에 비례해 키우고 빛을 등진 쪽 빛을 약하게 |
| 남성 얼굴이 밋밋함 | 턱 모서리와 턱 끝을 꺾고 양쪽 볼 그늘, 굵은 눈썹, 콧대 선을 추가 |
| 얼굴이 어려 보임 | 눈을 줄이고 턱을 늘림. 애니메풍 성인은 눈 단위 0.24, 턱 끝 y 1.45, 볼 그림자와 콧대 선 추가 |
| 목이 너무 길어 보임 | `stretch={"neck": 0.7-0.75}`. 애니메풍처럼 머리를 키워 그릴 때 특히 필요 |
| 어깨가 솟아 보임 | 내린 팔의 위팔 굵기를 줄이거나 어깨 쪽 윤곽을 살빛으로 풀어 줌 |
| 살이 평평함 | 그늘 비율을 0.45 이상으로 올리고 짙은 그늘과 반사광을 추가 |
| 3/4 앞에서 골반 윤곽선이 먼 허벅지를 가로지름 | 먼 다리 위 고관절 둘레의 몸 윤곽선을 지우고 가까운 허벅지 자리의 선만 남김 |
| 가까운 팔의 어깨에 원 모양 선이 생김 | 따로 칠한 팔다리는 관절 둘레의 윤곽선을 지워 몸과 이음 |
| 뒷면에서 턱이 목 위로 보임 | 얼굴이 등진 각도에서는 턱 덩어리를 몸보다 먼저 칠함 |
| 얼굴이 반으로 갈라져 보임 | 머리의 덩어리 그림자를 몸의 절반으로 줄이고 명암은 볼 그늘 띠로 줌 |
| 엉덩이 밑 주름이 옆구리로 밀려남 | 주름을 몸통 겉면이 아닌 엉덩이 타원체의 아래 가장자리에 그림 |
| 앉은 자세에서 골반 앞쪽 덩어리가 허벅지 밑으로 나옴 | 허벅지를 40도 넘게 들면 허벅지 사이에 숨으므로 그리지 않음 |
| 머리 다발이 가시처럼 뾰족함 | 단발 다발은 끝값이 0보다 큰 taper와 0.5 이상의 폭을 줌 |
| 옷 윤곽 모서리가 귀처럼 튀어나옴 | 단면 끝점만 이은 곡선이 모서리에서 부풂. Loft는 맨 위와 맨 아래를 고리의 호로 닫음 |
| 바지 허리가 윗옷 옆으로 삐져나옴 | 윗옷에 loose 0.5-0.7을 주어 오목한 허리를 메움 |
| 소매 어깨가 패드처럼 솟음 | 소매 뿌리 폭을 살과 거의 같게(ROOT_EASE) 두고 위팔에서 넓힘 |
| 쥔 손이 몸 뒤로 숨음 | 몸 앞을 가로지르는 먼 쪽 팔에 `in_front`를 줌 |
| 투샷에서 팔 중간이 잘려 보임 | `stage.collisions`로 관통을 찾아 안쪽 팔의 poles 바깥 성분을 줄이거나 간격을 넓힘 |
| 앞으로 굽힌 팔의 소매가 네모난 덩어리로 보이고 손이 튀어나옴 | 아래팔이 관찰자를 향하는 자세를 피하고 팔을 내리거나 옆으로 뻗음 |
| 맞잡은 손이 한 손만 보임 | 한쪽에 `palm_out`, 몸에 합쳐진 팔에 `in_front` |
| 엄지가 손바닥 위에 따로 얹힌 덩어리로 보임 | 손바닥 안쪽의 엄지 선을 옅게 그음(character는 자동) |
| 탁자 위 팔이 탁자 윗면에 덮임 | 그 팔을 defer로 미루고 탁자 윗면 다음에 칠함 |
| 긴 머리 다발이 어깨와 가슴을 뚫음 | 어깨 아래로 내려오는 다발에 `drape`(front 또는 back)를 줌 |
| 뒷모습 가운데에 목이 비침 | 뒷머리 다발의 뿌리 phi를 끝 phi와 같게 두어 다발이 가운데로 모이게 함 |
| 어깨 위에서 다발이 계단처럼 꺾임 | 드레이프 밀기를 미리 받는 점 수(`DRAPE_EASE`)를 늘림 |
| 템플릿끼리 얼굴이 비슷해 보임 | 눈 모양보다 얼굴형(턱 단면)과 눈썹, 입꼬리를 먼저 바꿈 |

| 긴 머리 정수리 양옆이 뿔처럼 솟음 | 긴 다발 taper의 첫 값을 0.35 안팎으로 좁힘 |
