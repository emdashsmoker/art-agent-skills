# 옷, 포즈, 장면

3차원 마네킹(`references/figure.md`의 3차원 마네킹)에 옷을 입히고 자세를 잡고 장소에 세우는 방법이다. 수치는 `examples/outfits.py`의 혼자 15개, 둘 3개 조합에서 검증한 값이다.

## 목차

- 구성
- 포즈 프리셋
- 카메라 프레이밍
- 옷 만들기 원칙
- 옷 목록
- 치마와 드레스
- 바람
- 투샷
- 장면
- 조합 예제

## 구성

| 모듈 | 하는 일 |
|---|---|
| `atelier.staging` | 포즈 프리셋 10종, 샷과 방향에 맞춘 카메라 (`pose_for`, `frame`) |
| `atelier.wardrobe` | 몸을 따르는 옷과 옷을 몸에 붙이는 도구 (`bikini`, `suit`, `hem`, `cut_leg`, `patch`, `strap` 등) |
| `atelier.drape` | 몸에서 떨어져 흘러내리는 천: 치마, 드레스, 스카프, 바람 (`Flare`, `flared_skirt`, `sundress` 등) |
| `atelier.turn` | 정면 그림 머리를 3/4 측면까지 돌리는 깊이 모형 (`references/figure.md`의 머리 돌리기) |
| `examples/scenes.py` | 장소 9종: 배경 그림, 바닥, 가구 색, 후처리 |
| `examples/outfits.py` | 성별, 옷, 포즈, 장소, 샷을 고르면 한 장을 그리는 조합 예제. 2명 조합 포함 |

## 포즈 프리셋

`pose_for(name, physique, bust)`는 여성 마네킹 기준으로 적은 자세를 체형의 다리 길이에 맞춰 늘린다. 같은 이름으로 남녀 모두 쓴다.

| 이름 | 자세 | 필요한 받침 |
|---|---|---|
| `standing` | 한 다리에 체중을 싣고 팔을 내림 | 없음 |
| `hand_on_hip` | 한 손을 허리에 얹고 팔꿈치를 바깥으로 | 없음 |
| `walking` | 앞발은 뒤꿈치, 뒷발은 발끝. 팔과 가슴이 다리와 반대로 돎 | 없음 |
| `arms_crossed` | 팔짱. 양손을 반대쪽 위팔 뒤로 넣음 | 없음 |
| `seated_chair` | 의자에 바로 앉아 손을 허벅지에 얹음 | `seat` 2개 (좌판, 등판) |
| `leaning_wall` | 벽에 등을 대고 한 발을 벽에 붙임 | `wall` (폭 1m 기둥) |
| `seated_ground` | 바닥에 앉아 무릎을 세우고 뒤로 팔을 짚음 | `ground` |
| `reclining` | 침대에 옆으로 누워 한 손을 머리 뒤에 | `bed` |
| `seated_crossed` | 의자에 앉아 오른 다리를 왼 무릎 위로 꼼. 왼손은 꼰 무릎에, 오른손은 무릎 위에 | `seat` 2개 (좌판, 등판) |
| `waving` | 서서 오른손을 머리 옆으로 들어 흔듦. 손바닥은 관객 쪽 | 없음 |

- 반환값 `Staging`은 `pose`, `supports`, `hand_at`, `hand_behind_head`를 가진다
    + `supports`는 `(역할, 형태)` 목록이다. 색은 장면이 정한다
- 새 포즈는 여성 기준 미터 단위로 적는다
    + 바닥은 z = 0, 인물은 -y 방향을 본다
    + 적은 뒤 남녀 모두 `build()`의 `strain`이 비었는지 확인한다
- 다리를 꼴 때는 위 다리의 정강이를 아래 다리 정강이보다 앞으로 뺀다
    + 두 정강이가 같은 깊이에 있으면 종아리가 서로 파묻힌다
- 팔짱은 팔꿈치를 앞으로 내야 한다
    + 팔꿈치가 옆에 있으면 아래팔이 관객 쪽으로 튀어나와 상자를 든 것처럼 보인다

## 카메라 프레이밍

`frame(marks, physique, shot, azimuth, elevation, distance, aspect, margin)`은 샷에 맞춰 카메라를 놓는다.

| 샷 | 아래 끝 |
|---|---|
| `full` | 발목 아래 10cm |
| `knee` | 무릎 아래 6cm |
| `waist` | 골반 아래 6cm |
| `bust` | 가슴 아래 6cm |

- 위 끝은 그려질 애니메 머리의 정수리다 (두개골보다 1.1배 큰 머리 기준)
- `azimuth`는 인물 둘레의 각도다
    + 양수면 인물의 왼쪽 옆이 더 보인다
    + 20-35도가 3/4 구도다. 머리도 같은 각도로 자동으로 돈다
- `elevation`은 눈높이 근처(5도)를 기본으로 둔다
    + 낮은 카메라는 인물을 크고 강해 보이게 한다
- 누운 자세는 가로 화면(`aspect` 0.7 안팎)과 넓은 여백(`margin` 0.12)을 쓴다

## 옷 만들기 원칙

옷 하나는 껍질, 자르기, 더하기, 칠하기 4단계로 만든다.

### 껍질

`dress(scene, marks, group, regions, thickness, smooth)`로 몸 영역을 두께만큼 키운다.

| 옷 | 두께 (m) | 상수 |
|---|---|---|
| 수영복, 이너웨어 | 0.004 | `FIT` |
| 티셔츠, 청바지, 반바지 | 0.008 | `SNUG` |
| 정장 재킷 | 0.012 | `JACKET` |
| 후드티 | 0.018 | |

- `smooth`는 0.012 안팎이다. 크면 녹임마다 부피가 붙어 옷이 부푼다
- 영역 이름: `neck`, `chest`, `breast`, `abdomen`, `pelvis`, `shoulder`(삼각근), `upper_arm`, `forearm`, `hand`, `thigh`, `shin`, `foot`
- `side=1`(왼쪽) 또는 `side=-1`(오른쪽)은 한쪽 팔다리만 고른다
- 바지 다리를 무리 하나로 따로 만들지 않는다
    + 따로 된 다리는 엉덩이에 녹지 않아 엉덩이 쪽 끝이 공처럼 부푼다
    + 골반과 두 다리를 한 무리로 키우고 다리마다 `cut_leg()`로 자른다

### 자르기

| 도구 | 쓰는 곳 |
|---|---|
| `hem(scene, group, point, kept)` | 평면으로 곧게 자름. 밑단, 허리선 |
| `cut_leg(scene, group, marks, name, at, keep_upper)` | 다리 하나만 자름. 다른 다리는 건드리지 않음. `at`은 0 엉덩이, 1 무릎, 2 발목 |
| `keep_polygon(scene, group, origin, frame, corners)` | 앞에서 본 볼록 다각형만 남김. 비키니 삼각 컵 |
| `cut_wedge(scene, group, origin, frame, apex, left, right)` | 꼭짓점에서 벌어지는 V를 앞쪽만 파냄. 재킷 앞섶, V 목선 |
| `scene.carve(Ellipsoid(...), group)` | 둥근 목선, 진동둘레 |

- 목선은 목 뿌리 위를 통째로 파낸다
    + 앞쪽만 파면 목 둘레 천이 고리로 남고 그 아래에 구멍이 뚫린다
- 자르는 평면(`HalfSpace`)과 겹친 형태(`Intersection`)는 끝이 없는 형태다. 파내기에만 쓴다

### 더하기

| 도구 | 쓰는 곳 |
|---|---|
| `onto(shapes, points, offset)` | 점들을 몸 표면에서 `offset`만큼 떨어진 곳으로 붙임 |
| `strap(shapes, points, lift)` | 끈 경로: 8mm마다 점을 채운 뒤 붙이고 다듬음. 능선 아래로 생긴 빈 구간은 다시 채움. 어깨끈, 홀터끈 |
| `Skin(scene)` | 렌더링되는 그대로 녹은 피부 표면. `strap([Skin(scene)], ...)`처럼 형태 목록 자리에 넣음 |
| `Surface(marks, regions)` | 일부 영역만 렌더링과 같은 방식으로 녹인 표면. 몸통 둘레 띠를 팔 없이 감을 때 씀 |
| `around(shapes, centre, axis, front, offset)` | 축 둘레로 몸을 감싸는 고리 점들. 허리 밴드, 소맷부리, 스타킹 윗단 |
| `rod(scene, group, points, radius)` | 점을 잇는 막대. 끈, 어깨끈, 밴드, 옷깃 |
| `patch(scene, group, marks, regions, thickness, smooth, origin, frame, corners)` | 옷 위에 얹는 천 한 겹. 라펠, 넥타이, 주머니 |

- 끈은 `strap([Skin(scene)], ...)`로 놓는다
    + 몸 형태들은 서로 녹아 붙어 실제 피부가 형태보다 최대 1cm 바깥에 있다
    + 형태 표면에 붙인 끈은 피부 속에 묻혀 쇄골 근처에서 끊겨 보인다
    + 안내점만 붙이면 점 사이 직선이 곡면 아래로 파고든다. `strap()`은 점을 촘촘히 채워 붙인다
    + 어깨 위처럼 능선 아래를 지나는 직선은 앞면과 뒷면으로 갈라 붙어 9cm 빈 구간을 남긴다
    + `strap()`은 빈 구간 가운데에 점을 넣는다. 구간 길이의 3분의 1만큼 들어 올린 뒤 붙인다
    + 더 높이 들면 점이 목에 붙는다
- 몸통 둘레 띠는 `Surface(marks, 영역)`에 감는다 (`_band(..., melted=True)`)
    + 원래 형태에 감은 띠는 녹은 피부 속에 1-16mm 묻힌다
    + `Skin(scene)`에 감으면 바깥에서 걸어 들어오다 몸통 옆의 팔에 먼저 닿는다
    + 밑가슴 띠는 `CHEST_BAND` (가슴, 유방, 배), 엉덩이 끈과 팬티 허리 띠는 `HIP_BAND` (골반, 배, 허벅지)
- 브라 어깨끈은 등 뒤 밑밴드 높이까지 내려 밴드와 만난다
- 비키니 밑가슴 띠는 한 바퀴를 다 돈다. 컵 아래 모서리를 지나 가운데에서 이어진다
- 몸통 옷은 골반 영역까지 키운 뒤 허리에서 자른다
    + 피부의 허리는 배와 골반이 녹아 만든 면이라 배까지만 키운 옷은 허리에서 피부 속으로 가라앉는다
- 소매는 곧은 막대로 만들고 삼각근 영역을 함께 키운다
    + 팔을 키운 소매는 근육을 드러내 보디빌더처럼 보인다
    + 삼각근을 빼면 어깨 솔기에 살이 보인다
- 넥타이, 라펠, 주머니는 `patch()`로 얹는다
    + 옷 표면은 녹임으로 조금씩 부풀어 있다. 원래 몸에서 잰 거리로 얹은 막대는 옷 속에 묻힌다
    + `patch()`는 아래 옷과 같은 방식으로 몇 mm 더 키워 어떤 곡면에서도 옷 위에 놓인다
- 헐렁한 옷은 둥근 상자(`RoundBox`)를 몸통에 녹여 곧게 떨어지게 한다
    + 타원체는 밑단 쪽이 좁아져 방패 모양이 된다
    + 아래팔과 손 모양을 옷에서 파내 팔이 옷 속에 묻히지 않게 한다 (팔짱, 주머니 근처의 손)

### 칠하기

옷 함수는 칠할 목록을 반환한다. `(무리, 색, 그림자 색)` 튜플은 `sculpt.paint`로 칠한다. 아래 함수는 렌더링 뒤에 실행하는 칠하기 함수를 만든다.

| 함수 | 효과 |
|---|---|
| `lace(groups, colour, tint, skin)` | 천을 칠한 뒤 고운 구멍 무늬로 살을 비침. 가장자리는 단단한 테두리 |
| `sheer(groups, colour, skin, skin_shadow)` | 얇은 스타킹. 가운데는 다리가 비치고 가장자리와 그늘은 어두움 |
| `seam(points, colour, width)` | 표면 위 박음질 선. 앞에 가린 것이 있으면 그 구간은 숨김 |

    + 같은 두께의 두 옷은 화소마다 앞뒤가 바뀌어 얼룩이 생긴다
    + 바지 안에 넣은 티셔츠는 바지보다 2mm 얇게 만든다

## 치마와 드레스

`atelier.drape`. 몸을 키운 껍질로는 몸에서 떨어져 퍼지는 천을 만들 수 없다. 치마는 허리에서 밑단까지 넓어지는 열린 껍질(`Flare`)이다.

- 치마 모양은 3구간이다
    + 허리: 피부에서 4mm (`WAIST_EASE`). 더 넓으면 허리 입구가 바구니 테두리처럼 보인다
    + 허리에서 엉덩이 가장 넓은 선(고관절 2cm 아래)까지: 엉덩이를 따라 내려온다
    + 그 아래: `flare`(1m당 넓어지는 m)로 곧게 퍼진다 (A라인). 몸에서 1.4cm 안으로는 들어오지 않는다
- 반지름은 높이 49줄, 방향 72개의 표로 둔다 (`body_profile`, `flare_profile`)
    + 높이마다 녹은 피부 둘레를 재고 볼록 껍질로 두 다리 사이를 잇는다. 천은 다리 사이로 파고들지 않는다
    + 치마는 내려갈수록 좁아지지 않는다. 엉덩이에 걸린 천은 그 아래로 말려 들어가지 않는다
    + 걷는 자세는 보폭만큼 치마가 저절로 넓어진다
- 주름은 엉덩이 선 조금 위에서 시작해 밑단으로 갈수록 깊어진다
    + 부드러운 주름은 간격과 깊이가 둘레를 따라 조금씩 달라진다 (`FOLD_JITTER`, `FOLD_SWELL`)
    + 플리츠는 고르게 각진 물결이다
- 손과 아래팔이 닿는 곳은 치마가 안으로 들어간다 (`obstacles`)
    + 들어가지 않으면 옆에 내린 손이 치마 속에 묻힌다
    + 피부 바로 위(`DENT_MARGIN`)보다 안으로는 들어가지 않는다. 더 들어가면 손 아래에 구멍처럼 파인 자국이 생긴다
- 안에 넣은 상의 위에 입는 치마는 허리 여유를 상의 두께만큼 준다 (`ease`, 티셔츠 위 1.4cm)
    + 여유가 없으면 상의가 치마 허리 아래로 비어져 나온다
- 앉거나 누운 자세(허벅지가 수직에서 50도 넘게 기움)에서 `flared_skirt()`는 튜브 치마로 바뀐다
    + 튜브 치마는 엉덩이와 허벅지를 키우고 두 다리 사이를 막대로 이어 무릎 위를 덮는다
    + 다리를 꼬거나 무릎을 세우면 치마는 무릎까지 올라가고 다리마다 따로 자른다
    + 그때 두 다리 사이는 납작한 타원체 천으로 잇는다 (`_web`). 둥근 막대는 다리가 벌어지면 공처럼 부풀고, 두 다리를 한 평면으로 자르면 무릎에서 뭉친다

| 함수 | 모양 |
|---|---|
| `flared_skirt(scene, marks, length, flare, folds, depth, pleats, wind, ease)` | 허리에서 엉덩이를 따라 내려와 퍼지는 A라인 치마. 기본 길이 48cm |
| `pleated_skirt(scene, marks, length, wind, ease)` | 칼주름 22개, 40cm |
| `mini_skirt(scene, marks, wind)` | 30cm |
| `tube_skirt(scene, marks, at, ease)` | 몸을 따르는 치마. `at`은 밑단 위치 (0 엉덩이, 1 무릎, 2 발목) |
| `pencil_skirt(scene, marks)` | 무릎 바로 위까지 오는 튜브 치마 |
| `sundress(scene, marks, length, wind)` | 끈 원피스: 가슴 위로 곧게 자른 몸판, 가는 어깨끈, 허리에서 퍼지는 치마 |
| `sheath_dress(scene, marks)` | 몸에 붙는 무릎길이 원피스. 어깨끈 없음 |
| `scarf(scene, marks, wind, length, width)` | 목에 2바퀴 감은 천, 앞쪽 매듭, 끝자락 2개. 바람이 없으면 가슴 앞으로 곧게 늘어짐 |

- 드레스 몸판과 치마는 허리 높이(골반 기준 0.165m)에서 만난다

### 스카프

- 목에 감은 천은 굵은 고리 2개다
    + 목 기둥 둘레를 따르고 앞이 낮다
    + 어깨 경사에 닿는 옆은 들어 올린다. 굵기의 절반까지는 어깨에 눌려 들어가게 둔다 (`SCARF_SQUASH`)
    + 다 들어 올리면 고리 옆이 턱보다 높아진다
- 끝자락은 납작한 띠(`Ribbon`)다
    + 매끈한 경로를 따라 얇은 상자를 이어 쓸어 만든다. 타원체를 이으면 울퉁불퉁한 띠가 된다
    + 마디마다 상자를 조금 길게 두어 굽은 바깥쪽에 홈이 생기지 않게 한다
    + 6마디씩 끊어 넣는다 (`ribbon()`). 조각마다 경계가 작아 렌더링이 빠르다
- 바람이 없으면 끝자락은 가슴에서 떨어진 채 중력 방향으로 곧게 늘어진다
    + 가슴을 넘은 뒤 그 거리를 유지한다. 가슴 아래로 말려 들어가지 않는다
- 바람이 있으면 끝자락은 깃발처럼 바람 쪽으로 날린다
    + 너비 방향은 위로 서고, 옆으로 물결치며 천천히 비틀린다
    + 2번째 끝자락은 조금 더 아래로 처져 두 끝이 겹치지 않는다

## 바람

옷 함수의 `wind`는 월드 좌표 벡터다. 길이는 밑단이 밀리는 거리(m)다. 0.35는 산들바람, 0.55는 센 바람이다.

| 효과 | 크기 |
|---|---|
| 밑단이 바람 쪽으로 밀림 | 바람 길이의 30% |
| 바람 쪽이 부풂 | 바람 1m당 반지름 45% |
| 바람 반대쪽이 다리에 붙음 | 퍼짐을 바람 1m당 200% 줄임. 0.5m 이상이면 퍼짐 없음 (`WIND_PRESS`) |
| 바람 쪽 밑단이 들림 | 바람 1m당 길이의 55%, 최대 45% |
| 주름이 깊어짐 | 바람 1m당 5cm |
| 스카프 끝이 바람 쪽으로 흩날림 | 물결과 비틀림이 함께 커짐 |

- 치마 둘레는 높이마다 바람에 밀린 중심에서 잰다
    + 바람 반대쪽은 다리에 붙고 바람 쪽은 자리를 얻는다
    + 바람 여유를 둘레 전체에 더하면 허리가 넓어지고 바람 반대쪽이 자루처럼 부푼다
- 바람이 관객 쪽(-y)을 조금 향하게 두면 들린 천이 몸 뒤로 숨지 않는다
- 머리카락은 정면 그림이라 바람에 날리지 않는다

## 투샷

- `staging.pair_for(name, physique_a, physique_b)`는 두 사람의 자세를 돌려 놓은 위치로 준다
    + 첫 사람이 관객 왼쪽에 선다

| 이름 | 자세 |
|---|---|
| `side_by_side` | 나란히 서서 서로 쪽으로 12도 돎. 한 사람은 허리에 손 |
| `holding_hands` | 나란히 서서 안쪽 손을 마주 잡음. 고개를 서로 쪽으로 돌림 |
| `facing` | 32도씩 돌아 마주 봄. 한 사람은 팔짱 |

- `staging.placed(staging, offset, turn)`는 어떤 자세든 돌려서 옮긴다
- `frame()`에 표지점과 체형을 목록으로 주면 모두가 들어오게 카메라를 놓는다
- 그리기는 `figure_study.draw_cast(style, width, setting, [Actor(sitter, pose, extras), ...])`가 한다
    + 사람마다 무리 이름에 접두어(`p0.`, `p1.`)를 붙여 한 번에 렌더링한다. 서로 가리고 그림자를 드리운다
    + 칠하기는 먼 사람부터 한다. 가까운 몸이 먼 사람의 그려진 머리를 덮는다
    + 장면의 후처리(`Setting.painters`)는 모두를 칠한 뒤 한 번만 실행한다
- 머리가 카메라에서 35도를 넘게 돌면 그려진 머리는 35도에서 멈춘다. 투샷에서 서로 마주 보는 각도는 35도 안으로 둔다

`examples/scenes.py`의 `PLACES`에 9종이 있다.

|---|---|---|---|

| `dusk` | 노을 하늘과 해 | 붉은 포장도로 | 없음 |
| `cafe` | 따뜻한 벽, 거리가 보이는 큰 창과 차양, 병을 올린 선반, 펜던트 조명 | 나무 바닥 | 의자 색, 머그를 올린 둥근 탁자 (인물 옆 뒤쪽) |
| `park` | 맑은 하늘, 언덕, 둥근 나무 | 잔디 6m | 벤치 색 |
| `panel_yard` | 눈 오는 밤, 조립식 아파트 2동, 잎 없는 나무, 나트륨 가로등 | 눈 3m | 콘크리트 벽과 녹색 벤치 색, 인물 오른쪽의 주황 테두리 빛, 내리는 눈 |
| `rooftop` | 밤하늘, 지평선의 탁한 빛, 발전소 굴뚝, 내려다보는 아파트 단지, 난간과 TV 안테나 | 옥상 1.6m, 양옆 30m | 내리는 눈 |

- 배경은 2차원 그림이다
    + 바다의 수평선은 카메라의 지평선(`horizon()`)에 맞춰 그린다
    + 바닥의 먼 끝은 `ground_edge()`로 구한다
- 배경의 땅과 3차원 바닥 판이 만나는 선은 배경의 경계에 맞춘다
    + 해변은 파도 거품, 공원은 언덕 밑자락이 그 선이다
    + 경계가 없으면 같은 색 잔디 위에 바닥 판의 윤곽선이 가로로 보인다
- 바닥의 먼 끝은 낮은 카메라에서도 지평선 5도 아래에 둔다 (카메라에서 약 9m 안)
    + 그보다 지평선에 가까운 바닥은 행마다 깊이가 크게 바뀌어 윤곽선이 겹쳐 어두운 띠가 된다
    + 공원 잔디가 3.5m인 까닭이다. 그 너머는 배경의 언덕이 맡는다
- 바닥은 3차원 판이라 인물의 그림자를 받는다
- `furnish(supports)`는 포즈의 받침을 보고 주변 가구를 더한다
    + 침대가 있으면 그 끝에 베개를 놓는다
- `painters`는 모든 인물을 칠한 뒤 한 번 실행한다
- 기둥 같은 받침은 화면보다 좁게 둔다. 화면을 다 덮는 벽은 장소를 가린다
    + 무릎 위 샷에서는 폭 1m 벽도 화면을 덮는다. 장소를 보여 줄 컷은 전신 샷이나 벽 없는 포즈를 고른다
- 뒤에서 찍으면(`azimuth` 180 안팎) 바닥 판과 바닥 먼 끝이 카메라 반대쪽으로 뒤집힌다 (`looking_back(camera)`)
- 넓은 화면은 바닥 판의 옆 끝이 보인다. 그 장소의 `ground_width`를 늘린다
- 옥상 아래 단지는 미터로 놓고 카메라로 투영한다
    + 캔버스 단위로 그린 배경은 화각이 다른 컷에서 크기가 어긋난다
    + 단지의 줄은 카메라에서 70-900m, 지붕은 이 옥상보다 낮다. 가까운 줄은 난간에 가려진다
- 조립식 아파트는 `panel_block()` 1번으로 그린다. 작게 보이는 먼 동은 꺼진 창을 생략하고 켜진 창만 그린다
