## 디자인 방향 문서 양식

장면 스크립트 작성 전에 아래 양식으로 `.md` 1개를 작성한다. 좌표를 잡기 전에 구도와 색을 글로 확정해야 수정 횟수가 줄어든다.

```
# 디자인 방향 문서
## 핵심 메시지
- 그림이 전달할 인상 1개
## 디자인 방향
- (공간과 구조) 화면 비율, 인물이 차지하는 비중, 여백의 위치
- (색상과 톤) 주조색, 보조색, 그림자 색의 방향
- (비례와 리듬) 기준 단위, 반복되는 형태
- (구성과 균형) 머리 위치, 시선 방향, 무게 중심
- (시각적 위계) 대비와 디테일을 배분할 순서
## 레이아웃
- 머리 중심 좌표, 머리 반지름, 광원 방향, yaw, roll
## 화풍
- anime, illust, painterly 중 선택과 배경
```

## 공정과 코드의 대응

| 작화 공정 | 코드 | 비고 |
|---|---|---|
| 기획 | 디자인 방향 문서 | 코드 작성 전 확정 |
| 작도 | `Character`, `HairStyle`, `geometry` | 단위 공간의 도형 데이터 |
| 밑색 | `painter.part()`의 `material.base` | 마스크에 단색 또는 그라데이션 |
| 음영 | `painter.part()`의 형태 음영, `painter.cast()` | 마스크에서 계산 |
| 선화 | `painter.part()`의 외곽선, `painter.stroke()` | 색 선, 굵기 변화 |
| 배경 | `background` 모듈 | 인물보다 먼저 그림 |
| 후보정 | `finish.apply()` | 화풍별 마감 |
| 검수 | `selftest.py`, 검수용 확대본 | 눈으로 확인 |

## 음영 원리

- (형태 음영) 마스크의 가장자리를 둥글게 깎은 높이 지도를 만들고 광원으로 비춤
    + `shading.bevel_light()`가 경계까지의 거리에서 높이를 만들고 법선과 광원의 내적을 계산
    + `roundness`는 도형 반폭 대비 둥근 구간의 비율, 얼굴은 0.15, 머리카락 다발은 0.75
- (드리운 그림자) 가리는 부품의 마스크를 광원 반대편으로 옮겨 받는 부품과 교차
    + 앞머리가 이마에, 머리가 목에, 옆머리가 어깨에 드리우는 그림자가 입체감의 대부분을 담당
- (셀과 연속의 차이) 동일한 빛 값에 문턱을 적용하면 셀, 구간에 매핑하면 연속 음영
    + `Style.shade_mode`가 분기를 결정하므로 장면 스크립트는 화풍을 의식하지 않음
- (큰 형태) 마감 단계에서 인물 전체에 광원 반대편으로 어두워지는 그라데이션을 추가
    + 부품별 음영만으로는 인물 전체의 덩어리감이 나오지 않음

## 선화 원리

- 외곽선은 마스크 경계 안쪽 띠
    + 광원 반대편에서 최대 1.7배 굵어지며 잉크 선의 강약을 대신함
- 선 색은 재질별 지정 색
    + 피부는 적갈색, 머리카락은 암갈색, 흰 옷은 남색 계열이 검은 선보다 부드러움
- 부품 내부의 선(머리카락 가닥, 옷주름, 쌍꺼풀)은 `painter.stroke()`의 양끝이 가는 획
    + `clip=`에 부품 마스크를 주어 도형 밖으로 나가지 않게 함

## 머리카락 구성

- 큰 덩어리, 다발, 가닥, 광택 순으로 쌓음
    + 낱가닥부터 그리면 머리카락으로 읽히지 않음
- 뒷머리는 `back_mass`(어두운 덩어리) 위에 `back_locks`(다발)를 올림
- 앞머리는 `cap`(두상을 덮는 덩어리) 위에 `bangs`(이마 다발)와 `side_locks`(옆머리)를 올림
    + 앞머리 다발은 뿌리 쪽 선과 음영을 흐리게 하여 `cap`과 이음매 없이 이어짐
- 광택 띠는 두상 중심에서 일정 거리의 호
    + 셀 화풍은 톱니 모양, 연속 음영 화풍은 매끈한 띠
- 다발 하나는 `LockSpec(root, tip, width, bend, sway)`
    + `bend`는 길이 대비 휘는 정도이며 아래로 내려가는 다발에서 양수는 화면 왼쪽으로 볼록
    + `sway`는 S자 굴곡이며 긴 머리카락에 0.03-0.08 사용

## 입체 렌더러의 원리

- (부풀림) 부품 마스크의 경계까지 거리에서 둥근 단면의 높이를 계산
    + 원은 반구가 되고 긴 띠는 반원통이 됨
- (합성) 부품마다 높이를 비교하여 더 높은 쪽이 보이게 함
    + 같은 깊이의 두 형태는 높이가 만나는 곳에서 이음매 없이 이어지므로 관절이 자연스러움
    + 깊이를 더 준 형태는 뒤 형태 위로 올라서며 그 경계가 가림 선이 됨
- (조명) 높이 지도의 기울기에서 법선을 구해 광원과의 각도로 밝기를 계산
    + 문턱을 적용하면 셀 음영, 구간에 매핑하면 연속 음영
- (그림자) 각 픽셀에서 광원 방향으로 나아가며 더 높은 표면이 있으면 그늘로 판정
- (틈새 어둠) 주변 평균보다 낮은 곳을 어둡게 하여 형태가 맞닿는 틈을 표현
- (선) 실루엣, 앞 형태의 경계, 깊은 골짜기 3곳에만 선을 그림
    + 형태 내부의 가파른 기울기에는 선을 그리지 않으므로 표면이 깨끗함

## 3D 인물 렌더러의 원리

- (형태) 몸, 머리카락, 옷은 모두 타원체, 구 사슬, 타원 단면을 이은 형태
    + 몸통은 골반 앞쪽에서 목까지 10개 단면을 촘촘히 이은 형태이며 단면 축은 이웃 관절의 회전을 섞어 비틀림 없이 이어짐
    + 단면 타원체는 경로를 따라 간격의 7배(`SECTION_OVERLAP`)까지 뻗어 이웃과 길게 겹치므로 표면에 골이 남지 않음
    + 팔다리와 손가락은 반지름이 변하는 구 사슬이며 이웃 구끼리 좁은 부드러운 최댓값(`SWEEP_BLEND`)으로 합침
    + 구 사이의 얕은 골은 법선을 앞뒤로 몇 도씩 흔들고 셀 그림자 경계에서 톱니로 드러나므로 이 합침이 톱니를 없앰
- (깊이) 화면 픽셀마다 관찰자에게 가장 가까운 표면의 깊이를 해석적으로 계산
    + 타원체는 광선과 단위구의 교차, 구는 원판 위 높이이므로 메시 없이 정확한 곡면이 나옴
- (녹아 붙음) 같은 그룹(피부끼리, 머리카락끼리, 같은 옷끼리)은 부드러운 최댓값으로 합쳐 관절과 겨드랑이가 이음매 없이 이어짐
    + 한 형태를 이루는 구들은 먼저 자기들끼리 합친 뒤 앞서 그린 형태와 1회만 섞으므로 부풂이 누적되지 않음
    + 이 부풂(최대 `SMOOTH_BLEND`/4)보다 옷을 덜 띄우면 피부가 옷을 뚫고 나옴
- (잘라내기) `cut` 함수가 참인 표면은 앞면 대신 뒷면을 보여 재킷 앞섶, 얼굴 개구부, 비키니 트임을 만듦
    + 여러 조각으로 된 형태는 조각들을 먼저 합친 앞면에서 1회만 잘라 가장자리에 계단이 생기지 않음(`_cut_part`)
- (조명) 깊이 지도를 `Relief`의 높이 지도로 넘긴 뒤 2D 소재와 같은 셀 음영, 드리운 그림자, 선 계산을 적용
    + 깊이 지도는 같은 재질 안에서만 흐려 타원체 사이의 얕은 능선이 줄무늬로 보이지 않게 함
    + 서로 다른 형태 사이에 깊이가 뛰는 곳과 재질이 바뀌는 곳에만 선을 그림
    + 깊이 차는 경계를 따라 평균한 뒤 문턱을 부드럽게 넘기므로 문턱 근처에서 선이 점선으로 끊기지 않음
- (표면 선) 솔기, 주머니, 머리카락 가닥은 3D 곡선을 투영한 뒤 그 지점의 표면 깊이와 재질이 맞는 구간만 그림
- (얼굴) 머리의 화면 각도에 따라 2D 초상 리그(정면에서 3/4), 옆얼굴, 표현 없음(뒷모습)을 고름
- (자세) 관절 회전으로 순운동학을 계산한 뒤 `Reach`가 있는 팔은 두 뼈 역운동학으로 어깨와 팔꿈치를 다시 계산
    + 팔꿈치 방향은 `pole`, 손 방향은 `fingers`와 `palm`, 손목 굽힘은 상한에서 멈춤
- (좁은 틈) 팔이 몸에서 머리카락 굵기만큼 떨어지면 배경이 렌즈 모양으로 비치고 선이 그 둘레를 그려 흰 타원이 됨
    + 깊이 버퍼를 넘기기 전에 부드러운 형태들이 두른 작은 빈 영역을 찾아 먼 쪽 형태로 메움
    + 먼 쪽 형태의 가파른 가장자리 깊이를 주변으로 평평하게 고르고 그 둘레의 가림 선과 주름 선을 생략
    + 단단한 물체(머그컵 손잡이 등)가 두른 구멍은 실제 구멍이므로 유지
- (바닥 접지) 모든 타원체와 구의 가장 낮은 점을 해석적으로 구해 바닥에 닿는 부위를 정함
    + 발바닥보다 `FLOOR_SLACK` 이상 낮은 부위가 없으면 발바닥, 있으면 그 부위들이 바닥에 놓이므로 눕기와 무릎 꿇기가 같은 배치 함수로 처리됨
- (표면을 따르는 끈) 끈 경로를 1.5cm 간격으로 나눈 뒤 몸통까지의 근사 거리(`distance_to_solids`)가 여유보다 작은 점만 바깥으로 밀고 다듬기를 반복
    + 이미 떨어진 점은 그대로 두므로 가슴 사이처럼 오목한 곳은 끈이 건너감

## 3D 장면 렌더러의 원리

- (원근) 화소마다 광선 1개를 보내며 광선은 화면 평면의 점에서 눈 쪽으로 기울어짐
    + 깊이 z의 점은 `plane + z * direction`이며 정사영은 방향이 (0, 0, 1)인 특수한 경우
    + 타원체와 구는 광선과의 이차방정식, 각진 형태는 광선 진행으로 교점을 구함
    + 눈 거리가 없는 카메라는 v4 코드 경로를 그대로 쓰므로 기존 그림이 바이트 단위로 같음
- (각진 형태) 부호 거리 함수는 점에서 표면까지의 거리(안쪽은 음수)
    + 광선은 경계구에 들어가는 지점에서 출발하여 거리만큼씩 전진하고 거리가 0.05화소 미만이면 적중
    + 빼기(`Cut`)와 합집합(`Union`)은 거리의 최대와 최소이므로 속 빈 컵과 손잡이를 한 형태로 만듦
- (한 장면) 물체마다 자기 카메라(월드 배치를 담은 `shift`와 `yaw`)로 같은 깊이 버퍼에 그림
    + `renderer.with_camera()`가 버퍼를 공유하므로 인물의 다리와 책상, 손과 노트북이 화소 단위로 앞뒤를 가림
    + 단단한 물체(`rigid` 그룹)는 녹아 붙지 않으므로 상판 위의 머그컵에 경계선이 생김
    + 방이 인물보다 깊으므로 높이 지도의 기준 깊이를 장면의 가장 먼 면에 맞춰 내림
- (화면과 빛) 조명 뒤에 화면 콘텐츠를 원근 변환으로 붙이고 바깥에만 빛 번짐을 더함
    + 화면은 물체 전용 재질로 찾으므로 다른 물체에 가린 부분에는 그려지지 않음
- (접촉 그림자) 바닥에 놓인 물체는 캔버스에, 상판에 놓인 물체는 받치는 가구의 표면 색에 부드러운 그림자를 더함
- (실내 벽면) 바닥, 천장, 벽 3면과 장식은 텍스처를 가진 사각형
    + 눈 앞 0.6머리 평면에서 잘라낸 뒤 투영하고 호모그래피로 텍스처를 붙임
    + 칠한 면의 방향(`facing`) 뒤에 눈이 있으면 생략하므로 카메라가 벽 밖에 서도 방 안이 보임
- (회화풍) 손 크기 사물은 중요도 0.85로 가는 붓을 받고 가구와 벽은 굵은 붓으로 남김
    + 얼굴은 화면 크기를 재어 작을수록 중요도를 1.0까지 올리므로 장면 속 작은 얼굴도 가장 가는 붓(0.9 단위)을 받음
- (유리) 불투명 공정을 마친 뒤 투명 부품만 별도 깊이 버퍼에 그려 장면보다 앞에 있는 화소에 합성
    + 합성은 옅은 색 덧칠, 윤곽 쪽으로 짙어지는 색(시선이 지나는 유리가 두꺼워짐), 반사광, 얇은 윤곽선의 4층
    + 장면의 깊이 버퍼는 바꾸지 않으므로 유리 뒤의 물체가 그대로 보임
- (겹침 검사) 두 물체의 경계 상자가 겹치는 공간에 1cm 간격 격자를 놓고 두 물체 안에 동시에 든 점의 부피를 셈

## 야외 장면 렌더러의 원리

- (무대) 건물과 땅은 실내 벽처럼 투영되는 평면 그림이며 3D 항목보다 먼저 칠함
    + 건물은 상자 4면과 지붕, 입면 텍스처는 층과 칸마다 창 1개, 이음매, 발코니, 출입구
    + 먼 건물부터 칠하고 눈에서의 거리만큼 안개 색을 섞음
- (화소에서 월드로) 화소의 시선과 평면의 교점, 또는 화소와 깊이에서 월드 좌표를 되돌림
    + 땅과 벽의 등빛, 인물과 사물의 등빛이 같은 월드 좌표 식을 쓰므로 빛 웅덩이와 인물의 밝기가 맞음
- (밤 조명) 3D 항목은 선과 얼굴까지 그린 뒤 화소마다 `환경광 + Σ 등색 × 세기 × 근접도`를 곱함
    + 근접도는 `1 / (1 + 거리² / reach²)`, 갓 있는 등은 아래로 향한 원뿔 밖에서 0으로 감
    + 화면, 전구, 불씨, 연기는 곱한 뒤 그리므로 어두운 장면에서도 밝음
- (하늘과 연무) 하늘 색 단계는 지평선 높이에 맞추고, 빈 화소는 지평선 띠, 3D 항목은 거리로 안개를 섞음
- (전선) 늘어진 줄(포물선 근사)을 투영하여 일정 굵기의 선으로 그리고 깊이 버퍼보다 뒤인 구간은 생략
- (젖은 도로) 각 등의 발밑에서 지면 아래 거울상까지 세로 줄기를 그려 반사를 흉내 냄
- (가는 형태) 화면 반지름 1픽셀 미만의 구 사슬은 구가 맞닿는 간격으로 그림
    + 그런 사슬은 구가 덮는 화소만 칠하므로 같은 화소를 4배 이상 적은 구로 칠함, 자작나무가 많은 풍경이 약 4배 빨라짐
- (덧그림과 색보정) 내리는 눈은 화풍 마감 뒤(`canvas.overlays`), 색보정은 그 다음
