# 기획: 여름 하늘 아래 고글에 손을 올린 비행사

`anime_sky_pilot.py`의 1단계 산출물 예시. 새 그림의 `brief.md`는 이 형식을 따른다.

- 주제: 한여름 바다 위 하늘을 배경으로 고글에 손을 올려 인사하는 성인 여성 비행사
- 화풍: 애니메풍
- 초점: 비행사의 눈과 그 옆에 올린 손
- 캔버스: 1600x900
- 큰 덩어리
    + 하늘(화면 전체 바탕)
    + 적란운(왼쪽 절반, 하늘 다음으로 큰 밝은 덩어리)
    + 인물 반신(오른쪽 삼분할선, 골반 중심 x 1060)
    + 바람에 날리는 목도리(인물에서 구름 쪽으로 뻗어 두 덩어리를 연결)
    + 바다(아래 띠, 수평선 y 770)
- 자세: 허리 위 구도. 화면 오른쪽 팔을 들어 손을 이마 옆에 올리고 반대쪽 팔은 내려뜨림
    + `chest_tilt=-5, spine=2, head=-7, arm_r=(52, 203), arm_l=(14, 4)`
- 광원: 왼쪽 위 (-0.6, -0.8)
- 명암 계획
    + 밝음: 구름, 털 목깃, 피부
    + 중간: 하늘, 바다, 장갑
    + 어두움: 가죽 재킷, 머리카락, 속눈썹
- 팔레트
    + 하늘 `#1b5fc4`에서 `#e3f3fc` 지배색(파랑 계열 그라데이션)
    + 구름 `#ffffff`, `#d3e2f6`, `#86a6d8` 보조색(빛, 중간, 그늘)
    + 재킷 `#8a5a3a`, 그늘 `#523026` 하늘의 보색 쪽 난색
    + 머리카락 `#b0502e`, 그늘 `#6e2a26`, 하이라이트 `#f0a070`
    + 피부 `#ffdcc6`, 그늘 `#e9a48c`
    + 눈 `#16402f`, `#2f9a6a`, `#a8f0c0`
    + 목도리 `#e5503f` 강조색(화면에서 유일한 빨강)
    + 고글 렌즈 `#2f6fc0`에서 `#bfe6fa` 하늘색을 인물 안으로 끌어옴
- 시선 유도: 목도리 자락과 머리카락이 구름에서 얼굴로 흐르고 든 팔이 얼굴을 가리킴
