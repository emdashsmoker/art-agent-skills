# 두머 무드 (doomer)

무드 프리셋. 동유럽 교외의 패널 아파트, 전선, 나트륨 가로등, 눈 내리는 흐린 저녁을 차갑게 칠하고 화면에 작은 온기 하나만 남긴다. 엔진은 `paintkit.doomer` 모듈이다.

## 1. 디자인 방향

### 핵심 메시지

- 차가운 콘크리트 도시에서 혼자 버티는 작은 온기
    + 모든 장면의 판단 기준이다. 이 문장을 화면 안에 글자로 넣지 않는다

### 5개 기준

| 기준 | 방향 |
|---|---|
| 공간과 구조 | 하늘, 눈밭, 콘크리트 벽 같은 넓은 빈 면을 남긴다. 지평선은 낮고 평평하게 둔다 |
| 색상과 톤 | 차가운 청회색이 화면의 약 70%, 콘크리트 회색이 약 20%, 따뜻한 색(가로등, 창, 불씨)은 10% 이하 |
| 비례와 리듬 | 같은 창, 같은 패널, 같은 전봇대를 반복한다. 반복을 깨는 한 점(켜진 창, 불씨)을 둔다 |
| 구성과 균형 | 수평선과 수직선이 화면을 지배한다. 인물은 3분할선 위에 작게 또는 한쪽에 치우쳐 둔다. 전선의 사선이 시선을 이끈다 |
| 시각적 위계 | 1순위 따뜻한 점, 2순위 인물 실루엣, 3순위 건물 리듬, 4순위 하늘과 눈의 질감 |

### 금지

- 채도 높은 원색, 맑은 파란 하늘, 웃는 표정, 밝은 한낮

## 3. 소재 함수

| 함수 | 내용 |
|---|---|
| `panel_facade(width_m, floors, ...)` | 패널 아파트 한 면을 평면으로 그린 Canvas. 층과 칸의 이음매, 창, 발코니(일부 유리 마감), 현관과 등, 얼룩 |
| `panel_block(cv, view, x0, x1, z0, z1, floors, ...)` | 직육면체 패널 아파트. 보이는 면(정면, 옆면)에 `panel_facade`를 원근으로 붙인다. 지붕 위 안테나 |
| `utility_pole(cv, base, height, ...)` | 콘크리트 전봇대와 가로대. 전선을 걸 점 목록을 돌려준다 |
| `pylon(cv, base, height, ...)` | 격자 송전탑. 전선을 걸 팔 끝 점 목록을 돌려준다 |
| `wires(cv, spans, sag=0.05, ...)` | 두 점 사이에 처진 전선. `spans`는 (시작점, 끝점) 목록 |
| `bare_tree(cv, base, height, ...)` | 잎 없는 겨울나무. `birch=True`면 흰 줄기에 검은 무늬 |
| `snowfall(cv, count, ...)` | 크기와 흐림이 다른 눈송이. 가까운 눈일수록 크고 흐리다 |
| `smoke(cv, start, rise, ...)` | 위로 흔들리며 퍼지는 연기. 담배 연기, 입김, 굴뚝 증기 |
| `lamp_glow(cv, point, radius, ...)` | 나트륨 등의 빛 번짐 |
| `cigarette(cv, base, tip, width)` | 필터, 종이, 불씨가 있는 담배. 불씨 위치를 돌려준다 |
| `mouth_point(head, side=1.0)` | 입꼬리 위치와 얼굴 앞 방향. 입에 문 담배를 놓을 때 |
| `finish(cv, ...)` | 두머 마감. 채도를 낮추고 그늘은 청록, 밝은 곳은 나트륨 주황으로 물들인다. 검정을 남색으로 띄우고 거친 입자와 비네트를 더한다 |

```python
from paintkit import Canvas, city, doomer, save_image

cv = Canvas(800, 600, doomer.PALETTE['sky_low'])
view = city.Perspective(vanishing=(400, 330), focal=700, eye=1.6)
doomer.panel_block(cv, view, -30.0, -8.0, 40.0, 52.0, floors=9, lit_ratio=0.2, seed=3)
doomer.snowfall(cv, 120, seed=3)
save_image('doomer_test.png', doomer.finish(cv, seed=3))
```

- 인물의 look은 `ILLUSTRATION`에 낮은 광원(`light_height` 0.45-0.55)을 쓴다
- 따뜻한 점은 화면당 1-2개로 제한한다. 늘리면 무드가 깨진다
- 마감의 `warmth`(0-1)로 나트륨 빛이 번지는 정도를 조절한다

## 4. 고정 캐스트

`scripts/examples/doomer_cast.py`에 두 인물이 있다. 남성, 여성, 투샷, 설정 숏 장면이 같은 인물을 쓴다.

| 인물 | 외형 | 의상 |
|---|---|---|
| 남성 (`MAN`) | 20대 중반, 짧은 흑발, 무표정 | 짙은 회색 후드티, 검은 바지, 흰 운동화. 입에 문 담배 |
| 여성 (`WOMAN`) | 20대 중반, 긴 흑발과 앞머리, 창백한 피부 | 와인색 긴소매 상의, 짙은 회색 긴 치마, 검은 신발 |

## 6. 검수 항목

- 따뜻한 점이 1-2개인가, 시선이 그 점에서 출발하는가
- 화면 70% 이상이 차가운 청회색 계열인가
- 반복 요소(창, 패널, 전봇대)가 같은 간격으로 이어지는가
- 전선이 전봇대와 철탑의 팔 끝에 정확히 걸리는가
- 연기와 눈이 인물 얼굴을 가리지 않는가
