# 검수 기준

## 절차

1. `--preview`로 렌더
2. `_overview.png`를 열어 전체 인상과 구도를 확인
3. `_face.png`를 열어 눈, 코, 입, 앞머리를 확인
4. 아래 항목을 점검하고 결함이 있으면 처방을 적용
5. 결함이 없으면 최종 크기로 렌더한 뒤 2-3단계를 1회 반복
    + 미리보기에서 보이지 않던 가는 선과 입자가 최종 크기에서 드러남

## 점검 항목

| 구분 | 확인 내용 |
|---|---|
| 구도 | 머리 위 여백이 화면 높이의 10-20%인가, 인물이 화면의 절반 이상을 차지하는가 |
| 얼굴 | 양쪽 눈의 높이와 크기가 맞는가, 턱선이 매끈한가, 코와 입이 얼굴 중심선 위에 있는가 |
| 눈 | 홍채가 눈꺼풀 안에 있는가, 하이라이트가 양쪽 눈에서 같은 쪽에 있는가 |
| 머리카락 | 두피가 보이지 않는가, 다발 뿌리에 이음매 선이 없는가, 광택 띠가 얼굴을 침범하지 않는가 |
| 몸 | 목 길이와 어깨 폭이 머리 크기와 어울리는가, 의상이 몸 밖으로 튀어나오지 않는가 |
| 빛 | 그림자가 모두 광원 반대편(기본 우하단)에 있는가 |
| 선 | 끊김과 계단 현상이 없는가 |
| 화풍 | 선택한 화풍의 특징(셀 경계, 종이 입자, 붓질)이 첫눈에 보이는가 |
| 전신 | 관절에 고리 모양 선이 없는가, 앞에 놓인 팔이 옷 위에 보이는가, 발이 지면 그림자 위에 있는가 |
| 인상 | 얼굴과 머리 비율이 의도한 인상(성숙함, 앳됨)과 맞는가, 의상이 의도한 부위를 덮는가 |
| 3D 인물 | 정면, 3/4, 측면, 뒷모습에서 피부가 옷을 뚫지 않는가, 관자놀이와 뒤통수에 두피가 보이지 않는가, 무릎과 팔꿈치가 반대로 꺾이지 않는가, 손이 몸에 묻히거나 뜨지 않는가, 발이 바닥에 닿는가, 끈이 끊겨 보이지 않는가, 셀 그림자 경계가 매끈한가 |
| 바닥 자세 | 누운 인물의 머리, 등, 엉덩이, 발뒤꿈치가 함께 바닥이나 매트리스에 닿는가, 무릎 꿇은 인물의 무릎과 발등이 바닥에 닿는가 |
| 손 | 손가락 굵기가 고른가, 손목과 손바닥 사이에 단차가 없는가 |
| 현대 사물 | `scene3d.overlaps()`가 빈 목록인가, 상판 위에 떠 보이지 않는가(접촉 그림자), 화면이 사용자를 향하는가, 유리 너머가 비쳐 보이는가 |
| 실내 장면 | 벽, 바닥, 가구의 소실 방향이 맞는가, 가구 다리와 발이 바닥에 닿는가, 앉은 인물의 엉덩이가 좌석 위에 있는가, 손이 자판이나 기기를 쥔 것으로 읽히는가 |
| 풍경 | 지평선 아래에 빈 곳이 없는가, 물에 비친 상이 호숫가에서 시작하는가, 먼 산이 가까운 산보다 옅은가 |
| 도시 | 창문 줄이 소실점으로 모이는가, 높은 건물이 종이처럼 얇게 보이지 않는가, 반사가 건물 바로 아래에 있는가 |
| 정물 | 물체가 탁자 위에 떠 보이지 않는가(밑점 그림자), 윤곽이 좌우 대칭인가 |
| 색 | 주조색과 배경의 대비가 충분한가, 그림자 색이 탁하지 않은가 |

## 증상별 처방

| 증상 | 원인 | 처방 |
|---|---|---|
| 이마에 피부가 넓게 보임 | 앞머리 다발 폭 부족 또는 `cap` 아랫변이 높음 | `bangs`의 `width`를 0.45 이상으로, `cap` 아랫변 y를 낮춤 |
| 정수리에 방사형 선이 많음 | 다발 뿌리 선이 드러남 | `rig_hair.ROOT_FADE`의 값을 키움 |
| 얼굴에 그림자 띠가 넓음 | 얼굴 `roundness` 과다 | `rig_face.FACE_ROUNDNESS`를 낮춤 |
| 눈 위에 가시 같은 그림자 | 앞머리 그림자가 길게 떨어짐 | `rig_face.FRINGE_SHADOW_DROP`을 줄임 |
| 머리가 작고 몸이 큼 | `head_radius` 부족 | `head_radius`를 키우고 `head_center`를 조정 |
| 목이 길어 보임 | `neck_offset`의 y 과다 | 1.55-1.65 범위로 낮춤 |
| 어깨가 넓어 남성적으로 보임 | `shoulder_half_width` 과다 | 1.35-1.45 범위로 조정 |
| 의상 모서리가 팔 위로 튀어나옴 | 천 도형이 몸통 옆선과 불일치 | 천 도형 끝점을 겨드랑이 좌표에 맞추고 몸 마스크와 곱함 |
| 광택 띠가 머리띠처럼 보임 | 띠가 가늘고 균일함 | `highlight_thickness`를 0.15 이상으로 |
| 멀리 있는 눈이 어색하게 좁음 | `yaw` 과다 | 절대값을 0.3 이내로 |
| 구름이 파란 덩어리로 보임 | 그늘 비중 과다 | `background.PUFF_SHADE_BAND`의 시작값을 키움 |
| 회화풍 얼굴이 얼룩덜룩함 | 가는 붓 층의 색 흔들림 | `brushwork.COLOR_JITTER`를 낮추거나 `RELIEF_GAIN` 뒤쪽 값을 낮춤 |
| 회화풍 얼굴이 허옇게 뜸 | 원화 명도 과다 | `finish.PAINT_GAMMA`를 키움 |
| 결과 파일이 실행마다 다름 | 난수를 `canvas.rng` 밖에서 생성 | 모든 난수를 `canvas.rng`에서 얻음 |
| 관절에 인형 같은 고리 선 | 앞 형태와 뒤 형태의 높이 차 | 같은 `depth`로 합치거나 깊이를 팔 길이에 따라 점진적으로 올림 |
| 둥근 물체가 서로 파고듦 | 앞 물체의 `depth` 부족 | `depth=FRONT` 사용 |
| 부푼 형태 둘레에 고리 | `bump()`의 가장자리 | 가장자리 없는 `swell()`로 교체 |
| 입체 표면에 방사형 줄무늬 | 높이 지도의 능선 | `relief.RIDGE_SMOOTHING`이나 `NORMAL_SMOOTHING_PX`를 키움 |
| 숨은 손의 손톱이 옷 위에 보임 | 마무리 그리기가 가려짐을 무시 | `relief.visible(name)`으로 잘라냄 |
| 회화풍에서 한쪽 대상만 어두움 | 떨어진 대상을 한 덩어리로 음영 | `canvas.shade_subject_as_one = False` |
| 산이 화면을 가득 메움 | 봉우리가 높거나 초점 거리가 김 | `peak_height`나 `Camera.focal`을 낮춤 |
| 산이 회색 덩어리로 보임 | 안개가 짙거나 바위 비중 과다 | `haze_distance`를 키우고 `terrain.ROCK_SLOPE`를 올림 |
| 호수가 가는 띠로 보임 | 카메라가 낮음 | `Camera.eye_height`를 올림 |
| 건물이 얇은 칼날로 보임 | 카메라 쪽 벽 누락 | `draw_buildings()`의 정면 벽 사용(기본 동작) |
| 천이 골함석처럼 보임 | 주름 간격이 일정함 | `stilllife.cloth()`의 `fold_units`를 키움 |
| 무릎과 팔꿈치에 가로 선 | 관절 앞뒤 형태를 따로 부풀림 | 관절을 지나는 한 덩어리로 부풀림(`rig_figure._limb_chain`) |
| 어깨에 점선 | 팔이 몸통 위로 올라선 경계 | 팔을 `edge=False`로 추가 |
| 아랫배나 하의 중앙의 어두운 띠 | 몸통 부풀림이 사타구니 꼭짓점에서 급경사로 꺼짐 | `rig_figure.LOWER_ABDOMEN` 높이를 키움 |
| 치마 옆으로 골반 피부가 비침 | 치마 윤곽이 체형의 골반 곡선보다 안쪽 | `rig_figure.SKIRT_UPPER_HIP`을 바깥으로 |
| 허리에 올린 손이 배 위에 놓임 | 손이 팔뚝 방향을 그대로 이어감 | `Pose.wrist_*`로 손가락을 아래로 돌림 |
| 인물이 의도보다 어려 보임 | 큰 눈, 짧은 하관, 큰 머리 | `adult_face()` 적용, `head_scale` 1.0 |
| (3D) 옷 위로 피부 조각이 비침 | 옷 두께가 피부끼리 녹아 붙는 부풂보다 작음 | 두께를 `TIGHT`(0.030) 이상으로, 층은 `GARMENT_LAYERS` 지정 |
| (3D) 상의 밑단에 바지가 톱니처럼 비침 | 바지의 허벅지 윗부분과 엉덩이 부풂 | 상의를 겹쳐 입는 층으로 지정하면 `hip_cover`가 자동 추가됨 |
| (3D) 옷이나 몸에 가로 줄무늬 음영, 그림자 경계의 톱니 | 단면 타원체나 구 사슬 사이의 골 | `body3d.SECTION_OVERLAP`(단면 길이), `SWEEP_BLEND`(구 사슬의 좁은 부드러운 합), `SURFACE_SMOOTH`를 키움 |
| (3D) 가림 선이 점선처럼 끊김 | 깊이 차가 문턱 근처에서 오르내림 | `body3d.LINE_JUMP_SMOOTH`를 키우거나 `LINE_MIN_LENGTH`로 짧은 조각 제거 |
| (3D) 끈이 피부에 묻혀 군데군데 끊김 | 끈 경로가 직선 구간에서 가슴, 쇄골, 목 안으로 들어감 | 끈 경로를 `wardrobe3d.over_skin()`에 통과시킴, 몸통 밖 거리 `STRING_CLEARANCE` |
| (3D) 끈 끝이 컵에서 떨어져 떠 있음 | 끈 시작점이 가슴 속에 있음 | 끈은 `_cup_corner()`가 찾은 보이는 컵 모서리에서 시작 |
| (3D) 소매나 바짓단이 풍선처럼 둥글게 끝남 | 구 사슬의 끝 반구 | 중간에서 끝나는 관에 `flat_hem()` 적용(`leg`, `sleeve`는 자동) |
| (3D) 잘라낸 앞섶 가장자리가 계단 모양 | 단면 조각마다 따로 잘림 | 같은 `part`의 조각은 합친 면에서 한 번에 자름(`DepthRenderer._cut_part`, 자동) |
| (3D) 긴 머리 끝이 망토처럼 둥글게 뭉침 | 뒷머리 판이 한 덩어리로 끝남 | `Hair3D.tips`로 끝을 가닥으로 나눔(`LONG_HAIR`는 기본 적용) |
| (3D) 남성 얼굴이 여성처럼 보임 | 긴 속눈썹, 큰 홍채, 입술색 | `male_face()` 사용(`lash_weight`, `brow_weight`, `iris_scale`, `lip_tint` 자동 설정) |
| (3D) 누운 인물이 떠 있거나 한쪽만 닿음 | 몸이 기울어 가장 낮은 한 점만 닿음 | 골반 `rx`와 고관절 `rx`를 0.02-0.05씩 조정, `ground_points()`로 닿는 부위 확인 |
| (3D) 주머니에 넣은 손가락이 바지 위로 보임 | 손이 몸 표면 밖에 놓임 | 손가락을 몸 안쪽(`fingers`의 z 음수)으로 향하게 하고 바지류 의상 사용 |
| (3D) 주머니 손 자세에서 소매 끝이 상의 밑단 밖으로 돌출 | 소매 끝이 상의 주머니 부풂보다 굵음 | `POCKET_SLEEVE_ROOM`, `POCKET_SLEEVE_WIDEN`을 키움(긴 소매는 `tuck_into_pocket`으로 자동 절단) |
| (3D) 팔과 몸 사이에 작은 흰 타원이나 검은 얼룩 | 팔과 몸이 머리카락 굵기만큼 떨어진 틈 | 렌더러가 `SLIVER_AREA`(0.004 머리 높이 제곱) 이하의 닫힌 틈을 메움, 더 큰 틈이 남으면 값을 키움 |
| (3D) 역광 장면인데 인물이 정면에서 밝게 빛남 | 기본 광원 사용 | `light`의 z를 음수로 지정 |
| (3D) 어깨끈이 손잡이처럼 어깨 위로 뜸 | 고정 좌표 원형 관 | 끈은 `strap_over_skin()`으로 생성 |
| (3D) 앉은 인물의 상의 밑단이 엉덩이 쪽에서 덮개처럼 튀어나옴 | 몸통 끝과 엉덩이 덮개의 절단 위치가 다름 | 둘 다 `hem_cut()` 평면으로 절단(하의 위 상의는 자동) |
| (3D) 3/4 얼굴의 먼 눈이 뺨 윤곽 밖으로 삐져나옴 | 이목구비가 윤곽선 띠 위나 얼굴 밖에 그려짐 | 이목구비는 윤곽선 안쪽, 머리카락 위 눈썹과 속눈썹은 머리와 머리카락 영역으로 제한(자동) |
| (3D) 측면 구도에서 손동작이 얼굴이나 몸에 가려짐 | 동작하는 손이 카메라 반대쪽 | `rig3d.mirrored(자세)`로 좌우 반전 |
| (3D) 수평 카메라에서 인물이 떠 보임 | 바닥 그림자가 시점과 무관한 타원 | `figure3d.floor_shadow()`가 원근 투영(자동) |
| (3D) 반바지가 치마처럼 보임 | 다리 길이가 사타구니 높이에서 끝나 가랑이 구분이 사라짐 | 다리 길이를 사타구니 아래로(`HOT_PANTS_LEG` 0.19), 앞 중심 솔기 자동 |
| (3D) 그림자 경계가 계단 모양 | 그림자 표본 간격이 넓음 | `relief.CAST_SAMPLE_PX`를 줄임 |
| (3D) 관자놀이나 옆머리에 피부가 보임 | 두피층이 잘린 범위가 넓음 | `Hair3D.scalp_drop`을 낮추거나 `FACE_OPENING`을 좁힘 |
| (3D) 소매가 공처럼 부풂 | 소매 여유가 어깨 위에서도 큼 | `wardrobe3d.SLEEVE_EASE_LENGTH`를 키우거나 소매 두께를 낮춤 |
| (3D) 어깨가 각지게 솟음 | 팔 뿌리 구가 몸통 위로 올라섬 | 승모근 형태(`TRAPEZIUS_SLOPE`)와 `ARM` 첫 조절점 높이를 조정 |
| (3D) 무릎이나 팔꿈치가 반대로 꺾임 | `rx` 부호 반대 | 무릎은 `rx` 양수, 팔꿈치는 `rx` 음수로 굽힘 |
| (3D) 손이 엉덩이에 묻힘 | 목표점이 체형보다 안쪽 | `Reach` 목표를 `hip_*` 관절 기준으로 지정(골반 폭을 따라감) |
| (3D) 손목이 부러진 듯 꺾임 | 손 방향이 팔뚝과 너무 다름 | `fingers`를 팔뚝 방향 쪽으로, 또는 `pole`로 팔꿈치 위치를 바꿈 |
| (3D) 옷 위에 점 같은 얼룩 | 가려진 솔기 선의 짧은 조각 | `figure3d.MIN_RUN_WIDTHS`를 키움 |
| (3D) 얼굴이 머리카락에 가려짐 | 머리 덩어리가 얼굴 앞으로 나옴 | `Hair3D.cap_radii`의 z를 줄이거나 `HAIRLINE_Y`를 올림 |
| (3D) 렌더가 느림 | 인물 수와 캔버스 크기에 비례 | 시트는 `--preview`로 검수하고 최종 렌더는 1회만 |
| (장면) 물체 모서리가 다른 물체 위로 튀어나옴 | 두 물체가 실제로 겹친 배치(노트북 뚜껑 뒤의 책) | `scene3d.overlaps(items)`로 겹친 쌍을 찾고 `on_top`의 offset을 옮김 |
| (장면) 유리가 불투명한 판처럼 보임 | 유리 부품을 `solids`에 넣음 | 투명한 부품은 `Prop3D.glass`에 넣음(`drinking_glass()`가 견본) |
| (장면) 케이블이 상판에 묻히거나 뜸 | 경로 점이 표면 높이와 다름 | 경로 점을 상판이나 바닥 높이에 둠(축은 반지름만큼 자동으로 뜸) |
