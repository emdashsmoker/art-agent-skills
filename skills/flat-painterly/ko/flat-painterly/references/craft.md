# 작화 원칙

화풍과 무관하게 적용되는 판단 기준. 기획 단계에서 구도, 명암, 색을 정할 때와 검수 단계에서 결함을 찾을 때 읽음.

## 구도

- 초점은 1곳
    + 화면에서 명암 대비가 가장 크고 윤곽이 가장 또렷하며 채도가 가장 높은 곳이 초점으로 읽힘
    + 세 요소를 초점에 몰아주고 나머지 영역에서는 아낌
- 초점은 화면 정중앙을 피해 삼분할 교차점 근처에 배치
    + 1600x900 화면의 교차점은 x 533 또는 1067, y 300 또는 600
- 큰 덩어리는 3-5개
    + 크기를 서로 다르게 잡아 대, 중, 소가 구분되게 함
- 덩어리를 서로 겹쳐 앞뒤 관계를 만듦
    + 겹침 없이 나란히 놓인 도형은 깊이 없이 평면으로 읽힘
- 시선을 초점으로 끄는 선을 1개 이상 배치
    + 가지, 길, 수평선, 머리카락 흐름, 빛줄기 등
- 화면 가장자리에 닿는 요소는 확실히 잘리게 하거나 확실히 떨어뜨림

## 명암

- 색을 정하기 전에 밝음, 중간, 어두움 3무리의 배치를 먼저 결정
    + 세 무리의 면적을 서로 다르게 잡아 한 무리가 화면을 주도하게 함
- 같은 무리 안의 색은 명도를 가깝게 유지
    + 그림자 안의 밝은 색이 빛 받는 면의 어두운 색보다 밝아지면 입체가 무너짐
- 광원은 1개로 정하고 모든 그림자와 하이라이트를 그 방향에 맞춤
- 렌더를 작게 줄여 봤을 때 주제가 읽히면 명암 구조가 성립

## 색

- 팔레트는 5-7색으로 제한하고 색마다 역할을 부여
    + 지배색은 화면 대부분을 차지하는 색 계열
    + 보조색은 지배색과 이웃한 색상
    + 강조색은 지배색의 보색이며 초점에만 소량 사용
- 그림자색은 밑색의 명도만 낮추지 않고 색상을 옮김
    + 난색 빛 아래 그림자는 한색 쪽으로, 한색 빛 아래 그림자는 난색 쪽으로 이동
    + `color.shade`가 한색 이동을 자동으로 수행
- 먼 것은 하늘색에 가깝게, 대비는 낮게, 윤곽은 흐리게 처리(공기 원근)
- 채도가 높은 색끼리 넓게 맞닿으면 눈이 피로해짐
    + 고채도는 작은 면적에, 넓은 면적은 중간 채도 이하로 구성
- 순수한 검정과 순수한 흰색은 최암부와 하이라이트 점에만 사용

## 형태

- 큰 형태에서 작은 형태 순서로 진행
    + 큰 형태의 비례가 틀린 상태에서 세부를 얹으면 세부를 전부 다시 그려야 함
- 실루엣만으로 대상을 알아볼 수 있게 설계
    + 팔, 꼬리, 가지처럼 특징적인 부분은 몸통 밖으로 빼서 윤곽에 드러냄
- 직선과 곡선, 큰 간격과 작은 간격을 섞음
    + 같은 크기와 같은 간격의 반복은 기계적으로 보임
    + 반복 요소는 난수로 크기, 간격, 기울기를 조금씩 흔듦
- 자연물의 윤곽은 `roughen`, `blob`, `ridge`로 불규칙성을 줌
- 둥근 입체는 `form_shadow`로 그림자를 얻고 각진 입체와 설계된 그림자는 직접 도형으로 그려 `clip`으로 제한
- 바닥에 놓인 물체는 닿는 자리에 짙고 좁은 접지 그림자를 넣고 그 위에 넓고 옅은 드리운 그림자를 겹침
    + 접지 그림자가 없으면 물체가 바닥에서 떠 보임

## 애니메풍 얼굴 비례

`examples/anime_sky_pilot.py`에서 렌더로 확인한 정면 얼굴의 단위 좌표. 두개골 반지름이 1이고 원점은 두개골 중심. 몸의 비례와 자세는 `references/figure.md`의 리그를 사용.

| 부위 | 좌표 |
|---|---|
| 정수리 | (0, -1.0) |
| 관자놀이 | (±0.98, 0.2) |
| 턱선 | (±0.88, 0.64), (±0.6, 1.04), (±0.28, 1.3) |
| 턱 끝 | (0, 1.4) |
| 눈 중심 | (±0.47, 0.36), 눈 반폭 0.27 |
| 눈썹 | y -0.02에서 -0.12 |
| 코 | (0.03, 0.74)에서 (0, 0.9) |
| 입 | y 1.02에서 1.1, 반폭 0.2 |
| 머리카락 바깥선 | 두개골보다 0.1-0.2 바깥 |

- 눈 반폭과 턱 길이가 나이대를 정함
    + 눈 반폭 0.27, 턱 끝 1.4는 젊은 성인. 눈을 키우고 턱을 줄일수록 어려 보임

| 부위 | 좌표와 처리 |
|---|---|
| 턱선 | (±0.92, 0.68)에서 꺾이는 턱 모서리, (±0.66, 1.1), (±0.3, 1.4) |
| 턱 끝 | (±0.13, 1.47)에서 꺾이는 평평한 턱 끝과 그 아래 그늘 |
| 눈 | 중심 (±0.44, 0.38), 반폭 0.235. 높이가 폭의 3분의 1인 가는 꼴, 눈꼬리 날개 없음 |
| 눈썹 | 눈에 가깝고 굵은 면. (0.1, -0.02)에서 (0.88, -0.06), 두께 0.08 안팎 |
| 코 | 콧대 선 (0.12, 0.34)에서 (0.08, 0.9)과 코끝 밑 그림자, 인중 선 |
| 입 | 얇은 윗입술 선 y 1.12-1.14, 반폭 0.22. 아랫입술 밑의 짧은 그늘 |

- 각도가 있는 얼굴은 `head3d.Head3D.face()`에 위 표들의 좌표를 그대로 넣음
    + 좌표가 얼굴 겉면에 붙어 각도만큼 찌그러지고 보이지 않는 부품은 `face.facing`으로 거름. 사용법은 `references/figure.md`의 각도별 머리와 머리카락

## 검수 목록

전체 이미지와 초점부 확대 이미지를 보며 위에서 아래로 점검.

| 구분 | 확인할 점 |
|---|---|
| 구도 | 초점이 1곳으로 읽히는가. 작게 줄여도 주제가 보이는가 |
| 비례 | 부품의 크기와 위치가 어색하지 않은가. 좌우 대칭이 필요한 곳이 어긋나지 않았는가 |
| 연결 | 부품 사이에 틈이나 배경이 비치는 구멍이 없는가. 닿아야 할 것이 닿아 있는가 |
| 명암 | 광원 방향이 모든 부품에서 일치하는가. 초점의 대비가 가장 큰가 |
| 색 | 팔레트 밖의 색이 끼어들지 않았는가. 강조색이 초점 밖에 흩어지지 않았는가 |
| 가장자리 | 화면 끝에서 도형이 어정쩡하게 끊기지 않았는가 |
| 재질 | 화풍 패스 뒤에 초점부 형태가 뭉개지지 않았는가. 밝은 곳이 하얗게 날아가지 않았는가 |
| 기계적 흔적 | 같은 모양이 같은 간격으로 반복되지 않는가. 완전한 원, 완전한 직선이 자연물에 남아 있지 않은가 |

## 흔한 결함과 처방

| 증상 | 원인 | 처방 |
|---|---|---|
| 도형이 예상과 다른 곳에 있음 | 좌표를 보지 않고 추정 | `guide_image`로 격자를 보고 좌표를 읽어 수정 |
| 곡선이 제어점 사이에서 부풀거나 꼬임 | 제어점 간격이 고르지 않음 | 중간 제어점을 추가하거나 꺾일 점을 corners에 지정 |
| 부품 사이로 배경이 비침 | 이웃 부품이 서로 맞닿기만 함 | 뒤 부품을 앞 부품 밑으로 충분히 밀어 넣어 겹침 |
| 그림자가 탁한 회색 | 밑색에 검정을 섞음 | `color.shade` 또는 색상을 옮긴 그림자색 사용 |
| 화면이 뿌옇고 밝은 곳이 날아감 | 빛 번짐 과다 | bloom과 diffusion 강도를 낮추고 밑색의 명도를 내림 |
| 반복 요소가 도장처럼 보임 | 크기와 간격이 일정 | 난수로 크기, 위치, 기울기, 불투명도를 흔듦 |
| 물체가 바닥에서 떠 보임 | 접지 그림자 없음 | 닿는 자리에 짙고 좁은 그림자를 MULTIPLY로 추가 |
| 작은 세부가 패스 뒤에 사라짐 | 세부가 붓이나 번짐보다 작음 | 세부를 키우거나 scale을 올리거나 패스 인자를 줄임 |
| 가는 선이 끊겨 보임 | scale 대비 선 폭이 1px 미만 | 선 폭을 올리거나 최종 scale을 올림 |
