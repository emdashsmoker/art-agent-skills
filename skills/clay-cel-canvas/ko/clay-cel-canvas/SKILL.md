# clay-cel-canvas

코드로 그림을 그리는 스킬. 확산 모델과 이미지 생성 API는 쓰지 않는다.

## 원리

- 그림은 절차의 합이다
    + 화가는 기획, 형태, 밑색, 명암, 선, 세부, 마감 순서로 작업한다
    + 각 절차는 좌표와 색과 합성 연산으로 기술된다
- 화풍은 절차별 매개변수의 묶음이다
    + 같은 장면 스크립트가 `ANIME`, `ILLUST`, `PAINTERLY` 세 화풍으로 렌더링된다
- 품질은 검수 횟수가 결정한다
    + 좌표를 적는 시점에는 결과를 볼 수 없다
    + 렌더링한 이미지를 직접 열어 본 뒤 고치는 과정이 작화의 본체다

## 준비

- 의존성: `numpy`, `opencv-python`
    + 없으면 작업 전에 먼저 설치한다
- 엔진 위치: 이 스킬 폴더의 `scripts/atelier/`
- 장면 스크립트 첫머리

```python
import sys
sys.path.insert(0, "<이 스킬 폴더>/scripts")
from atelier import Art, STYLES, spline, ellipse, symmetric, rotate, mix
```

## 좌표와 레이어

- 캔버스 너비는 항상 1000 단위다
    + 높이는 `1000 * aspect` 단위다
    + 픽셀 크기와 무관하므로 512px 미리보기와 2048px 최종본이 같은 스크립트를 쓴다
    + y축은 아래로 증가한다
- 레이어는 4장이다
    + `flat`: 밑색과 세부 채색
    + `shade`: 그림자 (곱하기)
    + `glow`: 빛 (스크린)
    + `line`: 선화
- `art.part()`로 부품을 추가하면 부품 영역 아래의 그림자, 빛, 선이 지워진다
    + 나중에 그린 부품이 앞에 놓인다
    + 그리는 순서는 뒤에서 앞이다
- `with art.place(at, scale, angle, flip, pivot):` 블록 안에서는 자체 좌표로 그린다
    + 머리, 손, 나무, 정물처럼 반복해 쓰는 부분 그림을 함수로 만들고 원하는 위치와 크기로 놓는다
    + 블록 안의 좌표, 굵기, 반경이 모두 함께 변환된다
    + 광원 방향은 변환되지 않으므로 뒤집거나 돌려도 그림자 방향이 맞는다

## 작업 절차

각 단계가 끝나면 512px로 렌더링하고 이미지를 직접 열어 확인한다. 결함이 보이면 다음 단계로 넘어가지 않고 고친다.

### 1단계 기획

스크립트 상단에 상수로 적는다.

- 대상과 구도: 화면 비율 `ASPECT`, 카메라 `VIEW = (중심 x, 중심 y, 확대율)`
- 광원: `LIGHT = (x, y, z)`는 빛이 오는 방향이다
    + 좌상단 정면광은 `(-0.45, -0.60, 0.66)`이다
- 색: `PALETTE` 딕셔너리에 8-16색을 이름 붙여 정한다
    + 주조색 1개, 보색 또는 대비색 1개, 무채색에 가까운 색 1개를 기준으로 삼는다
- 화풍: `anime`, `illust`, `painterly` 중 선택한다
    + 선택 기준은 `references/styles.md` 참조

### 2단계 형태

- 부품 목록을 뒤에서 앞 순서로 적는다
    + 인물 예시: 배경, 뒷머리, 목, 옷, 귀, 얼굴, 눈, 코와 입, 앞머리, 장신구
- 부품마다 조절점을 찍고 `spline(points, closed=True)`로 윤곽을 만든다
    + 조절점은 부품당 6-20개가 적당하다
    + 뾰족한 곳은 `(x, y, True)`로 표시한다
    + 좌우 대칭 형태는 절반만 찍고 `symmetric(half, axis_x)`를 쓴다
- 팔다리, 손가락, 나무줄기는 `art.tube([(x, y, 굵기), ...])`로 만든다
    + 관절 위치와 관절마다의 굵기만 정하면 둥근 살이 붙는다
- 인물은 `references/figure.md`의 비례 수치로 좌표를 정한다
- 풍경은 `references/scenery.md`, 도시는 `references/city.md`, 정물은 `references/still-life.md`의 조립 방법을 따른다
- 노트북, 가구, 건물처럼 상자와 원기둥으로 된 사물은 3차원 좌표로 정하고 `Camera`로 투영한다
    + 눈대중 좌표로는 평행한 모서리들이 한 소실점으로 모이지 않는다
- 전신 인물, 특히 앉거나 누운 자세와 인체 습작은 3차원 마네킹으로 만든다 (`atelier.mannequin`, `atelier.sculpt`)
    + 2차원 좌표로 찍은 팔다리는 자세가 복잡해질수록 길이와 겹침이 어긋나 몸이 뒤틀린다
    + 마네킹은 골반, 가슴, 머리의 방향과 손발의 목표 위치만 받고 팔꿈치와 무릎은 스스로 계산한다
    + 얼굴은 흉상 예제의 머리를 마네킹의 턱 위치에 얹는다
    + 체형은 `FEMALE`, `MALE` 2종이다. 남성은 흉상, 인체 습작, 착의 예제를 따로 갖춘다
- 옷 입은 인물은 `examples/outfits.py`의 조합으로 시작한다 (`references/wardrobe.md`)
    + 포즈 프리셋(`atelier.staging`), 옷(`atelier.wardrobe`), 장면(`examples/scenes.py`), 샷을 고른다
    + 카메라는 `frame()`이 샷에 맞춰 놓고, 머리는 몸의 고개 방향을 따라 3/4 측면까지 돈다
    + 치마, 드레스, 스카프와 바람은 `atelier.drape`, 2명은 `DUOS`와 `figure_study.draw_cast()`로 그린다
- 그림자 계산에 쓰일 마스크는 `art.shape(curve)`로 미리 만들어 둔다

### 3단계 밑색

- `art.part(curve_or_mask, color)`로 부품을 뒤에서 앞으로 추가한다
- 이 시점에 `art.save(path, stage="flat")`으로 실루엣과 색 배치를 확인한다
    + 실루엣만 보고도 대상이 읽혀야 한다

### 4단계 명암

- 형태 그림자는 `part()`가 자동으로 넣으며 `bulge`로 입체의 종류를 고른다
    + `bulge` 생략: 풍선처럼 부푼 입체. 원은 구, 띠는 원기둥이 된다. 과일, 팔다리, 구름, 몸통에 쓴다
    + `bulge=반경`: 가장자리만 둥근 납작한 입체. 반경이 작을수록 그림자가 가장자리에 얇게 진다. 옷, 얼굴, 벽, 종이에 쓴다
    + 평평해야 할 부품은 `shade=False`
- 드리운 그림자: `art.shadow(art.move(가리는_마스크, dx, dy) * 받는_마스크, tint)`
    + 머리카락이 이마에, 턱이 목에, 깃이 옷에 드리우는 그림자가 입체감을 만든다
- 그림자 색은 곱하기 색이다
    + 피부에는 밝은 분홍 계열을 쓴다 (예: `#EDCBC4`)
    + 그 외에는 기본값인 연보라를 쓴다

> (순서 규칙) 아래 부품에 드리우는 그림자는 위 부품을 그리기 전에 적용한다. 위 부품을 그린 뒤에 적용하면 그림자가 위 부품까지 물든다.

### 5단계 선

- 외곽선은 `part()`가 자동으로 그린다
    + 광원 반대편이 굵어진다
    + 선 색은 부품 색을 어둡게 한 색이다
    + 이어져 보여야 하는 부품은 `outline=False`
- 내부 선은 두 종류다
    + `art.line()`: 주름, 머리카락 결 같은 윤곽성 선이다. 선화가 없는 화풍에서는 그려지지 않는다
    + `art.mark()`: 속눈썹, 눈썹, 입술 선 같은 채색 획이다. 모든 화풍에서 그려진다
- 획의 굵기 변화는 `taper`로 준다: `both`, `start`, `end`, `none`

### 6단계 세부와 빛

- 시선이 모이는 곳부터 공들인다
    + 인물은 눈이다. 흰자, 홍채, 홍채 테두리, 동공, 아래쪽 반사광, 윗눈꺼풀 그림자, 하이라이트 순으로 쌓는다
- 빛은 `art.light(mask, color, opacity)`로 더한다
    + 하이라이트, 머리카락 윤기, 역광 테두리에 쓴다
- 부드러운 색 변화는 `art.blob()`과 `art.ramp()` 마스크로 만든다
    + 볼 홍조, 하늘 그라데이션, 머리카락 아래쪽의 어두운 색
- `art.focus_on(mask)`로 초점 영역을 지정한다
    + 마감 단계가 이 영역의 세부를 더 선명하게 남긴다

### 7단계 마감

- `art.save(path)`가 화풍별 후보정을 적용한다
- 분위기 층은 후보정 뒤에 씌운다: `art.grade = doomer` (`references/styles.md`의 분위기 층)
    + 어느 화풍에나 씌운다. 장면의 색과 소품도 같은 분위기로 고른다
- 최종본은 `width_px=1024` 이상으로 렌더링한다
    + 선이 더 깨끗해야 하면 2048로 그리고 `save(path, downscale=2)`를 쓴다
- `art.save_stages(path)`는 선, 밑색, 명암, 빛, 최종의 5단계를 한 장에 나란히 저장한다
    + 과정을 보여 달라는 요청에 사용한다

## 최소 예시

```python
art = Art(STYLES["anime"], width_px=512, aspect=1.0, light=(-0.45, -0.60, 0.66))
art.paint(art.everywhere(), "#F2C79A")                      # background
art.paint(art.ramp((0, 0), (0, 1000)), "#3F7C85", 0.9)      # gradient over it
art.blur(6)                                                 # push background out of focus
body = art.part(ellipse(500, 560, 260, 300), "#E8765C")     # shape, flat, form shadow, outline
leaf_mask = art.shape(spline([(500, 300), (640, 160, True), (560, 330)], closed=True))
art.shadow(art.move(leaf_mask, 20, 40) * body)              # cast shadow before the leaf is drawn
art.part(leaf_mask, "#4FA36B")
art.light(art.blob((400, 440), 90) * body, "#FFFFFF", 0.7)  # highlight
art.save("out.png")
```

## 검수 기준

렌더링을 열어 아래 항목을 하나씩 확인한다.

- 형태: 실루엣만으로 대상이 읽히는가
- 비례: 인물의 눈, 코, 입, 턱이 `references/figure.md`의 범위 안에 있는가
- 겹침: 부품 사이에 틈이나 삐져나온 조각이 없는가
- 명암: 모든 그림자가 광원 반대편에 있는가
- 물듦: 그림자가 다른 부품 위로 번지지 않았는가
- 초점: 가장 공들인 곳과 시선이 모이는 곳이 일치하는가
- 화풍: 선, 명암 경계, 질감이 선택한 화풍의 규칙과 맞는가

작은 부위는 잘라서 확대해 본다. 전체 화면에서는 눈과 입의 결함이 보이지 않는다.

## 자주 생기는 결함

| 증상 | 원인 | 처치 |
|---|---|---|
| 얼굴 아래쪽에 수염처럼 어두운 면 | 목에 드리운 그림자를 얼굴보다 나중에 적용 | 그림자 적용을 얼굴 `part()` 앞으로 이동 |
| 부품 옆에 밑색 조각이 삐져나옴 | 아래 부품이 위 부품보다 넓음 | 아래 부품의 폭을 줄임 |
| 그림자가 부품 전체를 덮음 | `bulge`가 부품 크기에 비해 큼 | `bulge`를 부품 폭의 1/5 이하로 축소 |
| 선이 중간에 끊겨 보임 | 뒤에 그린 부품이 선을 가림 | 부품 순서 조정 또는 `art.line()`으로 보강 |
| 허공에 뜬 선 | 가는 획의 시작점이 형태 밖에 있음 | 시작점을 형태 안쪽으로 이동 |
| 성인으로 그린 인물이 어려 보임 | 눈이 크고 눈 위치가 낮음 | `references/figure.md`의 성인 비례 적용 |
| 회화풍에서 얼굴이 뭉개짐 | 초점 영역 미지정 | 얼굴과 눈에 `art.focus_on()` 적용 |
| 몸이 관절 인형처럼 보임 | 팔다리를 부품마다 따로 그려 관절에 공 모양 명암이 생김 | 몸통과 팔다리 마스크를 합쳐 부품 1개로 그림 |
| 관절에 띠나 틈이 생김 | 겹쳐 그린 팔다리의 뿌리가 몸의 명암을 덮음 | `references/figure.md`의 이음매 처리 적용 |
| 몸에 선이 많아 인형 이음매처럼 보임 | 근육과 뼈의 굴곡을 전부 잉크 선으로 표시 | 선은 쇄골과 접히는 곳에만, 나머지는 옅은 그림자로 처리 |
| 손목과 발목에 장갑이나 양말 같은 띠 | 손발을 팔다리와 따로 칠해 명암이 끊김 | 손발 마스크를 팔다리 마스크에 합쳐 칠하고 세부만 얹음 |
| 회화풍에서 손가락과 발가락이 뭉침 | 선화가 없어 맞닿은 손가락의 경계가 사라짐 | `hands.separate()`로 틈 그림자 추가, 발가락 끝 사이에 틈을 둠 |
| 인물이 뻣뻣함 | 어깨선과 골반선이 평행 | 체중을 한 다리에 싣고 두 선을 반대로 기울임 |
| 원근이 어긋난 건물 | 창문과 도로를 눈대중 좌표로 배치 | `references/city.md`의 투영 함수로 좌표 계산 |
| 전신이 뒤틀려 보임 | 2차원 좌표로 팔다리를 찍어 길이와 앞뒤 겹침이 어긋남 | 3차원 마네킹으로 자세를 잡음 |

| 반소매 어깨 솔기에 살이 보임 | 삼각근이 소매 밖에 남음 | 소매에 `shoulder` 영역을 함께 키움 |
| 헐렁한 옷이 팔을 삼킴 | 몸판 상자가 팔 앞까지 덮음 | 아래팔과 손 모양을 옷에서 파냄 |
| 두 겹 옷에 얼룩이 생김 | 두 옷의 두께가 같아 화소마다 앞뒤가 바뀜 | 안쪽 옷을 2mm 얇게 만듦 |
| 끈이 쇄골 근처에서 끊겨 보임 | 녹아 부푼 피부 속에 끈이 묻힘, 점 사이 직선이 곡면 아래로 파고듦 | `strap([Skin(scene)], 점들)`로 촘촘히 채워 실제 피부에 붙임 |
| 어깨 위에서 끈이 끊김 | 능선 아래를 지나는 직선이 앞뒤 면으로 갈라 붙어 빈 구간이 남음 | `strap()`이 빈 구간 가운데에 점을 넣어 능선 위로 붙임 |
| 밑가슴 띠, 엉덩이 끈, 팬티 허리 띠가 안 보임 | 원래 형태에 감은 띠가 녹은 피부 속에 묻힘 | `Surface(marks, 몸통 영역)`에 감음 (`_band(..., melted=True)`). `Skin`은 옆의 팔에 먼저 닿음 |
| 브라 어깨끈이 등 위에서 끝남 | 끈 경로가 밑밴드까지 내려오지 않음 | 경로 끝을 등 뒤 밑밴드 높이까지 내림 |
| 원피스나 셔츠 아래 허리에 살이 보임 | 배까지만 키운 몸판이 허리에서 피부 속으로 가라앉음 | 골반 영역까지 키운 뒤 허리에서 자름 |
| 치마가 손을 삼킴 | 치마 반지름이 내린 손보다 바깥 | 손과 아래팔 자리에서 치마를 안으로 들임 (`Flare`의 `obstacles`) |
| 손 아래 치마에 구멍 같은 자국 | 손 자리 들임이 피부 속까지 파고듦 | 피부 바로 위에서 멈춤 (`flare_profile`의 접촉 표) |
| 치마 허리 입구가 바구니 테두리처럼 보임 | 허리 반지름에 바람 여유와 1.4cm 여유를 더함 | 허리는 피부에서 4mm. 여유는 엉덩이 아래부터 줌 |
| 치마가 갓이나 원뿔처럼 뻣뻣함 | 허리에서 바로 퍼지고 주름이 고른 사인파 | 엉덩이 선까지 몸을 따르다 퍼짐, 주름 간격과 깊이에 변화 |
| 바람 반대쪽 치마가 자루처럼 부풂 | 바람 여유를 둘레 전체에 더함 | 둘레를 바람에 밀린 중심에서 재고 바람 반대쪽은 퍼짐을 없앰 |
| 치마 허리 아래로 상의가 비어져 나옴 | 안에 넣은 상의가 치마 허리 여유보다 두꺼움 | `ease`를 상의 두께만큼 줌 (티셔츠 위 1.4cm) |
| 스카프가 초커처럼 뜨고 끝자락이 울퉁불퉁함 | 목에 가는 고리 1개, 타원체를 이은 끝자락 | 굵은 고리 2바퀴와 매듭, `Ribbon` 끝자락 2개 |
| 다리를 꼬거나 무릎을 세우면 치마가 무릎에서 공처럼 부풂 | 다리 사이를 둥근 막대로 잇고 두 다리를 한 평면으로 자름 | 무릎까지만 덮고 다리마다 자름. 다리 사이는 납작한 천 (`_web`) |
| 뒤에서 본 인물의 뒤통수에 얼굴이 그려짐 | 그려진 머리는 정면 그림 | 머리가 110도 넘게 돌면 머리카락만 얹음 (`figure_study.BACK_VIEW`) |
| 의자나 누울 자리가 흰 상자나 회색 판으로 보임 | 장소에 그 받침 역할의 색이 없음 | 장소마다 `seat`, `bed`, `wall` 색을 정함 |
| 같은 색 잔디에 바닥 판 윤곽선이 가로로 보임 | 배경 땅과 3차원 바닥의 경계가 어긋남 | 배경 언덕의 밑자락을 `ground_edge()`에 맞춤 |

| 털모자 골지가 모자 밖으로 삐져나옴 | 골지 선을 마스크 없이 그음 | 골지와 접힌 선을 붓 마스크로 만들어 모자 마스크와 곱함 |

| 뒤에서 찍으면 바닥이 카메라 쪽에만 깔림 | 바닥 판이 +y로만 뻗음 | `ground_prop(place, looking_back(camera))`로 뒤집음 |

| 무릎 위 샷의 벽이 장소를 다 가림 | 폭 1m 벽도 확대하면 화면을 덮음 | 전신 샷이나 벽 없는 포즈 |

| 이마를 드러낸 남성이 머리가 빠진 것처럼 보임 | 이마선이 가르마에서 꺼짐 | 이마선을 가르마에서 반대쪽 관자놀이까지 고르게 둠 |
| 짧은 머리가 헬멧처럼 보임 | 옆머리가 얼굴 윤곽 밖으로 턱까지 내려옴 | 옆과 목덜미를 얼굴 윤곽 안쪽으로 접어 넣음 |
| 앉은 자세의 치마가 종처럼 부풂 | 수직축 둘레의 치마가 앞으로 뻗은 허벅지까지 감쌈 | 허벅지를 따르는 튜브 치마로 바꿈 (`flared_skirt`가 자동 전환) |
| 바람에 날린 치맛단이 몸 뒤로 숨음 | 바람이 관객 반대쪽(+y)을 향함 | 바람에 관객 쪽(-y) 성분을 조금 줌 |

| 브라 컵이 반창고처럼 작음 | 가슴 타원체만 얇게 키워 녹은 경사가 드러남 | 가슴을 1.2cm 키운 몰드 컵 |
| 벽이 장소를 가림 | 받침 벽이 화면보다 넓음 | 기둥처럼 좁게 둠 |
| 발이 바닥에 묻히거나 뜸 | 발목 높이가 발 크기와 안 맞음 | 발바닥 가장 낮은 점을 바닥에 맞춤 (`references/figure.md`) |

## 금지

- 미성년자의 노출과 성적 묘사는 그리지 않는다
    + 미성년자: 18세 미만으로 설정된 인물, 아동의 몸(이차성징 이전 체형)으로 그려진 인물
    + 큰 눈 같은 그림체 특징만으로 미성년자로 판단하지 않는다
    + 요청의 일부가 여기에 해당하면 그 부분만 거절하고 나머지 작업은 계속한다

## 한계

- 어려운 대상: 옆얼굴과 뒷모습, 실사 수준의 질감
    + 얼굴은 정면 그림을 돌리므로 35도까지만 돈다
    + 뒤에서 본 머리는 머리카락만 그린다. 35-110도 사이의 옆모습은 어색하다
    + 몸이 복잡한 자세는 마네킹으로 해결된다
- 치마와 드레스는 허리에서 떨어지는 주름과 바람까지 다룬다
    + 천이 몸에 걸려 접히는 물리 계산은 하지 않는다. 앉은 자세의 치마는 허벅지를 따르는 모양으로 대신한다
    + 주름은 둘레의 물결이다. 천이 겹쳐 접히는 깊은 주름은 만들지 않는다
    + 스카프 끝자락은 면 하나의 띠다. 술과 천의 늘어진 겹은 없다
    + 머리카락은 바람에 날리지 않는다
- 소품은 머리에 붙은 2차원 그림이다
    + 담배는 입에만 문다. 손에 든 담배는 없다
    + 눈은 내리기만 한다. 사람과 옷 위에 쌓이지 않는다
    + 밤 장면의 인물도 같은 주광으로 칠한다. 어두운 분위기는 배경 색, 테두리 빛, 분위기 층이 만든다
- 투샷은 2명까지 프리셋이 있다. 더 많은 인원은 `draw_cast()`에 사람을 더해 그린다
- 마네킹 렌더링은 1280px에서 장면당 10-40초가 걸린다
- 인체는 그럴듯함을 목표로 한다
    + 비례와 무게중심과 큰 굴곡은 맞추고 근육 하나하나의 정밀 묘사는 하지 않는다
- 마네킹에는 골반 세부 형태가 없다
    + 인체 습작 예제 3종은 고전 인체화 구도다
- 한 장의 완성에는 렌더링과 검수를 5-15회 반복해야 한다
    + 반복 횟수를 줄이면 품질이 먼저 떨어진다
