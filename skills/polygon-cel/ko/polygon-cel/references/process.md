# 그림 공정과 엔진 대응

## 공정 대응표
- 스킬의 각 단계는 일러스트레이터의 작업 공정 1개에 대응

| 공정 | 엔진 모듈 | 산출 |
|---|---|---|
| 기획 | spec.py | 검증된 장면 스펙 |
| 구성 (비례, 골격) | config.py, rig.py | 두상 단위 비례, 3D 랜드마크 투영 |
| 형태 (얼굴, 헤어, 신체, 의상) | head.py, face.py, hair.py, body.py, musculature.py, hand.py, outfit.py, wardrobe.py, accessories.py | 레이어 스택 (폴리곤, 스트로크) |
| 형태 (시점) | backview.py, profile.py | 뒷모습 해부 구조, 옆모습 템플릿 |
| 형태 (장면 주제) | still_life.py, props.py, interior.py, landscape.py, city.py, shapes.py | 레이어 스택과 배경 |
| 형태 (손 소품) | handheld.py | 손바닥과 손가락 사이에 끼우는 물건, 화면 빛과 연기 |
| 선화 | renderer.py (line_mask) | 광원 반대편이 두꺼운 가변 폭 컬러 선화 |
| 채색 | renderer.py (_shade) | 기본색, 형태 음영, 캐스트 섀도, 림라이트, 하이라이트 |
| 화풍 | styles.py, painterly.py, watercolor.py | 셀, 소프트, 유화, 수채화 처리 |
| 후보정 | post.py | 글레이즈, 블룸, 토닝, 두머 색보정, 비네트, 입자 |

## 구성 원리
- 모든 치수는 두상 높이 H 단위
    + 두상 좌표계 원점은 정수리, 신체 좌표계 원점은 목 기저(흉골 상단)
- 두상은 Loomis 구성법의 구(두개골)와 턱 곡선의 합집합 윤곽
    + 3D 랜드마크를 yaw, pitch 회전 후 정사영하므로 3/4 측면에서 먼 쪽 눈 축소, 먼 쪽 광대 돌출, 턱 이동이 자동 발생
- 눈, 코, 입은 얼굴 원통면 위의 점으로 배치하고 원통 곡률로 가로 단축
- 헤어 다발은 두피 위 셸(두개골 반지름 + 두께)에 3D 척추 곡선으로 생성
    + 폭 방향도 3D에서 계산하므로 고개 회전 시 다발 폭이 자연 단축
- 신체는 관절 골격과 해부학 폭 프로파일을 가진 리본(캡슐)의 합집합

## 손과 포즈 원리
- 손은 3D 골격: 손바닥 블록, 손가락 4개 × 3마디, 엄지 3마디
    + 제스처는 마디별 굽힘 각도와 손가락 벌림 각도의 조합
    + 손가락 방향과 손바닥 법선으로 손 전체를 회전 후 투영
    + 손가락은 캡슐이므로 어느 방향에서 봐도 굵기가 유지되고 길이만 단축
    + 손가락별 레이어를 깊이 순서로 그려 앞 손가락이 뒤 손가락을 가림
- 팔 배치 3종이 그리는 순서를 결정
    + front: 몸통 의상 위, 소매 아래 (소맷부리가 손목을 덮음)
    + behind: 몸통 뒤
    + raised: 헤어와 얼굴 위 (손 흔들기)
- 콘트라포스토는 허리 아래 세로 전단(shear)으로 골반을 기울임
    + 회전을 쓰면 치맛단과 다리가 진자처럼 옆으로 쏠리므로 전단 사용
- 제스처 팔 포즈는 팔꿈치와 손목 목표점을 신체 좌표로 지정
    + 팔짱은 가슴 아래에서 두 팔뚝을 겹쳐 그림
    + 턱 괴기와 머리 넘기기는 한 손을 얼굴 옆으로 올려 raised 배치로 그림
    + 머리 뒤 깍지는 팔을 뒷머리보다 먼저 그려 머리카락이 팔꿈치 위로 흐르게 함
- 전신 자세는 다리 자세(stance) 템플릿과 팔 포즈의 짝
    + 걷기는 앞뒤 보폭과 반대쪽 팔 스윙
    + 기대기는 상체 기울기, 손을 등 뒤로, 한쪽 발을 벽에 붙여 반대쪽 다리 뒤로 숨김
    + 앉기는 정면으로 단축된 허벅지 끝에 둥근 무릎 캡을 그려 깊이를 표현
    + 앉은 인물은 키가 짧아지므로 구도 배율을 다시 계산해 화면을 채움
    + 의자, 스툴, 침대는 무릎 높이에 맞춘 상자형 좌석으로 인물 뒤에 그림
- 눕기는 리그 전체를 90도 회전(orient)해 서 있는 인물 템플릿을 그대로 눕힘
    + 두상과 신체 좌표 변환 마지막 단계에서 회전하므로 얼굴, 헤어, 의상이 모두 함께 회전
    + 침대 시트 위에 인물 실루엣을 비스듬히 밀어낸 그림자를 깔아 접지

## 체형 원리
- 체형은 몸통 실루엣의 세 구간으로 결정
    + 갈비뼈 아래 좁아지는 속도 (느리면 허리가 넓어 배가 나와 보임)
    + 허리 최소 폭과 높이
    + 골반 최대 폭 (허벅지 관절 간격도 함께 넓어짐)
- 가슴은 구면 법선을 가진 피부 층으로 입체 음영, 윤곽선 없이 가장자리를 흐려 가슴판에 섞음
- 옷 위에는 가슴 아래 그림자, 위쪽 경사의 빛, 옆으로 당겨지는 주름으로 볼륨을 표현
- 비키니 컵, 튜브 상의, 가슴 아래 주름 위치가 체형의 가슴 크기를 따라감
- 두상이 애니메 비례이므로 몸통도 허리와 골반의 대비를 줘야 머리와 몸이 한 캐릭터로 읽힘
- 가슴은 거의 원형인 아래 반구와 가슴판으로 완만하게 이어지는 위 경사로 구성
    + 법선은 중심 아래에서 구, 중심 위에서 점점 평평해지는 물방울형 (구를 그대로 쓰면 위 경사에 어두운 고리가 생김)
    + 구 반지름을 외곽선의 1.08배로 둬 아래 가장자리가 돌아나가며 초승달 그림자 생성
    + 아래 둥근 외곽선과 그 아래 흉곽에 드리운 그림자로 둥근 덩어리를 확정
- 옷 위에서도 같은 법선으로 천을 다시 음영해 초승달 그림자가 천에 나타남
    + 아래 외곽선을 천 위에 잉크로 그림
    + 가슴 사이 골 그림자로 두 덩어리를 분리
    + 음영 강도는 가슴 세로 반지름에 비례
- 삼각 비키니 컵의 아랫단은 가슴 외곽 호를 그대로 따라감 (컵이 공 모양으로 읽힘)
- 가슴 크기 4단계는 가슴 중심, 반지름을 함께 바꿈 (큰 가슴은 조금 아래, 바깥에 위치)
- 가슴은 팔보다 앞에 있으므로 몸 실루엣에 합치고 팔 마스크에서 뺌
    + large 이상은 바깥 곡선이 흉곽 선을 넘어 팔 앞으로 나옴 (옆 볼륨)
    + 상의 몸판도 가슴을 합친 형태로 만들고 소매는 가슴 영역을 비움
    + 외곽 잉크는 가슴 아래에서 바깥쪽을 따라 겨드랑이 방향으로 올라감
- 가슴 중심은 흉곽 표면보다 앞(깊이 0.25 + 반지름의 0.6)에 둬 몸을 돌리면 먼 쪽 가슴이 윤곽 밖으로 나옴
- 의상의 목둘레, 진동, 앞트임은 목 기저 위는 목 실루엣 깊이, 아래는 가슴 표면 깊이로 투영해 몸을 돌려도 어긋나지 않음
- 골반에는 돔 법선의 부드러운 명암만 넣음 (셀 경계를 넣으면 골반에 얼룩이 생김)

## 남성 골격 원리
- 근육 덩어리마다 회전 타원체 법선을 가진 피부 층을 둠 (셀 음영의 선명한 그림자와 부드러운 명암이 근육을 표현)
    + 대흉근은 쇄골 아래 판 형태, 돔 중심을 위로 올려 아래 경계에 그림자 띠 생성
    + 몸통: 승모근, 복직근 8분할, 전거근 3갈래, 외복사근
    + 팔: 삼각근, 이두근, 삼두근, 팔뚝 (팔 뼈 방향을 따라 배치해 어떤 포즈에도 따라감)
    + 다리: 대퇴사두근 바깥, 안쪽 눈물방울, 종아리 (납작한 돔과 낮은 경계값으로 얼룩 방지)
- 팔은 몸에서 조금 벌어지게 걸어 겨드랑이 아래 광배근 V자가 보이게 함
- 잉크 선은 화가가 실제로 긋는 경계에만 사용
    + 백선, 복직근 마디와 바깥 경계, 외복사근 경계, 삼각근 앞 홈, 이두근 아래 경계, 흉쇄유돌근, 목젖
    + 허벅지 안쪽 눈물방울 근육, 바깥 허벅지 곡선, 종아리 안쪽 경계
- 근육 표현 강도(body.muscle)가 근육 피부 층, 복근 그림자, 근육 선, 대흉근 판, 등 근육, 옷 위 대흉근 음영의 불투명도를 함께 조절
    + 체형별 기본값 slim 0.10, balanced 0.30, athletic 0.50 (v9까지는 모든 남성 1.0)
    + 실루엣(어깨 폭, 팔다리 굵기)은 체형이 결정하고 근육 강도는 표면 정의만 바꿈
- 옷 위 대흉근 음영은 0.45배에 근육 강도를 곱해 약화, 소매 여유는 절반으로 줄여 굵은 팔에서 소매가 부풀지 않게 함
- 의상의 목둘레, 칼라, 후드 안감, 진동은 목 굵기 비율과 어깨 이동량으로 자동 변형
- 헐렁한 반바지는 다리 사이에 쐐기 마스크를 빼서 두 다리로 읽히게 함 (빼지 않으면 스커트처럼 보임)
- 수영복과 속옷 하의는 앞판을 매끈한 면으로 처리하고 골반 앞쪽 형태를 강조하지 않음

## 얼굴 세부 원리
- 얼굴 길이는 턱 윤곽을 턱 시작점 기준으로 세로 확대, 코와 입은 눈선 기준으로 비례 이동
- 코 3종: small은 콧날 그림자 1획, button은 둥근 코끝 반사광, defined는 콧볼과 콧대 선
- 입술 3종: thin은 입선만, natural은 아랫입술 색면, full은 큐피드 활 윗입술과 광택
- 속눈썹은 윗눈꺼풀 선 굵기와 눈꼬리 갈래 수로 표현, none은 갈래 없이 눈꺼풀 선만 그림
- 짧은 헤어는 정수리 다발을 두피 셸 위 뿌리에서 가르마 쪽으로 쓸어 실루엣을 깨뜨림 (헬멧처럼 보이지 않게 함)

## 시점 원리
- (뒷모습) 같은 실루엣에 표면 정보만 교체
    + 앞판 전용 레이어(단추, 넥타이, 주머니, 가슴 볼륨 음영)는 이름 필터로 제외
    + 척추 홈, 견갑골, 허리 보조개, 남성 승모근과 광배근, 둔근을 돔 법선 피부 레이어로 그림
    + 하의 천은 둔근 위에서 구면 법선 음영을 받아 둥근 형태가 드러남
    + 팔뚝의 앞뒤 배치는 정면과 반대
    + behind 포즈의 손은 허리 뒤에 모임
    + 뒷머리는 의상 위, 등 위에 그림
    + 뒷머리의 밝은 반사광이 어두운 덩어리를 방지
    + 얼굴은 head.yaw 방향으로 돌아보는 정면 두상을 그대로 사용
- (옆모습) 정면 리그와 다른 전용 실루엣 템플릿
    + 얼굴 윤곽 1개가 이마, 코, 입술, 턱을 포함
    + 눈은 옆 눈 형태로 그림
    + 헤어는 두개골 호, 뾰족한 앞머리 끝, 얼굴 옆 헤어선이 1개 윤곽으로 이어진 덩어리와 가닥선
    + 몸통 깊이는 정면 폭의 약 0.55-0.7배로 잡아 막대처럼 얇아 보이지 않게 함
    + 가슴은 몸 윤곽에 합친 물방울형 볼륨
    + 상의는 가슴 끝에서 아래로 떨어지는 볼록 껍질
    + 목둘레는 목 깊이 구간에서 뒷목 높이와 앞목 높이를 잇는 사선으로 처리
    + 의상은 목둘레와 밑단 사이 몸 띠, 소매, 끈, 플레어로 일반화

## 의상 형태 원리
- 몸에 붙는 드레스와 펜슬 스커트는 골반과 허벅지의 볼록 껍질(convex hull)로 감싸 다리 사이 굴곡을 지움
- 슬랙스, 펜슬 스커트 위 셔츠는 허리선에서 잘라 넣어 입은 모습(턱인)으로 그림
- 엉덩이 아래로 내려오는 긴 상의는 골반에서 곧게 떨어지는 드레이프 폴리곤으로 그림
- 앉은 자세의 치마와 긴 상의 밑단은 무릎 위에서 잘라 허벅지 위에 얹힌 형태로 그림
- 새틴(슬립 드레스)은 좁고 강한 하이라이트, 니트와 면은 넓고 약한 하이라이트
- 팔꿈치가 어깨보다 높은 팔(머리 뒤 깍지, 머리 넘기기, 어깨동무)은 소매가 올라간 모습으로 그림
    + 위팔 소매를 상의 몸판 아래에 두어 팔을 따라 몸판 밖으로 나온 부분만 보이게 함
    + 상의 몸판을 그 팔로 자르지 않아 겨드랑이 아래가 몸판으로 덮임
    + 손목까지 이어진 긴 소매는 팔뚝 피부 위에 유지
- 래시가드는 여성은 비키니 위 크롭 길이, 남성은 골반까지 내려옴
- 가슴이 팔 앞으로 나오는 영역은 가슴의 둥근 아래 덩어리만 사용 (위쪽 완만한 경사는 가슴판으로 흡수)

## 장면 합성 원리
- 배경 장면을 먼저 렌더하고 인물을 그 위에 렌더
- 장면의 선화는 인물이 덮는 영역에서 지움 (인물 위로 배경 선이 비치지 않음)
- 인물은 장면의 광원 방향을 그대로 받고, 노을과 밤에는 장면 색으로 곱하기 색조와 역광을 받음
- 전신 구도는 발밑에 광원 반대쪽으로 밀린 그림자를 깔아 지면에 세움
- (원경 wide) 장면은 그대로 두고 인물만 작게 세움
    + 지면선을 캔버스 높이 약 83% 위치에 고정해 앉은 인물과 배율을 바꾼 인물도 같은 지면을 밟음
    + 단독 인물도 place.x로 장면 한쪽에 세워 장면이 주인공인 설정샷을 만듦

## 손 소품 원리
- (담배) 손바닥 레이어 뒤, 손가락 레이어 앞에 끼워 그림
    + 담배가 오므린 손가락 밑을 지나 손 밖으로 튀어나와 손가락 사이에 끼운 형태가 됨
- (캔, 휴대폰) 손등이 관객을 향하므로 손 전체를 물건 앞에 그림
    + 물건 중심을 손가락 뿌리 관절 아래에 두고 손가락 첫 마디가 물건 앞면을 가로지르게 함
    + 둘째, 셋째 마디는 물건의 먼 쪽 가장자리에서 관객 반대쪽으로 굽어 둥근 관절 끝으로 보임
    + 곧은 손가락이 가장자리 밖으로 나가면 물건을 관통한 모양, 가장자리에서 손가락을 직선으로 자르면 잘린 손가락 모양
    + 캔은 실제 비례(높이 0.50H, 지름 0.28H)로 두고 손을 후디 주머니보다 위에 둠
    + 휴대폰은 손바닥이 뒷면을 아래에서 받치고 손 위로 윗부분이 드러남, 엄지는 화면 쪽(관객 반대쪽)에 있어 휴대폰 뒤에 그림
    + 쥔 손과 물건은 후디 끈과 칼라보다 앞에 보이도록 해당 디테일을 손과 물건 영역에서 지움 (소매 끝은 손목 위 유지)
- 쥔 팔은 물건별 팔꿈치, 손목, 손바닥 방향을 고정하고 남성의 넓은 어깨만큼 바깥으로 이동
- 빛과 연기처럼 물건이 내는 효과는 인물 전체 위에 마지막으로 그림
    + 휴대폰 화면 빛은 손 주변의 작은 스크린 블렌드 타원 (크게 두면 가슴 위 흰 얼룩으로 보임)
    + 담배 연기는 불씨에서 시작해 넓어지고 흐려지는 물결 띠, 몸 바깥쪽으로 흘러 소매 위를 타지 않음

## 무드 원리
- 무드는 장면 스펙, 인물 배경, 인물 기본값 3묶음을 사용자 스펙 아래에 깔아 사용자 값이 항상 이김
- (doomer 색보정) 채도를 낮추고 그림자를 남색으로 곱하고 밝은 영역을 연한 회청색으로 스크린한 뒤 암부를 남회색으로 바램
    + 창문 불빛과 가로등만 난색으로 남아 빈 밤거리의 고독이 읽힘
- (전선) 거리 양쪽 전봇대와 가로대, 처지는 현수선 전선, 길을 가로지르는 전선으로 전선이 늘어진 주택가 밤거리 구성
- (밤 풍경) 달과 별, 달빛 광원, 어두운 하늘과 산, 푸른 회색 구름과 눈
- (비니) 두상 구면을 따라 접은 단과 골지를 그리고 정수리 다발을 생략해 모자 위로 머리카락이 뚫고 나오지 않게 함

## 투샷과 단체 원리
- (배치) 이웃 간격과 키 차이를 두상 높이 H 단위로 계산
    + 키가 큰 인물의 두정부를 구도 기준선에 맞추고 모든 인물의 발을 같은 지면에 맞춤
    + 고개와 옆모습 방향은 기본값으로 무리 중심을 향해 관계가 먼저 읽힘
    + 3명부터 캔버스 가로 폭을 늘리고, 4096px을 넘는 인원은 인물 크기를 줄여 맞춤
- (여러 줄) 뒷줄일수록 작고(줄마다 0.93배) 높은 지면(줄마다 두상 0.55배)에 세워 멀리 선 원근을 만듦
    + 앞줄과 인원이 같은 뒷줄은 간격 절반만큼 엇갈려 얼굴이 앞줄 머리 사이로 보임
    + 엇갈린 뒤 무리 전체를 다시 가운데 정렬해 가장자리 인물이 잘리지 않음
    + 뒷줄부터 앞줄 순서로 그림
- (그림 순서) 인물마다 렌더 패스를 분리하여 뒤 인물부터 앞 인물 순서로 그림
    + 레이어 이름이 패스 내부의 마스크 키이므로 패스 분리로 이름 충돌을 피함
    + 의자, 침대, 발밑 그림자는 두 인물 패스보다 먼저 그려 다른 인물을 가리지 않음
    + 앞 인물의 커버리지가 뒤 인물의 선화를 지움
- (정면 앉기) 무릎 바로 아래 정강이에 무릎에서 시작해 아래로 옅어지는 그림자를 넣음
    + 정면에서 단축된 허벅지가 관객 쪽으로 나왔다는 단서가 되어 서 있는 자세와 구별됨
- (손잡기) 두 팔을 2관절 역운동학으로 풀어 사이 지점에서 손목을 만나게 함
    + 팔을 거의 편 길이로 닿는 높이 중 낮은 쪽을 손 높이로 선택
    + 앞 손은 주먹 쥔 형태로 뒤 손의 손가락을 감싸 잡은 손으로 읽힘
- (어깨동무) 팔꿈치를 상대 목 뒤 먼 쪽, 손목을 먼 쪽 어깨 끝에 고정
    + 팔을 두르는 인물을 뒤에 그려 위팔이 상대의 머리와 목 뒤로 지나감
    + 상대 패스 이후 팔뚝과 손 영역만 다시 그리는 공개 패스로 어깨 위 팔을 표현
    + 공개 영역에서 상대의 목 기둥과 얼굴을 빼서 팔뚝이 목 뒤에서 나오는 경계를 만듦

## 노출 피부 원리
- 다리와 몸통을 하나의 실루엣으로 합쳐 외곽선이 허벅지를 가로지르지 않게 함
- 노출 의상이면 피부 베벨 반경을 키워 몸통과 팔다리가 원통처럼 음영
- 팔뚝 외곽선은 위팔과 겹치는 구간에서 생략 (팔꿈치 이음선 제거)
- 피부 형태 단서 4종을 의상 아래 층에 그림: 배꼽, 복부 중앙선, 서혜부 선, 가슴 아래 주름과 그림자
    + 의상이 덮는 부분은 자동으로 가려지므로 의상 종류와 무관하게 항상 적용
- 비키니 컵은 가슴 중심의 구면 법선으로 음영, 컵 아래 피부에 작은 그림자
- 끈과 튜브 상의는 몸통 마스크로 자르고 위팔 마스크로 빼서 팔 뒤로 지나가게 함

## 장면 원리
- (정물화) 꽃병, 병, 컵은 회전체, 과일은 회전 타원체
    + 실루엣의 기울기에서 정확한 법선을 계산하므로 명암 경계(terminator), 핵심 그림자, 하이라이트가 형태를 따라감
    + 사물마다 바닥 투영 그림자와 접지 그림자, 벽에는 오프셋 그림자
    + 테이블 반사광을 아래쪽 림라이트로 넣어 사물이 바닥에 앉은 느낌을 만듦
- (풍경화) 공기 원근: 먼 산맥일수록 지평선 하늘색에 섞이고 선과 대비가 약해짐
    + 산맥 능선은 1D 프랙털(중점 변위), 음영은 마스크 베벨 법선과 노이즈 기울기의 합
    + 눈은 절대 고도 위에만 쌓임, 호수는 산맥 폴리곤을 수면 기준으로 뒤집은 반사
    + 적운은 원형 덩어리 묶음과 평평한 밑면, 고체처럼 음영
- (도시화) 미터 단위 3D 좌표를 핀홀 카메라(눈높이 1.6m)로 투영
    + 모든 창문, 연석, 가로등이 같은 소실점으로 수렴
    + 건물 면은 정확한 평면 법선이므로 해가 드는 쪽과 그늘 쪽이 조명에서 결정
    + 먼 건물은 안개색으로 섞임, 밤에는 창문과 가로등이 빛번짐과 함께 발광
- (현대 사물) 노트북, 모니터, 키보드 같은 사물은 상자, 막대, 돔, 회전체 부품의 조립
    + 모든 부품을 같은 경사 정사영(높이 축에 깊이의 0.30배를 더함)으로 투영해 윗면 기울기가 일관됨
    + 상자 면은 화면 쪽 법선 성분이 양수인 면만 그려 숨은 면 제거
    + 화면은 테마별 그라데이션, 창, 텍스트 줄로 구성한 추상 인터페이스
    + 정물 그림자는 사물 전체 실루엣에서 계산
- (실내) 같은 경사 정사영 무대 위에 바닥, 벽, 창, 가구를 깊이 순서로 배치
    + 인물 배경의 무대 축척은 인물 두상 크기에서 계산
    + 무대를 인물보다 0.62배 작게 줄여 가짜 렌즈 깊이를 만듦
    + 방별 팔레트(벽, 바닥, 강조색)와 시간대 색조를 인물에도 적용

## 채색 원리
- 형태 명암(form): 셀 단계 위에 부드러운 명암을 더함
    + 정면을 향한 면은 기본색 유지, 빛을 등지는 면은 점점 어두워지고 빛을 향하는 면은 살짝 밝아짐
    + 가슴, 골반, 근육 덩어리에 적용, 피부 광택(스페큘러)과 함께 둥근 면으로 읽히게 함
- 형태 음영: 마스크 거리장으로 원형 베벨 높이를 만들고 기울기로 의사 법선 계산 (Johnston 2002, Lumo)
    + 가장자리만 기울어지고 내부는 평면이므로 애니메 특유의 테두리 음영이 생성
- 캐스트 섀도: 가리는 레이어 마스크를 광원 반대 방향으로 이동시킨 형태
    + 앞머리가 이마에, 턱이 목에, 헤어가 옷에 드리우는 그림자
    + 레이어 스택에서 위에 있는 레이어만 그림자를 드리움
- 그림자색은 명도 하강, 채도 상승, 색상 이동을 동시에 적용
    + 피부는 붉은 방향, 헤어와 의상은 푸른 보라 방향
    + 흰색, 회색처럼 채도가 거의 없는 색은 차가운 회청색 그림자
- 선화색은 인접 채색의 어두운 동계열 색 (컬러 선화)
- 선 굵기는 광원을 등진 쪽이 두껍고, 헤어 다발 선은 뿌리 쪽에서 사라짐

## 화풍 원리
- (anime_cel) 경계가 선명한 2단 음영, 진한 컬러 선화, 볼 사선 해칭
- (soft_illust) 흐린 경계 음영, 가늘고 밝은 선화, 난색 글레이즈, 블룸, 채도 보강
- (painterly) Hertzmann(1998) 다중 크기 곡선 붓터치
    + 큰 붓에서 작은 붓 순서로, 캔버스와 참조 이미지의 오차가 큰 격자에만 붓터치
    + 붓터치는 명도 기울기의 수직 방향(등명선)을 따라 휘어짐
    + 얼굴 영역은 오차 가중치를 높여 작은 붓으로 다시 칠함
    + 얼굴 높이가 캔버스 높이의 6% 미만인 원경 인물은 몸 전체를 마무리 붓으로 다시 칠함 (큰 붓이 손과 얼굴을 거리에 뭉갬)
    + 눈과 입은 렌더 원본을 일부 복원 (입이 작은 붓에 뭉개져 표정이 사라지는 현상 방지), 선화는 밑그림 수준으로 재기입
    + 붓모 결은 방향장 기반 선적분 합성(LIC), 임파스토는 붓터치 높이 버퍼의 부조 조명
- (watercolor) Bousseau(2006) 안료 밀도 모델 C' = C - (C - C²)(d - 1)
    + 밀도 d는 가장자리 안료 고임, 저주파 얼룩, 고주파 입자, 종이결의 합
    + 노이즈 변위로 경계를 흔들고, 무작위 영역에 번짐 적용
    + plain, gradient 배경은 인물에서 멀어질수록 종이 여백으로 페이드, 장면 배경은 페이드 없이 유지
    + 어두운 부분은 안료를 더 짙게 올림 (덧칠 효과, 밤하늘이 중간 회색으로 뜨는 현상 방지)
    + 그림 평균 명도가 0.20 이하인 밤 그림은 종이 페이드 없이 화면 전체를 칠함 (0.30까지 점진 전환)
    + 눈, 눈썹, 코, 입, 입술은 번짐 영역에서 제외 (번짐이 홍채를 검은 얼룩으로 뭉갬)
    + 가장자리 안료 고임은 중앙값 필터로 별, 반짝임 같은 점을 지운 이미지에서 계산 (점 둘레의 검은 고리 방지)
    + 선화는 연필 톤
